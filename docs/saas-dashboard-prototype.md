# RankWoven SaaS 後台核心頁面原型

更新日期：2026-07-25

## 1. 原型目標

本原型用於驗證 RankWoven SaaS 後台的核心資訊架構和工作流。它先使用前端靜態資料展示頁面形態，不接正式 API，不處理真實 CMS 寫入。

## 2. 核心導航

| 路由 | 頁面 | 核心用途 |
|---|---|---|
| `/` | 站點概覽 | 查看站點數、文章量、待審核建議、任務和 SEO 健康度 |
| `/sites` | 站點管理 | 管理 WordPress、Joomla、OpenCart 等站點連接狀態 |
| `/articles` | 文章審計 | 查看文章 SEO 分數、問題類型、優化機會和負責人 |
| `/review` | 內容審核 | 對比現有內容和 AI 建議，保留人工批准流程 |
| `/links` | 內部連結 | 審核來源文章、目標文章、錨文本、推薦理由和信心度 |
| `/tasks` | 任務隊列 | 追蹤同步、審計、生成、圖片和發佈任務 |
| `/cms-adapters` | CMS 適配器 | 查看各 CMS 擴展階段和能力覆蓋 |
| `/settings` | 設定 | 管理 API、AI Provider、媒體存儲和團隊設定 |

## 3. 設計取向

- 採用左側導航、頂部工具列、主工作區的後台布局。
- 優先呈現表格、狀態、進度與審核操作，避免行銷式大 Hero。
- 所有頁面保留空間給後續 API 接入、Loading、空狀態和錯誤狀態。
- 所有新增顯示文案走 `vue-i18n`，目前以 `zh-Hant` 和 `en` 作為第一批文案。
- 原型資料均在頁面內存中定義，後續可逐步替換為 API Response 類型。

## 4. 後續吸收方向

- 將頁面內的靜態資料替換為 `src/api/` 請求。
- 建立共用 `DataTable`、`StatusPill`、`ProgressBar` 和 `PageHeading` 元件。
- 為文章審核頁接入差異對比、快照和回滾操作。
- 為任務隊列接入 Worker 進度事件和錯誤重試。
