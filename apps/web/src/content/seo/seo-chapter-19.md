## 什麼是 Header 標籤？

**Header 標籤（H1-H6）** 是 HTML 中用來定義標題層級的標記，從最重要的 H1 到最次要的 H6，共六個層級。它們為頁面提供清晰的內容結構，就像一本書的章節標題。

```html
<h1>頁面主標題（最重要，每頁只有一個）</h1>
  <h2>主要章節</h2>
    <h3>子章節</h3>
      <h4>更細的子章節</h4>
        <h5>補充說明</h5>
          <h6>最細的補充（很少使用）</h6>
```

### Header 標籤的雙重價值

| 對象 | 價值 |
|------|------|
| **使用者** | 快速掃描頁面結構，找到感興趣的段落 |
| **搜尋引擎** | 理解頁面內容的層級關係和主題重點 |

> Google 的 John Mueller 曾說：「Header 標籤幫助我們理解頁面的結構和主題。它們是理解內容的強信號，但不是排名魔術。」

## 香港市場嘅 Header 標籤特別考量

| 考量 | 說明 | 例子 |
|------|------|------|
| **用香港人嘅問法** | Featured Snippet 同 AI 摘要最鍾意「問題型標題」。香港人問「點樣」「幾時」「邊度」「好唔好」，唔係「如何」「何時」「哪裡」「好嗎」 | `## 狗糧應該幾時換一次？` 好過 `## 狗糧應該多久更換一次？` |
| **中英夾雜要一致** | 雙語站嘅 H2 要同英文版對應，方便 hreflang 配對 | `## 申請流程 Application Process` |
| **地區型 H2** | 做 18 區頁時，用 H2 分明各區，但每區內容要獨特 | `## 旺角門市地址與營業時間`、`## 沙田門市地址與營業時間` |
| **價錢相關 H2** | 香港人最關心價錢，獨立 H2 講收費，容易被 Featured Snippet 抓取 | `## 2026 年香港搬屋收費參考（HK$）` |

## H1 標籤：頁面的靈魂標題

### H1 的基本規則

| 規則 | 說明 |
|------|------|
| **每頁只有一個 H1** | HTML5 允許每個 `<section>` 有一個 H1，但最佳實踐仍建議每頁一個 H1 |
| **包含主要關鍵字** | H1 應該包含該頁面最重要的目標關鍵字（香港用語版本） |
| **與 Title Tag 協同** | H1 與 Title Tag 相關但不必完全一致（見第 17 章） |
| **放在內容最前面** | H1 應該是頁面正文的第一個標題 |

### H1 vs Title Tag：功能定位

| | Title Tag | H1 |
|------|------------|-----|
| **顯示位置** | SERP 搜尋結果 | 頁面頂部 |
| **主要讀者** | 搜尋結果瀏覽者 | 頁面訪客 |
| **關鍵字策略** | 更精煉、更有吸引力 | 更描述性、更完整 |
| **長度建議** | 50-60 字元 | 20-70 字元（中文約 10-35 字） |

### H1 優化實戰範例（香港例子）

| 頁面類型 | ⭕ 好的 H1 | ❌ 差的 H1 |
|----------|-----------|-----------|
| 教學文章 | `2026 年 SEO 完整教學（香港篇）：由入門到第一頁排名` | `SEO` |
| 產品頁 | `皇家 S 系列小型犬狗糧 2kg（HK$298）` | `產品頁面` |
| 地區服務頁 | `觀塘搬屋公司：免費上門報價、包搬包拆裝` | `搬屋服務` |
| 關於我們 | `關於 PetHK 毛孩百貨 — 你嘅香港寵物健康夥伴` | `關於` |
| 補習社頁 | `沙田補習社：中小學專科班 HK$180/堂起` | `補習` |

### 常見 H1 錯誤

1. **沒有 H1**：頁面缺少主標題，Google 無法快速理解核心主題
2. **多個 H1**：在一個頁面使用多個 H1 標籤，分散語意焦點
3. **H1 只有圖片**：使用 `<img>` 作為 H1 的內容，Google 無法讀取
4. **H1 藏在 Logo 中**：這是許多香港中小企網站常見的錯誤
5. **H1 與內容無關**：H1 誇大或誤導使用者（例如寫「全港最平」但內容冇比較數據）

## H2-H6：建立清晰的內容層級

### 正確的標題層級結構

```
H1: 頁面主標題
├── H2: 第一大主題
│   ├── H3: 子主題 A
│   │   ├── H4: 細節 a
│   │   └── H4: 細節 b
│   └── H3: 子主題 B
├── H2: 第二大主題
│   ├── H3: 子主題 C
│   └── H3: 子主題 D
└── H2: 結論
```

### 標題層級四大紀律

#### 紀律 1：不要跳級

| ⭕ 正確 | ❌ 錯誤 |
|--------|--------|
| H1 → H2 → H3 → H4 | H1 → H3 → H2（層級混亂） |

跳過層級會讓 Google 難以理解內容的主從關係。

#### 紀律 2：自然融入關鍵字

在 H2 和 H3 中自然地使用相關關鍵字（**用香港用語**），但不要強行堆砌：

| ⭕ 好 | ❌ 差 |
|------|------|
| `## 狗糧四大選購原則` | `## 狗糧推介狗糧品牌狗糧評價` |
| `## 幼犬狗糧同成犬狗糧有咩分別` | `## 狗糧優惠狗糧促銷狗糧` |
| `## 香港邊度買狗糧最平` | `## 狗糧香港狗糧平狗糧邊度買` |

#### 紀律 3：保持簡潔有力

| 標籤 | 建議長度 |
|------|----------|
| H2 | 5-15 個中文字 |
| H3 | 5-12 個中文字 |
| H4-H6 | 5-10 個中文字 |

標題是「路標」，不是「說明書」。要讓使用者在 2 秒內理解這個段落講什麼。

> **中英夾雜要小心**：`## 申請流程及所需文件 Application Process and Documents` 太長，喺手機上會換三行。建議只用喺 H2，而且要縮短。

#### 紀律 4：標題要有資訊量

| ⭕ 有資訊量的標題 | ❌ 空洞的標題 |
|------------------|--------------|
| `## 點解無穀物狗糧更適合腸胃敏感嘅狗？` | `## 介紹` |
| `## 三個步驟快速判斷狗糧質素` | `## 第一步` |
| `## 2026 年香港搬屋收費參考（HK$1,280 起）` | `## 收費` |

## 使用 Header 標籤優化 Featured Snippet

Header 標籤是獲取 Featured Snippet（精選摘要）的重要信號。Google 經常從結構良好的內容中擷取 H2/H3 作為 Featured Snippet 的來源。

### Featured Snippet 優化技巧

1. **用 H2/H3 提問**：將常見問題作為 H2 或 H3（用香港人嘅問法）
2. **緊接著給出簡潔答案**：在標題後 1-2 句內給出直接答案（40-60 字）
3. **使用列表或步驟**：在 H2 後使用有序/無序列表更容易被擷取
4. **配合 FAQ Schema**：在結構化數據中重複 H2 的問答結構（見第 24 章）

**範例結構（香港寵物網店）**：

```html
<h2>狗糧應該幾時換一次？</h2>
<p>一般建議每 3-6 個月逐步調整一次狗糧品牌或配方。轉得太密（少於 1 個月）可能令狗狗腸胃唔舒服。</p>
<ul>
  <li>第 1-3 日：混合 25% 新糧 + 75% 舊糧</li>
  <li>第 4-6 日：混合 50% 新糧 + 50% 舊糧</li>
  <li>第 7-9 日：混合 75% 新糧 + 25% 舊糧</li>
  <li>第 10 日起：100% 新糧</li>
</ul>
```

> **AI 搜尋補充**：香港用家愈來愈多用 ChatGPT、Gemini、Perplexity、Copilot 同 Google AI Overviews。呢啲 AI 都偏好由「問題型 H2 + 緊接嘅簡短答案」抽取內容——呢個結構同時幫你贏 Featured Snippet 同 AI 引用。

## Header 標籤與無障礙設計（Accessibility）

良好的 Header 結構不僅對 SEO 有利，對使用螢幕閱讀器的視覺障礙使用者同樣重要：

- 螢幕閱讀器可以通過 Header 標籤快速跳轉頁面內容
- 清晰的層級結構讓所有使用者都能快速理解頁面組織
- 符合 WCAG 2.1 無障礙標準的 Header 結構也是 Google 評估頁面品質的信號之一

> **香港補充**：香港政府網站同受資助機構網站需要符合 WCAG 2.1 AA 級別；如果你做緊政府或公營機構項目，Header 層級係合規檢查項目之一。

## Header 標籤優化檢查清單

- [ ] 每個頁面只有一個 H1
- [ ] H1 包含頁面的主要目標關鍵字（香港用語）
- [ ] H1 與 Title Tag 相關但不完全相同
- [ ] H2-H6 形成清晰的層級結構（不跳級）
- [ ] 每個 H2/H3 都自然地融入相關關鍵字
- [ ] 問題型標題用咗香港人嘅問法（點樣 / 幾時 / 邊度 / 好唔好）
- [ ] 標題簡潔有力，有資訊量
- [ ] H2/H3 的問題型標題後緊接著簡潔的答案（Featured Snippet 優化）
- [ ] 標題層級結構支援無障礙設計（WCAG）
- [ ] 在行動裝置上，標題不會過長導致換行混亂（香港手機流量佔比高）
- [ ] 雙語站的 H2 有對應英文版，方便 hreflang 配對

## 重點回顧

1. **H1 = 頁面的靈魂標題**，每頁只有一個，包含主要關鍵字
2. **H2-H6 建立內容層級**，幫助使用者和搜尋引擎理解頁面結構
3. **不要跳級**（H1 → H3），保持層級連貫
4. **標題要有資訊量和關鍵字**，但不要堆砌；用香港人嘅字（推介、邊間好、幾時、點樣）
5. **用 H2/H3 提問 + 簡答**的結構來爭取 Featured Snippet 同 AI 引用
6. Header 標籤優化 = SEO + 使用者體驗 + 無障礙設計的完美交集
