> SEO 唔係一筆「費用」，而係一項「投資」。但任何投資都要有預算規劃，否則錢燒完都未見到結果。
>
> 香港市場細、人工貴，SEO 報價嘅落差可以好大 — 由 HK$2,000 一個月嘅「學生仔套餐」到 HK$100,000+ 嘅 4A 級代理商都有。呢章幫你睇清楚錢應該點使。

## SEO 預算的思維轉變

### 錯誤觀念 vs 正確觀念

| ❌ 錯誤觀念 | ✅ 正確觀念 |
|------------|------------|
| SEO 是免費的，為什麼要花錢？ | SEO 需要時間和專業，這些都有成本 |
| 花越多錢排名越快 | 預算要按階段分配，不是一次砸完 |
| 外包最便宜方案就好 | 便宜通常等於無效或黑帽，代價更高 |
| 一個月沒效果就停掉 | SEO 是長期投資，3-6 個月才開始見效 |
| 香港市場細，使少少就得 | 香港競爭密度高，內容要中英雙語，成本唔見得平 |

> 📌 **貨幣說明：** 本章所有金額一律以**港元（HK$）**計。坊間部分海外 SEO 公司或工具會用美元（US$）報價，記得自行換算（約 US$1 ≈ HK$7.8）並計埋信用卡手續費。

## SEO 的三種執行模式與成本結構

### 模式一：完全外包（Agency / 顧問）

**適合對象：** 沒有 SEO 團隊、快速啟動、需要專業指導的香港中小企至中大型企業。

| 項目 | 月費範圍（HK$） | 包含內容 |
|------|----------------|----------|
| 基礎方案 | HK$4,000 - 8,000 | 關鍵字研究、On-Page 優化建議、GSC 監控、月報 |
| 標準方案 | HK$8,000 - 20,000 | + 內容策略、技術 SEO 審計、連結建設計劃、定期會議 |
| 進階方案 | HK$20,000 - 60,000+ | + 專屬團隊、全方位策略、內容創作（中英雙語）、整合行銷 |

**香港市場實況：**
- HK$4,000 以下嘅「SEO 套餐」要特別小心 — 扣除工具成本（Ahrefs 等每月約 HK$800-1,500）後，實際人工時間可能得幾個鐘，通常只係自動化報表或者黑帽手法
- 中英雙語內容係香港網站嘅標配，如果要同時優化繁中 + 英文，報價通常要加 30-50%
- 一線代理商（4A / 大型數位行銷公司）月費普遍 HK$30,000 起跳

**優點：**
- 立即有專業團隊
- 不用管理人員
- 能快速啟動

**缺點：**
- 成本最高
- 溝通成本（代理商需要時間了解你的行業，香港本地行業知識尤其重要）
- 品質參差不齊

**選擇外包的紅旗訊號：**
```
☐ 保證「第一頁排名」或「X 個月內前 3 名」
☐ 不願透露具體做法
☐ 報價異常低（可能用黑帽或沒做事）
☐ 不提供香港本地案例或無法證明過去成效
☐ 要求 FTP / 管理員權限但不解釋為什麼
☐ 合約綁死但沒有退出機制
☐ GSC / GA4 帳號要開喺佢哋名下（🚩 大紅旗！
   應該用你自己公司名義開，只畀佢哋使用者權限）
☐ 無法提供每月做咗啲乜嘅具體清單
```

### 模式二：內部團隊（In-House）

**適合對象：** SEO 是核心營收渠道、有長期策略規劃的企業。

| 角色 | 月薪範圍（HK$） | 說明 |
|------|----------------|------|
| SEO 專員 | HK$18,000 - 28,000 | 日常執行：關鍵字、On-Page、報表 |
| SEO 經理 | HK$28,000 - 45,000 | 策略規劃、團隊管理、跨部門協調 |
| 內容寫手 | HK$15,000 - 25,000（或按篇 HK$500-1,500） | SEO 內容創作（可全職或外包） |
| 技術 SEO 工程師 | HK$30,000 - 55,000 | 網站技術優化、開發整合 |

> 📌 香港薪酬參考：以上為 2026 年香港市場嘅一般水平，金融、科技、跨國企業會再高 20-40%。外包一篇 1,500 字嘅繁中 SEO 文章，香港自由工作者行情約 HK$500-1,500／篇（視乎行業專業度）。

**精簡版內部團隊月成本：**
```
最小可行團隊（2 人）：
  SEO 專員（兼執行 + 策略）: HK$22,000
  內容寫手（全職或約聘）    : HK$18,000
  工具費用（Ahrefs 等）      : HK$2,500
  ─────────────────────────────
  月成本                     : ~HK$42,500
```

**優點：**
- 深度了解公司和行業（香港本地行業知識特別值錢）
- 快速反應和調整
- 建立公司內部的 SEO 知識庫
- 長期成本比外包低

**缺點：**
- 初期招聘成本高（香港請一個啱嘅 SEO 人可以搵 3-6 個月）
- 找到對的人不容易（香港 SEO 人才池細）
- 一個人離職就斷層

### 模式三：混合模式（Hybrid）— 最推薦

**運作方式：** 內部有一名 SEO 經理/專員 + 外包特定項目。

```
內部 SEO 經理
    │
    ├── 負責：策略、協調、監控、報表
    │
    └── 外包項目：
        ├── 技術審計：請外部專家做深度技術審計（一次性）
        ├── 內容創作：外包給香港寫手（按篇計費）
        ├── 英文內容：外包給母語級英文寫手 / 翻譯
        ├── 連結建設：與香港 PR / Outreach 代理商合作
        └── 網站開發：與工程團隊或外包開發協作
```

**混合模式的預算分配（月預算 HK$25,000 為例）：**
```
內部 SEO 專員薪資（部分時間/兼職） HK$12,000  (48%)
內容外包（2-4 篇/月，繁中）         HK$6,000   (24%)
連結建設 / 本地 PR 外包             HK$3,000   (12%)
SEO 工具費用                        HK$2,500   (10%)
教育訓練 / 雜支                     HK$1,500   (6%)
──────────────────────────────────────────────
總計                                HK$25,000
```

## 預算規劃的階段性投入

### SEO 投入曲線

```
投入
│
│                      ████████████████
│                  ████                （持續優化與內容生產）
│              ████
│          ████
│      ████
│  ████
│██
└──────────────────────────────────────→ 時間
 第1-2月  第3-6月  第7-12月  第13月+

前期投入較高（網站審計、技術修正、策略建立）
中期投入穩定（內容生產、連結建設）
後期投入轉為維護 + 優化（效率更高）
```

### 各階段預算分配建議

| 階段 | 時間 | 預算佔比 | 主要投入 |
|------|------|----------|----------|
| 基礎建設期 | 第 1-2 月 | 25-30% | 技術審計、網站修復、關鍵字研究、策略制定 |
| 內容建設期 | 第 3-6 月 | 35-40% | 大量內容創作、On-Page 優化、內部連結 |
| 權威累積期 | 第 7-12 月 | 25-30% | 連結建設、本地 PR、內容深化 |
| 持續優化期 | 第 13 月+ | 10-15% | 維護、更新、監控、競爭應對 |

> 🇭🇰 **香港特別提示：** 如果係香港本地服務業（裝修、清潔、醫療、法律、教育、地產），第 1-2 個月要額外預留預算做 **Google 商家檔案（GBP）優化** 同 **本地引用建設**（OpenRice、HKTDC、商會目錄、香港黃頁等）。呢筆投入對本地 SEO 嘅回報往往快過做內容。

## SEO 的三種計費方式比較

### 按月顧問費（Monthly Retainer）
```
模式：每月固定費用，包含約定的工作範圍
優點：可預測成本、穩定合作
缺點：產出不靈活，可能有些月份事情較少
適合：長期策略性 SEO（香港最常見的收費模式）
```

### 按項目計費（Project-Based）
```
模式：針對特定項目一次性報價
香港行情範例：
  技術 SEO 審計              : HK$8,000 - 20,000
  關鍵字研究報告              : HK$4,000 - 10,000
  網站搬遷 / 改版 SEO 顧問     : HK$12,000 - 40,000
  SEO 策略規劃                : HK$10,000 - 25,000
  網站內容 SEO 重寫（100 頁）  : HK$20,000 - 50,000
適合：特定需求、補充內部團隊能力
```

### 按績效計費（Performance-Based）
```
模式：按照排名/流量/轉換成效收費
注意：這種模式陷阱最多
⚠️ 紅旗：
  - 保證排名 → 幾乎都是騙人的
  - 只用長尾、無競爭關鍵字衝量（香港市場細，特別易呃）
  - 使用灰帽/黑帽手法快速見效後跑路
  - 用「保證首頁」換取長期綁約（香港消委會接過唔少呢類投訴）
適合：謹慎選擇，只與可信的團隊合作
```

## ROI 計算：SEO 值得投入嗎？

### 簡單 ROI 計算（香港例子）
```
年度 SEO 投入：HK$40,000/月 × 12 = HK$480,000
SEO 帶來的有機流量：每月 20,000 次訪問
轉換率：2%
客單價：HK$800
──────────────────────────
月營收 = 20,000 × 2% × 800 = HK$320,000
年營收 = HK$320,000 × 12 = HK$3,840,000
ROI = (3,840,000 - 480,000) / 480,000 = 700%
```

**對照：香港 Google Ads 嘅成本**
```
如果呢 20,000 次訪問全部靠 Google Ads：
  香港平均 CPC 約 HK$5-25（視行業，金融/法律可達 HK$80+）
  以 HK$12 CPC 計：20,000 × 12 = HK$240,000/月
  一年 = HK$2,880,000

對比 SEO 嘅 HK$480,000/年
→ SEO 嘅流量成本大約係廣告嘅 1/6，而且停咗都仲有
```

### SEO 的隱藏價值
不只是直接轉換，SEO 還提供：
- **品牌曝光價值：** 你的品牌每月被數萬香港用戶看到（這些如果靠廣告要花多少？）
- **輔助轉換：** SEO 是用戶旅程的第一步，後續從其他渠道轉換（香港用戶好興「Google 搜 → 上連登睇評價 → 再返嚟落單」）
- **內容資產：** SEO 內容是永久資產，不像廣告停了就沒了
- **競爭防禦：** 你不佔據搜尋結果，競爭對手就會
- **本地信任：** 喺香港，排得前 + 有真實 Google 評論，本身就係一種信任狀

## 如何評估 SEO 代理商／顧問？

### 面試問題清單

```
策略類：
☐ 你會為我們的行業（香港市場）做什麼樣的 SEO 策略？
☐ 你如何處理中英雙語 / 繁簡內容嘅 SEO？
☐ 你如何追蹤和報告 SEO 成效？
☐ 你認為我們網站目前最大的 SEO 問題是什麼？

執行類：
☐ 你會具體做哪些工作？（要具體，不要模糊的「我們會做 SEO」）
☐ 你如何做連結建設？會唔會用付費連結？
☐ 你使用哪些工具？
☐ 內容由邊個寫？係香港本地寫手定係外地？

溝通類：
☐ 報告頻率和格式？
☐ 誰是我們的對接窗口？
☐ 如果沒有效果，你們會怎麼調整？

倫理類：
☐ 你是否遵循 Google 網站管理員指南？
☐ 你過去有沒有客戶被 Google 懲罰過？
☐ 你能分享香港客戶的案例和數據嗎？
☐ GSC / GA4 帳號會用邊個名義開？（正確答案：你公司名義）
```

### 代理商合約應包含的條款

```
✓ 明確的工作範圍（要做什麼、不做什麼）
✓ 報告頻率和格式
✓ KPI 定義（不是排名保證，而是流量/轉換目標）
✓ 終止條款和通知期（通常 30 天）
✓ 數據所有權（GSC/GA4/Bing WMT 帳號要以你公司名義建立）
✓ 禁止使用黑帽手法（付費連結、PBN、AI 大量生成）嘅條款
✓ 保密協議
✓ 智慧財產權歸屬（內容、策略文件屬於你）
✓ 貨幣與付款條款（HK$ 計價、付款期、逾期處理）
```

## 本章重點回顧

| 預算區間（月） | 適合模式 | 關鍵建議 |
|---------------|----------|----------|
| < HK$8,000 | DIY + 工具 | 先自己學習執行，不要亂花錢 |
| HK$8,000-20,000 | 基礎外包 or 一個專員 | 先建立 SEO 基礎 |
| HK$20,000-50,000 | 混合模式 | 內部策略 + 外包執行（最推薦） |
| HK$50,000+ | 內部團隊 | 建立完整 SEO 團隊 |

> 💡 **SEO 預算的第一原則：不要把錢花在「保證排名」的人身上。把錢花在「持續創造優質內容」和「改善用戶體驗」上。**
>
> 香港版補充：**亦唔好將錢花喺「唔肯講清楚做乜」嘅人身上。** 一份 HK$8,000 一個月嘅 SEO 合約，至少要講得出每個月做咗邊幾篇內容、改咗邊幾頁、攞到邊幾個連結。
