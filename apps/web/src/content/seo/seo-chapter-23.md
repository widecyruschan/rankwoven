## 內部連結：最被低估的 SEO 力量

**內部連結（Internal Links）** 是指從你網站上的一個頁面連結到同網站的另一個頁面。與反向連結（Backlinks）不同，內部連結是你**完全可控**的排名助力。

> SEO 界有一句話：「你可以控制的最強排名工具，不是內容，不是關鍵字，而是內部連結。」

### 內部連結的三大 SEO 作用

| 作用 | 說明 |
|------|------|
| **權重傳遞** | 將高權重頁面（首頁、主力頁面）的排名力量傳遞到目標頁面 |
| **索引輔助** | 幫助 Google 發現和索引你網站上的所有重要頁面 |
| **上下文建立** | 錨點文字告訴 Google 目標頁面的主題，幫助主題相關性判斷 |

### 香港市場點解更加要靠內部連結

| 香港現實 | 內部連結點樣幫 |
|----------|----------------|
| **香港本地反向連結難攞**（媒體、商會目錄數量有限） | 內部連結係你完全可控嘅權重分配工具，特別重要 |
| **18 區頁 + 多服務頁令網站結構複雜** | 要靠 Hub & Spoke 同地區 Hub 將權重有系統咁分落去 |
| **中英雙語站容易互相「打架」** | 內部連結 + hreflang 要一齊處理，否則兩個語言版互相搶排名 |
| **香港搜尋量細，每頁流量有限** | 內部連結提升瀏覽深度，等有限流量發揮最大價值 |

## 內部連結策略一：錨點文字（Anchor Text）優化

**錨點文字** 是連結中可點擊的文字部分，它是 Google 理解目標頁面主題的**極強信號**。

### 錨點文字五大類型（香港例子）

| 類型 | 說明 | 範例 |
|------|------|------|
| **精確匹配** | 錨點文字 = 目標頁面的主要關鍵字 | 「狗糧推介」連結到 `pethk.hk/dog-food-guide/` |
| **部分匹配** | 錨點文字包含關鍵字的變體 | 「新手養狗揀狗糧方法」 |
| **品牌** | 使用品牌名稱 | 「PetHK 嘅選購指南」 |
| **裸 URL** | 直接使用網址 | `https://pethk.hk/dog-food-guide` |
| **通用** | 「按呢度」「睇多啲」 | 「想知多啲，按呢度」 |

### 錨點文字健康比例

| 類型 | 建議佔比 | 說明 |
|------|----------|------|
| 部分匹配 | 40-50% | 最自然的錨點類型 |
| 品牌 | 20-30% | 建立品牌信號 |
| 通用 | 15-20% | 自然的使用情境 |
| 裸 URL | 5-10% | 適用於參考資料連結 |
| 精確匹配 | 5-10% | 過多會被視為過度優化 |

> **紅線**：如果精確匹配錨點超過 20%，Google 可能判定為過度優化（特別是內部連結）。

### 錨點文字多樣化策略

對於同一目標頁面，使用**多種不同的錨點文字**來連結它（香港用語版）：

| 目標頁面：狗糧選購指南 |
|------------------------|
| 「狗糧推介」 |
| 「點樣揀啱狗狗嘅狗糧」 |
| 「小型犬狗糧選購注意事項」 |
| 「呢份完整嘅狗糧指南」 |
| 「PetHK 嘅狗糧挑選教學」 |

> **香港中英夾雜提示**：如果目標頁係英文版（`/en-hk/`），錨點文字就用英文；唔好喺繁中文章入面用英文錨點指去英文頁而唔標示，會令使用者同 Google 混亂。

## 內部連結策略二：連結位置與權重傳遞

### 連結位置對權重傳遞的影響

並非所有的內部連結都傳遞同等權重。Google 對不同位置連結的權重評估如下：

```
最高權重 ─→ 文章正文中的連結（Contextual Link）
    ↓
中高權重 ─→ 麵包屑導航中的連結
    ↓
中權重 ─→ 導航選單中的連結
    ↓
低權重 ─→ 側欄中的連結
    ↓
最低權重 ─→ 頁腳中的連結
```

**實戰法則**：想推哪個頁面，就在相關文章的正文中自然地連結過去。

### 首頁連結權重的分配

首頁通常是網站上權重最高的頁面。明智地使用首頁的內部連結：

- 首頁導航欄：連結到最重要的 5-8 個頁面
- 首頁內容區：連結到最新的或最重要的內容
- 頁腳：可以放完整的站點地圖連結（但權重傳遞效果最低）

**香港常見做法**：首頁加一個「服務地區」區塊，用文字連結落 18 區頁（中環、銅鑼灣、旺角、尖沙咀、沙田、將軍澳、元朗、屯門…）。呢個區塊喺首頁正文中間，權重傳遞比放喺頁腳好得多。

## 內部連結策略三：Hub & Spoke 模型

**Hub & Spoke**（中心輻射）是內部連結的經典架構：

```
                ┌─────────────────┐
                │   支柱頁面 (Hub)  │  ← 終極指南，涵蓋完整主題
                │ 狗狗狗糧終極指南  │
                └────────┬────────┘
           ┌─────────────┼─────────────┐
           │             │             │
    ┌──────┴──────┐ ┌───┴─────┐ ┌─────┴──────┐
    │ Spoke 頁面  │ │ Spoke   │ │ Spoke      │  ← 子主題長文
    │ 幼犬狗糧指南 │ │ 成分分析 │ │ 品牌比較   │
    └─────────────┘ └─────────┘ └────────────┘
```

**運作原理**：
1. Hub 頁面連結到所有 Spoke 頁面
2. 所有 Spoke 頁面連結回 Hub 頁面
3. Spoke 頁面之間也互相連結（當相關時）

**效果**：形成一個「連結飛輪」，每個頁面都獲得來自 Hub 的權重，同時互相加強主題相關性。

### 香港版：地區 Hub & Spoke

香港生意好多時係「服務 × 地區」嘅二維結構，可以做兩層 Hub：

```
                  ┌──────────────────────┐
                  │  主 Hub：搬屋服務總覽  │
                  └───────────┬──────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
  ┌─────┴──────┐      ┌──────┴──────┐      ┌──────┴──────┐
  │ 九龍地區 Hub │      │ 港島地區 Hub │      │ 新界地區 Hub │
  └─────┬──────┘      └──────┬──────┘      └──────┬──────┘
        │                     │                     │
   觀塘 / 旺角 /         中環 / 銅鑼灣 /        沙田 / 元朗 /
   深水埗 / 黃大仙       灣仔 / 東區           屯門 / 將軍澳
```

**運作方式**：
1. 主 Hub 連結到 3 個地區 Hub
2. 每個地區 Hub 連結到旗下各區頁，同時連結返主 Hub
3. 各區頁連結返所屬地區 Hub + 主 Hub
4. 同區鄰近地區之間互相連結（例如觀塘 ↔ 九龍城），符合用家實際搜尋行為

> **重要警告**：地區頁唔可以淨係換地名。每個區頁要有**獨特內容**（該區案例、實際收費、就近團隊、交通／泊車資訊），否則會被 Google 判為 doorway pages，成組頁面一齊沉。

### 實施步驟

1. 確認你的 Hub 頁面（通常是終極指南、主力產品頁、服務總覽頁）
2. 確認 Hub 下的 Spoke 頁面（子主題文章、地區頁）
3. 在 Hub 頁面中加入指向每個 Spoke 的連結
4. 在每個 Spoke 頁面中，連結回 Hub + 連結到相關的其他 Spoke
5. 雙語站：確保繁中版連繁中版、英文版連英文版，hreflang 互相對應

## 內部連結策略四：孤兒頁面消滅計劃

**孤兒頁面（Orphan Page）** 是指沒有任何其他頁面連結到它的頁面。Google 可能永遠不會發現這些頁面，即使它們的內容很好。

### 如何找出孤兒頁面？

| 方法 | 工具 |
|------|------|
| 比對 Sitemap 與內部連結資料 | Screaming Frog（爬取後比對） |
| GSC 中「已提交但未索引」的 URL | Google Search Console（記得兩個版本都要加：www / 非 www、http / https） |
| 網站爬蟲分析 | Ahrefs Site Audit、SEMrush Site Audit |

> **香港常見孤兒頁來源**：18 區頁批量生成（只放咗入 sitemap、冇喺任何頁面連結）、英文版頁（繁中版導覽冇連過去）、舊活動頁（活動完咗就冇人 link）。

### 修復孤兒頁面的優先級

```
有價值但孤立 → 添加內部連結 → 最高優先級
價值不高且孤立 → 考慮刪除或合併 → 中優先級
故意孤立（登陸頁、特殊頁面） → 保持原樣 → 無需修復
```

## 內部連結五大常見錯誤

| 錯誤 | 問題 | 修復方法 |
|------|------|----------|
| **過度使用精確匹配錨點** | Google 可能判為過度優化 | 將精確匹配降到 10% 以下 |
| **只在導航中連結** | 導航連結權重傳遞效果較低 | 在文章正文中增加上下文連結 |
| **連結到不重要頁面** | 浪費有限的首頁權重 | 只在導航中保留最重要頁面 |
| **孤兒頁面氾濫** | Google 無法發現這些頁面 | 確保每個頁面至少有一個內部連結 |
| **Nofollow 內部連結** | 內部連結不應該用 nofollow | 移除內部連結上的 nofollow |
| **雙語站語言錯配** | 繁中頁連去英文頁，令使用者同 Google 混亂 | 語言內互連 + hreflang 對應 |

## 內部連結實戰行動清單

### Week 1：審查現狀
- [ ] 使用 Screaming Frog 爬取全站，查看內部連結結構
- [ ] 找出孤兒頁面，評估每個頁面的價值（特別留意 18 區頁、英文版頁）
- [ ] 查看錨點文字分布，檢查是否過度優化
- [ ] 檢查雙語站語言錯配問題

### Week 2-3：結構優化
- [ ] 為重要頁面添加上下文內部連結
- [ ] 建立或完善 Hub & Spoke 結構（含地區 Hub）
- [ ] 多樣化重要頁面的錨點文字（用香港用語）
- [ ] 修復或刪除無價值的孤兒頁面

### Month 2+：持續維護
- [ ] 每發布一篇新內容，立即添加指向它的內部連結
- [ ] 每季審查一次內部連結健康狀態
- [ ] 定期更新舊文章中的內部連結（指向更新、更好的內容）

## 重點回顧

1. **內部連結 = 你完全可控的排名助力**——香港本地反向連結難攞，內部連結更加重要
2. **錨點文字多樣化**是關鍵，精確匹配不應超過 10%
3. **文章正文中的連結權重最高**，導航和頁腳的連結權重較低
4. **Hub & Spoke 模型**是內部連結的最佳架構；香港生意可做「服務 Hub × 地區 Hub」兩層
5. **地區頁要有獨特內容**，淨係換地名會被判 doorway pages
6. **孤兒頁面是 SEO 的隱形殺手**——定期清理
7. 內部連結不是「做一次就好」，而是**持續維護**的過程
