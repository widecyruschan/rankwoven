## Google 商家檔案是什麼？

**Google 商家檔案（Google Business Profile，簡稱 GBP，前身為 Google My Business）** 是 Google 提供的免費工具，讓商家管理在 Google 搜尋和 Google Maps 上的呈現方式。

```
當使用者搜尋你的商家名稱時：

┌──────────────────────────────────────┐
│  [你的商家名稱]                        │
│  ⭐ 4.8 (200+ 評論)                   │
│  🏪 類型：咖啡店                      │
│  📍 香港中環皇后大道中 100 號           │
│  🕐 營業中 · 08:00 - 22:00            │
│  📞 1234 5678                        │
│  🌐 example.com                      │
│  [路線] [致電] [網站] [儲存]           │
│                                      │
│  📸 照片集                            │
│  📝 Google Posts                     │
│  ⭐ 評論區                            │
│  ❓ Q&A 區                            │
└──────────────────────────────────────┘
```

> **關鍵認知：** 對大多數在地商家來說，GBP 是比官方網站更重要的「門面」。許多使用者從頭到尾都在 GBP 上完成資訊獲取，根本不會點進你的網站。

## GBP 建立與驗證流程

### 第一步：建立商家檔案

1. 前往 [business.google.com](https://business.google.com)
2. 登入你的 Google 帳號
3. 搜尋你的商家名稱（確認是否已被他人建立）
4. 如果不存在，點擊「新增商家」

### 第二步：填寫基本資訊

| 欄位 | 最佳實踐 |
|------|---------|
| **商家名稱** | 使用真實的商業登記名稱。**不要加入關鍵字或地點**（違反 Google 規範會導致停權） |
| **商家類別** | 選擇最精準的**主要類別**。這是最重要的設定之一 |
| **地址** | 如果有實體店面，填寫完整地址。如果是服務區域商家，可隱藏地址 |
| **服務區域** | 明確設定你服務的地理範圍 |
| **電話** | 使用在地電話號碼（不要用 0800 免付費電話） |
| **網站** | 連結你的官網或預約頁面 |

### 第三步：驗證

Google 會要求驗證你是該商家的真正擁有者：

| 驗證方式 | 適用對象 | 時間 |
|----------|---------|------|
| **明信片驗證** | 大多數商家 | 5-14 天（郵寄） |
| **電話驗證** | 部分符合條件的商家 | 即時 |
| **電子郵件驗證** | 部分符合條件的商家 | 即時 |
| **即時驗證** | 已在 Search Console 驗證過網站的商家 | 即時 |
| **錄影驗證** | 部分商家類型 | 需要錄製影片 |

> **不要跳過驗證。** 未驗證的商家檔案**不會**出現在 Google 搜尋和 Maps 中。

## GBP 的完整優化清單

### 必填欄位（影響排名最直接的）

| 欄位 | SEO 重要性 | 最佳實踐 |
|------|-----------|----------|
| **商家名稱** | 🔥🔥🔥🔥🔥 | 真實名稱，不加關鍵字 |
| **主要類別** | 🔥🔥🔥🔥🔥 | 選擇最精準的類別，參考 Google 官方類別清單 |
| **地址** | 🔥🔥🔥🔥🔥 | 精確、一致的格式 |
| **電話** | 🔥🔥🔥🔥🔥 | 在地號碼，可在網站和目錄中找到 |
| **營業時間** | 🔥🔥🔥🔥🔥 | 準確並定期更新（含特殊節日） |
| **網站** | 🔥🔥🔥🔥 | 連結到官網或最佳著陸頁 |

### 加分欄位（影響轉換和使用者體驗）

| 欄位 | 說明 | 影響 |
|------|------|------|
| **商家描述** | 750 字以內的商家介紹（關鍵字自然融入） | 🔥🔥🔥🔥 |
| **產品/服務** | 列出你提供的產品或服務及價格 | 🔥🔥🔥🔥 |
| **照片** | 封面照、內部照、外部照、團隊照、產品照 | 🔥🔥🔥🔥🔥 |
| **影片** | 30 秒內的商家介紹影片 | 🔥🔥🔥 |
| **屬性（Attributes）** | 無障礙設施、WiFi、戶外座位等 | 🔥🔥🔥 |
| **預約連結** | 直接連結到線上預約系統 | 🔥🔥🔥🔥 |
| **菜單** | 餐廳可直接上傳菜單 | 🔥🔥🔥🔥 |

### 商家描述撰寫指南

```
❌ 不好的描述：
「我們是最好的咖啡店，提供最美味的咖啡和食物。來試試看吧。」

✅ 好的描述（自然融入關鍵字）：
「[品牌名] 是一間位於香港中環的精品咖啡店，自 2018 年起提供手沖咖啡、
自家烘焙豆、和輕食早午餐。我們的咖啡豆來自公平貿易農場，
由專業咖啡師每日新鮮烘焙。店內提供 WiFi、戶外座位區，
歡迎帶寵物一同前來。每日 08:00 - 22:00 營業。」
```

## Google Posts（貼文）：免費的在地內容行銷

Google Posts 是你在 GBP 上發布的內容，會直接顯示在你的商家檔案和 Local Pack 中。

### Posts 的四種類型

| 類型 | 用途 | 持續時間 |
|------|------|----------|
| **一般更新** | 新品上市、服務更新、一般公告 | 7 天後過期（但仍可查看） |
| **活動** | 促銷活動、工作坊、特別活動 | 活動日期後過期 |
| **優惠** | 折扣、促銷代碼、限時優惠 | 設定的到期日 |
| **COVID-19 更新** | 特殊時期的營業資訊變更 | 持續顯示 |

### Posts 的最佳實踐

```
發布頻率：至少每週 1 篇
  → Google 偏好活躍更新的商家檔案

內容類型：
  ☑ 新產品/新服務公告
  ☑ 限時優惠和促銷
  ☑ 活動預告和回顧
  ☑ 部落格文章摘要 + 連結
  ☑ 客戶案例和推薦
  ☑ 節日問候

每篇 Post 的元素：
  ☑ 吸引人的圖片（1200×900 為最佳尺寸，<5MB）
  ☑ 簡潔有力的文字（150-300 字，前 80 字最關鍵）
  ☑ 明確的行動呼籲按鈕（預約/購買/了解更多/註冊）
  ☑ UTM 追蹤參數（追蹤從 GBP 來的流量）
```

## GBP 的照片策略

照片是 GBP 上最具影響力的元素之一。Google 的數據顯示，有照片的商家檔案獲得的**路線請求多 42%、網站點擊多 35%**。

### 照片類型與建議

| 照片類型 | 最少數量 | 說明 |
|----------|---------|------|
| **封面照** | 1 | 代表你品牌的最佳照片 |
| **標誌（Logo）** | 1 | 方形，幫助使用者識別你的品牌 |
| **外部照** | 3+ | 不同角度和時間（白天 + 晚上）的店外觀 |
| **內部照** | 3+ | 店內環境、裝潢、氛圍 |
| **產品/服務照** | 5+ | 你最受歡迎的產品或服務 |
| **團隊照** | 2+ | 團隊工作、專業形象 |
| **360 度環景照** | 1+ | 提供沉浸式體驗 |

### 照片最佳實踐

```
✅ 應該做：
  ☑ 使用高畫質照片（至少 720×720 像素）
  ☑ 定期新增照片（每週至少 1 張）
  ☑ 使用地理位置標記的照片
  ☑ 照片檔案名稱使用描述性文字
  ☑ 展示真實的環境和商品（不要用過度修圖的 stock photo）

❌ 不要做：
  ☐ 使用有浮水印或過度編輯的照片
  ☐ 使用與商家無關的照片
  ☐ 上傳低解析度的模糊照片
  ☐ 僅上傳幾張照片就停止更新
```

## GBP 的 Q&A 管理

GBP 上的「問與答」功能允許任何人提問和回答。

### 為什麼 Q&A 重要？

- 常見問題和答案會直接顯示在搜尋結果中
- 回答可以包含關鍵字，幫助在地 SEO
- 減少客服電話（使用者在搜尋結果中直接找到答案）

### Q&A 管理策略

```
主動策略（建立常見問題）：
  → 以商家身分主動提問並回答常見問題
  → 範例：
    Q: 「你們接受訂位嗎？」
    A: 「是的，我們接受電話和線上訂位。週末建議提前預約...」
    Q: 「有素食選項嗎？」
    A: 「我們有 5 款素食主餐和 3 款純素甜點...」

被動策略（監控與回覆）：
  → 設定通知，當有新問題時立即知道
  → 在 24 小時內回覆所有問題
  → 如果有不準確的回答，舉報並提供正確答案
```

## GBP 的常見違規與停權風險

### 最常見的違規行為

| 違規行為 | 風險 | 說明 |
|----------|------|------|
| **在商家名稱加入關鍵字** | 🔴 停權 | 例如真正的店名是「美味餐廳」，GBP 設為「美味餐廳 香港最佳中菜」 |
| **虛擬辦公室或 P.O. Box 地址** | 🔴 停權 | 必須有實體店面或實際服務客戶的地址 |
| **重複建立商家檔案** | 🟠 合併或移除 | 同一地點不應有多個 GBP |
| **評論操縱** | 🔴 停權 | 購買假評論、用優惠換評論、自評 |
| **假地址** | 🔴 停權 | 使用不屬於你的地址來覆蓋更多區域 |
| **不相關的類別選擇** | 🟡 排名下降 | 選擇與業務無關的類別 |

### 如果被停權怎麼辦？

```
1. 閱讀 Google 的暫停通知（會告知原因）
2. 修正違規問題
3. 透過 GBP 申訴表單提交重審請求
4. 提供證明文件（商業登記證、店面照片、水電帳單等）
5. 耐心等待（可能需要數週）
```

## GBP 分析與成效追蹤

GBP 內建的分析工具（Insights）提供以下數據：

| 指標 | 說明 | 代表意義 |
|------|------|----------|
| **搜尋查詢** | 使用者用什麼關鍵字找到你 | 驗證你的在地 SEO 關鍵字策略 |
| **搜尋類型** | 直接搜尋 vs 發現搜尋 vs 品牌搜尋 | 了解品牌知名度 |
| **顧客動作** | 造訪網站、請求路線、來電 | 衡量 GBP 轉換效果 |
| **方向請求** | 多少人點擊「路線」 | 實體店面吸引力 |
| **來電** | 多少人從 GBP 打電話 | 最直接的轉換指標 |
| **照片觀看次數** | 你的照片 vs 同類商家的照片觀看 | 照片品質的競爭力 |
| **熱門時段** | 什麼時候最多人查看你的檔案 | 營業策略的數據支撐 |
