## Google 商家檔案是什麼？

**Google 商家檔案（Google Business Profile，簡稱 GBP，前身為 Google My Business）** 是 Google 提供的免費工具，讓商家管理在 Google 搜尋和 Google Maps 上的呈現方式。**在香港，GBP 完全可用**，係本地 SEO 嘅基石。

```
當香港使用者搜尋你的商家名稱時：

┌──────────────────────────────────────┐
│  [你的商家名稱]                        │
│  ⭐ 4.8 (200+ 評論)                   │
│  🏪 類型：咖啡店                      │
│  📍 香港中環皇后大道中 100 號 12 樓     │
│  🕐 營業中 · 08:00 - 22:00            │
│  📞 +852 2345 6789                    │
│  🌐 example.com.hk                    │
│  [路線] [致電] [網站] [儲存]           │
│                                      │
│  📸 照片集                            │
│  📝 Google Posts                     │
│  ⭐ 評論區                            │
│  ❓ Q&A 區                            │
└──────────────────────────────────────┘
```

> **關鍵認知：** 對大多數香港本地商家來說，GBP 是比官方網站更重要的「門面」。許多使用者由頭到尾都喺 GBP 上面睇完地址、睇完評論、撳個電話就打過嚟，根本唔會入你個網。
>
> 餐飲業更要留意：好多人會「Google 睇地址 + OpenRice 睇食評」雙軌並行，兩邊都要顧。

## GBP 建立與驗證流程（香港）

### 第一步：建立商家檔案

1. 前往 [business.google.com](https://business.google.com)
2. 登入你的 Google 帳號
3. 搜尋你的商家名稱（確認是否已被他人或 Google 自動建立）
4. 如果不存在，點擊「新增商家」

> **香港常見情況：** 好多舖頭其實已經被 Google 自動建立咗「未認領」檔案（資料來源可能係舊目錄）。你要做嘅係**認領（Claim）**而唔係重新建立，否則會出現重複檔案。

### 第二步：填寫基本資訊

| 欄位 | 香港最佳實踐 |
|------|---------|
| **商家名稱** | 使用真實的商業登記名稱（BR 上的名稱）。**不要加入關鍵字或地區**（例如「美味餐廳 香港最佳中菜」會違規） |
| **商家類別** | 選擇最精準的**主要類別**。這是最重要的設定之一 |
| **地址** | 香港格式：區域 + 街道 + 門牌 + 大廈 + 樓層 + 室號。例如「香港中環皇后大道中 100 號 新鴻基大廈 12 樓 A 室」。服務區域商家可隱藏地址 |
| **服務區域** | 按 18 區或地區設定（香港**沒有郵遞區號**，所以用地區/自訂範圍） |
| **電話** | 使用香港號碼：`+852` + 8 位數字（例如 +852 2345 6789），或用本地格式 2345 6789。**唔好用 800/免費熱線做主號** |
| **網站** | 連結你的官網（.hk / .com.hk 為佳）或預約頁面，最好指到對應語言版本 |

### 第三步：驗證

Google 會要求驗證你是該商家的真正擁有者：

| 驗證方式 | 適用對象（香港情況） | 時間 |
|----------|---------|------|
| **明信片驗證** | 香港大多數商家 | 約 5-14 天（郵寄到香港地址，有時更耐） |
| **電話驗證** | 部分符合條件的商家 | 即時 |
| **電子郵件驗證** | 部分符合條件的商家（需用公司網域 email） | 即時 |
| **即時驗證** | 已在 Search Console 驗證過網站的商家 | 即時 |
| **錄影驗證** | 部分商家類型（需拍攝店面、招牌、營業證據） | 需錄製影片 |

```
香港驗證小貼士：
  → 用公司網域 email（@yourcompany.com.hk）會提高即時驗證成功率
  → 先在 Search Console 驗證網站，有機會觸發即時驗證
  → 錄影驗證要拍到：街道門牌、舖面招牌、內部環境、可證明你營運嘅嘢
  → 明信片寄失係常見嘅，收唔到就申請重寄（最多 2-3 次）
```

> **不要跳過驗證。** 未驗證的商家檔案**不會**出現在 Google 搜尋和 Maps 中。

## GBP 的完整優化清單

### 必填欄位（影響排名最直接的）

| 欄位 | SEO 重要性 | 香港最佳實踐 |
|------|-----------|----------|
| **商家名稱** | 🔥🔥🔥🔥🔥 | 真實名稱（跟 BR），不加關鍵字、不加「香港」「全港第一」 |
| **主要類別** | 🔥🔥🔥🔥🔥 | 選擇最精準的類別，參考 Google 官方類別清單（用英文類別庫，但顯示會中文化） |
| **地址** | 🔥🔥🔥🔥🔥 | 香港格式，與網站/OpenRice/Facebook 完全一致 |
| **電話** | 🔥🔥🔥🔥🔥 | +852 號碼，可在網站和目錄中找到 |
| **營業時間** | 🔥🔥🔥🔥🔥 | 準確並定期更新，含**香港公眾假期**、農曆新年、八號風球/黑色暴雨安排 |
| **網站** | 🔥🔥🔥🔥 | 連結到官網（/zh-hk/）或最佳著陸頁 |

### 加分欄位（影響轉換和使用者體驗）

| 欄位 | 說明 | 影響 |
|------|------|------|
| **商家描述** | 750 字以內的商家介紹（繁中為主，可中英夾雜） | 🔥🔥🔥🔥 |
| **產品/服務** | 列出你提供的產品或服務及價格（HK$） | 🔥🔥🔥🔥 |
| **照片** | 封面照、內部照、外部照、團隊照、產品照 | 🔥🔥🔥🔥🔥 |
| **影片** | 30 秒內的商家介紹影片 | 🔥🔥🔥 |
| **屬性（Attributes）** | 無障礙設施、免費 WiFi、戶外座位、接受八達通等 | 🔥🔥🔥 |
| **預約連結** | 直接連結到線上預約系統 | 🔥🔥🔥🔥 |
| **菜單** | 餐廳可直接上傳菜單（價錢用 HK$） | 🔥🔥🔥🔥 |

### 商家描述撰寫指南（香港版）

```
❌ 不好的描述：
「我們是全港最好的咖啡店，提供最美味的咖啡和食物。來試試看吧。」

✅ 好的描述（自然融入關鍵字 + 香港場景）：
「[品牌名] 是一間位於香港中環的精品咖啡店，自 2018 年起提供手沖咖啡、
自家烘焙豆、和輕食 All-day breakfast。我哋嘅咖啡豆嚟自公平貿易農場，
由專業咖啡師每日新鮮烘焙。店內提供免費 WiFi、戶外座位區，
歡迎帶埋狗狗一齊嚟。距離港鐵中環站 D2 出口步行約 3 分鐘。
每日 08:00 - 22:00 營業，接受八達通、PayMe、FPS 轉數快及信用卡。」
```

## Google Posts（貼文）：免費的本地內容行銷

Google Posts 是你在 GBP 上發布的內容，會直接顯示在你的商家檔案和 Local Pack 中。

### Posts 的四種類型

| 類型 | 用途 | 持續時間 |
|------|------|----------|
| **一般更新** | 新品上市、服務更新、一般公告 | 7 天後過期（但仍可查看） |
| **活動** | 促銷活動、工作坊、特別活動 | 活動日期後過期 |
| **優惠** | 折扣、促銷代碼、限時優惠（例如「全單 9 折」） | 設定的到期日 |
| **特別營業時間公告** | 節日、颱風、裝修期間的營業資訊變更 | 持續顯示 |

### Posts 的最佳實踐（香港節慶行事曆）

```
發布頻率：至少每週 1 篇
  → Google 偏好活躍更新的商家檔案

香港內容靈感：
  ☑ 節日：農曆新年、復活節、暑假、中秋、聖誕、除夕
  ☑ 季節性：雨季/颱風季服務安排、夏日優惠
  ☑ 新品/新服務公告、限時優惠（HK$ 明碼實價）
  ☑ 活動預告和回顧（例如「中環社區免費講座」）
  ☑ 部落格文章摘要 + 連結
  ☑ 客戶案例和推薦

每篇 Post 的元素：
  ☑ 吸引人的圖片（1200×900 為最佳尺寸，<5MB）
  ☑ 簡潔有力的文字（150-300 字，前 80 字最關鍵）
  ☑ 明確的行動呼籲按鈕（預約/購買/了解更多/註冊）
  ☑ UTM 追蹤參數（追蹤從 GBP 來的流量，喺 GA4 分開睇）
```

## GBP 的照片策略

照片是 GBP 上最具影響力的元素之一。Google 的數據顯示，有照片的商家檔案獲得的**路線請求多 42%、網站點擊多 35%**。

### 照片類型與建議

| 照片類型 | 最少數量 | 說明 |
|----------|---------|------|
| **封面照** | 1 | 代表你品牌的最佳照片 |
| **標誌（Logo）** | 1 | 方形，幫助使用者識別你的品牌 |
| **外部照** | 3+ | 不同角度和時間（日景 + 夜景）的舖面外觀，最好影到招牌 |
| **內部照** | 3+ | 店內環境、裝潢、氛圍 |
| **產品/服務照** | 5+ | 你最受歡迎的產品或服務 |
| **團隊照** | 2+ | 團隊工作、專業形象 |
| **360 度環景照** | 1+ | 提供沉浸式體驗（香港舖位細小尤其有用） |

### 照片最佳實踐

```
✅ 應該做：
  ☑ 使用高畫質照片（至少 720×720 像素）
  ☑ 定期新增照片（每週至少 1 張）
  ☑ 使用地理位置標記的照片（EXIF 地理資訊）
  ☑ 照片檔案名稱使用描述性文字（central-store-front.jpg）
  ☑ 展示真實的環境和商品（香港舖面細，要影得光猛企理）

❌ 不要做：
  ☐ 使用有浮水印或過度編輯的照片
  ☐ 使用與商家無關的照片（例如淨係放 OpenRice 食評截圖）
  ☐ 上傳低解析度的模糊照片
  ☐ 僅上傳幾張照片就停止更新
```

## GBP 的 Q&A 管理

GBP 上的「問與答」功能允許任何人提問和回答。

### 為什麼 Q&A 重要？

- 常見問題和答案會直接顯示在搜尋結果中
- 回答可以包含關鍵字，幫助本地 SEO
- 減少客服電話（使用者在搜尋結果中直接找到答案）

### Q&A 管理策略（香港版）

```
主動策略（建立常見問題，可用廣東話）：
  → 以商家身分主動提問並回答常見問題
  → 範例：
    Q: 「你哋接唔接受訂位？」
    A: 「我哋接受電話同網上訂位。週末同公眾假期建議提早 1 星期預約...」

    Q: 「有冇素食選擇？」
    A: 「我哋有 5 款素食主餐同 3 款純素甜點，全部 HK$88 起...」

    Q: 「收唔收八達通 / PayMe / FPS？」
    A: 「我哋接受八達通、PayMe、FPS 轉數快、支付寶香港、
        WeChat Pay HK 同信用卡（Visa / Master）...」

    Q: 「附近有冇停車場？」
    A: 「最近的停車場係 XX 廣場，步行約 5 分鐘...」

被動策略（監控與回覆）：
  → 設定通知，當有新問題時立即知道
  → 在 24 小時內回覆所有問題
  → 如果有不準確的回答，舉報並提供正確答案
```

## GBP 的常見違規與停權風險

### 最常見的違規行為

| 違規行為 | 風險 | 香港例子 |
|----------|------|------|
| **在商家名稱加入關鍵字** | 🔴 停權 | BR 名係「美味餐廳」，GBP 設為「美味餐廳 香港最佳中菜」 |
| **虛擬辦公室或 P.O. Box 地址** | 🔴 停權 | 用秘書公司地址、或用 P.O. Box 當實體地址 |
| **重複建立商家檔案** | 🟠 合併或移除 | 同一個尖沙咀舖位開咗 3 個 GBP |
| **評論操縱** | 🔴 停權 | 買假評論、用「俾 5 星送甜品」換評論、員工自評 |
| **假地址** | 🔴 停權 | 用唔屬於你嘅地址嚟覆蓋更多區（例如用元朗地址但實際做開中環） |
| **不相關的類別選擇** | 🟡 排名下降 | 餐廳選咗「旅行社」做主要類別 |
| **唔符合行業規管嘅內容** | 🟡 視行業而定 | 地產代理冇 EAA 牌照號碼、金融/保險內容違反 SFC/IA 規定 |

### 如果被停權怎麼辦？

```
1. 閱讀 Google 的暫停通知（會告知原因）
2. 修正違規問題（改名稱、改地址、移除違規內容）
3. 透過 GBP 申訴表單提交重審請求
4. 提供證明文件（香港：商業登記證 BR、公司註冊處紀錄、
   舖面照片連招牌、水電費單、租約）
5. 耐心等待（可能需要數週）
```

## GBP 分析與成效追蹤

GBP 內建的分析工具（Insights）提供以下數據：

| 指標 | 說明 | 代表意義 |
|------|------|----------|
| **搜尋查詢** | 使用者用什麼關鍵字找到你 | 驗證你的本地 SEO 關鍵字策略（留意係中文定英文 query） |
| **搜尋類型** | 直接搜尋 vs 發現搜尋 vs 品牌搜尋 | 了解品牌知名度 |
| **顧客動作** | 造訪網站、請求路線、來電 | 衡量 GBP 轉換效果 |
| **方向請求** | 多少人點擊「路線」 | 實體店面吸引力（香港人行路/搭港鐵為主） |
| **來電** | 多少人從 GBP 打電話 | 最直接的轉換指標 |
| **照片觀看次數** | 你的照片 vs 同類商家的照片觀看 | 照片品質的競爭力 |
| **熱門時段** | 什麼時候最多人查看你的檔案 | 營業策略與人手編排的數據支撐 |
