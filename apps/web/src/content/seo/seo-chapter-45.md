---

## 有害連結是什麼？

**有害連結（Toxic Backlinks）** 是來自低品質、垃圾或不相關網站的連結，這些連結可能對你網站的 SEO 產生負面影響。

並非所有低品質連結都是「有害的」。Google 通常會自動忽略大部分垃圾連結。但當有害連結的**數量或模式異常**時，就可能觸發 Penguin 演算法或手動處罰。

---

## 哪些連結可能是有害的？

### 🔴 高風險連結類型

| 類型 | 特徵 | 風險 |
|------|------|------|
| **付費連結（未標記）** | 你付費換取的 dofollow 連結 | 🔴 Google 手動處罰 |
| **連結交換（過度）** | 「你連結我，我連結你」的大量互換 | 🔴 被視為連結方案（Link Scheme） |
| **PBN（Private Blog Network）** | 專為操縱排名而建立的虛假網站網路 | 🔴🔴 極高風險 |
| **低品質目錄網站** | 什麼內容都收、沒有編輯審查的連結目錄 | 🟠 中高風險 |
| **垃圾留言連結** | 部落格留言、論壇回覆中塞入的連結 | 🟠 中高風險 |
| **不相關網站連結** | 來自與你主題完全無關的外語網站 | 🟡 中低風險 |
| **全站連結（Sitewide Links）** | 每個頁面都有同樣的連結（如頁尾連結） | 🟡 中低風險 |
| **自動生成的連結** | 由機器人/工具自動創建的連結 | 🔴 容易被偵測 |

### 🟢 無害但你不需要的連結

| 類型 | 說明 |
|------|------|
| 自然的低品質連結 | 來自新網站或小部落格的偶然連結，Google 會自動忽略 |
| Nofollow 的低品質連結 | Nofollow 不傳遞 PR，通常不需要擔心 |
| 少量的不相關連結 | 偶然的幾個不相關連結不會傷害你 |

> **核心原則：** 只有當你認為這些連結可能被 Google 視為「人為操縱」時，才需要採取行動。Google 通常會自動忽略自然的低品質連結。

---

## 如何識別有害連結

### 第一步：導出反向連結數據

使用 Ahrefs、Semrush 或 Google Search Console 導出你所有的反向連結。

### 第二步：篩選可疑連結

逐一檢查每個連結的以下特徵：

| 檢查項目 | 危險訊號 |
|----------|---------|
| **網站內容** | 內容極少、充滿廣告、與主題無關 |
| **網站設計** | 模板化、看起來像自動生成的 |
| **外部連結數量** | 一個頁面有數百個外部連結 |
| **域名指標** | DR/DA 極低（<5），但流量為零 |
| **流量** | Ahrefs/Semrush 顯示這個網站完全沒有自然流量 |
| **索引狀態** | 在 Google 搜尋 `site:域名` 結果極少或被 deindex |
| **錨點文字** | 全部使用精準匹配商業關鍵字 |
| **連結獲取方式** | 如果是你花錢買的，或者用工具自動生成的 |

### 第三步：評分與分類

將每個連結標記為：

```
🟢 無害：不需要處理
🟡 可疑：觀察，但先不動作
🔴 有害：應該移除或拒絕
```

---

## 處理有害連結的三步驟

### 步驟一：嘗試手動移除（最優先）

在考慮使用 Disavow 工具之前，先嘗試聯繫網站管理者移除連結：

```
聯繫郵件模板：

主旨：請求移除我們網站的連結

Hi [網站管理者]，

我們發現在你的網站 [網站 URL] 上有一個指向我們網站的連結：
[你的 URL]

我們正在整理我們的連結檔案，能否請你移除這個連結？

感謝你的協助。

[你的名字]
```

#### 手動移除的注意事項

- 至少嘗試聯繫 2-3 次
- 記錄所有聯繫嘗試（Google 人工審查時可能需要證明）
- 有些網站管理者不會回應，這是正常的
- 不要威脅或使用攻擊性語言

### 步驟二：評估是否需要 Disavow

**Disavow 不是日常 SEO 工具。** Google 明確表示：大多數網站不需要使用 Disavow 工具。

#### 需要 Disavow 的明確情境

```
✅ 應該使用 Disavow 的情境：
  1. 你收到了 Google 的「非自然連結」手動處罰通知
  2. 你曾經購買過連結，現在想要清理
  3. 你遭受了大量的負面 SEO 攻擊
  4. 你有大量明顯是人為操縱的連結

❌ 不需要使用 Disavow 的情境：
  1. 你的排名最近下降了（通常有其他原因）
  2. 你看到幾個低品質網站連結到你（Google 會自動忽略）
  3. 你的競爭對手建議你使用 Disavow（不要聽！）
  4. 「以防萬一」的心態
```

### 步驟三：建立並提交 Disavow 檔案

#### Disavow 檔案格式

```txt
# 註解行以 # 開頭
# 這是範例 Disavow 檔案

# 拒絕特定頁面的連結
https://spamwebsite.com/bad-page.html

# 拒絕整個域名的所有連結
domain:spamdomain.com

# 拒絕子域名的所有連結
domain:blog.spamdomain.com
```

#### 提交流程

1. 建立 `.txt` 檔案，編碼為 UTF-8
2. 前往 Google Search Console → Disavow Links Tool
3. 選擇你的網站資源
4. 上傳 Disavow 檔案
5. Google 會在下次爬取時應用這些指令

> **⚠️ 警告：** Disavow 是一個強大但危險的工具。錯誤地拒絕了好的連結可能會損害你的排名。如果你不確定某個連結是否應該被拒絕，**不要拒絕它**。

## 負面 SEO（Negative SEO）防禦

### 什麼是負面 SEO？

競爭對手或惡意攻擊者故意向你的網站發送大量垃圾連結，試圖讓 Google 認為你正在操縱排名，從而觸發處罰。

### 負面 SEO 的常見形式

| 形式 | 描述 |
|------|------|
| **垃圾連結轟炸** | 從數千個低品質網站建立指向你的連結 |
| **內容複製** | 複製你的內容發布到其他網站，導致重複內容問題 |
| **偽造社群訊號** | 購買假社群媒體互動 |
| **惡意評論** | 在 Google 商家檔案留下大量負面評價 |

### 防禦策略

```
1. 設定 Google Search Console 電子郵件通知
   → 如果收到手動處罰通知，立即採取行動

2. 定期監控反向連結檔案
   → 每月檢查是否有突然暴增的異常連結

3. 使用 Ahrefs / Semrush 的「新連結」監控
   → 設定警報，發現大量新低品質連結時收到通知

4. 強固你的網站安全
   → 防止駭客注入惡意內容或連結

5. 不要「以牙還牙」
   → 不要對攻擊者進行報復性負面 SEO
```

---

## 手動處罰（Manual Action）處理流程

### 什麼是手動處罰？

當 Google 的人工審查員判斷你違反了 Google 的品質指南時，會對你的網站進行手動處罰。你會收到 GSC 的通知。

### 手動處罰處理步驟

```
第 1 步：確認識別
  → 登入 GSC，查看「安全性與手動處罰」
  → 閱讀處罰的具體原因

第 2 步：診斷問題
  → 如果是「非自然連結」：
    → 導出所有反向連結
    → 識別出可疑連結
    → 分類：自己建立的 vs 攻擊者建立的

第 3 步：清理行動
  → 手動聯繫移除（記錄所有嘗試）
  → 無法移除的加入 Disavow 檔案

第 4 步：提交重審請求（Reconsideration Request）
  → 在 GSC 中提交
  → 說明你做了什麼來解決問題
  → 承認錯誤（如果是你造成的）
  → 說明未來如何避免

第 5 步：等待
  → 審查可能需要數天到數週
  → 如果被拒絕，加強清理後再次提交
```

### 重審請求的撰寫要點

```
✅ 好的請求包含：
  - 明確說明你識別出哪些連結是問題
  - 列出你手動聯繫移除的嘗試
  - 附上 Disavow 檔案
  - 承認錯誤（適用時）
  - 說明未來的預防措施

❌ 不好的請求：
  - 「我不知道為什麼被處罰」
  - 只說「我已經上傳了 Disavow 檔案」
  - 否認一切責任
  - 指責競爭對手（不是好的辯護）
```

## Disavow 的常見迷思

### 迷思 1：Disavow 是排名提升工具

**真相：** Disavow 是損害控制工具，不是排名提升工具。拒絕低品質連結不會讓你的排名上升——除非這些連結正在壓制你的排名。

### 迷思 2：你應該定期使用 Disavow 清理連結

**真相：** Google 強烈建議不要這樣做。Google 的 John Mueller 說：「如果你不確定某個連結是否應該被拒絕，不要拒絕。大多數網站完全不需要使用 Disavow 工具。」

### 迷思 3：Disavow 效果是即時的

**真相：** Disavow 檔案上傳後，Google 需要在下一次爬取這些連結時才會應用。這可能需要數週時間。

### 迷思 4：你應該拒絕所有低 DR/DA 的連結

**真相：** DR/DA 是第三方指標，Google 不使用它們來判斷連結品質。很多低 DR 的網站是完全合法和自然的。
