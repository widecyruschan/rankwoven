> 「關鍵字密度 3% 先會有排名」、「SEO 死咗啦」、「買幾個 .hk 連結就上到第一頁」— 香港 SEO 界嘅都市傳說多得驚人，尤其係啲「包上第一頁 HK$1,000/月」嘅推銷電話。本章用事實同邏輯逐一擊破。

---

## 迷思一：「SEO 己經過時了，AI 搜尋讓 SEO 沒用了」

### 真相：SEO 沒有過時，但 SEO 的方法改變了

```
2026 年的 SEO 確實和 2016 年不一樣：
- 不再能靠關鍵字堆砌取勝
- 不再能靠購買大量垃圾連結衝排名
- AI Overviews 改變了部分搜尋行為
- 香港用戶愈嚟愈多用 ChatGPT、Gemini、Copilot 直接問嘢

但 SEO 的核心從來沒有變：
「創造對用戶最有價值的內容，並確保搜尋引擎能夠找到和理解它」

AI 搜尋時代的 SEO：
- 內容品質比以往任何時候都重要
- 結構化資料成為新的基本功（FAQ Schema、Product Schema、LocalBusiness）
- 品牌權威度的重要性大幅提升
- 出現了新的機會：被 AI 引用、優化 llms.txt
- 香港視角：Google 香港仍佔 ~92-95%，而且 AI Overviews 嘅引用來源
  依然嚟自搜尋結果入面嘅網頁 → 排唔到名就唔會被引用
```

**結論：** SEO 沒有死，死的是舊的、操縱性的 SEO 手法。而家要做嘅係 SEO + GEO（生成式引擎優化）兩條腿行路。

## 迷思二：「只要把關鍵字塞滿頁面，排名就會上升」

### 真相：關鍵字堆砌（Keyword Stuffing）只會有反效果

Google 最後一次把關鍵字堆砌當成有效排名訊號，大概是十年前的事。

現代 Google 使用的是語意理解（BERT、MUM），它能理解：
- 同義詞（「抽濕機」=「除濕機」=「抽濕器」）
- 上下文（「Apple」係手機定係生果？「大廈」係樓定係大廈管理？）
- 相關主題（一篇完整的 SEO 文章不需要塞滿「SEO」）

```
香港常見反面教材：
❌ 「旺角裝修公司旺角裝修推薦旺角裝修報價旺角裝修邊間好」
   → 呢啲係 2010 年嘅手法，今日只會扣分

✅ 「旺角裝修公司點揀？2026 收費參考（HK$/呎）+ 8 間比較」
   → 一個主要關鍵字 + 自然覆蓋相關主題
```

**正確做法：** 自然地使用關鍵字和相關用語，專注在全面覆蓋主題，不要計算關鍵字出現次數。

## 迷思三：「買越多反向連結，排名越好」

### 真相：連結的品質遠比數量重要

```
極端例子：
- 網站 A：5 個來自香港主流媒體（香港01、經濟日報、明報）的連結 → 排名上升
- 網站 B：5,000 個來自垃圾目錄/論壇簽名檔的連結 → 被懲罰或沒效果

Google 的 Penguin 演算法（現已整合入核心）專門打擊連結操縱。
買來的連結看起來都一樣 → 很容易被機器學習識別。

香港市面常見陷阱：
  「HK$3,000 包 100 個 .hk 高質連結」
  「XX 個教育/政府網站連結套餐」
→ 呢啲幾乎全部都係 link farm / PBN，Google 一端就死
→ 而且呢啲係「買 dofollow 連結」，明確違反 Google 指引
```

**正確做法：** 專注在獲得少數高品質、編輯性給予的連結。一個嚟自香港主流媒體或者 .edu.hk 嘅連結，勝過千個垃圾連結。

## 迷思四：「網站上線後，Google 會自動找到我，不需要做什麼」

### 真相：Google 會找到你，但你應該幫它找到「正確的版本」

Google 確實會自動發現新網站，但如果沒有引導，它可能：
- 索引了錯誤的 URL（http vs https、www vs non-www、.hk vs .com）
- 錯過了重要頁面
- 索引速度很慢（香港新 .hk 網域可能要等好幾星期）

**正確做法：**
- 提交 XML Sitemap 到 GSC **同 Bing Webmaster Tools**（後者免費，順便 cover Yahoo 香港）
- 確保 robots.txt 沒有誤封（同時容許 AI 爬蟲：GPTBot、ClaudeBot、PerplexityBot、Google-Extended）
- 手動請求主要頁面建立索引
- 餐飲/零售：同步開 Google 商家檔案（GBP）同 OpenRice，令實體資料一致

## 迷思五：「SEO 做完一次就可以放著不管」

### 真相：SEO 是持續的過程，不是一次性的專案

```
競爭對手不會休息（香港同一區嘅補習社、裝修公司、餐廳全部都做緊 SEO）。
Google 的演算法會持續更新。
你的內容會過時（HK$ 價錢、地址、營業時間、法規）。
用戶的搜尋行為會改變（例如由「推薦」變咗「推介」、由網頁變咗小紅書）。
```

**做一次就停止的 SEO = 短暫的提升 + 長期的衰退。**

**正確做法：** 建立每月 SEO 維運節奏（內容更新、技術檢查、數據監控）。

## 迷思六：「Meta Description 是排名因素」

### 真相：Meta Description 不是直接的排名因素

Google 官方多次確認：Meta Description 不影響排名。

**但！它影響 CTR（點擊率），而 CTR 間接影響排名。**

一個好的 Meta Description：
- 讓你的搜尋結果在視覺上更吸引人
- 提高點擊率
- 間接地讓 Google 認為你的內容更相關

```
香港實用寫法：
❌ 「本公司提供專業優質的服務，歡迎查詢。」（冇人會撳）
✅ 「旺角補習社比較 2026：8 間收費（HK$180-$450/堂）、師資、
    家長真實評價一次睇晒。即睇邊間最抵。」
   → 有數字、有 HK$、有地區、有具體內容，CTR 差好遠
```

**正確做法：** 仍然要為每個重要頁面撰寫獨特的、有說服力的 Meta Description。你不寫，Google 會自動從你頁面擷取（很可能不夠好）。

## 迷思七：「排名第一就是 SEO 成功了」

### 真相：排名是手段，不是目的

```
糟糕的 SEO KPI：「我們要讓 XXX 排第一名」
好的 SEO KPI：「我們要讓有機流量成長 50%」或「SEO 轉換數成長 30%」

排名第一但：
- 搜尋量不到 100 → 幾乎沒人看到
  例如「元朗 24 小時 通渠」排第一，但全港每月得 20 次搜尋
- CTR 只有 1% → 很少人點進來
- 進來的流量都不轉換 → 沒有商業價值
  例如排第一嘅係「XX 邊間好」，但來嘅人淨係做功課，最後喺 OpenRice 落單

這不叫成功。
```

**正確做法：** 追蹤流量、轉換和 ROI，不只追蹤排名。香港中小企最實際嘅 KPI：每個月經網站/電話/WhatsApp 收到幾多單查詢。

## 迷思八：「用 AI 大量生成內容可以快速搶佔 SEO 排名」

### 真相：Google Helpful Content 系統專門打擊這種做法

2024-2025 年的多次 Google 更新中，大量依賴 AI 生成內容的網站遭到了嚴重的流量打擊。

Google 的標準很清楚：
- 「內容是為用戶建立的嗎？還是為搜尋引擎建立的？」
- 「內容展示第一手經驗和專業知識嗎？」
- 「讀完你的內容後，用戶還需要再搜尋其他資訊嗎？」

```
香港特別注意：
AI 生成繁中內容常見兩個致命問題：
1. 出簡體字或者台灣用語（「網絡」「部落格」「推薦」「除濕機」）
   → 香港用戶一睇就知唔係本地內容，跳出率極高
2. 「幻覺」嘅本地資訊（錯嘅 HK$ 價錢、錯嘅地區、錯嘅法規）
   → 對金融、醫療、地產呢啲 YMYL 行業係災難級，仲可能有合規風險
```

**AI 內容的正確用法：**
- AI 輔助研究和大綱
- AI 生成初稿 → 人工深度編輯、加入原創觀點和第一手經驗（例如你真係試過嗰 5 部抽濕機）
- 校對返香港繁中用語同 HK$ 價錢
- 不要把 AI 當成內容工廠

## 迷思九：「社群媒體的粉絲數和分享數直接影響 Google 排名」

### 真相：社群訊號不是 Google 的直接排名因素

Google 的官方說法是：社群媒體的分享、按讚、粉絲數不是排名因素。

**但社群媒體間接影響 SEO：**
- 社群推廣 → 更多人看到你的內容 → 更多人連結到你的內容 → 更多反向連結
- 社群曝光 → 品牌搜尋增加 → 品牌權威度提升
- 社群上的內容被更多網站引用 → 反向連結增加

```
香港嘅社群平台點分工：
- 連登（LIHKG）/ Uwants：主要價值係「品牌監控 + 關鍵字挖掘 + 口碑」
  → 唔係用嚟落廣告（會被圍攻），而係用嚟聽香港人真實講咩
- Facebook 社團：香港滲透率最高，擴散力最強（直接流量 + 品牌搜尋）
- Instagram / 小紅書：提升品牌搜尋量（用戶見到 → 上 Google 搜你個名）
- YouTube：Google 索引最強，影片可以直接出喺 Google SERP
- OpenRice（餐飲）：佢嘅頁面自己會排第一頁，係餐飲 SEO 嘅主戰場之一

⚠️ 另外：Bing 官方承認社群訊號係排名因素
   → 而 Yahoo 香港用 Bing 技術，所以 FB/IG 活躍對 Yahoo 香港係有直接幫助
```

**結論：** 為了 SEO 的間接效果（和品牌價值），社群媒體仍然值得經營。但不要期待貼文分享數增加就能直接提升 Google 排名。

## 迷思十：「Google Ads 投放可以幫助 SEO 排名」

### 真相：廣告投放和自然排名是完全獨立的系統

Google 官方多次強調：付費廣告（Google Ads）不會直接影響自然搜尋排名。付錢給 Google 不會讓你的自然排名變好。

**但廣告可以間接幫助 SEO：**
- 廣告數據：知道哪些關鍵字轉換好 → 優先用於 SEO 內容
- 品牌曝光：廣告讓更多人認識你的品牌 → 品牌搜尋增加
- 佔據 SERP：廣告 + 自然排名同時出現 = 更多點擊

```
香港實用做法（尤其新網站/新行業）：
1. 先用 Google Ads 少量投放（例如 HK$3,000-5,000/月）測試關鍵字
2. 2-4 星期後睇數據：邊啲字有點擊、有轉換、CPC 幾錢
3. 將轉換好嘅字優先寫 SEO 內容（長期免費流量）
4. 逐步減廣告、增自然流量

→ 呢個係香港中小企最常用嘅「以廣告養 SEO」策略
```

**結論：** 花錢投廣告不會直接提升排名。但廣告數據和品牌曝光能幫助你做出更好的 SEO 決策。

## 加分題：你可能也相信的 SEO 都市傳說（香港版）

| 都市傳說 | 真相 |
|----------|------|
| 「域名越老排名越好」 | 域名年齡的直接影響極小。老域名通常排名好是因為累積了內容和連結（Bing/Yahoo 會稍為睇重啲） |
| 「SSL 憑證的類型（EV > DV）影響排名」 | 所有 SSL 類型對 SEO 的影響都一樣 |
| 「中文 URL 對 SEO 不好」 | 中文 URL 會被編碼成 %XX%XX，對用戶不友好但對 SEO 沒有負面影響 |
| 「網站一定要天天更新才有排名」 | 頻繁更新有幫助但非必要。高品質的靜態內容也可以長期排名 |
| 「Bounce Rate（跳出率）是 Google 排名因素」 | Google 說不是。他們用的是更複雜的用戶滿意度訊號 |
| 「用 .com 好過 .hk」 | 視乎市場。主力做香港本地客，.hk/.com.hk 嘅本地信任度同地區訊號更強；做出海先用 .com |
| 「上連登發帖可以提升 Google 排名」 | 連登帖唔係你嘅網站，唔會直接提升你嘅排名。價值在於監控口碑、發掘廣東話關鍵字；直接落硬廣告仲會被圍攻 |

## 如何避免被 SEO 迷思誤導？

### 三條黃金法則

```
法則一：Google 官方說法優先
  → Google Search Central Blog、官方 X/Twitter 帳號
  → 香港相關：Bing Webmaster Tools Blog（Yahoo 香港用 Bing 技術）

法則二：數據 > 感覺
  → 用你自己的網站做測試（GSC + GA4 係免費嘅）
  → 唔好淨係聽人講「XXX 有效」，要睇數據
  → 香港特別注意：排名工具地區要 set 做「香港」，語言 set 繁中

法則三：常理判斷
  → 如果一個 SEO 技巧聽起來太簡單就能見效
  → 那它大概不是真的（或者是黑帽手法）
  → 「HK$1,000/月包上第一頁」呢類，用常理都知唔可能
```
