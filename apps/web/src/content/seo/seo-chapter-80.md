> 唔使係 SEO 專家都做得到嘅網站健檢。8 個步驟，1 小時內搵出你網站最需要修嘅 SEO 問題。
>
> 香港版加咗幾樣本地嘢：`.hk` 域名檢查、中英雙語 hreflang、Google 商家檔案（GBP）、OpenRice／本地引用、Yahoo 香港（Bing 索引）、同埋 PDPO 私隱合規。全部都係免費工具做得到。

## 健檢哲學：80/20 法則

大多數網站的 SEO 問題，80% 集中在 20% 的地方：
- 索引問題（被 noindex / robots.txt 封鎖）
- 內容品質（太短、太舊、太重複；或者繁中／英文版互相打架）
- 速度太慢（特別是手機版 — 香港用戶九成用手機睇）
- 行動版體驗不佳
- 沒有明確的目標關鍵字
- **本地 SEO 從未設定（GBP 未認領、NAP 不一致）** ← 香港網站最常見

這 8 個步驟專注於最常見、影響最大的問題。

## 步驟 1：檢查網站是否可以被 Google 找到（5 分鐘）

### 檢查一：Google 索引測試

```
打開 Google（建議用 google.com.hk）→ 搜尋：site:你的域名.hk
```

| 結果 | 意義 | 行動 |
|------|------|------|
| 看到你的頁面 | ✅ 網站有被索引 | 進行步驟 2 |
| 完全沒有結果 | 🔴 網站被 Google 封鎖 | 立即檢查 robots.txt 和 noindex |
| 只有首頁被索引 | 🟡 可能有技術問題 | 提交 Sitemap，檢查 noindex |
| 頁面數量遠少於預期 | 🟡 索引率低 | 檢查內容品質和 Crawl Budget |
| 淨係見到英文版／簡中版 | 🟡 hreflang 出錯 | 檢查多語言設定 |

### 檢查二：robots.txt

```
打開：你的域名.hk/robots.txt

如果看到：
  User-agent: *
  Disallow: /

→ 🔴 你的網站被完全封鎖！這是緊急狀況！
  立即修改 robots.txt 為：
  User-agent: *
  Allow: /
```

同時檢查有冇封鎖咗 AI 搜尋爬蟲（GPTBot / OAI-SearchBot / ClaudeBot / PerplexityBot）— 2026 年愈嚟愈多香港用戶用 ChatGPT、Gemini、Copilot 搵資料，封錯咗會失去 AI 引用機會。

### 檢查三：GSC 手動操作

```
GSC → 安全性與手動操作 → 手動操作

如果有任何通知 → 🔴 這是頭號優先處理的問題
```

> ⚠️ **香港常見情況：** 好多香港公司個 GSC 係當年開網站嗰間設計公司／SEO 公司開嘅，你根本入唔到去。如果係咁，即刻用 DNS 驗證建立新資源（DNS TXT record），唔使靠對方。呢個係健檢第一步嘅前置動作。

### 檢查四（香港加檢）：Yahoo 香港 / Bing 索引

```
到 hk.yahoo.com 搜尋：site:你的域名.hk

Yahoo 香港約 3-6% 份額，用嘅係 Bing 索引
（亦係 Microsoft Copilot 嘅搜尋來源）
如果完全冇結果 → 去 Bing Webmaster Tools
                 提交 Sitemap（免費，幾分鐘搞掂）
```

## 步驟 2：檢查核心頁面是否被索引（10 分鐘）

### 逐個檢查核心頁面

```
在 GSC 中使用「網址檢查」功能，檢查以下頁面：

☐ 首頁
☐ 主要分類頁面
☐ 最重要的 5 篇內容
☐ 關於我們頁面
☐ 聯絡頁面
☐ 地區/分店頁面（如適用，例如「中環分店」）
☐ 英文版首頁（如有多語言）
```

每個頁面的 URL Inspection 結果：
- 「網址在 Google 服務中」→ ✅ 已索引
- 「網址不在 Google 服務中」→ 🔴 未索引，需要調查原因

### 常見未索引原因及解法

```
原因：排除 (noindex)
→ 檢查頁面的 <meta name="robots" content="noindex"> 標籤
→ 如果不需要 noindex → 移除標籤 → 請求重新索引

原因：漫遊器已排除 (robots.txt)
→ 檢查 robots.txt 是否封鎖了該頁面
→ 修改 robots.txt → 請求重新索引

原因：已檢索 — 目前未建立索引
→ Google 認為內容品質不足
→ 改善內容深度和原創性
→ 增加內部連結
→ 香港常見：地區頁內容一式一樣只改地區名，
   被判「重複內容」→ 要為每區寫真實差異化內容

原因：重複網頁
→ 設定正確的 Canonical
→ 多語言網站要設 hreflang（zh-HK / en-HK / zh-CN）
→ 或差異化頁面內容
```

## 步驟 3：檢查網站速度（行動版）（10 分鐘）

### 使用 PageSpeed Insights 測試

```
https://pagespeed.web.dev/

測試你的首頁 + 最重要的 3 個頁面
一定要測試「行動版」（Mobile）的表現
```

### 快速解讀分數

```
Core Web Vitals 評估結果：

🟢 全部通過
   → 很好，網站速度不是大問題

🟡 部分需要改善
   → 查看具體哪個指標有問題
   → LCP 問題：優化最大圖片、啟用 CDN
   → INP 問題：減少 JavaScript 執行時間
   → CLS 問題：圖片加上 width/height 屬性

🔴 全部未通過
   → 速度是你 SEO 的重大障礙
   → 優先處理以下三項（見效最快）：
     1. 圖片壓縮 + 轉 WebP
     2. 啟用 CDN（揀有香港／亞太節點嘅）
     3. 啟用瀏覽器快取
```

> 🇭🇰 **香港特別注意：** PageSpeed Insights 嘅測試節點未必喺香港，分數只作參考。最好再用手機（用香港流動網絡，唔好駁 Wi-Fi）實際開一次，計吓幾耐先出到畫面。香港用戶喺地鐵、商場訊號唔穩陣時，慢網體驗差好遠。

## 步驟 4：檢查行動版體驗（5 分鐘）

### 使用 Google 行動裝置相容性測試

```
https://search.google.com/test/mobile-friendly

輸入你的首頁 URL 測試
```

### 常見行動版問題與解法

| 問題 | 解法 |
|------|------|
| 文字太小 | 基本字體大小至少 16px |
| 點擊元素太近 | 按鈕之間至少 8px 間距 |
| 內容超出螢幕 | 檢查 CSS overflow，使用 max-width |
| Viewport 未設定 | 加入 `<meta name="viewport" content="width=device-width, initial-scale=1.0">` |
| 彈出視窗擋畫面 | 香港好多網站一開就彈 WhatsApp／優惠 popup，Google 會扣分行動版體驗 |

### 手機實際瀏覽測試

```
用手機打開你的網站，快速檢查：
☐ 文字不需要放大就能閱讀？
☐ 按鈕夠大、容易點擊？（手指不會點錯）
☐ 不需要橫向捲動？
☐ 圖片正常顯示？
☐ 表單容易填寫？（香港地址欄位好難填，建議用自動完成）
☐ 彈出視窗不會擋住整個畫面？
☐ WhatsApp / 電話按鈕一撳就用到？（香港用戶最常用）
```

## 步驟 5：檢查 On-Page SEO 基礎（15 分鐘）

### Title Tag 檢查

```
用 Screaming Frog（免費版可以爬 500 頁）或手動檢查：

☐ 每個頁面有獨特的 Title Tag？
☐ Title 在 50-60 字元範圍內？
☐ 重要關鍵字在 Title 的前面？
☐ 沒有重複的 Title？
☐ 有冇加入香港元素（地區名、HK$、年份）？

常見問題：
❌ 所有頁面 Title 都一樣 → 加入動態變數或手動撰寫
❌ Title 太長被截斷 → 縮短到 60 字元以內
❌ Title 沒有關鍵字 → 加入主要關鍵字
❌ Title 是「未命名頁面」或「Home」→ 立即修改
❌ 繁中版 Title 出現簡體字或台式用語 → 統一用香港繁中
```

### Meta Description 檢查

```
☐ 每個重要頁面有 Meta Description？
☐ Description 是獨特的、有說服力的？
☐ 包含行動號召（CTA）？
☐ 有冇提到 HK$ 價錢或服務地區？（提升香港用戶點擊）

常見問題：
❌ 完全沒有 Description → 讓 Google 自動從內容擷取（可能不理想）
❌ 所有頁面 Description 都一樣 → Google 可能全部忽略
```

### Heading 結構檢查

```
☐ 每個頁面只有一個 H1？
☐ H1 包含主要關鍵字？
☐ H2/H3 形成邏輯層次（不是跳級，如 H1 → H3 跳過 H2）？
☐ Heading 不是用 <p> 或 <div> 偽裝的？
```

### 多語言 / hreflang 檢查（香港網站必檢）

```
☐ <html lang="zh-HK">（唔係 zh-TW / zh-CN）？
☐ 每個語言版本有對應嘅 hreflang？
  zh-HK（繁中香港）/ en-HK（英文香港）/ zh-CN（簡中）
☐ hreflang 有冇自我指向 + 互相指向？
☐ 有冇設 x-default？
☐ 英文版係咪真係英文（唔係機翻）？
```

### 圖片 SEO 檢查

```
隨機抽查 10 張圖片：

☐ 圖片有描述性的檔案名稱？（不是 IMG_001.jpg）
☐ 內容圖片有 alt 文字？（繁中描述）
☐ 裝飾性圖片有 alt=""（空字串）？
☐ 圖片檔案大小合理？（<200KB 為佳，大圖 <500KB）
☐ 係咪 WebP / 有冇 lazy loading？
```

## 步驟 6：檢查內容品質（15 分鐘）

### 隨機抽樣審查

```
隨機選擇 10 個內容頁面，針對每個頁面問：

☐ 內容是否有獨特的價值？
   → 使用者讀完能學到什麼？
   → 有其他網站不能提供的東西嗎？
   → 有冇提供香港本地資訊（HK$ 價錢、地區、
     本地法規、香港案例）？

☐ 內容是否滿足搜尋意圖？
   → 如果用戶搜「香港 裝修 報價 點計」，
     他得到的內容真的教會他了嗎？

☐ 是否有實質的深度？
   → 字數不是絕對標準，但一個有價值的內容通常 >800 字
   → 有數據、案例、圖片來支持觀點嗎？

☐ 內容是否過時？
   → 有提到年份/日期嗎？是最新的嗎？
   → HK$ 價錢係咪仲啱？
   → 外部連結是否還有效？

☐ 是否好讀？
   → 有適當的段落間距嗎？
   → 有使用列表和標題來組織內容嗎？
   → 行動版的可讀性好嗎？
   → 用語係咪地道香港繁中（唔係台式／大陸用語）？
```

### 低品質內容處理

```
如果你的網站有大量低品質頁面：

處理方式：
1. 改善：增加內容深度和價值（優先處理有流量的頁面）
2. 合併：將多個短內容合併成一篇深度文章
3. 刪除：對完全沒有價值的頁面，刪除或 301 轉址到相關頁面
   （香港常見：18 區頁面一式一樣 → 合併或逐區改寫）

注意：如果低品質頁面比例很高（>30%），
     這是 Google Helpful Content 系統會打擊的目標。

⚠️ 香港特別常見：直接將大陸／台灣嘅內容轉繁中放上香港站，
   冇加入任何本地資訊。呢類內容最容易中 Helpful Content。
```

## 步驟 7：檢查反向連結與本地引用（5 分鐘）

### 快速連結健康檢查

```
使用 Ahrefs 免費版（Site Explorer 免費有限功能）或 SEMrush：

☐ 你的引用網域（Referring Domains）數量？
   → 完全沒有 > 你的網站幾乎沒有權威度
   → 少於 10 > 需要開始連結建設
   → 10-50 > 正常成長中
   （香港市場細，本地網站嘅基數普遍比英美細，
     唔好直接同外國 benchmark 比）

☐ 連結來源品質：
   → 快速瀏覽 Top 20 來源網站
   → 有沒有來自色情/博弈/垃圾內容的連結？
   → 有冇香港本地來源（媒體、商會、目錄、OpenRice）？

☐ 錨點文字（Anchor Text）：
   → 品牌錨點（品牌名）應該佔最大比例
   → 精準匹配錨點（商業關鍵字）不應該超過 20%
   → 如果精準匹配 >50% > 高度可疑，可能是連結操縱
```

### 如果有很多低品質連結

```
先別恐慌！除非：
1. 低品質連結佔比極高（>50%）
2. 或者你已經收到了 GSC 的手動操作通知

如果以上兩個條件都不符合：
→ 大部分情況下 Google 會自動忽略低品質連結
→ 不需要主動 Disavow
→ 但如果很擔心，可以選擇性 Disavow 最惡意的來源

如果你收到了手動操作通知：
→ 按照手動操作的處理流程（聯絡移除 + Disavow + 重審）
```

### 香港本地引用快速檢查（5 分鐘）

```
☐ Google 商家檔案（GBP）係咪已經認領？
   → 搜尋你公司名 + 地區，睇吓有冇 Google Maps 資料
   → 未認領即刻認領（免費，本地 SEO 基石）

☐ NAP（名稱 / 地址 / 電話）一致性
   → 網站、GBP、Facebook、OpenRice、目錄
     五個地方嘅資料係咪完全一樣？
   → 地址格式：香港格式（室號/樓層、大廈、街道、地區）
   → 電話：+852 開頭

☐ 有冇本地評論？
   → Google 評論數量與評分
   → 餐飲：OpenRice 評分
   → 旅遊：TripAdvisor 評分
   → 有冇回覆評論？（有回覆會加分）

☐ 私隱與合規（香港）
   → 私隱政策頁存在並符合 PDPO？
   → 有收集資料嘅話有冇 Cookie 提示？
   → 價錢有冇標 HK$ 並列明是否包其他費用？
     （消委會指引）
```

## 步驟 8：建立改善優先級清單（10 分鐘）

### 將所有問題按影響 × 難度排序

```
影響力：高（影響大量頁面或核心頁面）
       中（影響部分頁面）
       低（影響少數次要頁面）

難度：  低（<1 小時可修復）
       中（1-4 小時可修復）
       高（需要開發團隊或大量時間）

優先級矩陣：
            難度低      難度中      難度高
影響力高  ┌──────────┬──────────┬──────────┐
          │ 🔴 P0    │ 🔴 P0    │ 🟡 P1   │
          │ 立即處理  │ 立即處理  │ 本周處理  │
          ├──────────┼──────────┼──────────┤
影響力中  │ 🟡 P1    │ 🟡 P1    │ 🟢 P2   │
          │ 本周處理  │ 本周處理  │ 本月處理  │
          ├──────────┼──────────┼──────────┤
影響力低  │ 🟢 P2    │ 🟢 P2    │ ⚪ P3   │
          │ 本月處理  │ 本月處理  │ 有空再處理 │
          └──────────┴──────────┴──────────┘
```

### 常見的 P0 問題（立即處理）

```
1. robots.txt 封鎖了整個網站
2. 重要頁面有 noindex 標籤
3. 網站完全沒有被 Google 索引
4. GSC 有手動操作通知
5. 首頁 Title Tag 空白或無意義
6. 網站速度極慢（LCP > 6 秒）
7. 行動版完全無法使用
8. GSC 出現安全性問題通知
9. （香港）GBP 未認領 / 被誤標為「已結束營業」
10. （香港）hreflang 錯誤導致英文版食咗繁中版流量
```

## 健檢頻率建議

| 網站狀態 | 健檢頻率 | 說明 |
|----------|----------|------|
| 新網站（<6 個月） | 每 2 週 | 快速迭代，問題多 |
| 成長期網站 | 每月 | 持續監控 |
| 穩定網站 | 每季 | 注重趨勢而非細節 |
| 每次 Google 核心更新後 | 立即 | 檢查影響 |
| 改版 / 搬域名後 | 第 1 週每日、之後每週 | 見第 78 章 |
| 香港旺季前 6-10 週 | 加做一次 | 確認旺季頁面上榜 |

| 7 | 反向連結 + 本地引用 | 5 分鐘 | 來源品質 + 錨點比例 + GBP/NAP |
| 8 | 改善計畫 | 10 分鐘 | P0 → P1 → P2 排序 |

> 💡 **每個月花 1 小時跑完呢 8 步。唔使 SEO 專家都可以搵到最關鍵嘅問題。**
