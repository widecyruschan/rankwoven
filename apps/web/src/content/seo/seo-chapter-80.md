> 不需要是 SEO 專家也能完成的網站健檢。8 個步驟，1 小時內找到你網站最需要修復的 SEO 問題。

---

## 健檢哲學：80/20 法則

大多數網站的 SEO 問題，80% 集中在 20% 的地方：
- 索引問題（被 noindex / robots.txt 封鎖）
- 內容品質（太短、太舊、太重複）
- 速度太慢（特別是手機版）
- 行動版體驗不佳
- 沒有明確的目標關鍵字

這 8 個步驟專注於最常見、影響最大的問題。

## 步驟 1：檢查網站是否可以被 Google 找到（5 分鐘）

### 檢查一：Google 索引測試

```
打開 Google → 搜尋：site:你的域名.com
```

| 結果 | 意義 | 行動 |
|------|------|------|
| 看到你的頁面 | ✅ 網站有被索引 | 進行步驟 2 |
| 完全沒有結果 | 🔴 網站被 Google 封鎖 | 立即檢查 robots.txt 和 noindex |
| 只有首頁被索引 | 🟡 可能有技術問題 | 提交 Sitemap，檢查 noindex |
| 頁面數量遠少於預期 | 🟡 索引率低 | 檢查內容品質和 Crawl Budget |

### 檢查二：robots.txt

```
打開：你的域名.com/robots.txt

如果看到：
  User-agent: *
  Disallow: /

→ 🔴 你的網站被完全封鎖！這是緊急狀況！
  立即修改 robots.txt 為：
  User-agent: *
  Allow: /
```

### 檢查三：GSC 手動操作

```
GSC → 安全性與手動操作 → 手動操作

如果有任何通知 → 🔴 這是頭號優先處理的問題
```

## 步驟 2：檢查核心頁面是否被索引（10 分鐘）

### 逐個檢查核心頁面

```
在 GSC 中使用「網址檢查」功能，檢查以下頁面：

☐ 首頁
☐ 主要分類頁面
☐ 最重要的 5 篇內容
☐ 關於我們頁面
☐ 聯絡頁面
```

每個頁面的 URL Inspection 結果：
- 「網址在 Google 服務中」→ ✅ 已索引
- 「網址不在 Google 服務中」→ 🔴 未索引，需要調查原因

### 常見未索引原因及解法

```
原因：排除 (noindex)
→ 檢查頁面的 <meta name="robots" content="noindex"> 標籤
→ 如果不需要 noindex → 移除標籤 → 請求重新索引

原因：漫遊器已排除 (robots.txt)
→ 檢查 robots.txt 是否封鎖了該頁面
→ 修改 robots.txt → 請求重新索引

原因：已檢索 — 目前未建立索引
→ Google 認為內容品質不足
→ 改善內容深度和原創性
→ 增加內部連結

原因：重複網頁
→ 設定正確的 Canonical
→ 或差異化頁面內容
```

## 步驟 3：檢查網站速度（行動版）（10 分鐘）

### 使用 PageSpeed Insights 測試

```
https://pagespeed.web.dev/

測試你的首頁 + 最重要的 3 個頁面
一定要測試「行動版」（Mobile）的表現
```

### 快速解讀分數

```
Core Web Vitals 評估結果：

🟢 全部通過
   → 很好，網站速度不是大問題

🟡 部分需要改善
   → 查看具體哪個指標有問題
   → LCP 問題：優化最大圖片、啟用 CDN
   → INP 問題：減少 JavaScript 執行時間
   → CLS 問題：圖片加上 width/height 屬性

🔴 全部未通過
   → 速度是你 SEO 的重大障礙
   → 優先處理以下三項（見效最快）：
     1. 圖片壓縮 + 轉 WebP
     2. 啟用 CDN
     3. 啟用瀏覽器快取
```

## 步驟 4：檢查行動版體驗（5 分鐘）

### 使用 Google 行動裝置相容性測試

```
https://search.google.com/test/mobile-friendly

輸入你的首頁 URL 測試
```

### 常見行動版問題與解法

| 問題 | 解法 |
|------|------|
| 文字太小 | 基本字體大小至少 16px |
| 點擊元素太近 | 按鈕之間至少 8px 間距 |
| 內容超出螢幕 | 檢查 CSS overflow，使用 max-width |
| Viewport 未設定 | 加入 `<meta name="viewport" content="width=device-width, initial-scale=1.0">` |

### 手機實際瀏覽測試

```
用手機打開你的網站，快速檢查：
☐ 文字不需要放大就能閱讀？
☐ 按鈕夠大、容易點擊？（手指不會點錯）
☐ 不需要橫向捲動？
☐ 圖片正常顯示？
☐ 表單容易填寫？
☐ 彈出視窗不會擋住整個畫面？
```

## 步驟 5：檢查 On-Page SEO 基礎（15 分鐘）

### Title Tag 檢查

```
用 Screaming Frog（免費版可以爬 500 頁）或手動檢查：

☐ 每個頁面有獨特的 Title Tag？
☐ Title 在 50-60 字元範圍內？
☐ 重要關鍵字在 Title 的前面？
☐ 沒有重複的 Title？

常見問題：
❌ 所有頁面 Title 都一樣 → 加入動態變數或手動撰寫
❌ Title 太長被截斷 → 縮短到 60 字元以內
❌ Title 沒有關鍵字 → 加入主要關鍵字
❌ Title 是「未命名頁面」或「Home」→ 立即修改
```

### Meta Description 檢查

```
☐ 每個重要頁面有 Meta Description？
☐ Description 是獨特的、有說服力的？
☐ 包含行動號召（CTA）？

常見問題：
❌ 完全沒有 Description → 讓 Google 自動從內容擷取（可能不理想）
❌ 所有頁面 Description 都一樣 → Google 可能全部忽略
```

### Heading 結構檢查

```
☐ 每個頁面只有一個 H1？
☐ H1 包含主要關鍵字？
☐ H2/H3 形成邏輯層次（不是跳級，如 H1 → H3 跳過 H2）？
☐ Heading 不是用 <p> 或 <div> 偽裝的？
```

### 圖片 SEO 檢查

```
隨機抽查 10 張圖片：

☐ 圖片有描述性的檔案名稱？（不是 IMG_001.jpg）
☐ 內容圖片有 alt 文字？
☐ 裝飾性圖片有 alt=""（空字串）？
☐ 圖片檔案大小合理？（<200KB 為佳，大圖 <500KB）
```

## 步驟 6：檢查內容品質（15 分鐘）

### 隨機抽樣審查

```
隨機選擇 10 個內容頁面，針對每個頁面問：

☐ 內容是否有獨特的價值？
   → 使用者讀完能學到什麼？
   → 有其他網站不能提供的東西嗎？

☐ 內容是否滿足搜尋意圖？
   → 如果用戶搜「如何 XXX」，他得到的內容真的教會他了嗎？

☐ 是否有實質的深度？
   → 字數不是絕對標準，但一個有價值的內容通常 >800 字
   → 有數據、案例、圖片來支持觀點嗎？

☐ 內容是否過時？
   → 有提到年份/日期嗎？是最新的嗎？
   → 外部連結是否還有效？

☐ 是否好讀？
   → 有適當的段落間距嗎？
   → 有使用列表和標題來組織內容嗎？
   → 行動版的可讀性好嗎？
```

### 低品質內容處理

```
如果你的網站有大量低品質頁面：

處理方式：
1. 改善：增加內容深度和價值（優先處理有流量的頁面）
2. 合併：將多個短內容合併成一篇深度文章
3. 刪除：對完全沒有價值的頁面，刪除或 301 轉址到相關頁面

注意：如果低品質頁面比例很高（>30%），
     這是 Google Helpful Content 系統會打擊的目標。
```

## 步驟 7：檢查反向連結健康度（5 分鐘）

### 快速連結健康檢查

```
使用 Ahrefs 免費版（Site Explorer 免費有限功能）或 SEMrush：

☐ 你的引用網域（Referring Domains）數量？
   → 完全沒有 > 你的網站幾乎沒有權威度
   → 少於 10 > 需要開始連結建設
   → 10-50 > 正常成長中

☐ 連結來源品質：
   → 快速瀏覽 Top 20 來源網站
   → 有沒有來自色情/博弈/垃圾內容的連結？

☐ 錨點文字（Anchor Text）：
   → 品牌錨點（品牌名）應該佔最大比例
   → 精準匹配錨點（商業關鍵字）不應該超過 20%
   → 如果精準匹配 >50% > 高度可疑，可能是連結操縱
```

### 如果有很多低品質連結

```
先別恐慌！除非：
1. 低品質連結佔比極高（>50%）
2. 或者你已經收到了 GSC 的手動操作通知

如果以上兩個條件都不符合：
→ 大部分情況下 Google 會自動忽略低品質連結
→ 不需要主動 Disavow
→ 但如果很擔心，可以選擇性 Disavow 最惡意的來源

如果你收到了手動操作通知：
→ 按照手動操作的處理流程（聯絡移除 + Disavow + 重審）
```

## 步驟 8：建立改善優先級清單（10 分鐘）

### 將所有問題按影響 × 難度排序

```
影響力：高（影響大量頁面或核心頁面）
       中（影響部分頁面）
       低（影響少數次要頁面）

難度：  低（<1 小時可修復）
       中（1-4 小時可修復）
       高（需要開發團隊或大量時間）

優先級矩陣：
            難度低      難度中      難度高
影響力高  ┌──────────┬──────────┬──────────┐
          │ 🔴 P0    │ 🔴 P0    │ 🟡 P1   │
          │ 立即處理  │ 立即處理  │ 本周處理  │
          ├──────────┼──────────┼──────────┤
影響力中  │ 🟡 P1    │ 🟡 P1    │ 🟢 P2   │
          │ 本周處理  │ 本周處理  │ 本月處理  │
          ├──────────┼──────────┼──────────┤
影響力低  │ 🟢 P2    │ 🟢 P2    │ ⚪ P3   │
          │ 本月處理  │ 本月處理  │ 有空再處理 │
          └──────────┴──────────┴──────────┘
```

### 常見的 P0 問題（立即處理）

```
1. robots.txt 封鎖了整個網站
2. 重要頁面有 noindex 標籤
3. 網站完全沒有被 Google 索引
4. GSC 有手動操作通知
5. 首頁 Title Tag 空白或無意義
6. 網站速度極慢（LCP > 6 秒）
7. 行動版完全無法使用
8. GSC 出現安全性問題通知
```

## 健檢頻率建議

| 網站狀態 | 健檢頻率 | 說明 |
|----------|----------|------|
| 新網站（<6 個月） | 每 2 週 | 快速迭代，問題多 |
| 成長期網站 | 每月 | 持續監控 |
| 穩定網站 | 每季 | 注重趨勢而非細節 |
| 每次 Google 核心更新後 | 立即 | 檢查影響 |

## 本章重點回顧

| 步驟 | 檢查內容 | 時間 | 最重要的一件事 |
|------|----------|------|---------------|
| 1 | 索引狀態 | 5 分鐘 | site: 搜尋 + robots.txt |
| 2 | 核心頁面索引 | 10 分鐘 | GSC URL Inspection |
| 3 | 網站速度 | 10 分鐘 | PageSpeed Insights 行動版 |
| 4 | 行動版體驗 | 5 分鐘 | 實際用手機測 |
| 5 | On-Page SEO | 15 分鐘 | Title / Meta / H1 / 圖片 |
| 6 | 內容品質 | 15 分鐘 | 抽樣 10 篇誠實評估 |
| 7 | 反向連結 | 5 分鐘 | 來源品質 + 錨點比例 |
| 8 | 改善計畫 | 10 分鐘 | P0 → P1 → P2 排序 |

> 💡 **每個月花 1 小時跑完這 8 步。不需要 SEO 專家也能找到最關鍵的問題。**
