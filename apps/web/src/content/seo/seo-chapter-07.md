## 搜尋意圖比關鍵字更重要

> **Google 的終極目標不是匹配關鍵字，而是滿足意圖。**

2013 年 Hummingbird 演算法上線後，Google 從「字面匹配」轉向「意圖理解」。你搜「蘋果」，Google 要判斷你想找的是水果、iPhone、還是股票代號——這就是意圖識別。2026 年的今天，這個能力已經極其精準。

對 SEO 來說，**理解搜尋意圖 = 理解 Google 的評分標準**。你的內容不符合用戶的真正意圖，關鍵字再精準也沒用。

> **香港版特別要留意**：香港人搜尋時成日 **繁中 + 廣東話口語 + 英文** 三樣撈埋，例如「邊間好」「推介」「點揀」「平唔平」「值唔值」「mortgage 邊間平」。同一個意圖可以有好幾種截然不同嘅寫法。如果你只優化書面語、忽略口語寫法，就好可能錯失咗香港人真正打入搜尋框嗰句說話。判斷意圖時，一定要用香港人嘅語言去搜、去驗證。

## 四大搜尋意圖

```
         ┌──────────────────────────┐
         │   搜尋意圖四象限          │
         ├──────────┬───────────────┤
         │ 資訊型   │  商業調查型    │
         │ Know     │  Consider     │
         ├──────────┼───────────────┤
         │ 導航型   │  交易型        │
         │ Go       │  Buy          │
         └──────────┴───────────────┘
```

---

## 一、資訊型意圖（Informational Intent）——「我想知道」

用戶想學習、了解或研究某個主題。

### 典型查詢模式

| 查詢詞開頭 | 範例 |
|-----------|------|
| 什麼是... | 「什麼是 SEO」 |
| 如何... | 「如何優化網站速度」 |
| 為什麼... | 「為什麼網站排名下降了」 |
| 教學 / 指南 | 「WordPress SEO 教學」 |
| 意思 / 定義 | 「Core Web Vitals 意思」 |
| 點 / 點樣（廣東話） | 「Google 商家檔案點樣申請」 |

### 內容策略

- **教學型文章**：步驟清晰的 how-to 指南
- **定義型文章**：名詞解釋、概念說明
- **終極指南**：一個主題的完整深度文章
- **清單型文章**：Top 10、完整列表
- **FAQ 頁面**：常見問題解答集

### SERP 特徵
- 精選摘要（Featured Snippet）出現率高
- People Also Ask（PAA）幾乎必出現
- 圖片 / 影片結果常見
- AI Overview 覆蓋率高

### 轉換策略
> 資訊型搜尋者**還沒有購買意願**。不要硬銷，而是用內容建立信任。引導方式：文章底部放相關資源連結、Email 訂閱、免費工具下載。

> **香港例子**：搜「香港有限公司點樣報稅」嘅人，只係想搞清楚流程，唔係想即刻搵會計師。呢篇文應該係一份清晰指南（邊個要報、幾時報、要乜文件），底部先至放「免費報稅 checklist 下載」或者「會計師免費諮詢」嘅 CTA。

---

## 二、導航型意圖（Navigational Intent）——「我想去」

用戶已經知道要去哪個網站，只是透過搜尋引擎來導航。

### 典型查詢模式

| 查詢詞 | 意圖 |
|--------|------|
| 「Facebook 登入」 | 直接去 Facebook 登入頁 |
| 「Ahrefs」 | 前往 Ahrefs 官網 |
| 「香港中央圖書館」 | 找到圖書館官網 |
| 「HKTVmall」 | 前往 HKTVmall 網店 |
| 「OpenRice」 | 前往開飯喇搵餐廳 |

### 內容策略

- **品牌官網 SEO**：確保品牌名稱搜尋第一名是你自己（這不是理所當然的！香港好多品牌名會畀 OpenRice、Facebook 專頁、討論區甚至代理商版面搶咗第一位）
- **登入頁面優化**：確保登入頁可以被搜尋引擎索引（如果需要）或正確使用 noindex
- **品牌 SERP 佔領**：確保搜尋品牌名時，出現的是正確的官網、社群連結、Knowledge Panel

### 特殊情況
- **品牌關鍵字被競品搶佔**：競爭對手可能投放你的品牌名廣告，搶走你的流量。你需要做好品牌 SEO 並考慮投放品牌字廣告做防禦。
- **被本地平台「插隊」**：喺香港，搜你品牌名時第一頁可能出現 OpenRice 頁、LIHKG 討論串、Facebook 專頁。呢啲唔係壞事（都係曝光），但你要確保佢哋嘅資料正確，同埋官網排第一。

---

## 三、商業調查型意圖（Commercial Investigation）——「我想比較」

用戶有購買意圖，但還在研究和比較階段。這是**含金量最高的意圖之一**。

### 典型查詢模式

| 查詢詞 | 意圖 |
|--------|------|
| 「iPhone 15 vs S24 比較」 | 產品比較 |
| 「最佳 SEO 工具推薦」 | 尋找最佳選擇 |
| 「Ahrefs 評價」 | 查看使用評價 |
| 「SEMrush 價格」 | 比較價格 |
| 「香港 SEO 公司推薦」 | 尋找服務商 |
| 「旺角 補習社 邊間好」 | 地區服務比較 |
| 「尖沙咀 拉麵 推介」 | 地區餐飲比較 |

### 內容策略

| 內容類型 | 說明 | 實例 |
|----------|------|------|
| 比較文章 | A vs B 的全面對比 | 「Ahrefs vs SEMrush：2026 年終極對比」 |
| 評價文章 | 誠實的產品使用心得 | 「使用 Ahrefs 一年的真實心得」 |
| 推薦清單 | 某領域的最佳選擇 | 「2026 年 10 大 SEO 工具推薦」 |
| 購買指南 | 幫助決策的指南 | 「如何選擇適合你預算的 SEO 工具」 |
| 方案對比 | 價格 / 功能比較表 | 「各 SEO 工具價格方案一覽（HK$）」 |
| 地區指南 | 按 18 區整理的選擇指南 | 「香港 18 區補習社比較：邊區最啱你？」 |

### 轉換策略

> 這是最接近轉換的資訊型內容。文章內嵌入**產品比較表**、**CTA 按鈕**、**限時優惠資訊**。誠實揭露優缺點比一面倒吹捧更能建立信任。
>
> 香港讀者對「老實評測」特別受落 —— 寫「呢間好，但收費偏貴，適合預算充足嘅人」，往往比寫「全港第一」更有說服力。價錢一律用 **HK$** 並註明是否含其他費用（消委會指引）。

---

## 四、交易型意圖（Transactional Intent）——「我要買」

用戶已經決定要採取行動——購買、註冊、下載、預約。

### 典型查詢模式

| 查詢詞 | 意圖 |
|--------|------|
| 「買 SEO 工具」 | 購買意圖 |
| 「Ahrefs 優惠碼」 | 尋找折扣後購買 |
| 「SEO 顧問服務」 | 購買服務 |
| 「下載 SEO 檢查清單」 | 下載資源 |
| 「SEO 課程報名」 | 報名課程 |
| 「中環 髮型屋 網上預約」 | 預約服務 |
| 「HKTVmall 優惠碼」 | 落單前搵折扣 |

### 內容策略

- **產品頁面（Product Page）**：詳盡的產品描述、規格、價格（HK$）、CTA
- **登陸頁面（Landing Page）**：專為轉換設計的單頁面
- **方案比較頁**：不同方案的價格和功能對照
- **結帳流程優化**：確保購買流程流暢（香港網店常見痛點：只支援信用卡而無 PayMe / FPS / AlipayHK，會令轉換率大跌）
- **預約流程**：本地服務（診所、髮型屋、補習社）要確保「一鍵預約 / WhatsApp 聯絡」喺手機版極之易撳

### SEO vs 廣告

> 交易型關鍵字通常也是 Google Ads 競爭最激烈的地方。頂部 4 則廣告 + 地圖結果 + 購物結果，自然排名可能被推到很下方。SEO + SEM 雙管齊下是這類關鍵字的最佳策略。香港嘅金融、醫療美容、移民、地產等行業尤其明顯 —— 頭版成個畫面都係廣告。

## 實戰：如何判斷搜尋意圖？

不用猜。直接看 SERP。

### 三步判斷法

1. **搜一下關鍵字**：打開無痕視窗，Google 搜尋目標關鍵字（**地區設定為香港**，否則你睇到嘅可能係其他市場嘅結果）
2. **觀察 SERP 特徵**：
   - 頂部有精選摘要？→ 資訊型
   - 出現購物結果？→ 交易型
   - 有比較網站排名前面？→ 商業調查型
   - 出現 Local Pack 地圖三寶？→ 本地 / 交易型（例如「沙田 裝修」）
   - 第一名係 OpenRice 或 LIHKG？→ 多數係餐飲 / 評價類商業調查型
   - 第一名是某品牌的官網？→ 可能是導航型或品牌詞
3. **分析排名前 5 的內容類型**：
   - 都是部落格文章？→ 資訊型
   - 都是產品頁面？→ 交易型
   - 混合文章和產品頁？→ 商業調查型

### 混合意圖（Mixed Intent）

現實中，很多關鍵字同時承載多種意圖。例如「SEO 工具」：
- 有人想了解什麼是 SEO 工具（資訊型）
- 有人想比較哪個工具最好（商業調查型）
- 有人想直接購買（交易型）

這時**看 Google 的 SERP 佈局來判斷主流意圖**——如果前 5 名中有 3 篇是比較文章，那主流意圖就是商業調查型。

> **香港實例**：「裝修公司」呢個字，香港 SERP 上面同時有「裝修報價教學」（資訊型）、「裝修公司比較平台」（商業調查型）、「即時報價」（交易型），仲有 Local Pack。主流意圖偏向商業調查 + 本地交易，所以你嘅落地頁應該係「比較 + 地區 + 報價」，而唔係一篇純教學文。

## 意圖矩陣：內容格式對照表

| 意圖 | 最適合內容格式 | 不適合的格式 |
|------|---------------|-------------|
| 資訊型 | 教學文章、終極指南、FAQ、影片 | 純產品頁、銷售頁 |
| 導航型 | 官網首頁、登入頁、品牌頁 | 長篇教學文章 |
| 商業調查型 | 比較文、評價文、推薦清單、地區指南 | 純定義性內容 |
| 交易型 | 產品頁、登陸頁、方案頁、預約頁 | 純資訊型文章 |

---

## 重點回顧

1. **搜尋意圖四象限**：Know（資訊型）、Go（導航型）、Consider（商業調查型）、Buy（交易型）
2. **先看 SERP 再寫內容**：Google 已經用排名告訴你主流意圖是什麼（記得將地區設為香港）
3. **內容格式要對齊意圖**：交易型意圖寫教學文 = 不可能排上去
4. **混合意圖要判斷主流**：排名前 5 的內容類型就是答案
5. **香港語言很重要**：廣東話口語（邊間好 / 推介 / 點揀）+ 中英夾雜，係命中真實搜尋嘅關鍵
6. **不同意圖不同轉換策略**：資訊型不要硬銷、商業調查型是黃金轉換機會
