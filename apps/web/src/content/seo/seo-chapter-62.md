## AEO 是什麼？

**AEO（Answer Engine Optimization）** 是優化內容以成為「答案引擎」首選來源的策略。答案引擎與傳統搜尋引擎的區別在於：它們直接提供答案，而非提供連結列表。

```
答案引擎的類型：

  內嵌式答案引擎：
    → Google Featured Snippet（精選摘要）
    → Google Knowledge Panel（知識面板）
    → Google AI Overviews
    → Google People Also Ask（其他人也問了）

  獨立式答案引擎：
    → Wolfram Alpha（計算型答案）
    → 語音助手（Siri、Alexa、Google Assistant）
    → 聊天 AI（ChatGPT、Claude、Gemini）

AEO 的核心問題：
  當使用者問「植牙過程多久？」時，
  答案引擎選擇誰的內容作為答案？
```

## Featured Snippet：答案引擎的原始形態

### Featured Snippet 的四種類型

Featured Snippet 是 Google 在搜尋結果頂部顯示的精選摘要。它是 AEO 的基礎，也是理解答案引擎邏輯的最佳入口。

```
類型 1：段落摘要（Paragraph Snippet）

  搜尋：「什麼是植牙？」

  ┌──────────────────────────────────────┐
  │  植牙是一種以外科手術方式將人工牙根   │
  │  植入顎骨以替代缺失牙齒的治療方式。   │
  │  它具有外觀自然、使用壽命長等優點...  │
  │                                      │
  │  [來源網站]                           │
  └──────────────────────────────────────┘

  最常見的類型，佔所有 Featured Snippet 的 ~50%

類型 2：列表摘要（List Snippet）

  搜尋：「植牙的步驟」

  ┌──────────────────────────────────────┐
  │  1. 初步評估：X 光檢查、3D 掃描      │
  │  2. 植入手術：將植體植入顎骨          │
  │  3. 骨整合期：約 3-6 個月            │
  │  4. 安裝牙冠：裝上最終假牙            │
  │  ...                                 │
  └──────────────────────────────────────┘

類型 3：表格摘要（Table Snippet）

  搜尋：「植牙費用比較」

  ┌──────────────────────────────────────┐
  │  類型      │ 費用範圍     │ 壽命     │
  │  單顆植牙  │ $20,000-35K │ 20+年   │
  │  牙橋      │ $8,000-15K  │ 10-15年 │
  │  活動假牙  │ $3,000-8K   │ 5-8年   │
  └──────────────────────────────────────┘

類型 4：影片摘要（Video Snippet）

  搜尋：「如何正確刷牙」
  → Google 顯示 YouTube 影片的特定時間段
```

### Featured Snippet 的排名因素

```
Google 如何選擇 Featured Snippet？

1. 內容的「回答性」
   → 你的頁面是否直接回答了搜尋查詢？
   → 答案是否在第一段或早期段落中？
   → 答案的語言是否與搜尋查詢匹配？

2. 頁面已有的排名
   → Featured Snippet 通常從排名前 5 的結果中選取
   → 你不需要是 #1，但需要在第 1 頁

3. 內容的結構化程度
   → 清晰定義的段落更容易被抓取
   → 列表格式更容易成為 List Snippet

4. 答案的簡潔性
   → Google 偏好 40-60 字的精簡答案（段落摘要）
   → 太短 = 不完整，太長 = 不適合摘要
```

## 如何贏得 Featured Snippet

### Step 1：找出 Featured Snippet 機會

```
方法：分析你已排名的關鍵字中，哪些有 Featured Snippet

工具：Ahrefs / Semrush
  → 查看你的關鍵字排名
  → 篩選你排名 1-5 且有 Featured Snippet 的關鍵字
  → 這些是你最有可能贏得的 Featured Snippet

你已有排名 + 有 Featured Snippet = 立即機會！
```

### Step 2：針對不同類型優化內容

**針對段落摘要（Paragraph Snippet）的優化：**

```
策略：40-60 字精確答案，放在 H2 下的第一段

查詢：「植牙是什麼？」

你的內容：
  <h2>什麼是植牙？</h2>
  <p>植牙是一種以外科手術方式，將人工牙根（植體）
  植入顎骨中，替代缺失牙齒的現代牙科治療方式。
  它具有外觀自然、咀嚼功能接近真牙、使用壽命長等優點。</p>
  <p>植牙技術起源於 1960 年代，經過數十年發展，目前已成為牙科領域中最成熟的缺牙修復方案之一...</p>

為什麼有效：
  ✅ 問題直接作為 H2
  ✅ 第一段是 40-60 字的精簡回答
  ✅ 包含了定義、三個核心優點
  ✅ 後續段落提供更詳細的資訊（但不影響 Snippet）
```

**針對列表摘要（List Snippet）的優化：**

```
策略：使用 <ol> 或帶有明確標記的列表

查詢：「植牙過程步驟」

你的內容：
  <h2>植牙的完整過程（分步說明）</h2>
  <ol>
    <li><strong>初步評估：</strong>牙醫進行全面口腔檢查，包括 X 光... </li>
    <li><strong>植入手術：</strong>在局部麻醉下，將植體精確植入顎骨...</li>
    <li><strong>骨整合期：</strong>等待 3-6 個月，讓植體與顎骨完全融合...</li>
    <li><strong>安裝牙冠：</strong>骨整合完成後，安裝定制的假牙牙冠...</li>
  </ol>

為什麼有效：
  ✅ H2 直接對應查詢
  ✅ 使用 <ol>（Google 明確偏好有序列表）
  ✅ 每個步驟有清晰的標題（<strong>）
  ✅ 步驟數量適中（4 個，不是 20 個）
```

**針對表格摘要（Table Snippet）的優化：**

```html
策略：使用 <table> 展示數據，而不是用圖片或文字描述

<h2>植牙與其他治療方案的比較</h2>
<table>
  <thead>
    <tr>
      <th>治療方案</th>
      <th>費用範圍（HKD）</th>
      <th>壽命</th>
      <th>優點</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>單顆植牙</td>
      <td>$20,000 - 35,000</td>
      <td>20+ 年</td>
      <td>外觀自然、不需磨損鄰牙</td>
    </tr>
    <tr>
      <td>牙橋</td>
      <td>$8,000 - 15,000</td>
      <td>10-15 年</td>
      <td>治療時間短、費用較低</td>
    </tr>
    <tr>
      <td>活動假牙</td>
      <td>$3,000 - 8,000</td>
      <td>5-8 年</td>
      <td>費用最低、無需手術</td>
    </tr>
  </tbody>
</table>

為什麼有效：
  ✅ 使用標準 HTML <table>（不是圖片表格！）
  ✅ 表格簡潔（3-5 列，不是 20 列）
  ✅ 第一行是最重要的比較對象
```

## People Also Ask（PAA）— 被低估的答案引擎版位

### PAA 的重要性

**People Also Ask**（其他人也問了）是 Google SERP 中「可展開的問答模塊」。它正變得越來越重要，因為它是 Google AI Overviews 的訓練資料來源之一。

```
┌──────────────────────────────────────┐
│  People Also Ask                      │
│                                       │
│  ▼ 植牙過程要多久？                    │
│  │ 植牙的整個過程通常需要 3-9 個月，   │
│  │ 取決於個人的骨整合情況...           │
│  │ [來源]                              │
│                                       │
│  ▼ 植牙後可以立即吃東西嗎？            │
│  ▼ 植牙的成功率是多少？                │
│  ▼ 什麼情況下不適合植牙？              │
└──────────────────────────────────────┘
```

### PAA 優化策略

```
PAA 的運作邏輯：
  Google 會自動擴展相關問題。當一個 PAA 問題被點擊，
  會觸發更多相關問題的顯示。這產生了一個
  「長尾問題網絡」。

策略：在你的內容中回答所有相關問題

做法：
  搜尋你的主要關鍵字 → 記錄 Google PAA 顯示的所有問題
  → 在文章中加入這些問題作為 H2 或 H3 → 每個問題用 40-60 字精簡回答

範例：
  關鍵字：「植牙」
  PAA 問題：
    → 植牙會痛嗎？
    → 植牙和牙橋哪個好？
    → 植牙健保有沒有給付？
    → 植牙後要注意什麼？

  在文章中加入：
    <h3>植牙會痛嗎？</h3>
    <p>植牙過程中使用局部麻醉，手術本身不會感到疼痛。
    術後的 2-3 天可能會有輕微腫脹和不適，
    「大多數患者表示疼痛程度遠低於預期...</p>

  這樣做：
    ✅ 即時回答了使用者的問題
    ✅ 增加了文章出現在 PAA 的機會
    ✅ 提升了整體內容的深度
```

## Google Knowledge Panel — 你的品牌答案卡

### 什麼是 Knowledge Panel？

**Knowledge Panel** 是 Google 搜尋結果右側（桌面版）或頂部（手機版）顯示的資訊卡。它來自 Google 的 Knowledge Graph。

```
搜尋：「陳大明牙醫診所」

┌──────────────────────────────┐
│  陳大明牙醫診所               │
│  牙科診所                     │
│  ⭐ 4.8 (320 則 Google 評論) │
│  地址：中環皇后大道中 100 號   │
│  電話：+852 1234 5678        │
│  營業時間：09:00 - 18:00     │
│  網站：chendaming-dental.hk  │
│                              │
│  [預約] [致電] [路線] [網站]  │
│                              │
│  熱門時段：...               │
│  評論摘要：...               │
│  來自網絡：...               │
└──────────────────────────────┘
```

### 如何獲得和優化 Knowledge Panel

```
必要條件：
  ☐ Google Business Profile 完整驗證和優化
  ☐ 網站上有完整的 Organization Schema
  ☐ 在 Wikidata 上建立條目（如符合標準）
  ☐ Wikipedia 條目也會觸發 Knowledge Panel（較難達成）

優化 Knowledge Panel 顯示的資訊：

方法 1：通過 GBP 控制大部分資訊
  → 地址、電話、營業時間、照片、評論
  → GBP 是 Knowledge Panel 最主要資訊來源

方法 2：通過 Schema 補充資訊
  → sameAs 連結（社交媒體等）
  → founder / employee 資訊
  → 服務描述

方法 3：讓 Google 從網絡中提取補充資訊
  → 發布新聞稿
  → 在行業媒體上出現
  → 社交媒體活躍度（部分影響）

如果你發現 Knowledge Panel 上的資訊有誤：
  → 桌面版：Knowledge Panel 底部有「提出修改建議」
  → 手機版：可以通過 GBP 修正核心資訊
  → Wikidata：如果資訊來自 Wikidata，在那裡修正
```

## 語音搜尋的 AEO 策略

### 語音搜尋的特性

```
語音搜尋 vs 文字搜尋：

  文字搜尋：
    「植牙 香港 費用 2026」

  語音搜尋：
    「OK Google，香港植牙大概要幾多錢？」
    「Hey Siri，附近邊度有牙醫？」
    「Alexa，what is a dental implant?」

關鍵差異：
  1. 更長、更口語化、更像對話
  2. 通常是問題形式（不是關鍵字片段）
  3. 搜尋者期待一個即時的「單一答案」
  4. 多數從手機或智慧音箱發起
```

### 語音搜尋優化

```
策略 1：針對「問題格式」優化

  加入「問題→答案」的內容格式：

  ❌ 關鍵字型內容：
    「香港植牙費用 2026 年最新價格」

  ✅ 問題型內容：
    <h2>香港植牙要幾多錢？2026 年最新費用指南</h2>
    <p>在香港，單顆植牙的費用通常在 HK$20,000 至
    HK$35,000 之間，具體費用取決於植體品牌、
    手術複雜度和診所位置...</p>

策略 2：回答要簡短直接

  語音助手通常只朗讀前 30-40 秒的內容
  （約 50-70 個英文單詞，或 80-100 個中文字）

  → 把最重要的答案放在第一段
  → 第一段應該可以獨立成為一個完整答案

策略 3：針對本地語音搜尋優化

  「我附近的牙醫」是語音搜尋中最常見的本地查詢

  → 確保 GBP 資訊完整（語音助手會讀取 GBP 數據）
  → 營業時間要準確（特別是「現在是否營業中」）
  → 地址格式要清楚（導航軟體會用到）
```

## AEO 監控與成功率衡量

```
追蹤你的 AEO 表現：

1. Featured Snippet 佔有率
   工具：Ahrefs / Semrush
   指標：你的關鍵字中，有多少比例贏得了 Featured Snippet？

2. PAA 曝光率
   工具：手動追蹤 / Semrush
   指標：你的內容出現在多少個 PAA 問題中？

3. Knowledge Panel 完整性
   手動檢查：搜尋你的品牌名稱
   指標：Knowledge Panel 的資訊是否完整且準確？

4. 語音搜尋可見度
   測試：用語音助手搜尋你的行業關鍵字
   指標：你的品牌是否被提及？

5. AI Overviews 引用率
   測試：搜尋你的目標關鍵字
   指標：你的內容是否在 AI Overviews 中被引用？
```
