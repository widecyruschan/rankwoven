---

Google 的排名演算法考慮超過 200 個信號（Signals），但如果要歸納出最核心的決定因素，可以濃縮為**五大支柱**。這五個因素不僅決定了你的網站能否排上第一頁，更決定了你能否**留在**第一頁。

---

## 因素一：內容品質（權重約 30-35%）

> 內容是 SEO 的靈魂。Google 反覆強調：**創造人們想要閱讀的內容，然後優化它，而不是反過來。**

### 1.1 內容有效性的四個層次

| 層次 | 定義 | Google 的判斷方式 |
|------|------|------------------|
| **滿足資訊需求** | 內容完整回答了使用者的問題 | 語意分析：內容是否覆蓋查詢的核心主題 |
| **滿足格式需求** | 內容採用了使用者期待的格式 | 分析 SERP 的主流內容類型（列表、教學、影片） |
| **超越基本需求** | 內容提供了其他頁面沒有的價值 | 比較你與排名競爭者的內容深度和獨特性 |
| **觸發正面互動** | 使用者閱讀後產生正向行為 | 評估停留時間、回訪率、社群分享 |

### 1.2 原創性 vs 重複內容

Google 的 Helpful Content 系統會處罰以下行為：
- 從多個來源拼湊內容而不添加新價值
- 大量使用 AI 生成而未經人工編輯優化
- 「薄內容」（Thin Content）：字數少、資訊密度低

**原創內容的三個信號**：
1. **獨特數據**：自己做的研究、調查、測試數據
2. **獨特觀點**：個人經驗分享、行業洞察、專業分析
3. **獨特呈現**：自製圖表、影片、工具

### 1.3 E-E-A-T 信號

延續第 10 章的討論，內容品質與 E-E-A-T 密不可分。Google 透過以下方式評估 E-E-A-T：

| 信號 | Google 可能觀察的指標 |
|------|----------------------|
| 經驗 | 內容中的具體描述、原創圖片、操作步驟的細節 |
| 專業 | 作者頁面的資歷展示、Schema 標記、業界引用 |
| 權威 | 來自權威網站的反向連結數量與品質 |
| 信任 | HTTPS、隱私政策、聯絡透明度、內容準確性 |

## 因素二：關鍵字與內容覆蓋（權重約 20-25%）

> 關鍵字不是「放進去就好」，而是要理解使用者背後的搜尋意圖，然後用正確的內容格式去滿足它。

### 2.1 關鍵字的四個層級

| 層級 | 說明 | 策略 |
|------|------|------|
| **核心關鍵字** | 網站主要想排名的 3-5 個大詞 | 首頁和主力頁面優化 |
| **主題關鍵字** | 圍繞核心詞的中型關鍵字群 | 建立主題群集（Topic Cluster） |
| **長尾關鍵字** | 搜尋量低但轉換率高的精準詞 | 部落格文章、FAQ 頁面 |
| **語意相關詞** | 不是直接搜尋詞但與主題相關 | 豐富內容深度，幫助 Google 理解上下文 |

### 2.2 TF-IDF 與內容覆蓋率

**TF-IDF（Term Frequency-Inverse Document Frequency）** 是衡量一個詞對一篇文檔重要程度的經典方法。在 SEO 中，我們用它來檢查內容是否「完整覆蓋」了某個主題。

**實戰方法**：
1. 用工具（如 Surfer SEO、Frase）分析排名前 10 頁面的關鍵詞使用模式
2. 找出競爭者都使用但你沒有的「漏洞詞」（Content Gaps）
3. 在內容中自然地補充這些詞

### 2.3 內容新鮮度（Freshness）

Google 的 **Query Deserves Freshness（QDF）** 機制會根據查詢類型調整對新鮮度的要求：

| 查詢類型 | 新鮮度要求 | 範例 |
|----------|-----------|------|
| 近期事件 | 極高（數小時內） | 「颱風路徑」、「選舉結果」 |
| 定期發生的事實 | 高（每年更新） | 「2024 奧運賽程」、「報稅截止日」 |
| 持續更新的主題 | 中（數月內） | 「SEO 趨勢」、「最佳手機推薦」 |
| 相對穩定的主題 | 低（1-2 年） | 「畢氏定理」、「什麼是 SEO」 |

**行動建議**：標註「發布日期」和「最後更新日期」，定期審查並更新關鍵內容。

## 因素三：網站權威性（權重約 20-25%）

> 反向連結仍然是 Google 排名前三重要的信號，但「品質」遠比「數量」重要。

### 3.1 反向連結的品質維度

| 維度 | 高品質連結 | 低品質連結 |
|------|-----------|-----------|
| **來源權威性** | 高 Domain Authority 網站 | 低 DA、垃圾網站 |
| **主題相關性** | 同領域或相關領域 | 完全不相關 |
| **連結位置** | 文章內文中的上下文連結 | 側欄、頁腳、留言區 |
| **連結自然度** | 有編輯價值的自然引用 | 明顯的付費連結或交換 |
| **錨點文字** | 自然多樣化的錨點 | 過度優化、均為精確匹配 |
| **連結新鮮度** | 持續獲得新連結 | 只有舊連結、無增長 |

### 3.2 PageRank 與連結權重傳遞

雖然 Google 不再公開更新 PageRank 數據，但連結權重傳遞的原理仍然有效：

```
你的頁面能獲得多少權重 = 連結來源頁面的權重 × 傳遞率 ÷ 來源頁面輸出的連結總數
```

**關鍵要點**：
- 一個來自高權重頁面的連結，勝過 100 個來自低品質頁面的連結
- 來自內容主體的連結（Contextual Link）傳遞的權重高於導航連結
- `nofollow` 連結不傳遞權重，但仍可能帶來流量
- `rel="ugc"` 和 `rel="sponsored"` 的權重傳遞效果較低

### 3.3 品牌信號

除了反向連結，Google 也觀察非連結的品牌信任：

| 信號類型 | 指標 |
|----------|------|
| **品牌搜尋量** | 有多少人直接搜尋你的品牌名稱？ |
| **品牌提及** | 網路上有多少未附連結的品牌提及？ |
| **社群互動** | 品牌在社群媒體上的討論度和互動量 |
| **直接流量** | 使用者是否直接輸入網址造訪？ |
| **回訪率** | 有多少使用者是回頭客？ |

> Google 的前搜尋品質負責人 Andrey Lipattsev 曾公開確認：**內容（Content）和連結（Links）是 Google 排名兩個最重要的信號。**

## 因素四：技術體驗（權重約 10-15%）

> 技術 SEO 是「必要但非充分」條件。技術做得再好，沒有好的內容也排不上去；但技術做得差，再好的內容也會被拖累。

### 4.1 Core Web Vitals（核心網頁體驗指標）

Google 將 Core Web Vitals 作為排名信號之一，由三個指標組成：

| 指標 | 全名 | 衡量什麼 | 良好標準 |
|------|------|----------|----------|
| **LCP** | Largest Contentful Paint | 最大內容加載時間 | ≤ 2.5 秒 |
| **FID** | First Input Delay | 首次互動延遲 | ≤ 100 毫秒 |
| **CLS** | Cumulative Layout Shift | 累計版面位移 | ≤ 0.1 |

**2024 年更新**：Google 宣布將以 **INP（Interaction to Next Paint）** 取代 FID，成為新的衡量標準。INP 衡量的是整個使用過程中所有互動的延遲，而非僅第一次。

### 4.2 非 Core Web Vitals 的技術因素

| 因素 | 影響 | 優化方法 |
|------|------|----------|
| **HTTPS** | 安全性基礎 | 安裝 SSL 憑證 |
| **行動友善** | Google 使用行動優先索引 | RWD 響應式設計 |
| **網站可爬取性** | 確保 Google 能抓取頁面 | robots.txt 正確配置 |
| **索引覆蓋率** | 確保重要頁面被索引 | Sitemap 提交 + GSC 監控 |
| **JS 渲染** | JS 內容是否可見 | SSR/預渲染關鍵內容 |
| **網頁結構** | 語意化 HTML 幫助理解 | 正確使用標題層級（H1-H6） |

## 因素五：網站結構（權重約 10-15%）

> 良好的網站結構不僅幫助使用者導航，更是 Google 理解網站內容層級的關鍵。

### 5.1 網站架構設計原則

| 原則 | 說明 | 目標 |
|------|------|------|
| **扁平化** | 任何頁面應在首頁 3 次點擊內可達 | 降低爬取深度 |
| **主題隔離** | 相關內容應在清晰的目錄下 | 建立主題權威 |
| **獨立網址** | 每個重要頁面有獨立、簡潔的 URL | 避免參數混亂 |
| **邏輯鏈接** | 內部連結反映內容的層級關係 | 傳遞語意上下文 |

### 5.2 內部連結的 SEO 價值

內部連結在 SEO 中有三個不可替代的作用：

| 作用 | 說明 |
|------|------|
| **權重分配** | 將首頁和主力頁面的權重傳遞到深層頁面 |
| **索引輔助** | 幫助 Google 發現和索引網站的所有重要頁面 |
| **上下文建立** | 錨點文字告訴 Google 目標頁面的主題 |

### 5.3 內部連結實戰法則

1. **錨點文字多樣化**：不要所有連結都用完全一樣的錨點文字
2. **深度連結**：不要只連結到首頁，要連結到相關的深層內容
3. **上下文連結**：在文章內文中自然地放置連結，而非在側欄中
4. **重要性傳遞**：從高權重頁面連結到你想提升的重要頁面
5. **避免孤兒頁面**：每個頁面至少有一個來自其他頁面的內部連結

## 五大因素優先級策略

### 新網站（0-6 個月）

| 優先級 | 因素 | 行動 |
|--------|------|------|
| 1 | 內容品質 | 產出 20-30 篇高品質原創內容 |
| 2 | 網站結構 | 建立清晰的架構和內部連結 |
| 3 | 技術體驗 | 確保 HTTPS、行動友善、基礎速度達標 |
| 4 | 關鍵字覆蓋 | 鎖定 10-15 個低競爭長尾關鍵字 |
| 5 | 網站權威 | 開始建立基礎反向連結（目錄提交、社群推廣） |

### 成長期網站（6-18 個月）

| 優先級 | 因素 | 行動 |
|--------|------|------|
| 1 | 網站權威 | 積極建立高品質反向連結 |
| 2 | 內容品質 | 更新和擴展現有內容，深化 E-E-A-T |
| 3 | 關鍵字覆蓋 | 拓展主題集群，覆蓋更多相關關鍵字 |
| 4 | 技術體驗 | 優化 Core Web Vitals，提升使用者體驗 |
| 5 | 網站結構 | 根據數據調整架構，強化重要頁面 |

### 成熟網站（18 個月以上）

| 優先級 | 因素 | 行動 |
|--------|------|------|
| 1 | 內容品質 | 維持內容新鮮度，持續提升深度 |
| 2 | 網站權威 | 鞏固行業地位，獲取更高品質的引用 |
| 3 | 技術體驗 | 追蹤 Core Web Vitals，保持技術競爭力 |
| 4 | 關鍵字覆蓋 | 拓展新主題和新服務的關鍵字 |
| 5 | 網站結構 | 定期審查和清理過時/低效內容 |

---

## 重點回顧

1. **五大因素**：內容品質（30-35%）、關鍵字與內容覆蓋（20-25%）、網站權威性（20-25%）、技術體驗（10-15%）、網站結構（10-15%）
2. **Google 官方確認**：內容（Content）和連結（Links）是最重要的兩個排名信號
3. **內容為王仍然成立**，但「為王」的不只是內容本身，還包括內容的品質、呈現和使用者體驗
4. **技術是基礎而非終點**——技術 SEO 做得再好，沒有好內容也排不上去
5. **網站的成長階段決定優先級**——不要在不恰當的階段追求不適合的目標
