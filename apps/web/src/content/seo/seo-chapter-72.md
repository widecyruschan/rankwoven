> 被 Google 處罰嘅感覺，就好似喺青馬大橋上面突然被警察截停。你唔知道自己做錯咗啲乜，但你知件事大鑊。
>
> 香港網站嘅常見劇本：老闆請咗一間「保證三個月上第一頁」嘅本地 SEO 公司，半年後流量歸零，先知對方用黑帽手法 — 呢個時候公司名譽、廣告預算、團隊信心全部一齊受傷。

## 兩種懲罰機制：手動 vs 演算法

Google 的懲罰機制分為兩大類，診斷和處理方式完全不同：

```
┌─────────────────────────────────────────────────┐
│              Google 懲罰機制                      │
├─────────────────────┬───────────────────────────┤
│   手動操作           │   演算法懲罰               │
│   (Manual Action)   │   (Algorithmic Penalty)   │
├─────────────────────┼───────────────────────────┤
│ 人工審查員決定       │ 演算法自動觸發              │
│ GSC 會通知你         │ GSC 不會通知               │
│ 明確告知原因         │ 靠數據自己判斷              │
│ 需要提交重審         │ 修正後等待下一次爬取更新     │
│ 處理完很快恢復       │ 恢復時間不確定              │
└─────────────────────┴───────────────────────────┘
```

---

## Part 1：手動操作（Manual Action）

### 什麼是手動操作？

Google 的審查團隊（真人）判定你的網站違反了網站管理員指南，對你的網站進行的針對性懲罰。

**手動操作的範圍：**
- 可能是特定頁面（Partial Match）→ 只有該頁面受影響
- 可能是全站（Site-wide Match）→ 整個網站排名下降

### 如何確認是否被手動操作？

**唯一且確定的方法：**
```
GSC → 安全性與手動操作 → 手動操作
```

如果有處罰，你會看到明確的通知，如：
> 「偵測到網站層級的問題：至 [你的網站] 的非自然連結」

**重要：** 如果 GSC 沒有任何手動操作通知，那你的問題就是演算法層級的，不是手動處罰。

> 🇭🇰 **香港提示：** GSC 通知只會發去已驗證嘅資源。好多香港公司嘅 GSC 係由舊 SEO 公司／舊網頁設計公司開嘅，通知全部送去對方 email。第一步要確認：**你係咪有 GSC 嘅管理員權限？** 冇嘅話即刻用 DNS 驗證搶返。

### 常見的手動操作類型

#### 類型一：非自然連結（Unnatural Links）

**最常見的手動操作**，分為兩種子類型：

| 子類型 | GSC 訊息 | 嚴重度 |
|--------|----------|--------|
| 連至你網站的連結 | 「偵測到連至 [網站] 的非自然連結」 | 🔴 |
| 從你網站連出的連結 | 「偵測到從 [網站] 連出的非自然連結」 | 🟡 |

**常見原因：**
- 購買了大量付費連結（香港常見：買「新聞稿網站」連結、買部落格連結）
- 參與連結交換網路（「你連我我連你」）
- 在低品質網站/目錄上大量建立連結
- 部落格留言垃圾連結
- 論壇簽名連結（連登、Uwants、Discuss 等）
- 付錢給他人「幫你做 SEO」結果做了黑帽連結 — **香港最常見的原因**

#### 類型二：內容貧乏（Thin Content）

**GSC 訊息：** 「內容品質低落，對使用者幾乎沒有附加價值」

**常見原因：**
- 大量自動生成內容（AI 紡紗）
- 聯盟行銷頁面只複製貼上廠商文案
- 門口頁：只為搜尋引擎建立的內容空洞頁面（香港常見：18 區／各區分店頁面內容完全一樣，只改地區名）
- 內容極短（<150 字）的頁面大量存在

#### 類型三：偽裝與欺騙性轉址（Cloaking & Sneaky Redirects）

**GSC 訊息：** 「對使用者顯示與 Google 不同的內容」或「欺騙性轉址」

**常見原因：**
- 根據 User-Agent 對 Googlebot 顯示不同內容
- 對用戶做未預期的轉址（點擊 A 結果跳到 B，例如跳去賭博／成人／借貸網站）

#### 類型四：隱藏文字與關鍵字堆砌

**GSC 訊息：** 「網站可能包含隱藏文字或關鍵字堆砌」

**常見原因：**
- 白色文字放白色背景
- 用 CSS 隱藏關鍵字
- 在頁尾大量堆砌關鍵字（如「中環 灣仔 銅鑼灣 尖沙咀 旺角 沙田 屯元天…」）

#### 類型五：垃圾內容（Spam）

**GSC 訊息：** 「使用者產生的垃圾內容」或「純垃圾內容」

**常見原因：**
- 論壇/留言區被機器人大量灌垃圾
- 網站被駭客植入垃圾頁面
- 純粹為廣告而建立的無價值網站

#### 類型六：結構化資料違規

**GSC 訊息：** 「網站上的結構化資料違反了我們的政策」

**常見原因：**
- 使用不相關的 Schema（如文章頁用 Product Schema）
- 星級評分造假（香港常見：自己畀自己 5 星 Review Schema）
- Schema 中的資訊與頁面實際內容不符（如標 HK$100 實際收 HK$500）

```
收到手動操作通知
    │
    ├─→ 第一步：冷靜，讀懂通知
    │   確認類型（連結？內容？偽裝？）
    │   確認範圍（全站？特定頁面？）
    │   確認邊個時段出事（對應邊一間 SEO 公司／邊次改版）
    │
    ├─→ 第二步：診斷與修正
    │   連結問題：
    │   ┌───────────────────────────────────┐
    │   │ 1. 導出 Ahrefs/SEMrush 所有連結  │
    │   │ 2. 標記所有可疑連結（付費/垃圾）  │
    │   │ 3. 聯絡站長要求移除               │
    │   │ 4. 無法移除的加入 Disavow 清單    │
    │   │ 5. 記錄所有嘗試聯絡的過程          │
    │   └─────────────────────────────────┘
    │   同時：
    │   ┌───────────────────────────────────┐
    │   │ • 立即終止與涉事 SEO 公司嘅合作    │

    │   │   （香港合約通常有權要求）         │
    │   │ • 保留所有往來記錄做證據           │
    │   └─────────────────────────────────┘
    │
    │   內容問題：
    │   ┌─────────────────────────────────┐
    │   │ 1. 找出所有低品質頁面             │
    │   │ 2. 改善內容（增加深度和價值）      │
    │   │    • 補上香港本地數據、HK$ 價錢   │
    │   │    • 每一區頁面要有真實差異化內容 │
    │   │ 3. 無法改善的 → 刪除或 noindex   │
    │   │ 4. 刪除所有門口頁                 │
    │   └─────────────────────────────────┘
    │
    ├─→ 第三步：撰寫重審請求（Reconsideration Request）
    │   ┌─────────────────────────────────┐
    │   │ 重審請求三要素：                  │
    │   │                                  │
    │   │ 1. 承認問題                      │
    │   │    • 清楚說明你做錯了什麼          │
    │   │    • 不要推卸責任                 │
    │   │                                  │
    │   │ 2. 說明修正行動                  │
    │   │    • 具體做了什麼修正              │
    │   │    • 附上證據（如 Disavow 檔案）   │
    │   │    • 列出已移除/改善的頁面         │
    │   │                                  │
    │   │ 3. 保證不再犯                    │
    │   │    • 說明日後如何避免              │
    │   │    • 新的流程/把關機制             │
    │   └─────────────────────────────────┘
    │   建議用英文寫（審查團隊係國際團隊），
    │   或中英對照，避免語意被誤解
    │
    └─→ 第四步：提交與等待
        GSC → 手動操作 → 提交重審請求
        通常 1-4 週內回覆
        如果被拒絕，重新修正後再次提交
```

## Part 2：演算法懲罰（Algorithmic Penalty）

### 什麼是演算法懲罰？

不是 Google 的真人決定懲罰你，而是演算法自動判斷你的網站品質不足，從而降低排名或取消索引。

### 演算法懲罰的類型

#### 1. Panda（內容品質懲罰）— 已整合入核心演算法

**目標：** 低品質、內容貧乏的網站

**受影響的典型網站：**
- 大量短文章（<300 字）的內容農場
- 內容高度重複的網站（香港常見：18 區／多區頁面只改地區名）
- 廣告比例過高的頁面
- 抄襲/紡紗內容

**診斷方法：**
- GA4：查看長期流量趨勢，Panda 更新日附近是否暴跌？
- GSC：查看索引率是否下降
- 手動審查內容：挑 50 個頁面，誠實評分

**修正方法：**
- Content Pruning：刪除或大幅改善低品質頁面
- 提高內容深度和原創性
- 降低廣告比例（特別是 Above the Fold）
- 無捷徑，需要扎實的內容改善

#### 2. Penguin（連結品質懲罰）— 已整合入核心演算法

**目標：** 操縱連結的網站

**受影響的典型網站：**
- 購買大量付費連結
- 參與連結交換網路
- 錨點文字過度商業化
- 來自低品質網站的大規模連結

**診斷方法：**
- Ahrefs/SEMrush 導出所有連結（地區設香港）
- 查看錨點文字分佈（精準匹配 >50% 有問題）
- 查看連結來源品質（DR 分佈）
- 查看連結獲取速度（突然暴增 = 可疑）

**修正方法：**
- 清理低品質連結（聯絡移除 + Disavow）
- 重新建立自然的連結配置
- 獲取更多高品質、品牌錨點的連結來稀釋（香港本地：香港01、經濟日報、明報、星島、商會目錄、OpenRice）

#### 3. Helpful Content（實用內容系統）

**目標：** 為搜尋引擎而非用戶建立的內容

**受影響的典型網站：**
- AI 大量生成、未經人工編輯的內容
- 回答用戶不關心的問題
- 內容深度不足，只是重新包裝網路既有資訊
- 沒有第一手經驗或專業見解
- ⚠️ 香港常見：將大陸／台灣嘅內容直接轉繁中，冇加入任何香港本地資訊（HK$ 價錢、地區、本地法規）

**診斷方法：**
- 誠實回答「這篇文章真的幫到香港用戶了嗎？」
- 查看 GA4 參與率（低參與 = 內容無用）
- 檢查內容是否有獨特的觀點或數據（係咪全部都係網上搵到嘅嘢）

**修正方法：**
- 刪除或大幅重寫低品質內容
- 加入第一手經驗、數據、案例（香港本地案例）
- 展示作者專業背景
- 這個懲罰的恢復期很長（數月），需要有耐心

#### 4. Core Updates（核心更新影響）

**目標：** Google 整體排名系統的重新校準

**特性：**
- 不是針對你個人的懲罰
- Google 對「什麼是好內容」的標準調整了
- 你的內容可能在新的標準下被認為不夠好

**診斷方法：**
- 對照核心更新日期（searchliaison 或 SEO 媒體）
- 你的流量變化是否與更新日吻合？
- 查看你的內容在新標準下是否仍然「最好」
- 同時用 Bing Webmaster Tools 對照 — 如果 Google 跌但 Bing（Yahoo 香港）冇跌，更加肯定係 Google 演算法因素

**應對方法：**
- 再次審視 Google 的品質評估指南
- 強化 E-E-A-T
- 改善用戶體驗（速度、可讀性、行動版）
- 這是一個持續改善的過程

## 手動 vs 演算法：診斷決策樹

```
流量暴跌
    │
    ├─→ GSC 有手動操作通知？
    │   ├─ 有 → 手動操作，按上述流程處理
    │   └─ 沒有 ↓
    │
    ├─→ 先排除香港本地因素：
    │   係咪農曆新年／長假／八號風球／行業淡季？
    │   ├─ 是 → 季節性，用 YoY 對照確認
    │   └─ 不是 ↓
    │
    ├─→ 跌幅是否與已知的演算法更新日期吻合？
    │   ├─ 是 → 演算法懲罰，評估受影響的內容類型
    │   └─ 不是 ↓
    │
    ├─→ 是否特定頁面暴跌而非全站？
    │   ├─ 特定頁面 → 可能是競爭對手超越你了
    │   └─ 全站範圍 + 長期趨勢 → 可能是演算法懲罰 ↓
    │
    └─→ 分析內容與連結品質
        ├─ 內容品質低 → Panda / Helpful Content 類型
        ├─ 連結品質低 → Penguin 類型
        └─ 兩者正常 → 可能是市場變化或競爭加劇
```

## 預防勝於治療：建立早期預警系統

### 每月健康檢查

```
☐ GSC 手動操作：每次打開 GSC 都先看這個
☐ GSC 安全性問題：確認沒有駭客入侵或惡意軟體
☐ 確認自己仍然係 GSC 管理員（唔好俾舊代理鎖住）
☐ 反向連結監控：設定 Ahrefs/SEMrush 的新連結通知
☐ 內容審查：每季抽樣 20 篇文章檢查品質
☐ UGC 監控：檢查論壇/留言區有沒有被灌垃圾
☐ 結構化資料：確認 Schema 與頁面內容一致（價錢、評分）
☐ 本地平台監控：GBP 有冇被改資料？OpenRice / Facebook
   評論有冇異常？（香港用戶鍾意喺呢度投訴）
```

### 反向連結的「有毒訊號」自動監控

建議在 Ahrefs 或 SEMrush 設定警報：
- DR < 10 的新連結（單筆可忽略，但大量就要注意）
- 來自 .xyz .top .icu 等可疑域名的連結
- 錨點文字包含商業關鍵字的連結
- 連結突然暴增 50%+

> 🇭🇰 **香港公司特別提醒：** 如果你委託咗 SEO 公司，記得喺合約寫明：
> 1. **GSC / GA4 / Bing WMT 帳號必須由你公司名義開設**，代理只可以有「使用者」權限，唔可以有「管理員」獨佔
> 2. **每月要提交完整工作清單**（做咗乜、落咗邊啲連結）
> 3. **禁止使用任何形式的付費連結／PBN／AI 大量生成內容**
> 4. **違規導致被罰要賠償**
>
> 呢幾條款可以慳返你幾百萬港元同半年時間。

## 本章重點回顧

| 懲罰類型 | 通知方式 | 處理關鍵 | 恢復時間 |
|----------|----------|----------|----------|
| 手動操作 — 非自然連結 | GSC 通知 | Disavow + 重審請求 | 1-4 週 |
| 手動操作 — 內容貧乏 | GSC 通知 | 內容改善 + 重審請求 | 1-4 週 |
| 演算法 — Panda 類 | 無通知 | 大規模內容品質提升 | 數月 |
| 演算法 — Penguin 類 | 無通知 | 清理連結 + 自然連結建設 | 數月 |
| 演算法 — Helpful Content | 無通知 | 建立真正有價值的內容 | 數月 |
| 核心更新影響 | 無通知 | 全面改善，持續優化 | 直到下次更新 |

> 💡 **核心原則：Google 不想懲罰你，它只是想給用戶最好的結果。如果你成為最好的結果，你就永遠不會被懲罰。**
>
> 換句香港講法：**與其諗點樣避開 Google 嘅法眼，不如諗點樣成為香港用戶心中最值得推介嗰個。**
