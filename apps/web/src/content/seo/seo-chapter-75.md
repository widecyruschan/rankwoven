## 第一季：基礎建設期（第 1-3 個月）

### 第 1 個月：審計、設定、策略

#### 目標
建立 SEO 基礎設施，理解現狀，制定策略。

#### 週工作拆解

**第 1 週：審計與診斷**
```
☐ 技術 SEO 審計（Screaming Frog / Sitebulb）
   - 檢查所有 HTTP 狀態碼
   - 檢查 robots.txt 和 Sitemap
   - 檢查 Canonical 設定
   - 檢查結構化資料
☐ Core Web Vitals 基線測量（PageSpeed Insights）
☐ GSC 設定與驗證（確認有管理員權限）
☐ GA4 設定與轉換事件確認
☐ 確認所有 SEO 工具已就位（Ahrefs/SEMrush 等）
```

**第 2 週：關鍵字研究**
```
☐ 列出所有商業核心關鍵字（10-20 個）
☐ 用 Ahrefs/SEMrush 擴展到長尾關鍵字
☐ 競爭對手關鍵字分析（找出 3-5 個主要競品）
☐ 建立關鍵字矩陣（按搜尋量 × 商業價值 × 難度排序）
☐ 確定第一季的目標關鍵字群組（挑 KD < 40 的先攻）
```

**第 3 週：內容盤點與策略**
```
☐ 盤點現有內容（哪些能留、哪些要改、哪些要刪）
☐ 建立 Topic Cluster 架構
☐ 規劃第一季要創建的內容清單（10-15 篇）
☐ 為每篇內容指定目標關鍵字和搜尋意圖
```

**第 4 週：修正與優化**
```
☐ 修復技術審計中發現的 P0 問題
☐ 優化現有 Top 10 頁面的 Title/Meta/H1
☐ 設定 SEO 監控 Dashboard（Looker Studio）
☐ 建立內容日曆（Content Calendar）
☐ 確保所有 URL 結構一致
```

#### 第 1 個月結束時應有的成果
- ✅ 技術審計報告（問題清單 + 優先級）
- ✅ 關鍵字矩陣（100+ 關鍵字 + 優先級排序）
- ✅ Topic Cluster 架構圖
- ✅ 內容日曆（Q1）
- ✅ SEO Dashboard 上線
- ✅ 網站無重大技術錯誤

---

### 第 2 個月：內容生產啟動、技術深化

#### 目標
開始規律發布內容，深化技術優化。

```
核心任務：
☐ 發布 4-8 篇 SEO 優化內容（每週 1-2 篇）
☐ 每篇文章包含：
   - 目標關鍵字覆蓋
   - 內部連結到相關頁面（3-5 條）
   - Schema 結構化資料（Article/FAQ 等）
   - 原創圖片 + Alt Text
☐ 設定內部連結規則（每篇新文章連結 3 篇舊文章）
☐ 開始網站速度優化（圖片壓縮、快取、CDN）
☐ 檢查並修復所有 404 錯誤
☐ 行動版體驗檢查（Mobile-Friendly Test）
☐ 提交新頁面到 GSC 請求索引
```

#### 內部連結建設
這是第 2-3 個月最重要的任務之一：
```
方法 1：在權威舊文章中插入新文章的連結
方法 2：建立「相關文章」區塊（自動推薦）
方法 3：在分類頁面中加入新文章
方法 4：確保導航選單包含最重要的頁面
```

#### 第 2 個月結束時應有的成果
- ✅ 8-16 篇 SEO 優化內容已發布
- ✅ 內部連結網絡初步建立
- ✅ 網站速度有明顯改善
- ✅ 404 錯誤清零
- ✅ 新內容開始被 Google 索引

#### 目標
根據數據調整策略，建立內容和連結的良性循環。

```
核心任務：
☐ 繼續發布 4-6 篇內容
☐ 第一次完整 SEO 成效回顧：
   - GSC：曝光/點擊趨勢、Top 關鍵字變化
   - GA4：有機流量、參與率、轉換率
   - 排名追蹤：目標關鍵字排名變化
☐ 根據數據調整內容策略：
   - 哪些類型的內容表現好？→ 多做
   - 哪些關鍵字進入 11-20 名？→ 優化這些頁面
☐ 開始簡單的連結建設：
   - 列出 10-20 個潛在的 Guest Post 機會
   - 在相關社群/論壇中提供有價值的內容（附連結）
   - 修復任何已發現的 Broken Link
☐ 更新表現前 5 名的文章（加入最新數據）
```

## 第二季：內容建設與權威累積期（第 4-6 個月）

### 第 4 個月：加速內容生產

```
核心任務：
☐ 發布 6-8 篇深度內容（長文 >2,000 字）
☐ 開始內容多元化：
   - 終極指南型（Ultimate Guide）
   - 案例研究型（Case Study）
   - 數據報告型（原創調查/統計）
   - 比較型（vs 文章）
☐ 優化排名 11-20 的頁面（低垂果實策略）
☐ 開始建立外部連結（Guest Post 1-2 篇）
☐ 提交網站到相關行業目錄（品質優先）
```

### 第 5 個月：權威建立啟動

```
核心任務：
☐ 發布 6-8 篇內容
☐ 建立「權威內容」（Pillar Page / Cornerstone Content）
   → 選 3-5 個核心主題，建立極詳細的長篇指南
   → 其他文章全部指向這些權威頁面
☐ 積極進行 Outreach：
   - 聯絡行業部落格請求 Guest Post
   - 尋找 Broken Link 機會
   - 回應 HARO（Help A Reporter Out）獲取媒體連結
☐ 優化已發布 2-3 個月的文章（Content Refresh）
   → 查看哪些文章的排名停在第二頁
   → 增加內容深度、補充最新數據
☐ 考慮建立免費工具/資源頁面（連結磁鐵）
```

### 第 6 個月：半年成效總結 + 策略調整

核心任務：
☐ 發布 6-8 篇內容
☐ 半年成效完整回顧：
   ┌────────────────────────────────────┐

   │ 排名：目標關鍵字排名分佈            │
   │ 轉換：有機轉換率與 ROI 試算         │

   └────────────────────────────────────┘
☐ 根據半年數據調整下半年策略
☐ 開始測試不同內容格式和推廣方式
☐ 淘汰表現差的內容，加強表現好的方向

## 常見時間線陷阱

### ❌ 陷阱一：第 1 個月就期待流量暴增
現實是第 1-3 個月主要是打基礎，流量增幅很小。但這是必要的投資。

### ❌ 陷阱二：第 6 個月還看不到效果就放棄
有些關鍵字需要 6-12 個月才能進入 Top 10。持續性是 SEO 最重要的成功因素。

### ❌ 陷阱三：只做內容不做連結
第 4 個月後如果不開始連結建設，排名天花板會很低。

### ❌ 陷阱四：做完半年就鬆懈
SEO 不是一次性的專案，是持續的過程。競爭對手不會休息。

## 本章重點回顧

| 季度 | 核心重點 | 關鍵產出 |
|------|----------|----------|
| Q1（1-3月） | 基礎建設 | 審計、策略、20+ 文章、技術修正 |
| Q2（4-6月） | 內容+權威 | 50+ 文章、Pillar Page、連結啟動 |
| Q3（7-9月） | 規模化 | 100+ 文章、穩定連結成長、系統化 |
| Q4（10-12月） | 收割+規劃 | 轉換優化、年度報告、明年策略 |

> 💡 **SEO 就像健身 — 前三個月看不出效果，但持續一年後，整個體態完全不一樣。**
