> 香港版嘅特別之處：香港市場細、季節性強（農曆新年、暑假、颱風季），加上本地 SEO（GBP、OpenRice、地區關鍵字）可以好快見效 — 所以節奏唔可以照抄外國教程，要就返香港嘅節慶同行業週期。

## 第一季：基礎建設期（第 1-3 個月）

### 第 1 個月：審計、設定、策略

#### 目標
建立 SEO 基礎設施，理解現狀，制定策略。

#### 週工作拆解

**第 1 週：審計與診斷**
```
☐ 技術 SEO 審計（Screaming Frog / Sitebulb）
   - 檢查所有 HTTP 狀態碼
   - 檢查 robots.txt 和 Sitemap
   - 檢查 Canonical 設定
   - 檢查結構化資料
   - 檢查 hreflang（zh-HK / en-HK / zh-CN）
☐ Core Web Vitals 基線測量（PageSpeed Insights）
☐ GSC 設定與驗證（確認你有管理員權限，唔係舊代理）
☐ Bing Webmaster Tools 設定（Yahoo 香港 + Copilot 用 Bing 索引）
☐ GA4 設定與轉換事件確認（時區：亞洲/香港，貨幣：HKD）
☐ 確認所有 SEO 工具已就位（Ahrefs/SEMrush 等）
☐ 香港本地設定：
   - Google 商家檔案（GBP）建立/認領/優化
   - 檢查 OpenRice（餐飲）、TripAdvisor（旅遊）資料
   - 檢查 Facebook / IG 專頁資料一致性
```

**第 2 週：關鍵字研究**
```
☐ 列出所有商業核心關鍵字（10-20 個）
☐ 用 Ahrefs/SEMrush（地區設香港）擴展到長尾關鍵字
☐ 競爭對手關鍵字分析（找出 3-5 個主要香港競品）
☐ 建立關鍵字矩陣（按搜尋量 × 商業價值 × 難度排序）
☐ 確定第一季的目標關鍵字群組（挑 KD < 40 的先攻）
☐ 香港專屬：建立「地區 + 服務」關鍵字組
   （例：「中環 裝修」「沙田 補習社」「觀塘 倉存」）
   按 18 區 + 核心服務交叉排列
```

**第 3 週：內容盤點與策略**
```
☐ 盤點現有內容（哪些能留、哪些要改、哪些要刪）
☐ 檢查繁中 / 英文 / 簡中版本是否有重複或錯向問題
☐ 建立 Topic Cluster 架構
☐ 規劃第一季要創建的內容清單（10-15 篇）
☐ 為每篇內容指定目標關鍵字和搜尋意圖
☐ 香港專屬：釐定內容用語（繁中香港用語，避免台式/大陸詞）
```

**第 4 週：修正與優化**
```
☐ 修復技術審計中發現的 P0 問題
☐ 優化現有 Top 10 頁面的 Title/Meta/H1
☐ 設定 SEO 監控 Dashboard（Looker Studio）
☐ 建立內容日曆（Content Calendar），對齊香港節慶
☐ 確保所有 URL 結構一致
☐ 建立 NAP 一致性（名稱/地址/電話）— 香港地址格式
```

#### 第 1 個月結束時應有的成果
- ✅ 技術審計報告（問題清單 + 優先級）
- ✅ 關鍵字矩陣（100+ 關鍵字 + 優先級排序，含 18 區地區詞）
- ✅ Topic Cluster 架構圖
- ✅ 內容日曆（Q1）
- ✅ SEO Dashboard 上線
- ✅ 網站無重大技術錯誤
- ✅ GBP 已完成認領與基礎優化

#### 目標

   - Schema 結構化資料（Article/FAQ/LocalBusiness 等）
   - 原創圖片 + Alt Text
   - 香港本地元素：HK$ 價錢、地區名、本地例子
☐ 設定內部連結規則（每篇新文章連結 3 篇舊文章）
☐ 開始網站速度優化（圖片壓縮、快取、CDN —
   建議選有香港/亞洲節點嘅 CDN）
☐ 檢查並修復所有 404 錯誤
☐ 行動版體驗檢查（Mobile-Friendly Test）
☐ 提交新頁面到 GSC 請求索引
☐ 同步提交新 Sitemap 到 Bing Webmaster Tools
☐ 開始建立地區著陸頁（如適用，每區要有真實差異化內容）

#### 內部連結建設
這是第 2-3 個月最重要的任務之一：
```

方法 3：在分類頁面中加入新文章
方法 4：確保導航選單包含最重要的頁面
方法 5（香港適用）：地區頁 ↔ 服務頁雙向連結
```

#### 第 2 個月結束時應有的成果
- ✅ 8-16 篇 SEO 優化內容已發布
- ✅ 內部連結網絡初步建立
- ✅ 網站速度有明顯改善
- ✅ 404 錯誤清零
- ✅ 新內容開始被 Google 索引（Bing 亦開始收）

| 11 | 鞏固 + 進階關鍵字 | 品牌搜尋量提升 |
| 12 | 年度總結 + 明年規劃 | 年度 ROI 報告 |

## 常見時間線陷阱

### ❌ 陷阱一：第 1 個月就期待流量暴增
現實是第 1-3 個月主要是打基礎，流量增幅很小。但這是必要的投資。
**香港例外：** 如果你係本地服務業，GBP 優化 + 地區頁可以喺第 1-2 個月就帶到查詢，呢個係唯一可以「快」嘅地方。

### ❌ 陷阱二：第 6 個月還看不到效果就放棄
有些關鍵字需要 6-12 個月才能進入 Top 10。持續性是 SEO 最重要的成功因素。

### ❌ 陷阱三：只做內容不做連結
第 4 個月後如果不開始連結建設，排名天花板會很低。
**香港做法：** 本地目錄 + 香港媒體 + 商會 + 行業網站，呢啲係香港相對容易攞到嘅高質連結。

### ❌ 陷阱四：做完半年就鬆懈
SEO 不是一次性的專案，是持續的過程。競爭對手不會休息。

### ❌ 陷阱五（香港獨有）：忽略旺季前置期
香港旺季（暑假、聖誕、農曆新年、開學）嘅內容要**提前 6-10 星期**發布先有時間上排名。等到旺季前一星期先出文，一定趕唔切。

### ❌ 陷阱六（香港獨有）：一套內容打繁中 + 英文 + 簡中
三種語言嘅搜尋意圖、用語、競爭對手都唔同。直接機翻會被 Google 當低質內容，亦會被香港讀者一眼睇穿。要做就分開做，並設好 hreflang。

## 本章重點回顧

| 季度 | 核心重點 | 關鍵產出 |
|------|----------|----------|
| Q1（1-3月） | 基礎建設 + 本地 SEO | 審計、策略、20+ 文章、GBP 優化、技術修正 |
| Q2（4-6月） | 內容+權威 | 50+ 文章、Pillar Page、本地連結啟動 |
| Q3（7-9月） | 規模化 | 100+ 文章、穩定連結成長、系統化、旺季部署 |
| Q4（10-12月） | 收割+規劃 | 轉換優化、年度報告、明年策略 |

> 💡 **SEO 就好似健身 — 前三個月睇唔出效果，但持續一年之後，成個體態完全唔同。**
>
> 香港版講法：**第一年你會覺得「使咗咁多錢得個寂寞」，第二年你會發現對手出幾多廣告費都追唔上你。**
