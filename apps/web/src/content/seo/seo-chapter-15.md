## 為什麼要做競品關鍵字分析？

> 你不需要從零開始猜測哪些關鍵字有用——你的競爭對手已經用他們的排名告訴你了。

競品關鍵字分析的價值在於：
- **節省時間**：與其盲目測試，不如直接分析已在該領域成功的網站
- **發現機會**：找到競爭對手忽略或做得不好的關鍵字
- **校準策略**：了解競爭格局，設定合理的 SEO 目標

**香港市場特別重要**：香港市場細（人口約 750 萬），關鍵字搜尋量普遍比台灣、大陸細一個量級，但商業價值密度高。「亂槍打鳥」嘅成本喺香港特別肉痛，所以更要靠競品數據校準。

## 誰是你的 SEO 競爭對手？

> **重要**：你的 SEO 競爭對手不一定是你的商業競爭對手。

### 商業競爭對手 vs SEO 競爭對手

| 類型 | 定義 | 香港範例 |
|------|------|------|
| **商業競爭對手** | 賣相同產品/服務的公司 | 你喺旺角開寵物用品店，另一間喺銅鑼灣都賣狗糧 |
| **SEO 競爭對手** | 在搜尋結果中與你競爭相同關鍵字的網站 | 你賣狗糧，但一篇香港寵物 Blog 嘅「狗糧推介」排喺你前面 |

**香港常見嘅「非同行」SEO 競爭對手**（呢啲往往先係真正對手）：

| 平台類型 | 香港例子 | 搶走咗邊啲字 |
|----------|----------|-------------|
| 討論區 | **LIHKG（連登）**、Uwants、Discuss.com.hk、高登 | 「XX 邊間好」「XX 推介」「XX 伏唔伏」 |
| 餐飲平台 | **OpenRice（開飯喇）** | 「尖沙咀 餐廳推介」「旺角 好食」 |
| 新聞媒體 | 香港01、經濟日報、明報、星島、東方、頭條日報、am730 | 話題型、資訊型字 |
| 行業平台 | Car1.hk（搵車）、28Hse / 星之谷（地產） | 高商業價值交易字 |
| 國際平台 | YouTube、Facebook 社團、Instagram、小紅書 | 評測、教學、生活資訊 |

**關鍵操作**：喺 Google（地區設香港）搜尋你的目標關鍵字，排名前 10 的網站就是你的 SEO 競爭對手——無論它們是競爭品牌、媒體網站、論壇還是個人部落格。

## 競品關鍵字分析的六步流程

```
步驟 1 → 步驟 2 → 步驟 3 → 步驟 4 → 步驟 5 → 步驟 6
鎖定競品   匯出關鍵字   分類分析   缺口辨識   機會排序   制定策略
```

---

### 步驟 1：鎖定競品（3-5 個）

選擇競品的原則：

| 原則 | 說明 |
|------|------|
| **排名相關性** | 在多個目標關鍵字上與你競爭排名 |
| **規模相近** | 選擇 1-2 個比你稍強、1-2 個規模相近的 |
| **內容類型** | 包含不同類型的競爭者（品牌站、內容站、論壇） |
| **香港本地性** | 至少 1-2 個係香港本地站（.hk / .com.hk），因為佢哋先掌握到香港用字 |

**工具操作**（以 Ahrefs 為例）：
```
Site Explorer → 輸入競品網域 → 右上角地區揀「Hong Kong」
→ 「Competing domains」報告
→ 找出與該網站共享最多關鍵字的其他網站
```

> **香港小貼士**：如果你做緊餐飲、美容、教育，記得手動加埋 OpenRice、連登、香港01 入競品清單——佢哋唔係同行，但係你嘅流量搶奪者。

---

### 步驟 2：匯出競品關鍵字

使用工具匯出競品排名的所有關鍵字。以 Ahrefs 為例：

```
Site Explorer → 輸入競品網域 → Organic Keywords 報告
→ 地區篩選：Hong Kong
→ 匯出為 CSV（包含關鍵字、排名、搜尋量、流量、URL）
```

**篩選重點**：
- 排名 1-20（首兩頁）
- 排除品牌關鍵字（如果目的是尋找非品牌機會）
- 有搜尋量的（>0）

> **香港市場嘅現實**：香港單一字詞搜尋量細，好多有價值嘅字喺工具入面顯示「0」或者得幾十。唔好因為數字細就掉咗佢——一個月 50 次搜尋嘅「將軍澳 裝修公司邊間好」，隨時幫你簽到一張 HK$300,000 嘅單。

**補充香港本地字**（工具搵唔到，要人手加）：

| 來源 | 點樣挖 | 例子 |
|------|--------|------|
| **LIHKG（連登）** | 搜尋框打產品/服務名，睇帖文標題同留言用字 | 「狗粮邊隻好」「邊度買平」 |
| **OpenRice** | 睇餐廳分類、地區標籤、食評標題 | 「銅鑼灣 一人火鍋」 |
| **小紅書** | 搜「香港 + 關鍵字」，睇筆記標題 hashtag | 「香港 狗糧 推介」「香港 補習 平」 |
| **Google 自動完成 + 「大家亦都問」** | 喺 google.com.hk 打種子字，睇建議 | 「狗糧推介 香港」「狗糧 邊度買」 |
| **Facebook / IG 社團** | 香港媽媽群、寵物群、裝修群嘅提問用字 | 「有冇人用過 XX？」 |

---

### 步驟 3：關鍵字分類分析

將競品關鍵字分成以下類別：

#### 3a. 依搜尋意圖分類

| 意圖 | 競品策略 | 你的機會 |
|------|----------|----------|
| 資訊型 | 大量部落格內容 | 評估內容深度：能否做得更好？ |
| 商業調查型 | 比較文、推薦清單 | 這是轉換金礦——重點攻擊 |
| 交易型 | 產品頁、登陸頁 | 直接競爭——評估競爭難度 |
| 導航型 | 品牌詞 | 通常不需要競爭 |

#### 3b. 依內容格式分類

觀察競品在該關鍵字使用什麼樣的內容格式：
- 長篇指南？清單文？比較表？影片？
- 內容格式是否符合使用者的搜尋意圖？
- 你是否可以提供更好的格式？

> **香港觀察**：香港用家手機主導，鍾意「表格 + 價錢 + 邊間平」嘅比較文，同埋 YouTube / IG Reels 短片。如果競品只係純文字長文，你加一條廣東話短片 + 價錢比較表，往往即刻贏。

#### 3c. 依難度分級

| 難度 | 判斷標準 | 你的策略 |
|------|----------|----------|
| **低** | 首頁有論壇、小型網站、內容品質差 | 立即創建更好內容 |
| **中** | 首頁有知名網站但內容可超越 | 列入優先內容計畫 |
| **高** | 首頁均為權威大站 | 長尾關鍵字包圍策略 |
| **不可能** | 維基百科、政府網站（如 .gov.hk）、品牌官網 | 放棄直接競爭 |

---

### 步驟 4：辨識內容缺口（Content Gap）

**內容缺口 = 競品有排名但你沒有的關鍵字**

#### 工具操作方法（Ahrefs Content Gap）

```
Content Gap 工具 → 輸入你的網域 + 3-5 個競品網域
→ 地區：Hong Kong
→ 顯示：競品有排名但你的網站完全沒有內容的關鍵字
```

#### 缺口類型分類

| 缺口類型 | 定義 | 行動 |
|----------|------|------|
| **完全缺口** | 你沒有任何頁面覆蓋這個關鍵字 | 創建新內容 |
| **品質缺口** | 你有頁面但排名遠低於競品 | 改善現有內容 |
| **意圖缺口** | 你有內容但不符合搜尋意圖 | 調整內容類型和格式 |
| **新鮮度缺口** | 你的內容比競品舊 | 更新內容 |
| **地區缺口** | 你冇覆蓋香港 18 區 / 地區字 | 建立地區登陸頁（中環、旺角、沙田、將軍澳、元朗…） |

> **地區缺口係香港獨有嘅金礦**：好多香港生意（裝修、搬屋、補習、美容、律師、醫療）嘅真實搜尋都帶地區名——「沙田 補習社邊間好」「觀塘 搬屋公司收費」。競品覆蓋咗 5 區，你覆蓋 18 區，就係你嘅缺口。

---

### 步驟 5：機會排序

對每個發現的缺口機會進行矩陣評估：

```
優先級矩陣：
              高
               │
  第二優先     │    第一優先
  (規劃中)     │    (立即執行)
               │
  ─────────────┼─────────────→ 競爭難度
               │
  第四優先     │    第三優先
  (低優先)     │    (如果有資源)
               │
              低
               ↑
           商業價值
```

**第一優先**（高價值 + 低難度）：
- 商業相關度高（研究/交易型）
- 競品排在前 10 但內容品質不佳
- 你能提供顯著更好的內容（例如補上香港價錢、地區、法規資訊）

**行動優先級排序表**（以香港寵物用品網店為例）：

| 關鍵字 | 月搜尋量（HK） | 競品排名 | 競品內容評分 | 你能超越？ | 優先級 |
|--------|----------------|----------|-------------|-----------|--------|
| 狗糧推介 2026 | 1,000 | #3 | 6/10 | ✅ 可超越 | 🔴 第一 |
| 幼犬狗糧邊隻好 | 300 | #1 | 9/10 | ❌ 難超越 | 🟡 第二 |
| 無穀物狗糧好唔好 | 200 | #5 | 4/10 | ✅ 可超越 | 🔴 第一 |
| 旺角 狗糧 邊度買 | 90 | #4（連登帖） | 3/10 | ✅ 可超越 | 🔴 第一 |

---

### 步驟 6：制定內容策略

#### 策略 A：直接超越（Head-to-Head）

**適用時機**：競品內容品質不高（< 7/10 評分），你能創造更好內容。

**執行方法**：
1. 徹底分析競品內容的弱點
2. 創建更全面、更深入、更新的內容
3. 使用 Skyscraper Technique（摩天大樓技術）
4. 主動推廣你的內容以獲取反向連結（香港可考慮香港01、經濟日報、商會目錄、HKTDC）

#### 策略 B：差異化競爭（Differentiation）

**適用時機**：競品內容不錯但缺少特定角度或格式。

**差異化方向**：
- 格式差異：競品是文章，你做成**廣東話影片 + 文字逐字稿**
- 深度差異：競品是清單，你加入**香港實測數據同 HK$ 價錢比較**
- 體驗差異：競品是理論，你加入實測和親身經驗
- 受眾差異：競品面向大眾，你專注特定人群（新手、專業人士）
- **本地差異**：補上香港法規（PDPO、消委會指引、EAA / SFC / IA 行業規管）同香港實際情況

#### 策略 C：長尾包圍（Long-Tail Encirclement）

**適用時機**：頭部關鍵字競爭過於激烈，你的網站權威性不足。

**執行方法**：
1. 放棄直接競爭頭部詞
2. 圍繞頭部詞創建大量長尾內容
3. 通過內部連結將長尾內容的權重匯集到目標頁面
4. 逐步積累主題權威性

```
頭部關鍵字：「laptop 推介 香港」
├── 長尾 1: 「2026 大學生 laptop 推介」
├── 長尾 2: 「HK$6,000 以內輕薄 laptop 推介」
├── 長尾 3: 「programmer 用咩 laptop 好」
├── 長尾 4: 「laptop 續航力比較 2026」
├── 長尾 5: 「香港 邊度買 laptop 平」
├── ...（20+ 篇長尾內容）
└── 全部內部連結回主力頁面 → 累積權威 → 終極指南排名上升
```

## 重點回顧

1. **SEO 競品 ≠ 商業競品**——在搜尋結果中與你競爭關鍵字的才算（香港常見對手係連登、OpenRice、香港01）
2. **做香港市場一定要將工具地區設為 Hong Kong**，並用 google.com.hk 驗證 SERP
3. **內容缺口分析**是競品關鍵字研究的核心——找出競品有排名你沒有的詞
4. **缺口五類型**：完全缺口（建新內容）、品質缺口（改善內容）、意圖缺口（調整格式）、新鮮度缺口（更新內容）、**地區缺口（補 18 區）**
5. **三種競爭策略**：直接超越（內容更好）、差異化（角度不同 + 香港本地化）、長尾包圍（逐步積累權威）
6. **手動 SERP 分析不可替代**——工具可以給你數據，但只有人工閱讀才能判斷內容品質
7. **香港本地字要人手挖**——連登、OpenRice、小紅書、Google 自動完成
