## 什麼是 Google 核心更新？

> **Core Update = Google 重新定義「什麼是好內容」的時刻。**

Google 每年進行數千次小更新，但**核心更新（Core Update）**是其中最重大的幾次——它會從根本上改變 Google 對內容品質的評估方式。核心更新不是針對特定網站或特定行為的懲罰，而是一次**排名的重新校準**。

### 核心更新的特徵

| 特徵 | 說明 |
|------|------|
| 範圍 | 全球性、跨語言、跨行業 |
| 頻率 | 每年約 2-4 次 |
| 持續時間 | 通常 1-2 週完成推送 |
| 影響 | 部分網站排名劇烈波動（20-50% 流量變化） |
| 恢復 | 沒有「修復」方法，需要真正改善內容品質 |

---

## 核心更新 ≠ 懲罰

這是 SEO 領域最常見的誤解。核心更新和手動處罰是兩種完全不同的東西：

| | 核心更新影響 | 手動懲罰（Manual Action） |
|---|---|---|
| **觸發方式** | 演算法自動判定 | 人工審查員判定 |
| **通知方式** | 不會通知你 | GSC 會發通知 |
| **原因** | 內容品質不再符合新標準 | 違反 Google 指南（垃圾內容、購買連結等） |
| **恢復方式** | 改善整體內容品質 | 修正問題後提交重審 |
| **影響範圍** | 整站或多個頁面 | 可以是特定頁面或整站 |

> **核心更新之後排名下降，不代表你做錯了什麼——可能是你的競爭對手做得更好。**

## 核心更新發生時：你該做什麼

### 第一階段：不要驚慌（Day 0-3）

**排名波動是正常的。** 核心更新推送期間（1-2 週），排名會劇烈波動。更新結束前看到的數據可能只是暫時的。

```
❌ 不要做的：
- 看到排名跌就立刻大改網站
- 開始瘋狂刪除內容
- 買大量連結試圖「補回來」

✅ 要做的：
- 記錄當前排名作為基準線
- 檢查 GSC 是否有手動處罰通知
- 觀察競爭對手的排名變化
- 等待更新完全推送結束
```

### 第二階段：數據分析（更新結束後 1-2 週）

更新推送完成後，分析具體哪些頁面受到影響：

**分析框架：**

1. **先看整體**：對比更新前後的流量變化（GSC 和 GA4）
2. **找模式**：哪些頁面跌了？哪些頁面漲了？有沒有共同特徵？
3. **看競爭對手**：誰取代了你的位置？他們的內容好在哪裡？
4. **檢查意圖匹配**：排名下降的頁面，內容格式是否符合用戶搜尋意圖？

**GSC 分析方法**：
```
在 Search Console 中：
1. 選擇更新前後各 2 週的日期範圍
2. 對比總點擊數、曝光數、平均排名
3. 按查詢排序：看哪些關鍵字排名變動最大
4. 按頁面排序：找出受影響最大的頁面
5. 查看國家/裝置區分：確認是否特定市場受影響
```

### 第三階段：行動方案（2-4 週後）

**Google 的官方建議**：沒有「快速修復」核心更新的方法。你需要問自己以下問題：

#### 內容品質自我審查問題（來自 Google 官方指南）

| 類別 | 問題 |
|------|------|
| **內容品質** | 內容是否提供原創資訊、報告、研究或分析？ |
| | 內容是否提供實質的、完整的、全面的主題描述？ |
| | 內容是否提供超越表面描述的深入見解？ |
| | 如果內容引用其他來源，是否增加了顯著的附加價值？ |
| **專業性** | 內容的標題是否誇大或聳動？ |
| | 這是你會想收藏、分享或推薦給朋友的內容嗎？ |
| | 內容是否有明顯的拼寫、排版或事實錯誤？ |
| **信任度** | 內容是否來自有公認權威的主題專家或熱愛者？ |
| | 內容的作者資訊是否清晰透明？ |
| | 對於 YMYL 主題，內容是否有足夠的引用和可信來源？ |

#### 實際改善步驟

| 優先級 | 行動 | 預期時間 |
|--------|------|----------|
| 🔴 高 | 合併、重寫或刪除低品質／「薄內容」頁面 | 立即開始 |
| 🔴 高 | 改善首頁和關鍵頁面的 E-E-A-T 信號 | 1-2 週 |
| 🟡 中 | 更新過時內容（特別是 YMYL 類頁面） | 2-4 週 |
| 🟡 中 | 增加作者介紹、引用來源、參考文獻 | 1-2 週 |
| 🟢 低 | 改善 Core Web Vitals | 持續進行 |
| 🟢 低 | 拓展內容深度與廣度 | 持續進行 |

## 復原的真實時間線

> **Google 公開說明：核心更新受影響的頁面，復原可能需要數月時間，直到下一次核心更新。**

這句實話可能令人沮喪，但這就是現實。核心更新的排名變化不會在幾天內恢復——Google 的演算法在等待**持續的、實質的改善信號**。

典型的恢復路徑：
```
核心更新 → 排名下跌
    ↓
分析問題，制定改善計畫（1-2 週）
    ↓
執行內容品質改善（2-4 週）
    ↓
等待 Google 重新評估（數月，通常要等到下一次核心更新）
    ↓
排名逐漸恢復或超越
```

## 預防勝於治療：核心更新的長期策略

與其每次核心更新都膽戰心驚，不如建立一套**核心更新抗性**的內容策略：

### 1. 建立 E-E-A-T 證據鏈

| E-E-A-T 維度 | 具體操作 |
|-------------|----------|
| **Experience（經驗）** | 文章中加入第一手使用經驗、真實案例、原創截圖 |
| **Expertise（專業）** | 作者頁面展示專業背景和證照、內容覆蓋專業細節 |
| **Authoritativeness（權威）** | 累積來自權威網站的反向連結、媒體報導、行業認可 |
| **Trustworthiness（信任）** | 清晰的聯絡方式、隱私政策、內容更新日期、引用來源 |

### 2. 定期內容審查（Content Audit）

每季度審查網站所有內容：
- **保留**：持續帶來流量的優質內容
- **改善**：有潛力但表現不佳的內容 → 更新、深化
- **合併**：多篇相似主題的薄內容 → 合併成一篇深度文章，301 轉址
- **刪除**：完全沒有價值、沒有流量的內容 → 刪除或 noindex

### 3. 保持內容新鮮度

特別是 YMYL 類型內容：
- 醫療文章應標註「醫學審閱日期」
- 統計數據應標註年份和來源
- 過時的資訊應加註更新說明
- 定期檢查和更新關鍵頁面

### 4. 關注「整體網站品質」而非單頁

核心更新是整站評估。一個網站有太多低品質頁面，會拖累整個網站的表現。**Content Pruning（內容修剪）**往往比創作新內容更能提升整體排名。

## 核心更新常見問答

**Q: 核心更新後排名跌了 50%，要等多久能恢復？**
A: 通常要等到下一次核心更新（2-4 個月）。少數情況下，如果改善夠明顯，可能在常規小更新中就恢復。

**Q: 可以在核心更新期間做內容改動嗎？**
A: 不建議。更新推送期間改動可能干擾 Google 正在進行的重新評估。等推送完成後再行動。

**Q: 排名跌了，是不是被懲罰了？**
A: 先檢查 GSC 有沒有手動處罰通知。沒有通知 = 不是懲罰，是內容品質不再符合新標準。

**Q: 流量跌了但排名沒變，是什麼情況？**
A: 可能原因：關鍵字整體搜尋量下降；SERP 出現新的 AI Overview 或精選摘要導致零點擊；季節性波動。

---

## 重點回顧

1. **Core Update ≠ 懲罰**：是 Google 重新定義「好內容」的標準
2. **不要驚慌**：推送期間的排名波動是暫時的，等更新完成再分析
3. **用數據做決策**：GSC 對比分析 + 競爭對手分析 + 意圖匹配檢查
4. **復原需要時間**：通常要等到下次核心更新（數月）
5. **預防是王道**：建立 E-E-A-T 證據鏈 + 定期內容審查 + 保持內容新鮮
