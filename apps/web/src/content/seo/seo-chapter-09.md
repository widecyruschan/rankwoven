## 什麼是 Google 核心更新？

> **Core Update = Google 重新定義「什麼是好內容」的時刻。**

Google 每年進行數千次小更新，但**核心更新（Core Update）**是其中最重大的幾次——它會從根本上改變 Google 對內容品質的評估方式。核心更新不是針對特定網站或特定行為的懲罰，而是一次**排名的重新校準**。

### 核心更新的特徵

| 特徵 | 說明 |
|------|------|
| 範圍 | 全球性、跨語言、跨行業（香港網站一樣受影響，無「地區豁免」） |
| 頻率 | 每年約 2-4 次 |
| 持續時間 | 通常 1-2 週完成推送 |
| 影響 | 部分網站排名劇烈波動（20-50% 流量變化） |
| 恢復 | 沒有「修復」方法，需要真正改善內容品質 |

---

## 核心更新 ≠ 懲罰

這是 SEO 領域最常見的誤解。核心更新和手動處罰是兩種完全不同的東西：

| | 核心更新影響 | 手動懲罰（Manual Action） |
|---|---|---|
| **觸發方式** | 演算法自動判定 | 人工審查員判定 |
| **通知方式** | 不會通知你 | GSC 會發通知 |
| **原因** | 內容品質不再符合新標準 | 違反 Google 指南（垃圾內容、購買連結等） |
| **恢復方式** | 改善整體內容品質 | 修正問題後提交重審 |
| **影響範圍** | 整站或多個頁面 | 可以是特定頁面或整站 |

> **核心更新之後排名下降，不代表你做錯了什麼——可能是你的競爭對手做得更好。**

> **香港常見情況**：香港市場細，第一頁嘅對手可能同時包括 OpenRice、LIHKG、大型集團 portal、香港新聞媒體。核心更新之後，Google 可能整體提升咗「本地平台」或「媒體」嘅權重，令你嘅企業網站被擠落去 —— 呢個唔係你被罰，而係 SERP 嘅「成分」變咗。處理方法唔係改自己個網，而係同時經營呢啲平台上面嘅版面。

## 核心更新發生時：你該做什麼

### 第一階段：不要驚慌（Day 0-3）

**排名波動是正常的。** 核心更新推送期間（1-2 週），排名會劇烈波動。更新結束前看到的數據可能只是暫時的。

```
❌ 不要做的：
- 看到排名跌就立刻大改網站
- 開始瘋狂刪除內容
- 買大量連結試圖「補回來」

✅ 要做的：
- 記錄當前排名作為基準線
- 檢查 GSC 是否有手動處罰通知
- 觀察競爭對手的排名變化
- 等待更新完全推送結束
```

### 第二階段：數據分析（更新結束後 1-2 週）

更新推送完成後，分析具體哪些頁面受到影響：

**分析框架：**

1. **先看整體**：對比更新前後的流量變化（GSC 和 GA4）
2. **找模式**：哪些頁面跌了？哪些頁面漲了？有沒有共同特徵？
3. **看競爭對手**：誰取代了你的位置？他們的內容好在哪裡？（在香港，取代你的可能係 OpenRice、LIHKG、香港01，而唔係同行）
4. **檢查意圖匹配**：排名下降的頁面，內容格式是否符合用戶搜尋意圖？

**GSC 分析方法**：
```
在 Search Console 中：
1. 選擇更新前後各 2 週的日期範圍
2. 對比總點擊數、曝光數、平均排名
3. 按查詢排序：看哪些關鍵字排名變動最大
4. 按頁面排序：找出受影響最大的頁面
5. 查看國家/裝置區分：確認是否特定市場受影響
   → 香港網站特別要做呢步：用「國家 = Hong Kong」篩選，
     確認跌嘅係香港流量定係海外 / 大灣區流量
     （若你有簡中版做內地客，跌嘅可能只係 zh-CN 頁面，
      咁就要用百度 / 內地角度去處理，而唔係改你嘅香港站）
```

### 第三階段：行動方案（2-4 週後）

**Google 的官方建議**：沒有「快速修復」核心更新的方法。你需要問自己以下問題：

#### 內容品質自我審查問題（來自 Google 官方指南）

| 類別 | 問題 |
|------|------|
| **內容品質** | 內容是否提供原創資訊、報告、研究或分析？ |
| | 內容是否提供實質的、完整的、全面的主題描述？ |
| | 內容是否提供超越表面描述的深入見解？ |
| | 如果內容引用其他來源，是否增加了顯著的附加價值？ |
| **專業性** | 內容的標題是否誇大或聳動？ |
| | 這是你會想收藏、分享或推薦給朋友的內容嗎？ |
| | 內容是否有明顯的拼寫、排版或事實錯誤？ |
| **信任度** | 內容是否來自有公認權威的主題專家或熱愛者？ |
| | 內容的作者資訊是否清晰透明？ |
| | 對於 YMYL 主題，內容是否有足夠的引用和可信來源？ |

> **香港版額外自查**：
> - 價錢資料係咪用 **HK$** 並列明更新日期？（香港消費者對過期價錢特別敏感）
> - 公司資料係咪完整？（地址、電話、BR 編號、聯絡人 —— 香港用家好在意「係咪真公司」）
> - 係咪有 **私隱政策**？香港受《個人資料（私隱）條例》（PDPO）規管，收集用戶資料、評論、表單都要寫明用途
> - YMYL 行業（金融、保險、醫療、法律、地產）係咪符合本地規管要求？（證監 SFC、保監局 IA、地產代理監管局 EAA、消委會指引）
> - 分店頁 / 地區頁係咪互相複製？（香港連鎖集團最常見嘅薄內容問題）

#### 實際改善步驟

| 優先級 | 行動 | 預期時間 |
|--------|------|----------|
| 🔴 高 | 合併、重寫或刪除低品質／「薄內容」頁面（尤其分店頁、地區頁） | 立即開始 |
| 🔴 高 | 改善首頁和關鍵頁面的 E-E-A-T 信號（作者資歷、公司資料、引用來源） | 1-2 週 |
| 🟡 中 | 更新過時內容（特別是 YMYL 類頁面、價錢、法規資訊） | 2-4 週 |
| 🟡 中 | 增加作者介紹、引用來源、參考文獻 | 1-2 週 |
| 🟢 低 | 改善 Core Web Vitals（用香港 / 流動網絡做測試基準） | 持續進行 |
| 🟢 低 | 拓展內容深度與廣度 | 持續進行 |

## 復原的真實時間線

> **Google 公開說明：核心更新受影響的頁面，復原可能需要數月時間，直到下一次核心更新。**

這句實話可能令人沮喪，但這就是現實。核心更新的排名變化不會在幾天內恢復——Google 的演算法在等待**持續的、實質的改善信號**。

典型的恢復路徑：
```
核心更新 → 排名下跌
    ↓
分析問題，制定改善計畫（1-2 週）
    ↓
執行內容品質改善（2-4 週）
    ↓
等待 Google 重新評估（數月，通常要等到下一次核心更新）
    ↓
排名逐漸恢復或超越
```

> **香港小市場嘅優勢**：香港市場細、競爭對手數量有限，只要你肯認真改善內容深度（例如補上真實案例、原創數據、第一手經驗），復原速度有時會比大市場快 —— 因為你只需要打贏十幾個對手，而唔係幾百個。呢個係香港 SEO 少有嘅「地利」。

## 預防勝於治療：核心更新的長期策略

與其每次核心更新都膽戰心驚，不如建立一套**核心更新抗性**的內容策略：

### 1. 建立 E-E-A-T 證據鏈

| E-E-A-T 維度 | 具體操作（香港場景） |
|-------------|----------|
| **Experience（經驗）** | 文章中加入第一手使用經驗、真實香港案例（例如實測過程、現場相片、客戶個案）、原創截圖 |
| **Expertise（專業）** | 作者頁面展示專業背景和證照（香港專業資格：CPA、CFA、律師、醫生、地產代理牌照、EAA 編號等）、內容覆蓋專業細節 |
| **Authoritativeness（權威）** | 累積來自有權威網站的反向連結、媒體報導（香港01、明報、經濟日報、星島、頭條日報、信報）、行業認可（HKTDC、商會、專業學會） |
| **Trustworthiness（信任）** | 清晰的聯絡方式（香港地址 + 電話）、私隱政策（符合 PDPO）、內容更新日期、引用來源、價錢以 HK$ 列明 |

### 2. 定期內容審查（Content Audit）

每季度審查網站所有內容：
- **保留**：持續帶來流量的優質內容
- **改善**：有潛力但表現不佳的內容 → 更新、深化
- **合併**：多篇相似主題的薄內容 → 合併成一篇深度文章，301 轉址
- **刪除**：完全沒有價值、沒有流量的內容 → 刪除或 noindex

### 3. 保持內容新鮮度

特別是 YMYL 類型內容：
- 醫療文章應標註「醫學審閱日期」
- 統計數據應標註年份和來源（香港數據優先引用政府統計處、金管局 HKMA、證監 SFC 等官方來源）
- 過時的資訊應加註更新說明
- 定期檢查和更新關鍵頁面

### 4. 關注「整體網站品質」而非單頁

核心更新是整站評估。一個網站有太多低品質頁面，會拖累整個網站的表現。**Content Pruning（內容修剪）**往往比創作新內容更能提升整體排名。

### 5. 分散平台風險（香港特別適用）

唔好將所有雞蛋放喺自己網站一個籃度。香港 SERP 上面，OpenRice（餐飲）、LIHKG / Uwants（討論）、香港新聞媒體（品牌）、HKTDC / 商會目錄（B2B）本身就係高權威版面。喺呢啲平台經營好你嘅資料同聲譽，即使自己網站短期波動，品牌曝光都唔會斷。

## 核心更新常見問答

**Q: 核心更新後排名跌了 50%，要等多久能恢復？**
A: 通常要等到下一次核心更新（2-4 個月）。少數情況下，如果改善夠明顯，可能在常規小更新中就恢復。香港市場細，改善幅度夠大時，有時會比預期快。

**Q: 可以在核心更新期間做內容改動嗎？**
A: 不建議。更新推送期間改動可能干擾 Google 正在進行的重新評估。等推送完成後再行動。

**Q: 排名跌了，是不是被懲罰了？**
A: 先檢查 GSC 有沒有手動處罰通知。沒有通知 = 不是懲罰，是內容品質不再符合新標準。

**Q: 流量跌了但排名沒變，是什麼情況？**
A: 可能原因：關鍵字整體搜尋量下降（香港季節性波動明顯，例如暑假、農曆新年）；SERP 出現新的 AI Overview 或精選摘要導致零點擊；SERP 版位被 OpenRice / 地圖三寶佔據令自然結果下移。

**Q: 我有簡中版做內地客，核心更新後簡中版跌但繁中版無事，點解？**
A: 內地簡中內容嘅競爭環境同評分基準同香港唔同，而且內地用家主要用百度 / 微信 / 小紅書，Google 喺內地並非主戰場。呢個情況要分開處理：簡中版要用內地 SEO 思路（百度 / 小紅書 / 微信搜一搜）去優化，唔好用香港站嘅邏輯硬套。

## 重點回顧

1. **Core Update ≠ 懲罰**：是 Google 重新定義「好內容」的標準
2. **不要驚慌**：推送期間的排名波動是暫時的，等更新完成再分析
3. **用數據做決策**：GSC 對比分析（記得篩選國家 = Hong Kong）+ 競爭對手分析 + 意圖匹配檢查
4. **復原需要時間**：通常要等到下次核心更新（數月）
5. **預防是王道**：建立 E-E-A-T 證據鏈 + 定期內容審查 + 保持內容新鮮 + 分散平台風險
6. **香港本地加分**：公司資料完整、價錢用 HK$、符合 PDPO 與行業規管、經營 OpenRice / LIHKG / 香港媒體版面
