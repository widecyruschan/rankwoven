## 什麼是在地 SEO？

**在地 SEO（Local SEO）** 是針對「地理位置相關搜尋」的優化策略。當使用者搜尋帶有地理意圖的關鍵字時，Google 會顯示在地搜尋結果。

```
使用者在 Google 搜尋：
  「香港 咖啡店」
  「我附近的牙醫」
  「尖沙咀 日式料理」

Google 的回應：
  ┌─────────────────────────────────┐
  │  Local Pack（地圖結果 + 3 商家）   │
  │  🏪 咖啡店 A  ⭐4.8  📞         │
  │  🏪 咖啡店 B  ⭐4.5  📞         │
  │  🏪 咖啡店 C  ⭐4.3  📞         │
  │  [更多商家]                       │
  ├─────────────────────────────────┤
  │  傳統自然搜尋結果...               │
  └─────────────────────────────────┘
```

> **關鍵數據：** 46% 的 Google 搜尋具有在地意圖。76% 的使用者在手機搜尋「附近的...」後 24 小時內會造訪實體商家。

## 在地 SEO 與一般 SEO 的關鍵差異

| 面向 | 一般 SEO | 在地 SEO |
|------|---------|----------|
| **主要目標** | 在搜尋結果中排名 | 在 Local Pack 和 Google Maps 中排名 |
| **核心訊號** | 反向連結、內容品質、技術 SEO | Google 商家檔案、NAP 一致性、在地評論 |
| **競爭對手** | 全國/全球 | 同城市、同區域 |
| **排名因素** | 200+ | 在地相關性、距離、商家知名度 |
| **關鍵平台** | 你的網站 | Google 商家檔案（GBP） |

## Local Pack 排名三大因素

Google 的在地排名基於三個核心因素：

### 1. 相關性（Relevance）

你的商家檔案與使用者的搜尋有多匹配？

```
提升相關性的方法：
  ☑ 選擇正確的商家類別（Primary Category）
  ☑ 在商家描述中自然地包含相關關鍵字
  ☑ 發布與你的服務相關的內容（Google Posts）
  ☑ 明確列出你提供的產品和服務
```

### 2. 距離（Distance）

使用者與商家之間的物理距離。這是你**無法直接控制**的因素，但你可以：

```
策略：
  → 如果有多個分店，建立每個分店的獨立 GBP
  → 在商家檔案中明確標示服務區域
  → 考慮在搜尋量高的區域設立新的服務點
```

### 3. 知名度（Prominence）

你的商家在線上和線下有多知名？

```
知名度的來源：
  ✅ Google 評論的數量和評分
  ✅ 在地目錄和引用網站的數量與品質
  ✅ 你的網站在一般搜尋中的排名
  ✅ 社群媒體上的品牌曝光
  ✅ 新聞報導和公關曝光
  ✅ 在地反向連結
```

## 在地 SEO 的搜尋者行為模式

### 「Near Me」搜尋的爆炸性增長

```
2018-2026 年「near me」搜尋的變化：
  「near me」+「now」搜尋增長 150%
  「open now near me」增長 200%
  行動裝置上的在地搜尋占 70%+
```

### 使用者期望的資訊

當使用者在手機上搜尋在地商家時，他們最常尋找：

| 資訊 | 重要性 | 你的 GBP 應該提供 |

| 營業時間 | 🔥🔥🔥🔥🔥 | 準確並即時更新（含假日） |

| 電話號碼 | 🔥🔥🔥🔥 | 可直接點擊撥打 |

## 在地 SEO 的新趨勢（2026）

### 1. AI 驅動的在地搜尋

Google 的 SGE（Search Generative Experience）和 AI Overviews 正在改變在地搜尋的呈現方式。AI 會直接彙總多個商家的資訊，提供更豐富的在地搜尋結果。

### 2. 零點擊在地搜尋增加

越來越多使用者在 Google Maps / Local Pack 中完成所有資訊獲取，不需要點擊進入網站。

```
對策：
  → 確保 GBP 上的資訊極度完整
  → Local Pack 上的資訊就是你的「新首頁」
```

### 3. 語音搜尋的在地化

「OK Google，最近的咖啡店在哪裡？」這類語音搜尋高度依賴在地 SEO。

```
語音搜尋優化：
  → 使用自然語言和對話式內容
  → 問答格式的內容更容易被語音助手引用
  → 確保「near me」類的查詢能觸發你的商家
```

### 4. 在地化內容與社群融入

Google 越來越看重商家與在地社群的連結。參與在地活動、贊助、在地新聞報導都會正面影響在地排名。

## 在地 SEO 的快速啟動清單

如果你今天才開始做在地 SEO，這是你應該做的第一輪動作：

```
第 1 週：
  ☐ 建立/認領你的 Google 商家檔案
  ☐ 填寫所有資訊（類別、營業時間、服務、照片）
  ☐ 確認 NAP（名稱/地址/電話）在網站上正確

第 2 週：
  ☐ 在主要在地目錄建立檔案（Yelp、OpenRice、TripAdvisor 等）
  ☐ 請 5 位滿意的客戶留下 Google 評論
  ☐ 建立一個在地化的網站頁面（例如：/hong-kong-store）

第 3 週：
  ☐ 發布第一篇 Google Post
  ☐ 回覆所有現有的 Google 評論
  ☐ 確保網站有 Schema 結構化資料（LocalBusiness）

第 4 週：
  ☐ 開始追蹤在地排名
  ☐ 建立一個簡單的本地反向連結（例如：在地商會、合作夥伴）
  ☐ 每月發布 Google Post 並持續管理評論
```
