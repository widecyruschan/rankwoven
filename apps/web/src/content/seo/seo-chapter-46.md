## 什麼是本地 SEO？

**本地 SEO（Local SEO）** 是針對「地理位置相關搜尋」的優化策略。當使用者搜尋帶有地理意圖的關鍵字時，Google 會顯示本地搜尋結果。

```
香港使用者在 Google 搜尋：
  「香港 咖啡店」
  「我附近嘅牙醫」
  「尖沙咀 日本料理」
  「旺角 邊間補習社好」

Google 的回應：
  ┌─────────────────────────────────┐
  │  Local Pack（地圖結果 + 3 商家）   │
  │  🏪 咖啡店 A  ⭐4.8  📞         │
  │  🏪 咖啡店 B  ⭐4.5  📞         │
  │  🏪 咖啡店 C  ⭐4.3  📞         │
  │  [更多商家]                       │
  ├─────────────────────────────────┤
  │  傳統自然搜尋結果...               │
  └─────────────────────────────────┘
```

> **關鍵數據：** 46% 的 Google 搜尋具有本地意圖。76% 的使用者在手機搜尋「附近的...」後 24 小時內會造訪實體商家。
>
> **香港背景：** Google 喺香港佔約 92-95% 搜尋份額（其餘：Yahoo 香港 ~3-6%、Bing ~3-5%），所以香港本地 SEO = 主攻 Google，同時唔好忽略 Bing（因為 Copilot 用 Bing 索引）同 Yahoo 香港（35+ 族群仍有份額）。

## 本地 SEO 與一般 SEO 的關鍵差異

| 面向 | 一般 SEO | 本地 SEO（香港） |
|------|---------|----------|
| **主要目標** | 在搜尋結果中排名 | 在 Local Pack 和 Google Maps 中排名 |
| **核心訊號** | 反向連結、內容品質、技術 SEO | Google 商家檔案、NAP 一致性、本地評論 |
| **競爭對手** | 全港/全球 | 同區（例如尖沙咀 vs 尖沙咀，唔係尖沙咀 vs 中環） |
| **排名因素** | 200+ | 本地相關性、距離、商家知名度 |
| **關鍵平台** | 你的網站 | Google 商家檔案（GBP）+ OpenRice（餐飲） |

## Local Pack 排名三大因素

Google 的本地排名基於三個核心因素：

### 1. 相關性（Relevance）

你的商家檔案與使用者的搜尋有多匹配？

```
提升相關性的方法：
  ☑ 選擇正確的商家類別（Primary Category）
  ☑ 在商家描述中自然地包含相關關鍵字（繁中 + 英文）
  ☑ 發布與你的服務相關的內容（Google Posts）
  ☑ 明確列出你提供的產品和服務（價錢用 HK$）
```

### 2. 距離（Distance）

使用者與商家之間的物理距離。這是你**無法直接控制**的因素，但你可以：

```
策略（香港 18 區場景）：
  → 如果有多個分店，建立每個分店的獨立 GBP
    （中環、銅鑼灣、尖沙咀、旺角、沙田、將軍澳、元朗...）
  → 在商家檔案中明確標示服務區域
  → 考慮在搜尋量高的區域設立新的服務點（例如由觀塘擴去將軍澳）
```

### 3. 知名度（Prominence）

你的商家在線上和線下有多知名？

```
知名度嘅來源（香港版）：
  ✅ Google 評論的數量和評分
  ✅ OpenRice 評論（餐飲業命脈）、TripAdvisor（旅遊）、Facebook 推薦
  ✅ 本地目錄和引用網站的數量與品質（黃頁、HKTDC、旅發局、商會）
  ✅ 你的網站在一般搜尋中的排名
  ✅ 社群媒體曝光（Facebook 專頁、IG、小紅書、LIHKG 討論）
  ✅ 香港新聞媒體報導（香港01、明報、經濟日報、星島、頭條）
  ✅ 本地反向連結（區內合作夥伴、學校、商會）
```

## 本地 SEO 的四大支柱（香港版）

```
支柱 1：Google 商家檔案（GBP）
  → 完整填寫、定期更新、積極管理評論
  → 香港 GBP 完全可用，係本地 SEO 基石
  → 詳見第 47 章

支柱 2：本地引用與 NAP 一致性
  → 確保名稱、地址（香港格式）、+852 電話在全網一致
  → 香港平台：OpenRice、TripAdvisor、黃頁、Facebook、HKTDC、香港旅發局、商會目錄
  → 詳見第 49 章

支柱 3：本地評論管理
  → Google 評論為主；餐飲業必須同時做 OpenRice
  → 鼓勵正面評論、專業回覆負面評論（可用廣東話 + 英文）
  → 詳見第 48 章

支柱 4：本地化網站內容
  → 18 區 / 地區著陸頁、本地部落格內容
  → 例如「沙田區裝修指南」「港島區牙科收費比較」
  → 詳見第 47、50 章
```

## 本地 SEO 的搜尋者行為模式

### 「Near Me」搜尋的爆炸性增長

```
2018-2026 年「near me」搜尋的變化：
  「near me」+「now」搜尋增長 150%
  「open now near me」增長 200%
  行動裝置上的本地搜尋占 70%+
```

> **香港版口語查詢：** 香港人唔一定打「near me」，更多會打「旺角 邊間好」「銅鑼灣 推介」「幾錢」「平唔平」「值唔值」「附近有冇」。做關鍵字研究時要把呢啲粵語口語變體納入。

### 使用者期望的資訊

| 資訊 | 重要性 | 你的 GBP 應該提供 |
|------|--------|------------------|
| 營業時間 | 🔥🔥🔥🔥🔥 | 準確並即時更新（含香港公眾假期、八號風球安排） |
| 地址/位置 | 🔥🔥🔥🔥🔥 | 精確香港地址（大廈 + 樓層 + 室號）+ 港鐵出口指引 |
| 電話號碼 | 🔥🔥🔥🔥 | +852 8 位數字，可直接點擊撥打 |
| 評分和評論 | 🔥🔥🔥🔥 | 積極管理 Google + OpenRice 評論 |
| 網站連結 | 🔥🔥🔥🔥 | 連結到你的官網或預約頁面 |
| 照片 | 🔥🔥🔥🔥 | 高質素的舖面同內部照片 |
| 選單/服務清單 | 🔥🔥🔥 | 完整且更新（價錢用 HK$） |
| 熱門時段 | 🔥🔥 | Google 自動從造訪數據生成 |

## 本地 SEO 的新趨勢（2026）

### 1. AI 驅動的本地搜尋

Google 的 AI Overviews / AI Mode 正在改變本地搜尋的呈現方式。AI 會直接彙總多個商家的資訊，提供更豐富的本地搜尋結果。

```
例如搜尋「中環 適合商務午餐嘅餐廳」：
  AI 會綜合 Google 評論、OpenRice 評價、香港媒體報導、
  部落格文章，然後列出 3-5 間並附理由。

→ 你要做嘅：確保 NAP 一致、評論量足、有第三方正面提及
```

### 2. 零點擊本地搜尋增加

越來越多香港使用者在 Google Maps / Local Pack 中完成所有資訊獲取，不需要點擊進入網站。

```
對策：
  → 確保 GBP 上的資訊極度完整
  → Local Pack 上的資訊就是你的「新首頁」
  → 餐飲業同時要打理 OpenRice（很多人直接喺 OpenRice 決定去邊食）
```

### 3. 語音搜尋的本地化

「OK Google，最近的便利店喺邊？」這類語音搜尋高度依賴本地 SEO。

```
語音搜尋優化（香港雙語）：
  → 使用自然語言和對話式內容（廣東話口語 + 英文）
  → 問答格式的內容更容易被 AI 助手引用
  → 確保「near me」「附近」類的查詢能觸發你的商家
```

### 4. 本地化內容與社群融入

Google 越來越看重商家與本地社群的連結。參與區內活動、贊助、區內新聞報導都會正面影響本地排名。

```
香港做法：
  → 贊助區內學校/體育會活動、參與各區商會
  → 喺 LIHKG / Facebook 地區社團有真實討論（唔係洗版）
  → 被區內媒體（例如地區報、香港01 地區版）報導
```

## 本地 SEO 的快速啟動清單（香港版）

如果你今天才開始做本地 SEO，這是你應該做的第一輪動作：

```
第 1 週：
  ☐ 建立/認領你的 Google 商家檔案（GBP）
  ☐ 填寫所有資訊（類別、營業時間、服務、照片）
  ☐ 確認 NAP（名稱/香港地址/+852 電話）在網站上正確

第 2 週：
  ☐ 在香港主要本地目錄建立檔案
     （OpenRice、TripAdvisor、黃頁 HK、Facebook、HKTDC、所屬商會）
  ☐ 請 5 位滿意的客人留下 Google 評論（餐飲加做 OpenRice）
  ☐ 建立一個本地化的網站頁面（例如：/zh-hk/locations/tsim-sha-tsui）

第 3 週：
  ☐ 發布第一篇 Google Post（可以配合節日：農曆新年、聖誕、暑假）
  ☐ 回覆所有現有的 Google 評論（廣東話 + 英文都得）
  ☐ 確保網站有 LocalBusiness Schema（詳見第 52 章）

第 4 週：
  ☐ 開始追蹤本地排名（手動無痕搜尋或 BrightLocal）
  ☐ 建立一個本地反向連結（區內商會、合作夥伴、學校/機構）
  ☐ 每月發布 Google Post 並持續管理評論
```

## 香港法規小提醒

```
◼ PDPO《個人資料（私隱）條例》
  → 收集客人資料（預約表單、會員登記、評論活動）要講清用途

◼ 行業廣告規管
  → 地產代理（EAA）、證監（SFC）、保監局（IA）對相關行業
    廣告內容有規管；GBP 描述、Post、網站文案都受影響

◼ 消委會指引
  → 顯示價錢通常為 HK$，需列明「已包／未包」其他費用
  → 唔好喺 GBP 或網站寫誤導性優惠（可構成不良營商手法）
```
