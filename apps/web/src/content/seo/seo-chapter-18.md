## 什麼是 Meta Description？

**Meta Description（元描述）** 是 HTML 文件 `<head>` 區域中的一個標籤，用來提供頁面內容的簡短摘要。它通常顯示在搜尋結果頁面（SERP）的標題下方，以灰色小字呈現。

```html
<head>
  <meta name="description" content="這是一段 150-160 字元的頁面描述，會顯示在 Google 搜尋結果的標題下方，幫助使用者決定是否點擊進入你的頁面。">
</head>
```

### Meta Description 的角色轉變

| 時期 | 角色 |
|------|------|
| **2009 年前** | 排名因子（Google 會根據 Description 中的關鍵字來排名） |
| **2009 年以後** | Google 官方宣布 Description **不再是排名因子** |
| **現在** | 純粹的**點擊率優化工具**和**使用者體驗元素** |

> 關鍵理解：Meta Description 不直接影響排名，但一個好的 Description 能顯著提升 CTR，而 CTR 的提升**可能**間接影響排名。

## 香港市場嘅 Meta Description 特別考量

| 考量 | 說明 |
|------|------|
| **用香港人嘅字** | 香港人寫「推介」「收費」「邊間好」「平唔平」「值唔值」；唔好用「推薦」「費用」「哪家強」（台灣／大陸腔會令香港人覺得係外地網站，CTR 會跌） |
| **價錢寫 HK$** | 香港用家對價錢極敏感，Description 入面寫明「HK$298 起」好過「價格優惠」 |
| **寫明地區與送貨範圍** | 「旺角門市即日取」「全港 18 區免運」呢類字對香港 CTR 提升明顯 |
| **列明包唔包其他費用** | 配合消委會指引，香港商戶顯示價錢通常要列明係咪「已包其他費用」，Description 都要一致，否則會推高跳出率 |
| **中英夾雜要節制** | 專業／金融／B2B 場景可以中英夾雜，但生活消費類最好全繁中 + 粵語口語 |

## Meta Description 不直接影響排名，為什麼還重要？

### 1. CTR（點擊率）的直接驅動

資料顯示，優化過的 Meta Description 可以將 CTR 提升 **5-15%**。在 SERP 中，Description 是使用者決定要不要點進去的第二個判斷依據（第一個是 Title Tag）。

### 2. 提升搜尋結果的「佔有率」

良好的 Description 讓你的搜尋結果在視覺上更突出、更專業，從而在眾多結果中脫穎而出。

> **香港實況**：香港商業類關鍵字嘅 SERP 通常擠滿連登帖、OpenRice、香港01 等高權威平台。你嘅 Description 如果得一句「我們提供優質服務」，喺呢堆結果入面完全冇存在感——一定要寫具體（價錢、地區、年份、數量）。

### 3. 間接排名影響

雖然 Google 官方表示 Description 不直接影響排名，但學界和業界的多項研究表明：
- 高 CTR → Google 認為你的結果更符合使用者需求 → 排名可能上升
- 低跳出率（好 Description 能設定正確預期）→ 正向使用者體驗信號

### 4. 社群分享的預設描述

當你的頁面被分享到 Facebook、LinkedIn、WhatsApp 等平台時，Meta Description 通常會作為預設的分享文字（如果沒有設定專門的 OG Description）。

> **香港補充**：香港人最常用 WhatsApp 轉發連結，WhatsApp 預覽會讀取 OG Description，冇嘅話就用 Meta Description。所以 Description 要「單獨睇都講得通」。

## Meta Description 的最佳實踐

### 黃金公式

```
最佳 Meta Description = 價值主張摘要 + 關鍵字自然融入 + 行動呼籲 (CTA)
```

**香港版黃金公式**：
```
價值主張（含 HK$ 價錢／地區／年份） + 香港用語關鍵字自然融入 + CTA
```

### 四大優化法則

#### 法則 1：控制長度

| 裝置 | 建議長度 |
|------|----------|
| **桌面版** | 150-160 字元（約 920px） |
| **行動版** | 約 120 字元（約 680px） |
| **最安全範圍** | 140-155 字元 |

超過上限的部分會被 Google 截斷，以「...」表示。確保核心資訊在前 120 個字元內。

> **香港特別注意**：香港手機搜尋佔比極高（超過七成），行動版得約 120 字元。中文字每個計 2 個字元位，所以中文 Description 實際上得約 60 個中文字——開頭 30 個字之內就要講完核心價值。

**檢查工具**：使用 [Mangools SERP Simulator](https://mangools.com/serp-simulator)（地區設 Hong Kong）預覽 Description 的顯示效果。

#### 法則 2：自然融入關鍵字

Google 會在 SERP 中**粗體顯示**與使用者查詢匹配的關鍵字。當你自然地融入關鍵字時，你的搜尋結果會更顯眼。

| ⭕ 好 | ❌ 差 |
|------|------|
| `想幫你嘅小型犬揀最啱嘅狗糧？我哋整理 2026 年獸醫推介嘅 10 款品牌，由成分分析到 HK$ 價錢比較，幫新手主人做出最好嘅選擇。` | `狗糧推介狗糧品牌狗糧評價狗糧價錢。買狗糧就嚟我哋網站，最好嘅狗糧推介平台。` |

#### 法則 3：加入清晰的 CTA（行動呼籲）

在 Description 末尾加入一個簡潔的行動呼籲，引導使用者點擊：

| CTA 類型 | 香港範例 |
|----------|---------|
| 資訊獲取 | 「立即睇完整指南 →」 |
| 產品購買 | 「限時優惠，即刻選購 →」 |
| 本地服務 | 「免費報價，WhatsApp 查詢 →」 |
| 學習進階 | 「免費下載完整教學 →」 |
| 解決方案 | 「了解點樣解決你嘅問題 →」 |

#### 法則 4：反映頁面內容的真實價值

Description 必須準確反映頁面內容。誇大或誤導的 Description 會導致：
- 高跳出率（使用者點進去發現內容不符）
- Google 可能會重寫你的 Description
- 損害品牌信任度

> **合規提醒（香港）**：如果你喺 Description 寫咗價錢或優惠，頁面入面就要真係有，而且要符合**消委會指引**——標價要列明係咪「已包其他費用」。金融／保險／地產等受規管行業（SFC、IA、EAA）對廣告字眼有額外要求，Description 都算廣告內容一部分。

#### 法則 5：每個頁面的 Description 必須唯一

與 Title Tag 一樣，每個頁面的 Meta Description 必須是唯一的。重複的 Description 會讓 Google 自動生成替代文字，失去你控制搜尋結果外觀的機會。

#### 法則 6：使用主動語態和對話式語氣

| 被動語態 | 主動語態 |
|----------|----------|
| `本頁面提供了關於 SEO 的資訊。` | `學好 SEO 只需 30 日？我哋整理咗由入門到精通嘅完整路徑，帶你一步步掌握香港 Google 排名技巧。` |

#### 法則 7：針對行動版優化

超過 60% 的搜尋來自行動裝置（**香港更加係超過七成**）。行動版的 Description 顯示空間更小，因此：
- 將最重要的資訊放在前 100 個字元（約 50 個中文字）
- 避免冗長的開場白
- 直接切入核心價值（價錢、地區、賣點）

## Google 重寫 Meta Description

與 Title Tag 一樣，Google 經常會重寫 Meta Description。根據研究，約 **63-71%** 的 Meta Description 會被 Google 部分或完全重寫。

### Google 重寫 Description 的常見原因

| 原因 | 解決方法 |
|------|----------|
| Description 太短或太長 | 控制 140-155 字元 |
| Description 與查詢關鍵字無關 | 確保 Description 涵蓋頁面的核心主題（用香港用語） |
| Description 是關鍵字堆砌 | 自然地使用關鍵字 |
| 多個頁面 Description 重複 | 每個頁面使用唯一的 Description |
| Description 未反映頁面實際內容 | 確保 Description 準確描述頁面內容（價錢、地區要一致） |
| Google 認為直接從頁面擷取更準確 | 在頁面關鍵位置放置與 Description 相似的文字 |

### 被重寫時的應對策略

1. **接受現實**：Google 重寫 Description 非常普遍，如果重寫後的版本合理，不用過度擔心
2. **檢查頁面內容**：確保頁面開頭段落包含你希望顯示的核心資訊（HK$ 價錢、地區、年份）
3. **調整 Description**：如果 Google 多次重寫，嘗試調整 Description 的風格和內容
4. **使用結構化資料**：Schema Markup 可以幫助 Google 更準確地理解你的頁面（見第 24 章）

## 何時不該寫 Meta Description？

有些情況下，**不寫 Description 可能更好**：

| 情況 | 原因 |
|------|------|
| 長篇內容頁 | Google 可能從頁面中擷取與查詢更相關的片段 |
| 新聞文章 | Google 傾向從內文擷取最新、最相關的片段 |
| 極度長尾的頁面 | 不同查詢的相關片段不同，Google 更懂得動態生成 |

> **實務建議**：對於你的主力頁面（首頁、核心產品頁、主力內容、地區服務頁），**一定**要寫 Description。對於海量長尾內容，寫一個好的 Description 仍然有幫助，但不要為了寫而寫。

## Meta Description 檢查清單

檢查每個重要頁面的 Description：

- [ ] Description 是否在 140-155 字元以內？（中文約 60-70 個中文字）
- [ ] 是否自然融入了目標關鍵字？（Don't stuff!）
- [ ] 是否用咗香港用語？（推介 / 收費 / 邊間好 / HK$）
- [ ] 是否包含清晰的行動呼籲（CTA）？
- [ ] 是否準確反映了頁面內容？（價錢、地區要同頁面一致）
- [ ] 描述是否有吸引力？會讓人想點擊嗎？
- [ ] 每個頁面的 Description 是否唯一？
- [ ] 在行動裝置上，核心資訊是否在前 100 字元？
- [ ] Google 是否經常重寫這個 Description？
- [ ] 如果頁面被分享到 WhatsApp / Facebook，預覽效果如何？
- [ ] 價錢係唔係 HK$，有冇列明包唔包其他費用？

## 重點回顧

1. **Meta Description 不直接影響排名**，但直接影響 CTR——而 CTR 可能間接影響排名
2. **黃金公式**：價值主張 + 關鍵字自然融入 + CTA（香港版再加 HK$ 價錢與地區）
3. **最佳長度**：140-155 字元，行動版核心資訊在前 100 字元（香港手機佔比超過七成）
4. **用香港人嘅字**：推介 / 收費 / 邊間好 / 平唔平，唔好寫台灣腔
5. **每個頁面的 Description 必須唯一**，否則 Google 會自行生成
6. **約 63-71% 的 Description 會被 Google 重寫**——遵守最佳實踐以盡量保留控制權
7. Description 是**免費的廣告文案**——花心思寫好它，你的 CTR 會回報你
