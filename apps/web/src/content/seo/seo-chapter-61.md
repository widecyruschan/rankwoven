## GEO 是什麼？與傳統 SEO 的關鍵區別

**GEO（Generative Engine Optimization）** 是針對生成式 AI 搜尋引擎（ChatGPT Search、Perplexity、Google AI Overviews / AI Mode、Gemini、Microsoft Copilot 等）的優化策略。與傳統 SEO 不同，GEO 的目標不是「排名」，而是「被 AI 引用並正確呈現」。

> **香港視角：** 香港用家嘅 AI 接觸點以 **Google AI Overviews / AI Mode** 為主（Google 喺香港佔 ~92-95%），其次係 **ChatGPT、Gemini、Perplexity、Claude**；**Microsoft Copilot / Bing** 雖然只有約 3-5% 份額，但要計埋 **Yahoo 香港搜尋（用 Bing 技術，~3-6%）**同企業 Windows / Edge 環境，實際影響大過數字。AI 搵香港本地資訊時，除咗全球來源（Wikipedia、Reddit、YouTube、LinkedIn），仲會參考 **LIHKG、Discuss.com.hk、Uwants、高登、OpenRice、香港新聞媒體**，以及年輕人愛用嘅 **小紅書（RED）**。

```
傳統 SEO 漏斗：
  使用者搜尋 → 看到你的連結 → 點擊 → 進入網站

GEO 漏斗：
  使用者提問 → AI 生成回答 → 回答中引用你的內容 →
  使用者看到你的品牌/資訊 →
  （可能）點擊引用連結 → 進入網站

關鍵差異：
  → 傳統 SEO：競爭的是 SERP 上的位置
  → GEO：競爭的是 AI「心中的」權威地位
  → 傳統 SEO：使用者主動搜尋
  → GEO：使用者可能根本不知道你的存在，是 AI 決定了要引用誰
```

## GEO 的四大優化領域

```
領域 1：內容可引用性（Citeability）
  你的內容是否容易被 AI 提取和引用？

領域 2：品牌權威度（Brand Authority）
  AI 是否認為你的品牌是可信的資訊來源？

領域 3：語義存在感（Semantic Presence）
  你的品牌和內容是否在 AI 的訓練資料和索引中？

領域 4：格式適配性（Format Compatibility）
  你的內容格式是否適配 AI 的回答生成方式？
```

## 領域 1：內容可引用性（Citeability）

### 讓你的內容「值得被引用」

AI 引用內容時，偏好以下特性：

```
✅ 高可引用性的內容特徵：

1. 有明確的「引用句」
   AI 傾向引用可以直接放入回答中的句子。

   ❌ 低可引用性：
     「植牙其實有很多要考慮的地方，每個人的情況都不一樣，
     但一般來說如果處理得當效果都不錯。」

   ✅ 高可引用性：
     「根據臨床研究，現代植牙的 10 年成功率達 95% 以上。」

2. 有獨特的數據點
   AI 傾向引用提供「獨特數據」的來源。

   ✅ 高可引用性：
     「2026 年香港大學牙醫學院的研究顯示，
     香港成年人中有 45% 曾考慮接受植牙治療。」
     （香港內容嘅獨特數據特別值錢：AI 搵「香港植牙」時，
      全球來源通常冇本地數字，你嘅原創數據就係首選）

3. 結構化的定義
   AI 偏好引用清晰的定義句。

   ✅ 高可引用性：
     「植牙（Dental Implant）是一種以外科手術方式，
     將人工牙根（植體）植入顎骨，替代缺失牙齒的治療方式。」

4. 步驟化的說明
   AI 偏好有明確順序的步驟。

   ✅ 高可引用性：
     「Step 1: 初步評估 → Step 2: 植入手術 →
      Step 3: 骨整合期 → Step 4: 安裝牙冠」
```

### 創建「引用句（Cited Sentences）」的策略

```
為每一篇重要文章建立「引用句清單」：

文章主題：隱形牙套矯正完整指南

引用句 1（定義型）：
  「Invisalign 隱形牙套是一種使用透明、可拆卸的塑膠牙套，
  逐步移動牙齒以達到矯正效果的治療方式。」

引用句 2（數據型）：
  「根據 Invisalign 官方數據，全球已有超過 1,400 萬人
  使用 Invisalign 完成牙齒矯正。」

引用句 3（比較型）：
  「相比傳統金屬牙套，隱形牙套的平均治療時間縮短約 20%，
  且回診頻率減少約 30%。」

引用句 4（建議型）：
  「牙醫建議，每天佩戴隱形牙套 20-22 小時，
  僅在進食和刷牙時取下，以確保最佳矯正效果。」

引用句 5（香港本地型 — 本地查詢最易被引用）：
  「香港私家診所隱形牙套療程一般 HK$25,000 起，
   另設銅鑼灣、尖沙咀、沙田分店，覆診約 6-8 次。」
   → 包埋 HK$ 價錢、地區、分店，AI 答「香港 Invisalign 幾錢」
     時可以直接拎嚟用

將這些引用句放在文章中的顯眼位置（開頭、h2 下的第一段、
重要結論），而非埋在文章深處。
```

## 領域 2：品牌權威度（Brand Authority）

### AI 如何判斷「這個品牌可信嗎？」

```
AI 的品牌權威度判斷維度：

1. 品牌在網絡上的「存在密度」
   → 品牌名稱在多少權威頁面上出現？
   → 品牌被多少其他網站提及？
   → 品牌是否有 Wikipedia / Wikidata 條目？

2. 品牌的「專業背書」
   → 是否有專業認證的公開記錄？
   → 是否被行業協會列出？
   → 是否獲得過行業獎項？

3. 品牌的「媒體能見度」
   → 是否被主流媒體報導過？
   → 報導的內容是正面還是負面？
   → 報導的媒體本身是否權威？

4. 品牌的「一致性」
   → 品牌資訊在不同平台是否一致？
   → 品牌名稱、地址、聯絡方式是否統一？
```

### 建立品牌權威度的 GEO 策略

```
策略 1：數位足跡最大化

  目標：讓品牌出現在 AI 可能「看到」的每一個地方

  ☐ 行業目錄（確保 NAP 一致）
  ☐ 專業協會網站
  ☐ Google Business Profile（香港本地 SEO 基石）
  ☐ Bing Places / Bing Webmaster Tools
     （Yahoo 香港搜尋 + ChatGPT / Copilot 索引來源）
  ☐ Wikipedia / Wikidata（如符合標準）
  ☐ Crunchbase / 企業資訊平台
  ☐ 行業報告和研究（被引用）

  香港本地足跡（AI 搵本地答案時會參考）：
  ☐ 香港新聞媒體：香港01、明報、經濟日報、星島、東方、
     頭條日報、am730、信報、HKET、商業電台、TVB
  ☐ OpenRice（餐飲）、TripAdvisor（旅遊）、
     28Hse / 星之谷（地產）、Car1.hk（汽車）
  ☐ 社群口碑：LIHKG（連登）、Discuss.com.hk、Uwants、
     高登、Facebook 社團、Instagram
  ☐ 小紅書（RED）：香港年輕人 discovery 入口，影響力上升中
  ☐ 官方 / 半官方：公司註冊處（ICRIS）、香港貿發局（HKTDC）、
     香港中華總商會、生產力促進局、香港旅發局、
     政府「資料一線通」

策略 2：專業背書可視化

  將你的專業資格展示在 AI 可以讀取的地方：

  → 網站上的「關於我們」頁面 + Person Schema
  → 行業目錄上的專業檔案
  → LinkedIn 個人頁面（公開、完整填寫）
  → 學術平台（Google Scholar、ResearchGate）

策略 3：媒體曝光策略化

  不只是追求媒體曝光，而是確保媒體報導的內容
  包含 AI 可以提取的「品牌資訊」：

  → 報導中包含你的完整品牌名稱和核心服務描述
  → 報導中包含你的專業背景
  → 線上版本中確保品牌名稱是文字（不是圖片）

  香港數位 PR 重點媒體：
  → 大眾：香港01、明報、東方日報、星島日報、頭條日報、am730
  → 財經 / B2B：信報、經濟日報、HKET
  → 廣播：商業電台、TVB
  → 呢批媒體喺 Google 權威度高，AI 引用香港資訊時經常拎佢哋做來源
```

## 領域 3：語義存在感（Semantic Presence）

### 你的品牌在 AI 的「語義地圖」中在哪裡？

```
AI 的語義理解：

當 AI 「思考」牙科服務時：

  AI 的關聯網絡：
  牙科服務
    ├── 植牙 ─── 陳大明牙醫診所 ✅（你存在於此！）
    │   ├── 瑞士 Straumann 植體
    │   ├── 即日植牙
    │   └── 微創植牙
    ├── 隱形牙套
    ├── 牙齒美白
    └── 根管治療

問題：如果你在 AI 的語義地圖中不存在，
      當 AI 被問到「香港植牙推薦」時，
      你根本不在候選名單上。

目標：讓你的品牌在關鍵的語義節點上出現。
```

### 如何建立語義存在感？

```
方法 1：主題集群（Topic Clusters）

  不只是寫一篇「植牙」的文章，
  而是建立一個完整的植牙主題集群：

  樞紐頁面（Pillar）：
    植牙完整指南（3,000 字）

  集群頁面（Cluster，8-10 篇）：
    → 植牙 vs 牙橋：哪個更適合你？
    → 植牙費用完全解析 2026
    → 植牙過程：從評估到完成
    → 植牙痛不痛？真實經驗分享
    → 全口植牙：All-on-4 技術詳解
    → 植牙保險：哪些保險覆蓋植牙？
    → 植牙失敗的原因和預防方法
    → 植牙後護理完整指南

  效果：
  → AI 在你的網站上找到多篇植牙相關內容
  → AI 判斷你在植牙主題上「有深度」
  → 你的品牌在 AI 的植牙語義節點上建立存在感

方法 2：在權威平台上建立主題權威

  不僅僅是你的網站，在外部平台上也建立主題內容：

  → 在 Medium / Substack 發表行業文章
  → 在 LinkedIn 發布專業見解（香港 B2B / 金融 / 專業服務必爭）
  → 在行業論壇回答專業問題
  → 成為媒體報導中的專家評論來源

  香港等效平台（本地語義存在感）：
  → LIHKG（連登）、Discuss.com.hk、Uwants、高登
    → 香港最大討論區，Google 權威高，AI 會當作「本地真實意見」
  → OpenRice（餐飲）、TripAdvisor（旅遊）
  → Facebook 社團（香港家長 / 消費者 / 行業群組極活躍）
  → 小紅書（RED）：美妝、餐飲、旅遊、生活資訊嘅香港 discovery 入口
  → YouTube（香港 KOL / 教學片，Google 索引強）

  ⚠️ 但書：國際 AI 仍然大量引用 Wikipedia、Reddit、YouTube、
     LinkedIn 等全球英文來源，呢點唔會變。
     本地平台係「補充」，唔係「取代」——兩層都要做。

  效果：
  → AI 在不同平台上看到你的專業內容
  → 品牌在該主題的語義網絡中無處不在
```

## 領域 4：格式適配性（Format Compatibility）

### AI 偏好哪些內容格式？

根據研究，以下格式的內容最容易被 AI 引用：

| 格式 | 被 AI 引用機率 | 說明 |
|------|:-----------:|------|
| **FAQ（問答）** | 🔥🔥🔥🔥🔥 | AI 可以直接提取 QA 對 |
| **How-to（步驟指南）** | 🔥🔥🔥🔥🔥 | AI 偏好有步驟的內容 |
| **Listicle（清單文章）** | 🔥🔥🔥🔥 | 「10 大」「最佳 5 個」等 |
| **數據報告** | 🔥🔥🔥🔥 | 獨特數據極受歡迎 |
| **比較表** | 🔥🔥🔥🔥 | AI 做比較時會引用 |
| **定義頁面** | 🔥🔥🔥🔥 | 術語解釋型內容 |
| **傳統文章** | 🔥🔥 | 除非極度權威，否則偏好結構化格式 |
| **影片/播客** | 🔥 | AI 較難從中提取資訊 |

### 為 AI 優化內容格式

```
做法 1：在文章中加入 FAQ 區塊

  ## 常見問題（FAQ）

  ### 植牙痛不痛？
  [2-3 句精確答案]

  ### 植牙可以用多久？
  [2-3 句精確答案，含數據]

  ### 哪些人不適合植牙？
  [2-3 句精確答案，含醫學術語]

  記得加入 FAQ Schema！

做法 2：使用 How-to 結構

  ## 如何選擇植牙醫生？5 步驟指南

  第 1 步：檢查執業資格
  [簡潔說明]

  第 2 步：審查經驗年資
  [簡潔說明]

  ...

  記得加入 HowTo Schema！

做法 3：建立獨立的數據頁面

  /data/hk-dental-implant-statistics-2026/

  內容：
  → 2026 年香港植牙市場數據
  → 成功率統計
  → 費用範圍統計（以 HK$ 計，分港島 / 九龍 / 新界）
  → 各地區植牙數量對比

  在整個網站中引用這個數據頁面，
  使其成為「數據樞紐」。
```

### 實例 1：從部落格文章到 GEO 優化文章

### 實例 2：Perplexity 優化策略

```
Perplexity 的特性：
  → 每個回答都有明確的來源引用
  → 偏好學術性和數據驅動的內容
  → 答案以段落為主，引用以角標顯示

Perplexity 優化重點：
  ✅ 內容中要有明確的「事實陳述」
  ✅ 引用來源（讓 Perplexity 可以追溯）
  ✅ 避免模糊用語（「有人說」「一般認為」）
  ✅ 使用學術寫作語氣（可以在某些頁面）

實例：
  Perplexity 查詢：「香港植牙平均費用」

  被引用的來源：
  ✅ 「根據 2026 年香港牙醫學會調查，
      香港單顆植牙的平均費用為 HK$20,000-35,000。」
  ✅ 香港新聞媒體（經濟日報 / 香港01）嘅醫療費用報導
  ✅ OpenRice 式本地目錄、診所官網嘅清晰價目表

  ❌ 不容易被引用的：
     「植牙費用因人而異，最好諮詢牙醫獲取報價。」
     「價錢實惠，歡迎查詢。」（冇數字 = 冇得引用）
```

### 實例 3：ChatGPT Search 優化策略

```
ChatGPT Search 的特性：
  → 傾向引用有「即時性」的資訊
  → 偏好來源多樣化
  → 回答更口語化和互動性

ChatGPT Search 優化重點：
  ✅ 內容應該能回答「連續追問」
  ✅ 確保你的內容出現在即時索引中
  ✅ 內容中預測並回答後續問題

實例：
  香港使用者問 ChatGPT：「中環有咩牙醫推介？」

  ChatGPT 可能引用你的內容，如果：
  → 你的頁面中有「中環牙醫推介」相關內容
     （用粵語口語字都包埋，對應真實查詢）
  → 你的頁面提到具體服務和 HK$ 價格
  → 你的 GBP 資訊完整（ChatGPT 會參考 GBP 數據）
  → 你喺 Bing 索引入面（ChatGPT 搜尋大量依賴 Bing，
     所以香港網站一定要交 Bing Webmaster Tools）
  → 你嘅品牌喺 LIHKG / OpenRice / 香港媒體有正面討論
```

## GEO 的測量與追蹤

### 你無法用傳統 SEO 工具追蹤 GEO

```
傳統 SEO KPI：
  → 排名位置 → Ahrefs / Semrush 追蹤
  → 點擊率 → Google Search Console
  → 自然流量 → Google Analytics

GEO 需要的新 KPI：
  → 品牌被 AI 引用的次數 → 新興工具
  → AI 引用中的品牌曝光度 → 需手動追蹤
  → 被 AI 引用後的網站流量 → GA4（來源標記）

目前的追蹤方法：
  1. 手動測試（最可靠）
     定期在 ChatGPT、Gemini、Perplexity、Copilot、
     Google（AI Overviews / AI Mode）中
     搜尋你的行業關鍵字，記錄你的品牌是否被引用
     → 香港做法：用廣東話 + 粵語口語字測試
       （「邊間好」「推介」「點揀」「平唔平」）

  2. 新興工具
     → ZipTie（AI 引用監控）
     → AIOSEO 引用追蹤功能
     → 使用 Brand24 追蹤品牌被提及
       （記得設定監測 LIHKG、Discuss、Uwants、小紅書）

  3. GA4 輔助
     查看 Referral 流量中是否有來自
     perplexity.ai、chatgpt.com、gemini.google.com、
     copilot.microsoft.com 等來源
```

### 第 1-2 個月：打好可引用性基礎

```
☐ 強化數據點（引用研究、統計、調查）
```
