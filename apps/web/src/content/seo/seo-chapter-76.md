## 角色一：SEO 策略經理（SEO Strategy Manager）

### 核心職責
- 制定整體 SEO 策略與路線圖
- 跨部門協調（行銷、工程、內容、產品）
- 預算管理與 ROI 追蹤
- 向上報告 SEO 成效
- 競爭對手分析
- 產業趨勢追蹤

### 必備技能
| 技能 | 重要度 | 說明 |
|------|--------|------|
| SEO 全領域知識 | ⭐⭐⭐⭐⭐ | 技術、內容、連結都要懂 |
| 策略思維 | ⭐⭐⭐⭐⭐ | 不只執行，還要會規劃 |
| 數據分析 | ⭐⭐⭐⭐ | 從數據中找出機會和問題 |
| 溝通能力 | ⭐⭐⭐⭐ | 向老闆報告、跨部門協調 |
| 專案管理 | ⭐⭐⭐⭐ | 同時管理多條工作線 |
| 商業思維 | ⭐⭐⭐ | 理解 SEO 如何貢獻營收 |

### 典型背景
- 3-5 年 SEO 實戰經驗
- 曾經管理過 SEO 團隊或專案
- 有成功案例（可量化的 SEO 成效）

### 日常工作節奏
```
每日：
  - 查看 SEO Dashboard（流量/排名異常）
  - 查看 GSC 通知（手動操作、安全問題）

每週：
  - 團隊 1:1 或小組會議
  - 內容進度審查
  - 競爭對手動態檢查

每月：
  - 月報製作與報告
  - 策略會議（調整下月重點）
  - 預算審查

每季：
  - 季度回顧 + 策略大調整
  - 團隊績效評估
```

## 角色二：SEO 專員（SEO Specialist）

### 核心職責
- 關鍵字研究與矩陣維護
- On-Page SEO 優化（Title、Meta、H1、內部連結）
- 內容 Brief 撰寫（給寫手的 SEO 指引）
- GSC / GA4 日常監控
- 排名追蹤
- 競爭對手內容分析
- 基礎技術 SEO（robots.txt、Sitemap、Canonical）

### 必備技能
| 技能 | 重要度 | 說明 |
|------|--------|------|
| 關鍵字研究 | ⭐⭐⭐⭐⭐ | 核心基本功 |
| On-Page SEO | ⭐⭐⭐⭐⭐ | 日常最常做的事 |
| GSC / GA4 操作 | ⭐⭐⭐⭐⭐ | 數據來源 |
| SEO 工具使用 | ⭐⭐⭐⭐ | Ahrefs, SEMrush, Screaming Frog |
| 基礎 HTML/CSS | ⭐⭐⭐ | 能看懂和修改簡單代碼 |
| 內容判斷力 | ⭐⭐⭐ | 能判斷內容是否滿足搜尋意圖 |
| 英文閱讀能力 | ⭐⭐⭐ | 大部分 SEO 資源是英文的 |

### 典型背景
- 1-3 年 SEO 經驗
- 或從內容行銷 / 數位行銷轉職
- 有個人網站或 Side Project SEO 經驗加分

### SEO 專員的成長路徑
```
初階 SEO 專員（0-2 年）
  → 執行既定策略、學習基本功

中階 SEO 專員（2-4 年）
  → 獨立制定策略、帶領小專案

資深 SEO 專員 / 策略經理（4-6 年）
  → 管理團隊、制定整體策略

SEO 總監 / VP（6+ 年）
  → 多市場策略、預算管理、商業決策
```

## 角色三：技術 SEO 工程師（Technical SEO Engineer）

### 核心職責
- 網站技術 SEO 審計
- Core Web Vitals 優化
- JavaScript SEO（確保 JS 內容可被索引）
- 結構化資料實作（Schema Markup）
- Crawl Budget 優化
- 網站搬遷 SEO
- Log File Analysis
- 與開發團隊合作實現 SEO 需求

### 必備技能
| 技能 | 重要度 | 說明 |
|------|--------|------|
| HTML/CSS/JavaScript | ⭐⭐⭐⭐⭐ | 能讀懂並修改前端代碼 |
| 爬蟲工具（Screaming Frog） | ⭐⭐⭐⭐⭐ | 技術審計基本功 |
| 網站效能優化 | ⭐⭐⭐⭐ | CWV、CDN、快取策略 |
| 伺服器/主機知識 | ⭐⭐⭐⭐ | Log 分析、伺服器設定 |
| Python / SQL | ⭐⭐⭐ | 自動化腳本、數據處理 |
| Schema 結構化資料 | ⭐⭐⭐⭐ | JSON-LD 實作 |
| CMS 開發知識 | ⭐⭐⭐ | WordPress 等 CMS 的 SEO 設定 |

### 技術 SEO 工程師 vs 一般工程師
| 面向 | 一般前端工程師 | 技術 SEO 工程師 |
|------|---------------|----------------|
| 關注點 | 使用者體驗 | Googlebot 體驗 + 使用者體驗 |
| 效能指標 | 主觀感受 | LCP / INP / CLS（客觀數據） |
| 渲染方式 | CSR 優先（React/Vue） | SSR / SSG 優先 |
| 連結設計 | 美觀優先 | 可爬取性優先 |

### 日常工作
```
每日：
  - 監控網站健康狀態（uptime、錯誤頁面）
  - 查看 GSC 技術指標（CWV、索引狀態）

每週：
  - 與開發團隊同步 SEO 需求
  - 實作新的 Schema 標記
  - 檢查新部署的功能是否影響 SEO

每月：
  - 完整技術審計
  - Crawl Budget 分析
  - Log File Analysis
```

## 角色四：SEO 內容策略師 / 寫手

### SEO 內容策略師（Content Strategist）

**核心職責：**
- 制定內容行銷策略
- Topic Cluster 規劃
- 內容日曆管理
- 搜尋意圖分析（決定內容格式和角度）
- 內容成效分析

### SEO 寫手（SEO Content Writer）

**核心職責：**
- 根據 SEO Brief 撰寫文章
- 關鍵字自然融入
- 內容結構化（H2/H3 層次）
- 內部連結添加
- 內容更新（Content Refresh）

### 必備技能（寫手）

| 技能 | 重要度 | 說明 |
|------|--------|------|
| 寫作能力 | ⭐⭐⭐⭐⭐ | 最基本的要求 |
| SEO 知識 | ⭐⭐⭐⭐ | 理解關鍵字、搜尋意圖、On-Page |
| 行業知識 | ⭐⭐⭐⭐ | 寫什麼行業就要懂那個行業 |
| 研究能力 | ⭐⭐⭐⭐ | 能把複雜主題轉化為易懂內容 |
| 資料整理 | ⭐⭐⭐ | 善用數據、案例增加內容深度 |
| 編輯校對 | ⭐⭐⭐ | 零錯字、格式整齊 |

### SEO Brief 範本

```markdown
## 文章 Brief

- **目標關鍵字：** [主要 1 個 + 次要 3-5 個]
- **搜尋意圖：** [資訊型/商業型/交易型]
- **目標讀者：** [一句話描述]
- **字數：** [建議範圍]
- **內容結構（建議 H2）：**
  1. [H2 標題 1] — 覆蓋子主題 A
  2. [H2 標題 2] — 覆蓋子主題 B
  3. [H2 標題 3] — 覆蓋子主題 C
- **必含元素：**
  - [ ] 數據/統計引用
  - [ ] 實際案例
  - [ ] 步驟/清單格式
  - [ ] 內部連結（至少 3 條）
- **競品參考：** [URL 1], [URL 2]
- **獨特角度：** [我們的內容哪裡不同？]
- **截止日期：** [YYYY-MM-DD]
```

### 寫手管理要點

```
✓ 先給 1-2 篇試稿，確認品質和 SEO 理解度
✓ 提供明確的 SEO Brief，不要只給關鍵字
✓ 建立內容品質標準（架構、深度、格式）
✓ 定期給予回饋（不只是改錯字，還要教 SEO 思考）
✓ 建立內容資產庫（讓寫手可以參考過往的優秀案例）
```

## 角色五：數據分析師（SEO Analyst）

### 核心職責
- SEO Dashboard 建立與維護
- 跨平台數據整合（GSC + GA4 + CRM）
- SEO ROI 計算
- 異常檢測與根因分析
- A/B 測試設計與分析
- 預測模型（哪些內容值得投資？）

### 必備技能
- SQL / Python（數據處理）
- Looker Studio / Tableau（視覺化）
- GSC + GA4 API 使用
- 統計分析

### 對 SEO 團隊的價值
```
沒有數據分析師：
  → 「感覺最近流量掉了」→ 憑感覺亂改

有數據分析師：
  → 「過去 14 天，Blog 分類流量下降 23%，主要原因
      是 3 篇核心文章的排名從 Top 3 掉到 Top 8，
      對應的競爭對手在 7/5 發布了更新的內容」
  → 精準修正
```

## 四種團隊規模的配置方案

### 一人 SEO（Solopreneur / 小型網站）

```
你（什麼都自己做）
  ├── 關鍵字研究
  ├── 內容撰寫
  ├── 技術 SEO（基本）
  ├── 連結建設
  ├── 數據分析
  └── 策略規劃

工具支援：
  Ahrefs / GSC / GA4 / Screaming Frog / ChatGPT

時間分配建議：
  40% 內容創作
  25% 關鍵字研究 + 策略
  15% 技術檢查
  10% 連結建設
  10% 數據分析
```

### 2-3 人小團隊（成長型公司）

```
SEO 經理（1 人）
  ├── 策略規劃
  ├── 關鍵字研究
  ├── 數據分析與報告
  └── 外部資源管理

內容寫手（1-2 人，可外包）
  ├── SEO 文章撰寫
  └── 內容更新

技術支援（與工程團隊協作 / 外包）
  ├── 技術問題修復
  └── 網站效能優化
```

### 5-7 人中型團隊（SEO 為核心渠道）

```
SEO 總監（1 人）
  ├── SEO 策略經理（1 人）
  │   ├── SEO 專員（1-2 人）
  │   │   ├── 日常 On-Page 優化
  │   │   ├── 關鍵字研究
  │   │   └── 報表製作
  │   └── 數據分析師（1 人）
  │
  ├── 內容團隊（2-3 人）
  │   ├── 內容策略師（1 人）
  │   └── SEO 寫手（1-2 人）
  │
  └── 技術 SEO 工程師（1 人，與開發團隊一起）
```

### 10+ 人大型團隊（企業級）

```
VP of SEO / Growth
  ├── SEO 總監
  │   ├── 策略團隊（2-3 人）
  │   ├── 技術 SEO 團隊（2-3 人）
  │   └── 數據分析團隊（2 人）
  ├── 內容團隊（3-5 人）
  └── 連結建設/PR 團隊（2-3 人）
```

## 團隊協作流程

### 每週 SEO Sprint（建議節奏）

```
週一：Sprint 規劃
  - 回顧上週進度
  - 設定本週優先任務
  - 分配工作

週三：內容品質審查
  - 審查本週產出的內容
  - 給予即時回饋

週五：數據回顧
  - 查看本週 SEO Dashboard
  - 討論異常和機會
  - 調整下週計劃
```

### 跨部門協作地圖

```
SEO 團隊 ←→ 內容行銷團隊
  協作點：內容 Brief、內容日曆、內容推廣

SEO 團隊 ←→ 產品團隊
  協作點：產品頁面 SEO、功能開發 SEO 考量、URL 結構

SEO 團隊 ←→ 工程團隊
  協作點：技術 SEO 需求、網站速度、Schema 實作

SEO 團隊 ←→ PR / 社群團隊
  協作點：連結建設、內容推廣、品牌監控

SEO 團隊 ←→ 設計團隊
  協作點：頁面設計 SEO 建議、圖片優化、行動版設計
```

## 招聘指南：如何找到對的 SEO 人才？

### SEO 專員面試評估表

```
技術能力（35%）：
☐ 能否解釋搜尋引擎的三階段運作？
☐ 能否說明 SEO 排名的主要因素？
☐ GSC 和 GA4 的操作經驗？
☐ 是否用過 Ahrefs/SEMrush/Screaming Frog？

實戰經驗（30%）：
☐ 請分享一個你主導的 SEO 專案和成果
☐ 你如何做關鍵字研究？（請實際操作）
☐ 如果流量突然下降 30%，你怎麼診斷？

策略思維（20%）：
☐ 對我們網站的初步 SEO 建議？（開放式問題）
☐ 你如何決定一個關鍵字值得投資？
☐ 你最近關注的 SEO 趨勢是什麼？

文化契合（15%）：
☐ 對 SEO 的熱情來自哪裡？
☐ 你如何學習新的 SEO 知識？
☐ 團隊協作經驗
```

### 實作測試建議

```
給應徵者一個實際任務（計時 60 分鐘）：
1. 給一個網站 URL 和 3 個目標關鍵字
2. 要求：
   - 快速技術審計（10 分鐘）
   - On-Page 優化建議（20 分鐘）
   - 內容策略建議（20 分鐘）
   - 製作一頁簡報呈現（10 分鐘）

觀察重點：
- 有沒有用工具輔助？
- 建議是否合理且可執行？
- 溝通是否清晰？
```

### 紅旗訊號（不該錄用的徵兆）

```
❌ 只談排名不談流量/轉換
❌ 無法解釋「為什麼」—只會說「這樣做會提升排名」
❌ 沒有數據習慣（不追蹤、不測量）
❌ 無法展示任何過去成果
❌ 認為黑帽手法「只要不被抓到就好」
❌ 過度關注關鍵字密度和過時的戰術
```
