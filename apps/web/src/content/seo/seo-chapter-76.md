> 一個人嘅 SEO 可以做出成績，但一個啱嘅團隊可以把 SEO 變成公司嘅核心增長引擎。
>
> 香港嘅現實：SEO 人才池細、人工貴、請人難。所以香港公司好少會一開始就砌完整團隊 — 多數係「一個 SEO Manager + 外包寫手 + 同 IT 協作」。呢章會講清楚唔同規模嘅配置，等你唔使請多餘人。

### 必備技能

| 爬蟲工具（Screaming Frog） | ⭐⭐⭐⭐⭐ | 技術審計基本功 |
| 網站效能優化 | ⭐⭐⭐⭐ | CWV、CDN、快取策略 |
| 伺服器/主機知識 | ⭐⭐⭐⭐ | Log 分析、伺服器設定 |
| Python / SQL | ⭐⭐⭐ | 自動化腳本、數據處理 |

| CMS 開發知識 | ⭐⭐⭐ | WordPress / Shopify / SHOPLINE 等嘅 SEO 設定 |
| 多語言架構 | ⭐⭐⭐⭐ | hreflang、ccTLD（.hk / .com.hk）、子目錄 |

### 技術 SEO 工程師 vs 一般工程師
| 面向 | 一般前端工程師 | 技術 SEO 工程師 |
|------|---------------|----------------|
| 關注點 | 使用者體驗 | Googlebot 體驗 + 使用者體驗 |
| 效能指標 | 主觀感受 | LCP / INP / CLS（客觀數據） |
| 渲染方式 | CSR 優先（React/Vue） | SSR / SSG 優先 |
| 連結設計 | 美觀優先 | 可爬取性優先 |
| 多語言 | 語言包切換 | hreflang + 獨立 URL 結構 |

### 日常工作
```
每日：
  - 監控網站健康狀態（uptime、錯誤頁面）
  - 查看 GSC 技術指標（CWV、索引狀態）

每週：
  - 與開發團隊同步 SEO 需求
  - 實作新的 Schema 標記
  - 檢查新部署的功能是否影響 SEO

每月：
  - 完整技術審計
  - Crawl Budget 分析
  - Log File Analysis
  - Bing Webmaster Tools 狀態檢查（Yahoo 香港 / Copilot）
```

> 💡 **香港現實：** 好少香港公司請得起專職技術 SEO 工程師（月薪 HK$30,000-55,000）。常見做法係由前端工程師兼任 + 每年請外部顧問做 1-2 次深度技術審計（HK$8,000-20,000／次）。

### 必備技能（寫手）

| SEO 知識 | ⭐⭐⭐⭐ | 理解關鍵字、搜尋意圖、On-Page |

| 中英夾雜處理 | ⭐⭐⭐⭐ | 香港專業/金融/科技內容常見中英夾雜，要寫得自然 |

### SEO Brief 範本

```markdown
## 文章 Brief

- **目標關鍵字：** [主要 1 個 + 次要 3-5 個]
- **目標地區：** 香港（關鍵字研究地區設 Hong Kong）
- **語言版本：** 繁中（香港用語）/ 英文 / 簡中
- **搜尋意圖：** [資訊型/商業型/交易型]
- **目標讀者：** [一句話描述，例如「準備裝修嘅香港樓宇業主」]
- **字數：** [建議範圍]
- **內容結構（建議 H2）：**
  1. [H2 標題 1] — 覆蓋子主題 A
  2. [H2 標題 2] — 覆蓋子主題 B
  3. [H2 標題 3] — 覆蓋子主題 C
- **必含元素：**
  - [ ] 數據/統計引用（優先香港本地數據）
  - [ ] 香港實際案例
  - [ ] HK$ 價錢/收費參考
  - [ ] 地區資訊（18 區 / 服務覆蓋範圍）
  - [ ] 步驟/清單格式
  - [ ] 內部連結（至少 3 條）
- **用語要求：** 繁體中文（香港用法），避免台式／大陸用語
- **競品參考：** [URL 1], [URL 2]
- **獨特角度：** [我們的內容哪裡不同？]
- **截止日期：** [YYYY-MM-DD]
```

### 寫手管理要點

```
✓ 先給 1-2 篇試稿，確認品質和 SEO 理解度
✓ 提供明確的 SEO Brief，不要只給關鍵字
✓ 建立內容品質標準（架構、深度、格式）
✓ 定期給予回饋（不只是改錯字，還要教 SEO 思考）
✓ 建立內容資產庫（讓寫手可以參考過往的優秀案例）
✓ 香港特別：講清楚用語要求（繁中香港用法），
  並提供一份「禁用詞」清單（例如唔好寫「網絡」
  要寫「網路」？視公司 style guide 而定）
✓ 英文內容建議搵母語級寫手，唔好直接機翻繁中稿
```

```

## 團隊協作流程

### 每週 SEO Sprint（建議節奏）

```
週一：Sprint 規劃
  - 回顧上週進度
  - 設定本週優先任務
  - 分配工作

  - 審查本週產出的內容

  - 查看本週 SEO Dashboard
  - 討論異常和機會
  - 調整下週計劃

```
SEO 團隊 ←→ 內容行銷團隊

SEO 團隊 ←→ 產品團隊

SEO 團隊 ←→ PR / 社群團隊

SEO 團隊 ←→ 設計團隊
  協作點：頁面設計 SEO 建議、圖片優化、行動版設計

SEO 團隊 ←→ 分店 / 前線營運（香港本地服務業必備）
  協作點：GBP 更新、評論回覆、地區頁內容、門市資料一致性

SEO 團隊 ←→ 法務 / 合規（金融、保險、醫療、地產）

           PDPO 私隱條例、消委會指引）
```

☐ 有冇做過本地 SEO（GBP、地區頁、目錄引用）？

實戰經驗（30%）：
☐ 請分享一個你主導的 SEO 專案和成果
☐ 你如何做香港市場的關鍵字研究？（請實際操作）
☐ 如果流量突然下降 30%，你怎麼診斷？
☐ 有冇處理過中英雙語網站嘅經驗？

策略思維（20%）：
☐ 對我們網站的初步 SEO 建議？（開放式問題）
☐ 你如何決定一個關鍵字值得投資？
☐ 你最近關注的 SEO 趨勢是什麼？（AI 搜尋 / GEO 相關）
☐ 香港市場細，你會點樣揀戰場？

文化契合（15%）：

### 實作測試建議

```
給應徵者一個實際任務（計時 60 分鐘）：
1. 給一個香港網站 URL 和 3 個目標關鍵字
   （其中一個要係「地區 + 服務」類）
2. 要求：
   - 快速技術審計（10 分鐘）
   - On-Page 優化建議（20 分鐘）
   - 內容策略建議（20 分鐘）
   - 製作一頁簡報呈現（10 分鐘）

觀察重點：
- 有沒有用工具輔助？
- 建議是否合理且可執行？
- 有冇考慮到香港市場特性（雙語、細市場、本地 SEO）？
- 溝通是否清晰？
```

### 紅旗訊號（不該錄用的徵兆）

```
❌ 只談排名不談流量/轉換
❌ 無法解釋「為什麼」—只會說「這樣做會提升排名」
❌ 沒有數據習慣（不追蹤、不測量）
❌ 無法展示任何過去成果
❌ 認為黑帽手法「只要不被抓到就好」
❌ 過度關注關鍵字密度和過時的戰術
❌ 唔識分繁中香港用語同台式／大陸用語嘅分別
❌ 完全冇本地 SEO（GBP / 地區）概念
```

## 本章重點回顧

| 角色 | 一句話 | 關鍵技能 |
|------|--------|----------|
| SEO 策略經理 | 設定方向，管理資源 | 策略 + 溝通 + 商業思維 + 中英雙語 |

| 內容策略師/寫手 | 產出能排名的內容 | 寫作 + SEO + 行業知識 + 香港用語 |
| 數據分析師 | 從數據中找到答案 | SQL + Dashboard + 統計 |
| 本地 SEO 專員（香港重要） | 守住 GBP 與本地引用 | GBP + OpenRice + 18 區 + NAP 一致性 |
