## 什麼是 NAP？

**NAP** 是三個元素的縮寫：

| 字母 | 代表 | 香港說明 |
|------|------|------|
| **N** | Name（商家名稱） | 你的商家在商業登記（BR）上和公開呈現的名稱 |
| **A** | Address（地址） | 香港格式的實體地址或服務區域 |
| **P** | Phone（電話號碼） | 客戶可以直接聯繫你的香港電話（+852 + 8 位數字） |

NAP 一致性（NAP Consistency）是本地 SEO 的**核心基礎**——在所有線上平台、目錄和網站上，你的 NAP 資訊必須**完全一致**。

```
想像 Google 的角色：

Google 在網絡上「爬取」你的商家資訊時，
它像是在做一份調查問卷：

  🔍 網站上的 NAP：新鴻基大廈 12 樓 A 室
  🔍 OpenRice 上的 NAP：新鴻基大厦 12/F, Unit A  ← 不一致！
  🔍 Facebook 上的 NAP：電話 2345 6789 ← 網站係 +852 2345 6789！
  🔍 黃頁 HK 上的 NAP：中環皇后大道中 100 號 ← 少咗「香港」

Google 的結論：
  ❌ 這些資訊不一致，這個商家可能不可靠。
  ❌ 降低本地搜尋排名。
```

> **一句話總結：** NAP 不一致 = Google 認為你的商家資訊不準確 = 你失去排名和客戶。
>
> **香港特別麻煩嘅地方：** 中英文地址並存（「香港中環皇后大道中 100 號」vs「100 Queen's Road Central, Central, Hong Kong」）、樓層寫法分歧（「12 樓」vs「12/F」）、電話有冇 +852。所以你要**定兩套正本**（中文版 + 英文版），但每個平台唔好混用。

## 為什麼 NAP 一致性如此重要？

### SEO 的影響

NAP 一致性直接影響：

1. **Google 對商家的信任度**：當 Google 在多個來源找到一致的 NAP 資訊，它更有信心在搜尋結果中推薦你
2. **本地排名**：NAP 一致性是 Local Pack 排名的重要因素
3. **Google Maps 準確性**：不一致的 NAP 可能導致消費者導航到錯誤地址（香港樓上舖特別容易出事）
4. **使用者體驗**：客戶打錯電話、去錯地址 = 失去生意

```
NAP 不一致的實際後果（香港案例）：

案例：一間由旺角搬去深水埗嘅餐廳
  網站上：深水埗新地址（已更新）
  Google Maps 上：旺角舊地址（未更新）
  OpenRice 上：旺角舊地址 + 舊電話
  Facebook 上：深水埗新地址（得個名冇樓層）

結果：
  ❌ Google 唔確定邊個地址啱，兩個版本嘅排名都跌
  ❌ 客人跟 Google Maps 去咗旺角舊舖，摸門釘
  ❌ 電話打去舊號碼冇人聽（香港客人會直接放棄，唔會再試）
  ❌ 熟客以為結業，流失
```

### 學術研究支持

根據 Moz 的 Local Search Ranking Factors 研究，NAP 相關的引用訊號占本地排名因素的 **15-20%**，是僅次於 Google 商家檔案和評論的第三大因素。

## NAP 一致性的四大原則（香港版）

### 原則 1：精確（Exact）

```
✅ 正確：香港中環皇后大道中 100 號 新鴻基大廈 12 樓 A 室
❌ 錯誤：香港中環皇后大道 100 號 12A（少咗「中」，樓層寫法唔同）

✅ 正確：+852 2345 6789
❌ 錯誤：2345 6789（缺區號）／852-2345-6789（連字符格式唔統一）

✅ 正確：陳大明牙醫診所
❌ 錯誤：陳大明牙醫（少咗「診所」，同 BR 名不符）
```

> **原則：** 揀定一套 NAP 格式（中文正本 + 英文正本），喺所有地方一致使用。唔好一時有 +852、一時冇；唔好一時寫「12 樓」、一時寫「12/F」。

### 原則 2：完整（Complete）

每次都提供完整的 NAP 三元素。不要只提供電話但沒有地址、或只有名稱但缺少電話。

```
香港樓上舖必填細節：
  → 大廈名稱（例如「新鴻基大廈」「金百利中心」）
  → 樓層（「12 樓」；有「高層/低層」之分要寫明，香港好多商廈分高低層）
  → 室號（「A 室」／「Unit A」）
  → 地區 + 香港／九龍／新界
```

### 原則 3：統一（Consistent）

- 所有線上平台 → 相同格式
- 所有分店 → 各自的 NAP 獨立且準確（中環分店唔可以用銅鑼灣分店嘅電話）
- 搬遷/改名後 → 立即更新所有平台（詳見後續章節）

### 原則 4：本地化（Localized）

```
香港地址格式的標準寫法（中文正本）：

✅ 區域 + 街道 + 門牌 + 大廈 + 樓層 + 單位
   香港中環皇后大道中 100 號 新鴻基大廈 12 樓 A 室

英文正本（外籍客人 / 國際平台用）：
✅ Unit A, 12/F, Sun Hung Kai Centre, 100 Queen's Road Central,
   Central, Hong Kong

⚠️ 香港唔使寫郵遞區號
   香港並冇正式郵遞區號制度。Google 有時用 999077 作佔位，
   但網站 Schema 入面建議直接省略 postalCode，或只喺
   平台要求時先填 999077。

⚠️ 唔好中英撈埋：「100 Queen's Road Central 12 樓 A 室」
   → 揀一套，用到底。
```

## 什麼是本地引用（Local Citation）？

**本地引用**是指任何在網路上提及你的商家 NAP 資訊的頁面。這些可以是有連結的（Linked Citation）或無連結的（Unlinked Citation）。

```
引用的類型：

1. 結構化引用（Structured Citation）
   本地目錄上的商家檔案頁面
   香港例子：OpenRice、TripAdvisor、黃頁 HK（Yellow Pages HK）、
            Yelp HK、Facebook 專頁、HKTDC、香港旅發局

2. 非結構化引用（Unstructured Citation）
   在新聞報導、部落格文章、社群媒體中提及
   香港例子：香港01 報導「陳大明牙醫診所喺中環開業」、
            LIHKG 討論串、地區 Facebook 社團推介
```

### 引用的 SEO 價值

```
高品質引用 → 增強 Google 對商家資訊的信心
大量的引用 → 提升本地知名度（Prominence）
一致的引用 → 強化 NAP 訊號
本地引用 → 展示與本地社群的連結（Google 好睇重）
```

## NAP 一致性審核步驟

### Step 1：建立你的「正本 NAP」

在開始任何優化之前，先確定你的 NAP 標準格式（**中文正本 + 英文正本**）。

```
我的 NAP 正本（中文）：

名稱：陳大明牙醫診所
地址：香港中環皇后大道中 100 號 新鴻基大廈 12 樓 A 室
電話：+852 2345 6789
網站：https://www.chendaming-dental.com.hk

我的 NAP 正本（英文）：

Name: Dr. Chan Dental Clinic
Address: Unit A, 12/F, Sun Hung Kai Centre, 100 Queen's Road Central,
         Central, Hong Kong
Phone: +852 2345 6789
Website: https://www.chendaming-dental.com.hk

補充（entity 驗證用）：
  商業登記號碼（BR No.）：XXXXXXXX-XXX
  公司註冊處（ICRIS）紀錄：確保公司名同 BR 一致
```

### Step 2：進行 NAP 審核

使用以下方法檢查你的 NAP 在網絡上的呈現：

```
方法 A：手動搜尋（香港做法）
  1. Google 搜尋你的商家名稱（中文名 + 英文名，各加引號）
  2. Google 搜尋你的電話號碼（+852 2345 6789 同 23456789 兩種寫法）
  3. Google 搜尋你的地址（含引號）
  4. 記錄所有出現你 NAP 的頁面
  5. 逐一檢查是否一致

方法 B：使用工具
  → Moz Local（NAP 審核功能）
  → BrightLocal（Citation Tracker）
  → Semrush Listing Management
  → Whitespark Local Citation Finder

⚠️ 注意：呢啲工具嘅目錄庫以歐美為主，對 OpenRice、黃頁 HK、
   HKTDC 等香港平台覆蓋有限，香港引用要靠**人手建立同檢查**。
```

### Step 3：建立 NAP 不一致清單

```
NAP 審核表（香港範例）

平台            | NAP 一致？ | 問題說明
----------------|-----------|-------------------------------
Google GBP      | ✅        | 完全一致
網站（/zh-hk/）  | ✅        | 完全一致
OpenRice        | ❌        | 電話冇 +852；地址寫 12/F 唔係 12 樓
TripAdvisor     | ❌        | 仲用緊改名前的舊名
Facebook        | ⚠️        | 冇寫室號
黃頁 HK          | ❌        | 未建立檔案
香港旅發局       | ❌        | 未建立檔案（旅遊相關行業要補）
商會目錄         | ⚠️        | 地址用英文版，網站用中文版
```

### Step 4：逐一修復

```
修復優先級（香港版）：
  1. 先修復 Google GBP（最核心）
  2. 再修復 OpenRice / TripAdvisor / Facebook（香港高流量平台）
  3. 再修復黃頁 HK、HKTDC、旅發局、商會
  4. 最後處理長尾目錄

每個平台的修復步驟：
  1. 登入該平台的商家後台
  2. 更新 NAP 資訊為正本格式
  3. 確認更新成功（登出後搜尋查看）
  4. 記錄更新日期（方便下次審核）
```

## 商家搬遷 / 改名時的 NAP 管理（香港）

### 搬遷流程

```
第 1 步：更新 Google 商家檔案
  → 立即更新新地址（香港樓上舖記得寫埋樓層同室號）
  → 可能需要重新驗證（改地址通常 trigger 驗證）

第 2 步：更新網站
  → 更新網站上所有提及舊地址的地方（頁尾、聯絡頁、分店頁）
  → 更新 LocalBusiness Schema 結構化資料
  → 建立 301 轉址（如果 URL 有包含地區，例如 /locations/mong-kok → /locations/sham-shui-po）

第 3 步：更新香港主要目錄平台
  → OpenRice（餐飲）、TripAdvisor、Facebook、黃頁 HK、HKTDC、商會
  → 按優先級順序處理

第 4 步：建立新的本地目錄
  → 喺新地址所屬地區建立新嘅引用
    （例如搬去沙田，就加入沙田商會、沙田地區社團相關目錄）

第 5 步：通知客人
  → 發 Google Post、Facebook 帖、WhatsApp 廣播通知熟客
  → 喺網站加搬遷公告（最少 3 個月）
```

### 改名流程

```
額外注意事項（香港）：
  ✅ 在所有平台使用新名稱（跟商業登記證更新後的名稱）
  ✅ 商業登記（BR）改名後 1 個月內要向稅務局申報，
     之後先好大規模改網上檔案，確保文件一致
  ✅ 喺 Google 商家檔案中可以保留歷史名稱（如適用）
  ✅ 關鍵字放喺新名稱要小心：例如「陳大明牙醫診所 - 中環隱形牙套專家」
  ❌ 唔好濫加關鍵字（違反 Google 政策，會停權）
```

## 常見 NAP 錯誤及解決方案（香港版）

| 常見錯誤 | 為什麼會發生 | 解決方案 |
|----------|------------|---------|
| 電話格式不一致 | 有時寫 +852，有時淨寫 8 位數字 | 揀一個格式（建議 +852 2345 6789）並喺所有地方用 |
| 地址縮寫不同 | 「12 樓 A 室」vs「12A」vs「12/F, Unit A」 | 揀完整寫法（中文正本 + 英文正本各一套） |
| 中英文地址混用 | 平台自動翻譯或人手亂填 | 同一平台固定用一種語言版本 |
| 樓層冇寫高低層 | 香港商廈分高低層（例如「高層 12 樓」） | 正本寫明「高層／低層」 |
| 使用追蹤電話號碼 | 為咗追蹤唔同渠道用唔同號碼 | **主 NAP 用一個一致嘅號碼**，追蹤號碼只用於廣告著陸頁 |
| 舊地址殘留 | 搬遷後未更新所有平台 | 系統性審核同更新 |
| 共用地址（虛擬辦公室） | 多家公司用同一地址（香港秘書公司常見） | 加樓層/室號區分；最好用真實營運地址 |
| 自動生成的檔案 | 目錄平台自動由第三方數據抓取 | 認領（Claim）並修正呢啲自動生成嘅檔案 |

## Schema 結構化資料 — 網站的 NAP 聲明

在你的網站上加入 **LocalBusiness Schema** 是最權威的 NAP 聲明方式。

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Dentist",
  "name": "陳大明牙醫診所",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "皇后大道中 100 號 新鴻基大廈 12 樓 A 室",
    "addressLocality": "中環",
    "addressRegion": "香港島",
    "addressCountry": "HK"
  },
  "telephone": "+85223456789",
  "url": "https://www.chendaming-dental.com.hk",
  "openingHours": "Mo-Fr 09:00-18:00, Sa 09:00-13:00",
  "priceRange": "$$",
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": 22.2810,
    "longitude": 114.1577
  }
}
</script>
```

> **關鍵：** Schema 中的 NAP 必須與你的正本 NAP 100% 一致。
>
> **香港提示：** 香港冇正式郵遞區號，`postalCode` 建議省略（或填 999077）；`addressCountry` 用 `"HK"`；電話用 `+852` 開頭嘅國際格式。
