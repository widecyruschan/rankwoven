## 從零到發布的完整架構

寫一篇能排名的 SEO 文章不是靈感來了就寫，而是有一套可複製的流程。本章提供一套經過驗證的 **五階段寫作框架**，涵蓋從關鍵字研究到發布後追蹤的完整流程。

---

## 階段一：策略規劃（Strategy）

### 1.1 選題三問

在開始寫任何文章之前，問自己三個問題：

```
❓ 誰會搜尋這個主題？（目標受眾）
❓ 他們搜尋時想要什麼？（搜尋意圖）
❓ 我能在什麼地方贏過競爭對手？（差異化機會）
```

### 1.2 關鍵字映射（Keyword Mapping）

不要只針對一個關鍵字寫作。每篇文章應涵蓋：

| 關鍵字層級 | 數量 | 使用位置 |
|-----------|------|----------|
| **主關鍵字** | 1 個 | H1 標題、第一段、URL、meta description |
| **次要關鍵字** | 3-5 個 | H2 標題、重點段落 |
| **長尾關鍵字** | 5-10 個 | 自然地分散在內文中 |
| **LSI 語義關鍵字** | 不限 | 自然的相關用語（不是刻意塞入） |

#### 實例：目標關鍵字「SEO 文章寫作」

```
主關鍵字：SEO 文章寫作
次要關鍵字：SEO 寫作技巧、SEO 文章架構、SEO 內容優化
長尾關鍵字：如何寫一篇會排名的文章、SEO 文章撰寫流程、部落格 SEO 寫作教學
LSI 關鍵字：關鍵字密度、meta description、內部連結、文章結構、H1 H2 H3
```

### 1.3 SERP 分析

搜尋目標關鍵字，分析前 5 名的頁面：

| 分析項目 | 要觀察什麼 |
|----------|-----------|
| **內容格式** | 文章？影片？產品頁？列表？ |
| **內容長度** | 平均字數範圍 |
| **內容深度** | 涵蓋了哪些 H2 子主題？ |
| **內容差距** | 競爭對手漏掉了什麼？ |
| **多媒體使用** | 用了多少圖片/影片/表格？ |
| **Featured Snippet** | 有沒有精選摘要？是什麼格式？ |

> **關鍵洞察：** 不要試圖從零創新。先理解 Google 對這個主題的「期待格式」，再在此基礎上超越。

## 階段二：架構設計（Structure）

### 2.1 文章大綱模板

```
H1：文章主標題（含主關鍵字）
│
├─ 引言段落（200-300 字）
│   ├─ 鉤子（Hook）：為什麼這個主題重要？
│   ├─ 承諾（Promise）：看完這篇你會學到什麼？
│   └─ 預覽（Preview）：簡述文章會涵蓋的內容
│
├─ H2：第一個核心子主題
│   ├─ 解釋概念
│   ├─ 提供範例
│   └─ 具體步驟或應用
│
├─ H2：第二個核心子主題
│   ├─ H3：子要點 A
│   ├─ H3：子要點 B
│   └─ 對比表格或列表
│
├─ H2：第三個核心子主題
│   └─ ...（依此類推）
│
├─ H2：常見錯誤 / 注意事項
│   └─ 列表形式呈現
│
├─ H2：總結 + 行動呼籲
│   ├─ 回顧關鍵要點
│   └─ 下一步指引
│
└─ FAQ 區塊（選配）
    └─ 回答 "People Also Ask" 中的問題
```

### 2.2 H2 標題的撰寫公式

| 公式 | 範例 |
|------|------|
| **數字 + 名詞 + 好處** | 「5 個 SEO 寫作技巧讓你的文章排名第一頁」 |
| **如何 + 動詞 + 目標** | 「如何在一小時內寫出一篇 SEO 優化文章」 |
| **什麼是 + 概念** | 「什麼是搜尋意圖？完整解析與實例」 |
| **A vs B + 比較** | 「長尾關鍵字 vs 短尾關鍵字：何時該用哪個？」 |
| **為什麼 + 問題** | 「為什麼你的 SEO 文章排名上不去？」 |
| **步驟 + 目標** | 「SEO 文章寫作 7 步驟：從新手到專家」 |

## 階段三：內容撰寫（Writing）

### 3.1 引言的四種有效鉤子

| 鉤子類型 | 範例 |
|----------|------|
| **驚人數據** | 「90% 的網頁從來沒有從 Google 獲得過任何流量——你的文章會不會是其中之一？」 |
| **痛點共鳴** | 「花了三天寫的文章，發布三個月了還在第 5 頁？你不是一個人。」 |
| **直接答案** | 「SEO 文章寫作的祕密不在於關鍵字密度，在於搜尋意圖匹配。」 |
| **反直覺觀點** | 「越長的 SEO 文章排名不一定越好——數據顯示 1,500 字的文章才是甜蜜點。」 |

### 3.2 段落結構：BLUF 法則

**BLUF = Bottom Line Up Front（結論先行）**

```
❌ 傳統寫法：
「在 SEO 的世界裡，有很多因素會影響文章排名。首先我們要了解搜尋引擎如何評估內容品質...（囉嗦）...因此，你應該把最重要的關鍵字放在標題裡。」

✅ BLUF 寫法：
「把主要關鍵字放在 H1 標題裡。為什麼？因為 Google 會優先讀取 H1 來判斷文章主題。根據 Ahrefs 的研究，H1 包含精準關鍵字的文章排名明顯更高。具體做法是：...」
```

### 3.3 關鍵字自然融入技巧

| 位置 | 融入方式 | 範例 |
|------|---------|------|
| **H1 標題** | 主關鍵字前置 | 「SEO 文章寫作：從新手到專家的完整指南」 |
| **第一段** | 前 100 字內自然出現 | 「寫好一篇 SEO 文章不僅需要好的寫作能力...」 |
| **H2 標題** | 次要關鍵字自然融入 | 「## 為什麼 SEO 文章架構比你想像的重要」 |
| **圖片 Alt** | 描述性 + 關鍵字 | `alt="SEO 文章寫作框架流程圖"` |
| **URL** | 精簡 + 主關鍵字 | `/seo-writing-framework` |
| **結尾** | 回顧關鍵概念 | 「掌握這些 SEO 寫作技巧後，你的下一篇文章...」 |

> **⚠️ 避免關鍵字堆砌：** 自然的關鍵字密度在 1-2% 左右。如果你讀起來覺得「這個詞出現太多次了」，Google 也會這樣覺得。

### 3.4 增加可信度的寫作技巧

```markdown
1. 引用權威來源
   「根據 Google 官方 Search Central 文件指出...」
   「Backlinko 對 11,800 萬個搜尋結果的研究發現...」

2. 加入數據支持
   「我們分析了 500 篇排名前 10 的文章，發現...」

3. 展示親身經驗
   「在管理 50+ 客戶網站的 SEO 過程中，我們觀察到...」

4. 引用專家觀點
   「Google 的 John Mueller 在 Twitter 上回應...」

5. 提供可驗證的範例
   附上真實截圖、數值、工具輸出結果
```

## 階段四：On-Page 優化（Optimization）

### 4.1 發布前的 SEO 檢查清單

```
☐ Title Tag：
   ☐ 包含主關鍵字（放在前面）
   ☐ 長度 50-60 字元
   ☐ 有吸引力（不是純關鍵字列表）
   ☐ 每個頁面獨一無二

☐ Meta Description：
   ☐ 包含主關鍵字
   ☐ 長度 150-160 字元
   ☐ 包含行動呼籲（CTA）
   ☐ 摘要文章價值

☐ URL 結構：
   ☐ 簡短（3-5 個詞）
   ☐ 包含主關鍵字
   ☐ 使用連字號（-）分隔
   ☐ 無多餘的日期或數字

☐ 標題層級：
   ☐ 只有一個 H1
   ☐ H2/H3 形成邏輯層級
   ☐ 多個 H2 包含重要子主題

☐ 圖片優化：
   ☐ 每張圖片有描述性 alt 文字
   ☐ 檔案名稱有意義（不是 IMG_1234.jpg）
   ☐ 使用 WebP 格式
   ☐ 適當壓縮（< 100KB）

☐ 內部連結：
   ☐ 2-5 個相關文章連結
   ☐ 使用描述性錨點文字
   ☐ 確保沒有孤兒頁面

☐ 結構化資料：
   ☐ 文章類型使用 Article Schema
   ☐ 教學類型使用 HowTo Schema
   ☐ 驗證無錯誤
```

### 4.2 發布後的立即檢查

```
1. 用 site:yourdomain.com/新文章URL 檢查是否已被索引
2. 在 GSC 中請求索引（Request Indexing）
3. 確認所有連結（內部＋外部）都正確運作
4. 在手機上檢查文章顯示效果
5. 用 PageSpeed Insights 檢查載入速度
```

## 階段五：追蹤與迭代（Tracking & Iteration）

### 5.1 文章表現的關鍵時間點

| 時間 | 重點觀察 |
|------|---------|
| **發布後 1 週** | 是否已被索引？初始排名位置？ |
| **發布後 1 個月** | 排名是否穩定？開始獲得長尾流量？ |
| **發布後 3 個月** | 排名趨勢是上升還是下降？是否需要內容更新？ |
| **發布後 6 個月** | 全面審查：內容是否過時？競爭對手是否有更好的內容？ |

### 5.2 文章迭代升級的觸發條件

當出現以下情況時，應該重新審視和升級文章：

```
⬇️ 排名從前 10 名滑落到第 2 頁
⬇️ 自然流量連續 2 個月下降
⬆️ 競爭對手發布了明顯更好的同主題內容
📅 文章發布超過 12 個月未更新
🔄 Google 演算法更新後排名大幅波動
```

### 5.3 迭代升級的具體做法

| 升級程度 | 做法 | 預期效果 |
|----------|------|----------|
| **小幅更新** | 修正過時資訊、更新統計數字、修復失效連結 | 維持排名穩定性 |
| **中幅更新** | 增加新章節、補充最新趨勢、加入新數據來源 | 排名小幅提升（3-5 位） |
| **大幅改版** | 重寫 50%+ 內容、重新設計架構、增加多媒體 | 可能回到第一頁甚至更高 |
