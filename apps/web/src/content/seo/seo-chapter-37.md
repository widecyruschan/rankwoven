## 從零到發布的完整架構

寫一篇能排名的 SEO 文章不是靈感來了就寫，而是有一套可複製的流程。本章提供一套經過驗證的 **五階段寫作框架**，涵蓋從關鍵字研究到發布後追蹤的完整流程。

---

## 香港市場寫作前嘅三個前提

喺開始之前，先記低三件香港專屬嘅事：

| 前提 | 說明 |
|------|------|
| **繁體中文，唔好簡體** | 香港讀者對簡體字極敏感，一篇文出現幾個簡體字，信任度即刻跌 |
| **用香港用語** | 「網上」唔係「網路」、「推介」唔係「推薦」（兩者都要，但香港搜尋明顯偏向「推介/邊間好」）、「Blog」唔係「部落格」 |
| **中英夾雜係正常** | 香港人日常就係中英夾雜，專業/B2B/金融題材尤其。硬轉成全中文反而唔自然 |

## 階段一：策略規劃（Strategy）

### 1.1 選題三問

在開始寫任何文章之前，問自己三個問題：

```
❓ 誰會搜尋這個主題？（香港嘅邊一群人？幾多歲？住邊區？）
❓ 他們搜尋時想要什麼？（想睇比較？想知價錢？想搵地址？）
❓ 我能在什麼地方贏過競爭對手？（香港本地細節？實測？價錢？法規？）
```

**香港版選題例子：**
```
❓ 邊個會搜「香港 寬頻 邊間好」？→ 搬屋 / 新入伙嘅香港家庭，25-45 歲
❓ 佢哋想要啲咩？→ 唔係技術規格，而係「邊間冇綁約」「邊間上載快」「實際價錢 HK$/月」
❓ 我點贏過 PCCW / 香港01 嘅比較文？→ 我做實測（去 5 個地區試 speedtest）+ 列明隱藏收費
```

### 1.2 關鍵字映射（Keyword Mapping）

不要只針對一個關鍵字寫作。每篇文章應涵蓋：

| 關鍵字層級 | 數量 | 使用位置 |
|-----------|------|----------|
| **主關鍵字** | 1 個 | H1 標題、第一段、URL、meta description |
| **次要關鍵字** | 3-5 個 | H2 標題、重點段落 |
| **長尾關鍵字** | 5-10 個 | 自然地分散在內文中 |
| **LSI 語義關鍵字** | 不限 | 自然的相關用語（不是刻意塞入） |

#### 實例：目標關鍵字「SEO 文章寫作」

```
主關鍵字：SEO 文章寫作
次要關鍵字：SEO 寫作技巧、SEO 文章架構、SEO 內容優化
長尾關鍵字：如何寫一篇會排名的文章、SEO 文章撰寫流程、Blog SEO 寫作教學
LSI 關鍵字：關鍵字密度、meta description、內部連結、文章結構、H1 H2 H3
```

#### 香港實例：目標關鍵字「香港 網店 平台」

```
主關鍵字：香港網店平台
次要關鍵字：網店平台推介、開網店 香港、網上開店 收費
長尾關鍵字：香港網店平台邊間好、SHOPLINE 好唔好、開網店要幾錢香港、
            網店平台 月費 比較、香港網店 邊隻平
LSI 關鍵字：網店系統、POS、FPS 轉數快、PayMe、順豐、Google 商家檔案、
            網店 SEO、網店物流
粵語/口語變體：開網店推介、網店邊間好、開網店幾錢、香港開網店攻略
```

> **香港做法：** 香港人搜嘢鍾意加「香港」「推介」「邊間好」「幾錢」。做關鍵字映射時，記得額外開一欄「粵語/口語變體」，呢啲字競爭低但轉化高。

### 1.3 SERP 分析

搜尋目標關鍵字，分析前 5 名的頁面（**記得用香港 SERP**：可以用無痕模式 + `&gl=hk&hl=zh-HK`，或者直接喺香港 IP 搜）：

| 分析項目 | 要觀察什麼 |
|----------|-----------|
| **內容格式** | 文章？影片？產品頁？列表？定係 OpenRice / 28Hse / Car1.hk 呢類平台頁？ |
| **內容長度** | 平均字數範圍 |
| **內容深度** | 涵蓋了哪些 H2 子主題？ |
| **內容差距** | 競爭對手漏掉了什麼？（香港本地細節？價錢？法規？） |
| **多媒體使用** | 用了多少圖片/影片/表格？ |
| **Featured Snippet** | 有沒有精選摘要？是什麼格式？ |
| **平台壟斷程度** | 頭 5 位有幾多位係大平台？如果全部係平台，你要搵長尾位入 |

> **關鍵洞察：** 不要試圖從零創新。先理解 Google 對這個主題的「期待格式」，再在此基礎上超越。

## 階段二：架構設計（Structure）

### 2.1 文章大綱模板

```
H1：文章主標題（含主關鍵字）
│
├─ 引言段落（200-300 字）
│   ├─ 鉤子（Hook）：為什麼這個主題重要？（香港讀者角度）
│   ├─ 承諾（Promise）：看完這篇你會學到什麼？
│   └─ 預覽（Preview）：簡述文章會涵蓋的內容
│
├─ H2：第一個核心子主題
│   ├─ 解釋概念
│   ├─ 提供範例（香港例子）
│   └─ 具體步驟或應用
│
├─ H2：第二個核心子主題
│   ├─ H3：子要點 A
│   ├─ H3：子要點 B
│   └─ 對比表格或列表（含 HK$ 價錢）
│
├─ H2：第三個核心子主題
│   └─ ...（依此類推）
│
├─ H2：香港常見情況 / 注意事項
│   └─ 列表形式呈現（例如「香港法規」「香港收費」）
│
├─ H2：常見錯誤 / 注意事項
│   └─ 列表形式呈現
│
├─ H2：總結 + 行動呼籲
│   ├─ 回顧關鍵要點
│   └─ 下一步指引
│
└─ FAQ 區塊（選配）
    └─ 回答 "People Also Ask" 中的問題（香港版）
```

### 2.2 H2 標題的撰寫公式（香港版）

| 公式 | 香港範例 |
|------|---------|
| **數字 + 名詞 + 好處** | 「5 個 SEO 寫作技巧令你篇文排上 Google 第一頁」 |
| **如何 + 動詞 + 目標** | 「點樣喺一小時內寫出一篇 SEO 優化文章」 |
| **什麼是 + 概念** | 「香港網店 SEO 係乜？完整解析與實例」 |
| **A vs B + 比較** | 「SHOPLINE vs Shopify：香港網店邊隻好？」 |
| **為什麼 + 問題** | 「點解你篇 SEO 文章排名上唔到第一頁？」 |
| **步驟 + 目標** | 「SEO 文章寫作 7 步驟：由新手到專家」 |
| **邊間好 + 年份** | 「2026 香港會計軟件邊間好？8 款實測比較」 |
| **幾錢 + 主題** | 「香港開網店要幾錢？2026 全套費用清單」 |

## 階段三：內容撰寫（Writing）

### 3.1 引言的四種有效鉤子

| 鉤子類型 | 香港版範例 |
|----------|----------|
| **驚人數據** | 「90% 嘅網頁從來冇喺 Google 攞過任何流量——你篇文會唔會係其中之一？」 |
| **痛點共鳴** | 「花咗三日寫嘅文，出咗三個月仲喺第 5 頁？你唔係一個人。」 |
| **直接答案** | 「SEO 文章寫作嘅秘密唔係關鍵字密度，係搜尋意圖匹配。」 |
| **反直覺觀點** | 「越長嘅 SEO 文章排名唔一定越好——數據顯示 1,500 字嘅文章先係甜蜜點。」 |
| **香港本地痛點** | 「香港人搜『會計軟件』，點解你篇文排第 8？因為你寫嘅係台灣收費同台灣法規。」 |

### 3.2 段落結構：BLUF 法則

**BLUF = Bottom Line Up Front（結論先行）**

```
❌ 傳統寫法：
「喺 SEO 嘅世界入面，有好多因素會影響文章排名。首先我哋要了解搜尋引擎點樣評估內容
品質...（囉嗦）...因此，你應該將最重要嘅關鍵字放喺標題入面。」

✅ BLUF 寫法：
「將主要關鍵字放落 H1 標題。點解？因為 Google 會優先讀取 H1 去判斷文章主題。
根據 Ahrefs 嘅研究，H1 包含精準關鍵字嘅文章排名明顯更高。具體做法係：...」
```

### 3.3 關鍵字自然融入技巧

| 位置 | 融入方式 | 香港版範例 |
|------|---------|-----------|
| **H1 標題** | 主關鍵字前置 | 「香港網店 SEO：由開舖到落單完整指南」 |
| **第一段** | 前 100 字內自然出現 | 「寫好一篇香港 SEO 文章唔止需要好嘅寫作能力...」 |
| **H2 標題** | 次要關鍵字自然融入 | 「## 點解香港網店嘅文章架構比你想像中重要」 |
| **圖片 Alt** | 描述性 + 關鍵字 | `alt="香港網店 SEO 文章寫作框架流程圖"` |
| **URL** | 精簡 + 主關鍵字 | `/hk-seo-writing-framework` |
| **結尾** | 回顧關鍵概念 | 「掌握呢啲 SEO 寫作技巧之後，你下一篇文...」 |

> **⚠️ 避免關鍵字堆砌：** 自然的關鍵字密度在 1-2% 左右。如果你讀起來覺得「這個詞出現太多次了」，Google 也會這樣覺得。
>
> **繁中特別注意：** 中文冇空格分隔，關鍵字密度好易「睇落好高但其實正常」。唔好用英文 SEO 嘅 1-2% 硬套落中文——**以「讀落自唔自然」為準**，多過以數字為準。

### 3.4 增加可信度的寫作技巧

```markdown
1. 引用權威來源
   「根據 Google 官方 Search Central 文件指出...」
   「Backlinko 對 11,800 萬個搜尋結果的研究發現...」
   「根據政府統計處 / 通訊事務管理局（OFCA）嘅數據...」

2. 加入數據支持
   「我哋分析咗 500 篇香港關鍵字排名前 10 嘅文章，發現...」

3. 展示親身經驗
   「喺管理 50+ 個香港客戶網站嘅 SEO 過程入面，我哋觀察到...」

4. 引用專家觀點
   「Google 嘅 John Mueller 喺 X 上面回應...」
   「本地專家（例如香港某大學教授 / 行業協會）指出...」

5. 提供可驗證的範例
   附上真實截圖、HK$ 價錢、工具輸出結果、實地相片
```

## 階段四：On-Page 優化（Optimization）

### 4.1 發布前的 SEO 檢查清單

```
☐ Title Tag：
   ☐ 包含主關鍵字（放在前面）
   ☐ 長度 50-60 字元（繁中約 25-30 個中文字，因為中文字佔位較闊）
   ☐ 有吸引力（不是純關鍵字列表）
   ☐ 每個頁面獨一無二

☐ Meta Description：
   ☐ 包含主關鍵字
   ☐ 長度 150-160 字元（繁中約 70-80 個中文字）
   ☐ 包含行動呼籲（CTA）
   ☐ 摘要文章價值

☐ URL 結構：
   ☐ 簡短（3-5 個詞）
   ☐ 包含主關鍵字（英文 slug，避免中文 URL 編碼問題）
   ☐ 使用連字號（-）分隔
   ☐ 無多餘的日期或數字

☐ 語言設定：
   ☐ <html lang="zh-HK">（唔好寫 zh-TW 或 zh-CN）
   ☐ 如有英文版，設定 hreflang zh-HK / en-HK

☐ 標題層級：
   ☐ 只有一個 H1
   ☐ H2/H3 形成邏輯層級
   ☐ 多個 H2 包含重要子主題

☐ 圖片優化：
   ☐ 每張圖片有描述性 alt 文字（繁中）
   ☐ 檔案名稱有意義（不是 IMG_1234.jpg）
   ☐ 使用 WebP 格式
   ☐ 適當壓縮（< 100KB）

☐ 內部連結：
   ☐ 2-5 個相關文章連結
   ☐ 使用描述性錨點文字
   ☐ 確保沒有孤兒頁面

☐ 結構化資料：
   ☐ 文章類型使用 Article Schema
   ☐ 教學類型使用 HowTo Schema
   ☐ 本地商家加 LocalBusiness（含香港地址格式）
   ☐ 驗證無錯誤

☐ 香港本地檢查：
   ☐ 價錢全部係 HK$，並標示日期
   ☐ 冇簡體字、冇台灣用語
   ☐ 例子係香港場景（地區、平台、法規）
```

### 4.2 發布後的立即檢查

```
1. 用 site:yourdomain.com.hk/新文章URL 檢查是否已被索引
2. 喺 GSC 請求索引（Request Indexing）
3. 順便喺 Bing Webmaster Tools 提交（覆蓋 Yahoo 香港 + ChatGPT/Copilot）
4. 確認所有連結（內部＋外部）都正確運作
5. 喺手機上檢查文章顯示效果（香港手機滲透率極高，一定要測）
6. 用 PageSpeed Insights 檢查載入速度（建議用香港/新加坡節點測）
7. 分享去 WhatsApp / Facebook 睇下預覽圖（og:image）出唔出到
```

## 階段五：追蹤與迭代（Tracking & Iteration）

### 5.1 文章表現的關鍵時間點

| 時間 | 重點觀察 |
|------|---------|
| **發布後 1 週** | 是否已被索引？初始排名位置？（香港細市場，新文收錄通常快過大市場） |
| **發布後 1 個月** | 排名是否穩定？開始獲得長尾流量？ |
| **發布後 3 個月** | 排名趨勢是上升還是下降？是否需要內容更新？ |
| **發布後 6 個月** | 全面審查：內容是否過時？競爭對手是否有更好的內容？ |
| **每年稅季 / 大型節日前** | 香港季節性文章要提前 4-6 星期更新（例如報稅文喺 3 月更新） |

### 5.2 文章迭代升級的觸發條件

當出現以下情況時，應該重新審視和升級文章：

```
⬇️ 排名從前 10 名滑落到第 2 頁
⬇️ 自然流量連續 2 個月下降
⬆️ 競爭對手（或者 OpenRice / 香港01 呢類平台）發布了明顯更好的同主題內容
📅 文章發布超過 12 個月未更新
🔄 Google 演算法更新後排名大幅波動
💰 文中 HK$ 價錢 / 政府收費 / 法規已經變咗
```

### 5.3 迭代升級的具體做法

| 升級程度 | 做法 | 預期效果 |
|----------|------|----------|
| **小幅更新** | 修正過時資訊、更新統計數字與 HK$ 價錢、修復失效連結 | 維持排名穩定性 |
| **中幅更新** | 增加新章節、補充最新趨勢、加入新數據來源（例如香港最新統計） | 排名小幅提升（3-5 位） |
| **大幅改版** | 重寫 50%+ 內容、重新設計架構、增加多媒體（實測相片/影片） | 可能回到第一頁甚至更高 |
