## 為什麼關鍵字研究是 SEO 的起點？

關鍵字研究是整個 SEO 策略的**地基**。所有後續的內容創作、頁面優化、內部連結布局，都必須建立在正確的關鍵字研究之上。

> 選錯關鍵字 → 寫了沒人看的內容 → 沒有流量 → 沒有轉換 → 沒有回報。

這不是誇大——數據顯示，**超過 90% 的網站流量來自不到 10% 的關鍵字**。關鍵字研究的目標就是找到那 10%。

> **香港市場嘅第一件事**：做關鍵字研究前，所有工具嘅**地區一定要設為「Hong Kong」、語言設為「繁體中文」**。否則你睇到嘅係全球或者美國嘅搜尋量，對香港市場嚟講完全無參考價值。
>
> 另外要調低心理預期：香港人口七百幾萬，一個月 5,000 次搜尋嘅字喺香港已經係「大詞」；而一個月 300-800 次嘅地區長尾字（例如「將軍澳 補習社」），商業價值可能仲高過大詞。唔好用台灣 / 美國嘅搜尋量標準去衡量香港。

## 階段一：種子關鍵字（Seed Keywords）挖掘

種子關鍵字是你的關鍵字研究起點——那些最能代表你業務核心的詞。

### 1.1 從五個來源挖掘種子關鍵字

| 來源 | 方法 | 範例（以「香港寵物用品網店」為例） |
|------|------|------------------------------|
| **自身業務** | 列出你的核心產品/服務類別 | 「狗糧」「貓砂」「寵物玩具」 |
| **團隊腦力激盪** | 業務、客服、產品團隊分別列出 | 客服：「狗狗唔食嘢點算」→ 內容方向 |
| **現有客戶語言** | 分析客服對話、評價、詢問內容 | 「小型犬狗糧推介」「防敏感貓砂」「邊隻貓砂好」 |
| **既有網站數據** | GSC 查看已有排名和點擊的詞 | 發掘自己都不知道的關鍵字機會 |
| **社群聆聽** | 觀察目標客群在香港平台的發言 | LIHKG 寵物版、Uwants、Facebook 社團（如「香港狗奴會」）、小紅書 `#香港養狗` `#貓奴日常` 中的常見問題 |

> **香港客戶語言特別值錢**：香港人問嘢好口語 —— 「邊隻好」「有冇推介」「邊度買平」「值唔值」「點揀」，仲會中英夾雜（「dog food 邊隻好」）。呢啲說話先係真正會被打入搜尋框嘅字，唔好淨係收集書面語。

### 1.2 種子關鍵字的篩選標準

一個好的種子關鍵字應該同時滿足：

| 標準 | 說明 |
|------|------|
| **高相關性** | 與你的業務、產品或服務直接相關 |
| **搜尋意圖明確** | 你能清楚判斷使用者在搜尋這個詞時的意圖 |
| **商業潛力** | 這個詞能帶來潛在客戶或收入 |
| **可競爭** | 你的網站有機會在這個詞上取得排名（非遙不可及） |

## 階段二：關鍵字擴展——從 20 個到 200+ 個

種子關鍵字只是起點，真正的價值在於從它們擴展出更豐富的關鍵字庫。

### 2.1 六大擴展方法

#### 方法 1：Google 自動建議（Autocomplete）

當你在 Google 搜尋框中輸入關鍵字時，Google 會自動跳出建議。這些建議基於真實使用者的搜尋行為，是金礦。

```
輸入「狗糧」 → Google 建議（香港）：
├─ 狗糧 推介
├─ 狗糧 品牌
├─ 狗糧 評價
├─ 狗糧 點揀
└─ 狗糧 幼犬
```

**技巧**：使用 `_`（底線）作為萬用字元，讓 Google 在中間填入建議詞。
```
「狗 _ 狗糧」→ 「狗 唔食 狗糧」「狗 挑食 狗糧」
```

> **香港一定要做嘅變體**：同一個意思要試晒幾種寫法 —— 繁中書面語（「狗糧推薦」）、廣東話口語（「狗糧推介」「狗糧邊隻好」）、中英夾雜（「dog food 推介」）。三種寫法嘅建議清單會唔同，加埋先至係完整嘅香港詞庫。

#### 方法 2：相關搜尋（Related Searches）

在搜尋結果頁面最底部，Google 會顯示 8 個相關搜尋建議。這些詞通常代表使用者在主查詢之後會搜尋的下一個詞——換句話說，這些詞反映了使用者的**資訊旅程**。

#### 方法 3：People Also Ask（PAA）

PAA 區塊是關鍵字靈感的超級金礦。每個問題都可以展開，展開後又會出現更多相關問題。

**實戰技巧**：
1. 搜尋你的種子關鍵字（地區設為香港）
2. 展開所有 PAA 問題
3. 記錄所有問題（尤其是反覆出現的主題）
4. 對每個展開後出現的新問題重複步驟 2-3

#### 方法 4：關鍵字工具擴展

| 工具 | 核心功能 | 適合階段 |
|------|----------|----------|
| **Google Keyword Planner** | 基礎搜尋量、競爭度（記得設地區 = 香港） | 初期規劃 |
| **Ahrefs** | 搜尋量、點擊率、關鍵字難度、SERP 分析（可篩選 HK 資料庫） | 全面研究 |
| **SEMrush** | 關鍵字魔術工具、問題關鍵字（可設 HK 資料庫） | 全面研究 |
| **Ubersuggest** | 免費關鍵字建議 | 初學者/預算有限 |
| **AlsoAsked** | PAA 資料視覺化（可選地區 / 語言） | 內容規劃 |

#### 方法 5：競品關鍵字分析

分析競爭對手正在排名的關鍵字（詳見第 15 章）：
- 哪些關鍵字他們有排名但你沒有？
- 哪些關鍵字他們排名很好但內容品質不佳？（這是你的突破口）

> **香港競品唔只係同行**：你嘅「競品」可能仲包括 OpenRice、LIHKG、大型集團 portal、香港新聞媒體、HKTVmall 等。用 Ahrefs / SEMrush 輸入佢哋嘅網域，睇吓佢哋靠乜嘢關鍵字霸住第一頁，你先至知道要「打低佢哋」定係「加入佢哋」。

#### 方法 6：香港論壇與社群挖掘

**LIHKG（連登）、Uwants、Discuss.com.hk、高登討論區、Facebook 社團、小紅書、OpenRice** —— 這些是香港真實使用者提問的地方。關注他們使用的語言，而非行銷術語。

```
挖掘方法（以 LIHKG 為例）：
site:lihkg.com 狗糧
→ 睇佢哋點樣問、用乜字眼、關心乜嘢（價錢？成份？邊度買？）

Facebook 社團：搜尋「香港 狗狗」「香港 貓奴」等社團
→ 睇常見問題帖文嘅標題用語

小紅書：搜「香港 狗糧」「香港 貓砂」
→ 睇香港年輕人點樣描述同搜尋
```

## 階段三：關鍵字篩選與優先級排序

有了 200+ 個潛在關鍵字後，你需要一套標準來決定「先攻哪一個」。

### 3.1 關鍵字評估矩陣

對每個關鍵字評估以下四個維度，每個維度 1-5 分：

| 維度 | 1 分（差） | 3 分（中等） | 5 分（好） |
|------|-----------|------------|-----------|
| **搜尋量**（香港標準） | < 30/月 | 100-500/月 | > 1,000/月 |
| **商業價值** | 純資訊型 | 研究/比較型 | 交易/購買型 |
| **競爭難度** | 首頁均為大站 / 本地平台 | 有中等網站 | 有小站或論壇內容 |
| **內容匹配度** | 無法提供獨特價值 | 可提供但需大量投入 | 你已有深厚專業知識 |

> **香港版調整**：上表嘅搜尋量門檻已經按香港市場縮細咗。香港人口七百幾萬，一個月 1,000 次搜尋已經係好可觀嘅字；地區長尾字（「沙田 狗糧」）一個月 50-200 次都值得做，因為意圖極之精準。

### 3.2 關鍵字優先級公式

```
優先級分數 = 搜尋量分數 × 0.3 + 商業價值分數 × 0.3 + (5 - 競爭難度分數) × 0.3 + 內容匹配度 × 0.1
```

**最高的優先級是**：搜尋量適中（非最大）、商業價值高、競爭難度低、你剛好有獨特見解的關鍵字。

### 3.3 低垂果實（Low-Hanging Fruit）策略

「低垂果實」是指那些**容易取得排名**且**已有一定流量**的關鍵字。這些通常具備以下特徵：

- 你已經在 Google 排名第 6-20 名
- 競爭者內容品質明顯不佳
- Featured Snippet 可以被你搶走
- 長尾關鍵字，競爭度低

**行動 SOP**：
1. 在 GSC 中找到目前排名第 6-20 的關鍵字（篩選國家 = Hong Kong）
2. 分析排名在你前面的頁面內容
3. 創建比它們更好（更全面、更新、更有用）的內容
4. 優化內部連結，把權重導向這篇新內容

## 階段四：關鍵字分群與頁面對應

### 4.1 關鍵字分群原則

將相似意圖的關鍵字歸為一組，每組對應一個頁面。

| 分群維度 | 分在同一群 | 分在不同群 |
|----------|-----------|-----------|
| **搜尋意圖** | 意圖相同或高度重疊 | 意圖明顯不同 |
| **搜尋量層級** | 量級相近 | 一個數千、一個個位數 |
| **主題相關性** | 同一子主題 | 不同主題方向 |
| **語言變體** | 廣東話口語 / 書面語 / 中英夾雜的同一意圖 | 唔同語言市場（繁中 vs 英文 vs 簡中） |

### 4.2 關鍵字與頁面類型對應

| 關鍵字類型 | 建議頁面類型 | 範例（香港場景） |
|-----------|-------------|------|
| 品牌關鍵字 | 首頁 / 關於我們 | 「HKTVmall 官網」→ 首頁 |
| 產品/服務核心詞 | 產品頁 / 服務頁 | 「狗糧推介」→ 商品分類頁 |
| 資訊型關鍵字 | 部落格文章 / 指南 | 「狗糧點揀」→ 選購指南 |
| 比較型關鍵字 | 比較表 / 對比文章 | 「皇家 vs Hill's」→ 品牌比較文 |
| 問題型關鍵字 | FAQ 頁面 / 教學文 | 「狗狗唔食嘢點算」→ 解決方案文 |
| 地區關鍵字 | 地區頁 / 分店頁（要有獨有內容） | 「旺角 寵物用品店」→ 分店專頁 |
| 價格關鍵字 | 價格頁 / 方案頁（HK$） | 「狗糧 邊度買平」→ 價格比較頁 |

### 4.3 關鍵字蠶食（Keyword Cannibalization）防止

> 關鍵字蠶食 = 多個頁面競爭同一個關鍵字 → 分散權重 → 全部都排不上去。

**檢查方法**：在 `site:你的網域 "關鍵字"` 中搜尋，看有多少個頁面在競爭同一關鍵字。

**解決方案**：
1. 合併相關內容為一篇終極指南
2. 設定 Canonical URL 指向主力頁面
3. 301 重定向次要頁面到主力頁面
4. 為每個頁面分配不同的關鍵字焦點

> **香港常見蠶食**：18 區頁 / 分店頁全部針對同一個核心字（例如全部優化「寵物用品」），結果互相打。正確做法：地區頁針對「地區 + 服務」（「沙田 寵物用品」），主分類頁先至針對「寵物用品」。

## 重點回顧

1. **關鍵字研究四階段**：種子挖掘 → 擴展詞庫 → 篩選排序 → 分群對應
2. **工具地區必須設為香港**，並用香港嘅搜尋量標準去判斷
3. **Google 自動建議、PAA、相關搜尋**是免費且最真實的關鍵字來源（口語體 / 書面語 / 中英夾雜三種寫法都要試）
4. **香港社群平台係獨有金礦**：LIHKG、Uwants、Discuss、高登、Facebook 社團、小紅書、OpenRice
5. **優先級公式**幫助你在 200+ 關鍵字中做出取捨
6. **低垂果實策略**讓你在短期內看到 SEO 成果
7. **一個關鍵字群對應一個頁面**，地區頁要錯開焦點，避免關鍵字蠶食
8. 工具很重要，但**對香港使用者語言的深入理解**更重要
