## 什麼是 Local Pack？

**Local Pack**（本地套件）是 Google 針對具有本地意圖的搜尋查詢，在搜尋結果頁面（SERP）頂部顯示的**三個商家結果**，通常伴隨地圖顯示。

```
香港使用者搜尋「中環 咖啡店」後的 SERP 佈局：

┌────────────────────────────────────────────┐
│                                            │
│  📍 Local Pack（佔據最上方位置）              │
│  ┌──────────────────────────────────────┐  │
│  │ 🏪 咖啡店 A                         │  │
│  │ ⭐ 4.8 (320) · 中環 · 營業中        │  │
│  │ 🏪 咖啡店 B                         │  │
│  │ ⭐ 4.6 (180) · 中環 · 營業中        │  │
│  │ 🏪 咖啡店 C                         │  │
│  │ ⭐ 4.5 (250) · 中環 · 營業中        │  │
│  │ [更多地點]                           │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  自然搜尋結果（排在 Local Pack 下方）         │
│  🔗 咖啡店 D 官方網站                      │
│  🔗 「中環 Cafe 推介 2026」文章            │
│  🔗 OpenRice 中環咖啡店排行榜              │
│                                            │
│  付費廣告（Google Ads）                     │
│  [贊助] 咖啡店 E 中環分店                  │
│                                            │
└────────────────────────────────────────────┘
```

> **關鍵數據：** Local Pack 佔據了 SERP 最顯眼的位置。研究顯示 Local Pack 的點擊率（CTR）高達 **30-40%**，遠高於下方的自然搜尋結果。
>
> **香港特點：** 香港地方細但競爭密度極高（中環一個街口可以有 20 間 Cafe），所以「距離」嘅影響相對細，反而「相關性 + 評論數」更容易分勝負。呢個對小店係好消息。

## Local Pack 排名機制

### Google 的本地排名演算法

Google 使用三個因素來決定 Local Pack 的排名順序：

```
排名公式（簡化版）：

Local Pack 排名 = 相關性 × 距離 × 知名度

詳細說明：
  相關性（Relevance）：你的商家與使用者搜尋的匹配程度
  距離（Distance）：使用者與商家之間的物理距離
  知名度（Prominence）：你的商家在線上和線下的知名程度
```

### 三因素的權重變化（香港例子）

| 搜尋類型 | 香港例子 | 主導因素 |
|----------|------|---------|
| **品牌搜尋** | 「陳大明牙醫診所」 | 相關性（知名度也很高） |
| **類別搜尋** | 「旺角 牙醫」 | 距離 + 知名度 |
| **地區 + 評價搜尋** | 「沙田 邊間補習社好」 | 知名度（評論 + 內容） |
| **Near Me 搜尋** | 「我附近嘅牙醫」 | 距離（極度重要） |
| **緊急搜尋** | 「24 小時通渠 觀塘」 | 相關性 + 距離 |
| **品質導向搜尋** | 「中環 最好嘅牙醫」 | 知名度（評論分數極度重要） |

## 策略 1：最大化相關性（Relevance）

### 選擇正確的 GBP 類別

GBP 的**主要類別（Primary Category）**是相關性的最重要訊號。選擇錯誤 = 你永遠不會出現在正確的搜尋中。

```
策略：
  主要類別選擇最能描述你核心業務的類別。

  範例：一間位於銅鑼灣、提供一般牙科、植牙和隱形牙套的診所

  ✅ 主要類別：牙醫（Dentist）
  ✅ 次要類別：植牙專科醫師、牙齒矯正專科醫師

  ❌ 唔好將「隱形牙套」設為主要類別
     → 太狹窄，會錯失一般牙科的搜尋流量

  香港常見錯誤：
  ❌ 茶餐廳選咗「Restaurant」而唔係「Hong Kong Style Cafe」
  ❌ 樓上補習社選咗「Education Center」而忽略更具體類別
```

### 優化商家描述（Business Description）

GBP 描述欄有 750 個字符的空間。這是你告訴 Google 和潛在客戶「你是誰」的地方。

```
撰寫 GBP 描述的黃金法則：

1. 前 250 個字符最重要（行動裝置上會截斷）
2. 自然地包含核心關鍵字（繁中 + 英文都得），但不要關鍵字堆砌
3. 強調你的獨特賣點（USP）
4. 包含服務區域（18 區中的哪些區）
5. 加入行動呼籲（CTA）

香港範例描述：

「陳大明牙醫診所位於中環核心地段，由超過 15 年經驗的陳大明醫生主理。
我們提供全面的牙科服務，包括一般檢查、植牙、隱形牙套矯正、
牙齒美白及緊急牙科護理。診所採用最新的 3D 掃描技術，
為每位病人制定 personalised 治療方案。
中環、金鐘、上環、灣仔居民可步行抵達，港鐵中環站 D2 出口 3 分鐘。
立即致電 +852 2345 6789 預約首次諮詢（首次檢查 HK$500 起）。」
```

GBP 允許你列出你提供的**服務（Services）**和**產品（Products）**。

```
服務列表策略（價錢用 HK$）：
  ✅ 為每個服務設定獨立名稱、描述和價格
  ✅ 每個服務的描述中包含相關關鍵字
  ✅ 定期檢查和更新服務清單

香港範例服務清單（牙科）：

## 策略 2：克服距離劣勢（Distance）

距離是你無法控制的排名因素，但你可以「策略性地管理」它。

### 如果你不在搜尋熱區

```
策略 A：優化相關性和知名度來補償距離劣勢

  香港地方細，如果你喺中環邊緣（例如上環）而對手喺中環核心，
  但你的 GBP 優化遠比佢好、評論更多、評分更高——你仍然可能在
  Local Pack 中勝出。Google 演算法唔係純距離排序。

策略 B：考慮在熱區設立服務點

  如果你的客戶集中在特定區域（例如金融區上班族），
  考慮喺該區域設立據點：
  → 小型共享辦公室的私人房間（中環、金鐘有大量 service office）
  → 合作診所的借診時段
  → 衛星服務點（必須能喺營業時間內接待客戶）
```

### 服務區域商家（Service Area Business）

如果你的商家沒有實體店面但服務特定區域，正確設定服務區域至關重要。

```
GBP 設定（香港）：
  ✅ 選擇「服務區域商家」類型
  ✅ 隱藏你的地址（如果是家庭辦公室 / 工廈單位）
  ✅ 明確設定你的服務區域

⚠️ 香港冇郵遞區號，所以用「地區 / 18 區」或自訂範圍設定：
  → 例如：中西區、灣仔區、油尖旺區
  → 或自訂多邊形範圍（Google Maps 上圈）

服務區域設定建議：
  → 以你的實際服務範圍為準，不要誇大
     （例如寫住服務全港，但實際淨係做港島 → 違規風險）
  → 考慮設定多個服務區域：中環、金鐘、上環、灣仔
  → 每個服務區域在你的網站上應有一個對應的著陸頁
```

## 策略 3：建立知名度（Prominence）

### 評論 — 知名度的核心引擎

```
評論對 Local Pack 排名的影響：

評論數量 → 你的商家被多少人知道
  ✅ 10 個評論 vs 200 個評論 = 顯著的知名度差異

評論分數 → 品質訊號
  ✅ 4.8 分 vs 3.9 分 = 點擊率和排名差異

評論內容 → 相關性訊號
  ✅ 評論中提到「植牙」「隱形牙套」「中環」→ 這些關鍵字的相關性提升
  ✅ 廣東話用語（「唔洗等」「好細心」）都係自然語言訊號

評論的新鮮度 → 活躍度訊號
  ✅ 持續有新的評論 → Google 認為你的商家仍在積極營運
```

```
Google 評論 → 直接影響 Local Pack 排名（主力）
OpenRice 評論 → 餐飲業嘅轉化主場，亦會排喺品牌詞 SERP
Facebook 推薦 → 社群口碑，間接影響
TripAdvisor → 做遊客生意必爭（尖沙咀、銅鑼灣、旺角一帶尤其重要）
```

### 引用 — 知名度的基礎設施

引用（Citations）的數量和一致性向 Google 證明你的商家是「真實存在且在行業內有影響力的」。

```
香港引用策略金字塔：

  Tier 1：Google Business Profile
  Tier 2：香港主要目錄（OpenRice、TripAdvisor、黃頁 HK、Facebook、Apple Maps）

  Tier 6：一般目錄（補充數量）

  優先完成 Tier 1-3，再逐步擴展到 Tier 4-6。
```

## Local Pack 排名常見問題

### Q1：為什麼我的 GBP 資訊很完整，但還是排不進 Local Pack？

```
可能原因（香港常見）：
  1. 評論數量和評分不如競爭對手（香港同區競爭密度極高）
  2. NAP 在網絡上不一致（尤其 OpenRice 同 Facebook 地址唔同）
  3. 網站缺乏本地化內容和香港本地反向連結
  4. GBP 類別選擇不當
  5. 距離劣勢（距離搜尋者太遠）
  6. 主要做英文客但網站得繁中版（或相反）

解決方案：
  逐一檢查以上因素，找出最薄弱的環節並強化。
```

### Q2：可以付費來提升 Local Pack 排名嗎？

```
答案：不可以。

Local Pack 是 100% 有機的排名結果。
你無法通過付費 Google Ads 直接影響 Local Pack 排名。

但你可以：
  → 使用 Google Ads（本地廣告）獲得付費版位
  → 間接通過 Google Ads 帶來的流量和品牌曝光提升知名度
```

### Q3：廣告和 Local Pack 會互相影響嗎？

```
答案：不會直接影響，但有間接效益。

Google Ads 不會直接提升你的 Local Pack 排名，
但廣告帶來的品牌知名度提升、更多人搜尋你的商家名稱、
更多人造訪你的網站——這些間接影響都可能提升你的
本地知名度（Prominence）。
```

### Q4：香港舖位喺樓上（樓上舖）會唔會輸俾地舖？

```
答案：唔會直接輸，但要補強。

Google 睇嘅係地址準確性同可達性，唔係街舖定樓上舖。
但樓上舖要特別做：
  ✅ 地址寫明大廈名 + 樓層 + 室號（唔好淨寫「XX 大廈」）
  ✅ 加清晰嘅交通指引（港鐵出口、升降機位置）
  ✅ 上傳大廈入口相（幫客人認門口）
  ✅ GBP 加「位於 X 大廈 12 樓」等屬性描述
```

## Local Pack 排名優化優先級矩陣

```
