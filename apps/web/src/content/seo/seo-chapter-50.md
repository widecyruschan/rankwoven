## 什麼是 Local Pack？

**Local Pack**（在地套件）是 Google 針對具有在地意圖的搜尋查詢，在搜尋結果頁面（SERP）頂部顯示的**三個商家結果**，通常伴隨地圖顯示。

```
搜尋「中環 咖啡店」後的 SERP 佈局：

┌────────────────────────────────────────────┐
│                                            │
│  📍 Local Pack（佔據最上方位置）              │
│  ┌──────────────────────────────────────┐  │
│  │ 🏪 咖啡店 A                         │  │
│  │ ⭐ 4.8 (320) · 中環 · 營業中        │  │
│  │ 🏪 咖啡店 B                         │  │
│  │ ⭐ 4.6 (180) · 中環 · 營業中        │  │
│  │ 🏪 咖啡店 C                         │  │
│  │ ⭐ 4.5 (250) · 中環 · 營業中        │  │
│  │ [更多地點]                           │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  自然搜尋結果（排在 Local Pack 下方）         │
│  🔗 咖啡店 D 官方網站                      │
│  🔗 「中環最佳咖啡店推薦」文章              │
│  🔗 OpenRice 中環咖啡店排行榜              │
│                                            │
│  付費廣告（Google Ads）                     │
│  [贊助] 咖啡店 E 中環分店                  │
│                                            │
└────────────────────────────────────────────┘
```

> **關鍵數據：** Local Pack 佔據了 SERP 最顯眼的位置。研究顯示 Local Pack 的點擊率（CTR）高達 **30-40%**，遠高於下方的自然搜尋結果。

## Local Pack 排名機制

### Google 的在地排名演算法

Google 使用三個因素來決定 Local Pack 的排名順序：

```
排名公式（簡化版）：

Local Pack 排名 = 相關性 × 距離 × 知名度

詳細說明：
  相關性（Relevance）：你的商家與使用者搜尋的匹配程度
  距離（Distance）：使用者與商家之間的物理距離
  知名度（Prominence）：你的商家在線上和線下的知名程度
```

### 三因素的權重變化

不同類型的搜尋，三因素的權重不同：

| 搜尋類型 | 範例 | 主導因素 |
|----------|------|---------|
| **品牌搜尋** | 「陳大明牙醫診所」 | 相關性（知名度也很高） |
| **類別搜尋** | 「中環 牙醫」 | 距離 + 知名度 |
| **Near Me 搜尋** | 「我附近的牙醫」 | 距離（極度重要） |
| **緊急搜尋** | 「24 小時牙醫急診」 | 相關性 + 距離 |
| **品質導向搜尋** | 「中環 最好的牙醫」 | 知名度（評論分數極度重要） |

## 策略 1：最大化相關性（Relevance）

### 選擇正確的 GBP 類別

GBP 的**主要類別（Primary Category）**是相關性的最重要訊號。選擇錯誤 = 你永遠不會出現在正確的搜尋中。

```
策略：
  主要類別選擇最能描述你核心業務的類別。

  範例：一間提供一般牙科、植牙和隱形牙套的診所

  ✅ 主要類別：牙醫（Dentist）
  ✅ 次要類別：植牙專科醫師、牙齒矯正專科醫師

  ❌ 不要把「隱形牙套」設為主要類別
     → 太狹窄，會錯失一般牙科的搜尋流量
```

### 優化商家描述（Business Description）

GBP 描述欄有 750 個字符的空間。這是你告訴 Google 和潛在客戶「你是誰」的地方。

```
撰寫 GBP 描述的黃金法則：

1. 前 250 個字符最重要（行動裝置上會截斷）
2. 自然地包含核心關鍵字，但不要關鍵字堆砌
3. 強調你的獨特賣點（USP）
4. 包含服務區域（如果適用）
5. 加入行動呼籲（CTA）

範例描述：

「陳大明牙醫診所位於中環核心地段，由超過 15 年經驗的陳大明醫生主理。
我們提供全面的牙科服務，包括一般檢查、植牙、隱形牙套矯正、
牙齒美白及緊急牙科護理。診所採用最新的 3D 掃描技術，
為每位病人制定個人化治療方案。
中環、金鐘、上環居民可步行抵達。
立即致電 +852 1234 5678 預約首次諮詢。」
```

### 列出服務和產品

GBP 允許你列出你提供的**服務（Services）**和**產品（Products）**。

```
服務列表策略：
  ✅ 為每個服務設定獨立名稱、描述和價格（可選）
  ✅ 每個服務的描述中包含相關關鍵字
  ✅ 定期檢查和更新服務清單

範例服務清單：
  🦷 一般牙科檢查及洗牙 — HK$500 起
  🦷 專業牙齒美白 — HK$3,000 起
  🦷 隱形牙套矯正 — 免費諮詢
  🦷 植牙手術 — HK$20,000 起
  🦷 緊急牙科護理 — 即日預約
```

### Google Posts — 內容即相關性

定期發布 Google Posts 不僅向潛在客戶傳遞資訊，也告訴 Google 你的商家是**活躍和相關的**。

```
Post 內容策略：
  每週至少發布 1-2 篇

Post 類型建議：
  📢 優惠推廣：「暑期牙齒美白 8 折優惠」
  📰 最新消息：「診所新增 3D 掃描設備」
  🎉 活動：「中環社區免費牙科檢查日」
  💡 衛教內容：「5 個保護牙齒的日常習慣」
  🏆 案例分享：「隱形牙套矯正前後對比」
```

## 策略 2：克服距離劣勢（Distance）

距離是你無法控制的排名因素，但你可以「策略性地管理」它。

### 如果你不在搜尋熱區

```
策略 A：優化相關性和知名度來補償距離劣勢

  如果你的競爭對手就在搜尋者旁邊，但你的 GBP 優化遠比他們好、
  評論更多、評分更高——你仍然可能在 Local Pack 中勝出。
  Google 演算法不是純距離排序。

策略 B：考慮在熱區設立服務點

  如果你的客戶集中在特定區域，考慮在該區域設立據點。
  小型共享辦公室的私人房間、
  合作診所的借診時段、
  都是降低成本的選項。
```

### 服務區域商家（Service Area Business）

如果你的商家沒有實體店面但服務特定區域，正確設定服務區域至關重要。

```
GBP 設定：
  ✅ 選擇「服務區域商家」類型
  ✅ 隱藏你的地址（如果是家庭辦公室）
  ✅ 明確設定你的服務區域（按城市、郵政編碼或區域）

服務區域設定建議：
  → 以你的實際服務範圍為準，不要誇大
  → 考慮設定多個服務區域（例如：中環、金鐘、上環、灣仔）
  → 每個服務區域在你的網站上應有一個對應的著陸頁
```

## 策略 3：建立知名度（Prominence）

### 評論 — 知名度的核心引擎

```
評論對 Local Pack 排名的影響：

評論數量 → 你的商家被多少人知道
  ✅ 10 個評論 vs 200 個評論 = 顯著的知名度差異

評論分數 → 品質訊號
  ✅ 4.8 分 vs 3.9 分 = 點擊率和排名差異

評論內容 → 相關性訊號
  ✅ 評論中提到「植牙」「隱形牙套」→ 這些關鍵字的相關性提升

評論的新鮮度 → 活躍度訊號
  ✅ 持續有新的評論 → Google 認為你的商家仍在積極營運
```

> **詳見第 48 章：Google 評論管理與回覆策略**，有完整的評論策略。

### 引用 — 知名度的基礎設施

引用（Citations）的數量和一致性向 Google 證明你的商家是「真實存在且在行業內有影響力的」。

```
引用策略金字塔：

  Tier 1：Google Business Profile
  Tier 2：主要目錄（OpenRice、Yelp、TripAdvisor、Yellow Pages）
  Tier 3：行業特定目錄（例如牙科專用目錄）
  Tier 4：在地社群（商會、在地媒體、合作夥伴網站）
  Tier 5：一般目錄（補充數量）

  優先完成 Tier 1-3，再逐步擴展到 Tier 4-5。
```

> **詳見第 49 章：NAP 一致性與在地引用管理**

### 在地反向連結

反向連結對在地 SEO 的價值和一般 SEO 一致——但重點放在**在地相關**的連結。

```
高價值的在地反向連結：

  ✅ 本地新聞媒體報導（HK01、明報、星島日報等）
  ✅ 在地商會網站（香港總商會、中小企商會等）
  ✅ 在地活動頁面（贊助或參與本地活動的頁面）
  ✅ 合作夥伴網站（供應商、合作診所、轉介網絡）
  ✅ 本地教育機構（大學、中學的合作頁面）
  ✅ 專業協會（香港牙醫學會等）
  ✅ 在地部落格（本地美食/生活部落格的推薦）
```

## 策略 4：網站優化 — 在地訊號的放大器

### 在地著陸頁（Local Landing Page）

每個服務區域應該有一個專屬的在地著陸頁。

```
在地著陸頁的關鍵元素：

  ✅ 頁面標題包含城市/區域名稱 + 關鍵字
     範例：「中環牙醫推薦 | 陳大明牙醫診所 - 中環核心地段」

  ✅ H1 包含地區關鍵字
     範例：「中環專業牙科服務 — 步行即達」

  ✅ 內容提及周邊地標、街道、交通方式
     範例：「本診所位於皇后大道中新鴻基大廈 12 樓，
            中環地鐵站 D2 出口步行約 3 分鐘」

  ✅ 嵌入 Google Maps（該分店位置）

  ✅ LocalBusiness Schema 結構化資料

  ✅ 清晰的 CTA 和聯絡資訊
     範例：「📞 立即預約：+852 1234 5678」

  ✅ 客戶推薦（來自該區域的真實客戶）

  ✅ 內部連結到其他相關在地頁面
```

### 網站整體的在地化

```
網站層面的在地 SEO 優化：

  Title Tag → 包含主要服務城市
  「中環牙醫推薦 | 陳大明牙醫診所 | 隱形牙套矯正專家」

  Meta Description → 包含區域 + 服務 + CTA
  「陳大明牙醫診所位於中環核心地段，提供專業植牙、隱形牙套、
   牙齒美白等全面牙科服務，15 年經驗。立即致電預約諮詢！」

  Footer → 包含完整 NAP + Schema

  About 頁面 → 強調在地連結和歷史

  部落格 → 定期發布與在地相關的內容
   「中環上班族的牙齒保健指南」
   「香港人最常見的 5 個牙科問題」
```

## 策略 5：競爭對手分析與逆轉排名

### 分析 Local Pack 中的對手

```
當你尚未進入 Local Pack 時，分析佔據位置的競爭對手：

分析清單：
  □ 他們的 GBP 類別設定是什麼？
  □ 他們的評論數量和評分是多少？
  □ 他們發布 Google Posts 的頻率？
  □ 他們的商家描述中包含了什麼關鍵字？
  □ 他們的在地引用數量（使用 Moz Local 或 BrightLocal 檢查）？
  □ 他們的網站上是否有在地著陸頁？
  □ 他們的反向連結中，有多少是來自在地來源？

行動：
  找出你和對手之間最大的差距，
  優先彌補最容易追上的差距。
```

### 追蹤你的 Local Pack 排名

```
免費方法：
  → 使用無痕模式在 Google 搜尋你的目標關鍵字
  → 手動記錄 Local Pack 位置
  → 缺點：搜尋結果會因搜尋位置和個人化而變化

付費工具：
  → BrightLocal（專門的在地排名追蹤）
  → Semrush（Map Rank Tracker）
  → Local Falcon（在地排名可視化地圖）
  → Places Scout（全面的在地 SEO 工具）
```

## Local Pack 排名常見問題

### Q1：為什麼我的 GBP 資訊很完整，但還是排不進 Local Pack？

```
可能原因：
  1. 評論數量和評分不如競爭對手
  2. NAP 在網絡上不一致
  3. 網站缺乏在地化內容和在地反向連結
  4. GBP 類別選擇不當
  5. 距離劣勢（距離搜尋者太遠）

解決方案：
  逐一檢查以上因素，找出最薄弱的環節並強化。
```

### Q2：可以付費來提升 Local Pack 排名嗎？

```
答案：不可以。

Local Pack 是 100% 有機的排名結果。
你無法通過付費 Google Ads 直接影響 Local Pack 排名。

但你可以：
  → 使用 Google Ads（在地廣告）獲得付費版位
  → 間接通過 Google Ads 帶來的流量和品牌曝光提升知名度
```

### Q3：廣告和 Local Pack 會互相影響嗎？

```
答案：不會直接影響，但有間接效益。

Google Ads 不會直接提升你的 Local Pack 排名，
但廣告帶來的品牌知名度提升、更多人搜尋你的商家名稱、
更多人造訪你的網站——這些間接影響都可能提升你的
在地知名度（Prominence）。
```

```
影響力高 + 容易執行 → 立即做

```
