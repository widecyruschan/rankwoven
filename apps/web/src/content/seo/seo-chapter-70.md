> SEO 出事嘅時候，最危險嘅反應係「憑感覺亂改」。本章畀你一套標準化嘅診斷 SOP，好似醫生睇症咁：問症狀 → 做檢查 → 下診斷 → 開藥方。

## SEO 診斷的黃金法則

### 三個原則

1. **先排除外部因素，再看內部問題** — 先確認不是 Google 演算法更新、季節性波動（如農曆新年、暑假、颱風）、競爭對手動作等外部因素，才去改網站
2. **數據交叉驗證，不要只看單一指標** — 流量掉了可能是排名問題，也可能是 SERP 功能改變、CTR 下降、或關鍵字需求減少
3. **一次只改一個變數** — 避免同時修改 Title + 內容 + 內部連結，這樣永遠不知道哪個改動產生了效果

### 診斷工具箱

| 工具 | 主要用途 | 優先級 |
|------|----------|--------|
| Google Search Console | 排名/曝光/點擊/索引/技術問題 | 🥇 第一站 |
| Google Analytics 4 | 流量/行為/轉換 | 🥇 第一站 |
| Bing Webmaster Tools | 香港 Bing / Yahoo 香港 / Copilot 索引檢查 | 🥇 第一站（香港必備） |
| Ahrefs / SEMrush | 排名追蹤/連結分析/競品 | 🥈 第二站 |
| Screaming Frog | 技術爬取/大規模診斷 | 🥈 第二站 |
| PageSpeed Insights | 速度/Core Web Vitals | 🥉 第三站 |
| Google Trends（地區設「香港」） | 搜尋需求趨勢 | 🥉 第三站 |

> 🇭🇰 **香港視角提示：** 香港搜尋市場約 Google 92-95%、Yahoo 香港 3-6%（用 Bing 技術）、Bing 3-5%。所以除咗 GSC，都要定期開 **Bing Webmaster Tools** 睇索引狀態 — 因為 Yahoo 香港同 Microsoft Copilot 都係食 Bing 嘅索引，呢度出問題 GSC 係睇唔到嘅。

## 診斷場景一：有機流量突然暴跌

### 症狀
有機流量在短時間內（1-7 天）大幅下降 30% 以上。

### 診斷流程（5 分鐘快速排查）

```
流量暴跌
    │
    ├─→ 步驟 1：檢查是否 Google 演算法更新
    │   ┌─────────────────────────────────┐
    │   │ 查看 @searchliaison (X/Twitter)  │
    │   │ 查看 SEO 社群（MozCast 等工具）    │
    │   │ 查看 Google Search Status 儀表板 │
    │   └─────────────────────────────────┘
    │   如果有更新 → 記錄影響範圍，等待恢復 → 跳到步驟 5
    │
    ├─→ 步驟 2：檢查 GSC 手動操作
    │   GSC → 安全性與手動操作
    │   如果有處罰 → 理解原因 → 修正 → 提交重審
    │
    ├─→ 步驟 3：檢查技術問題
    │   ┌─────────────────────────────────┐
    │   │ GSC → 索引 → 頁面               │
    │   │ 檢查是否突然大量頁面被取消索引    │
    │   │ 檢查 robots.txt 是否誤封         │
    │   │ 檢查 noindex 標籤是否誤設        │
    │   │ 檢查伺服器是否 5xx 錯誤          │
    │   │ 檢查 .hk 域名 / DNS 是否正常     │
    │   └─────────────────────────────────┘
    │
    ├─→ 步驟 4：細分流量損失來源
    │   GSC → 成效 → 比較（過去 7 天 vs. 前 7 天）
    │   ┌─────────────────────────────────┐
    │   │ 按「查詢」分組：                  │
    │   │   - 所有關鍵字都掉 → 全站問題     │
    │   │   - 只有幾個關鍵字掉 → 頁面層級   │
    │   │                                   │
    │   │ 按「網頁」分組：                  │
    │   │   - 找出降幅最大的 5 個頁面       │
    │   │   - 檢查這些頁面有沒有被改過？     │
    │   │                                   │
    │   │ 按「國家」分組：                  │
    │   │   - 香港跌但海外冇跌？            │
    │   │     → 本地 SEO / GBP / 地區問題   │
    │   │   - 全部跌 → 全站問題             │
    │   └─────────────────────────────────┘
    │
    └─→ 步驟 5：對症下藥
        ┌──────────────────────────────────────────┐
        │ 原因               │ 解法                 │
        ├──────────────────────────────────────────┤
        │ 演算法更新影響      │ 改善 E-E-A-T，等恢復  │
        │ 手動處罰            │ 修正問題 + 提交重審   │
        │ 大量頁面未索引      │ 檢查 noindex/robots  │
        │ 競爭對手內容更新    │ 檢視競品，加強內容   │
        │ SERP 功能改變       │ 結構化資料 + 長尾策略 │
        │ 網站改版            │ 檢查 301/Canonical   │
        │ 關鍵字需求下降       │ Google Trends（香港） │
        │ 季節性 / 颱風 / 假期 │ 對照去年同期         │
        └──────────────────────────────────────────┘
```

### 進階診斷：使用 GSC 比較報表

```
步驟 A：設定比較日期範圍（本週 vs 上週）
步驟 B：先看「總點擊次數」變化 → 確認確實下降
步驟 C：再看「總曝光次數」→ 曝光也降 = 排名問題
       → 曝光沒降 = CTR 問題
步驟 D：CTR 問題 → 檢查 SERP 外觀是否有變化（AI Overviews 出現？）
```

> 🇭🇰 **香港特別要留意嘅外部因素：**
> - **八號風球 / 黑色暴雨**：香港一掛風球，本地服務（餐飲、零售、裝修）嘅搜尋量即刻插水，但「外賣」「網購」可能反而升。呢啲係真實波動，唔係 SEO 問題。
> - **農曆新年 / 復活節 / 暑假 / 聖誕**：香港嘅長假會令 B2B 搜尋量大跌，零售同旅遊就大升。一定要用 YoY（去年同期）對照，唔好用 MoM。
> - **LIHKG 連登 / Facebook 社團爆帖**：可能一朝帶來大量 referral 流量，隔幾日又跌返 — 呢啲唔係 organic，要喺 GA4 用「工作階段媒體」分開睇。

## 診斷場景二：排名緩慢下滑（非突然暴跌）

### 症狀
核心關鍵字的排名在 1-3 個月內從第 3 名掉到第 8 名，或持續緩慢下滑。

### 診斷流程

```
排名緩慢下滑
    │
    ├─→ 檢查一：內容新鮮度
    │   文章發布多久了？超過 12 個月？
    │   → 更新內容，加入最新數據和案例
    │   → 香港例子：一篇「2024 香港寬頻優惠比較」
    │     喺 2026 年已經完全過時，一定跌
    │
    ├─→ 檢查二：競爭對手動態
    │   用 Ahrefs/SEMrush 查看（地區設香港）：
    │   ┌─────────────────────────────────┐
    │   │ - 誰在排名上升？                 │
    │   │ - 他們的內容比你多了什麼？        │
    │   │ - 他們最近獲得了哪些新連結？      │
    │   └─────────────────────────────────┘
    │   → 找出差距，補強內容
    │
    ├─→ 檢查三：內部連結衰減
    │   舊文章是否漸漸失去內部連結？
    │   → 在新文章中適當引用舊文章
    │   → 檢查導航結構是否改動
    │
    ├─→ 檢查四：關鍵字意圖轉移
    │   搜尋該關鍵字，SERP 上的內容類型是否變了？
    │   → 用戶意圖可能從「資訊型」變成「交易型」（或相反）
    │   → 調整你的內容格式來匹配新的意圖
    │   → 香港例子：「香港 移民 英國」由資訊型
    │     （點樣申請）變成交易型（邊間顧問好）
    │
    └─→ 檢查五：技術債累積
        網站速度是否逐漸變慢？
        Core Web Vitals 是否惡化？
        → PageSpeed Insights 檢查
        → 清理不必要的插件和資源
```

## 診斷場景三：流量不錯但沒轉換

### 症狀
有機流量穩定成長，但轉換率持續低迷。

### 診斷流程

```
高流量低轉換
    │
    ├─→ 檢查一：流量品質
    │   ┌─────────────────────────────────┐
    │   │ GA4 → 有機搜尋查詢報表            │
    │   │ 查看帶來最多流量的關鍵字           │
    │   │ 這些關鍵字的搜尋意圖是什麼？        │
    │   │ 如果是「資訊型」意圖佔大多數        │
    │   │ → 你的內容匹配了錯誤的意圖階段      │
    │   └─────────────────────────────────┘
    │
    ├─→ 檢查二：內容與意圖不匹配
    │   搜尋「香港 裝修 報價 點計」嘅人
    │   被導到一個硬銷申請頁 → 佢要嘅係指南，唔係即刻落單
    │   解法：建立資訊型內容 → 內部連結引導到報價頁
    │
    ├─→ 檢查三：CTA 位置與設計
    │   使用 GA4 熱力圖或捲動深度追蹤：
    │   ┌─────────────────────────────────┐
    │   │ - CTA 是否埋在內容太深處？        │
    │   │ - 用戶讀到 50% 就離開了？         │
    │   │ → 把 CTA 提前到 25-30% 位置      │
    │   │ - CTA 文案是否模糊？              │
    │   │ → 改為具體行動（下載指南 vs 了解更多）│
    │   └─────────────────────────────────┘
    │   🇭🇰 香港用戶偏好：WhatsApp 按鈕、打電話
    │      按鈕、Google Maps 導航 — 呢啲 CTA
    │      通常比「填表單」轉化率高好多
    │
    ├─→ 檢查四：著陸頁體驗
    │   - 頁面載入速度（移動端 < 3 秒）？
    │   - 彈出視窗是否干擾閱讀？
    │   - 行動版表單是否好填寫？
    │   - 有冇 WhatsApp / 電話號碼可以即刻聯絡？
    │
    └─→ 檢查五：目標受眾匹配
        用 GA4 的「人口統計」報表確認：
        - SEO 流量的人口特徵是否符合你的目標客戶？
        - 如果是 B2B 但來的都是學生 → 內容策略需要重新定位
        - 香港例子：賣中環寫字樓清潔服務，但流量
          全部嚟自「DIY 清潔教學」→ 意圖完全錯配
```

## 診斷場景四：大量頁面未被索引

### 症狀
GSC 顯示大量頁面「已檢索 — 目前未建立索引」或「找到但未建立索引」。

### 診斷流程

```
大量頁面未索引
    │
    ├─→ 第一步：量化問題範圍
    │   GSC → 索引 → 頁面 → 查看「為什麼網頁未建立索引」
    │   記錄每個原因的數量
    │   同時檢查 Bing Webmaster Tools（Yahoo 香港用 Bing 索引）
    │
    ├─→ 第二步：分類處理
    │
    │   原因：重複網頁，未選為標準網頁
    │   ├─ Canonical 設定錯誤？
    │   ├─ 內容過於相似？
    │   │   🇭🇰 常見：繁中 / 英文 / 簡中三個版本
    │   │      內容太似但 hreflang 冇設 → 被判重複
    │   └─ 解法：檢查 canonical 標籤 + hreflang，差異化內容或合併頁面
    │
    │   原因：找到但未建立索引
    │   ├─ Google 認為內容品質不足
    │   ├─ Crawl Budget 不夠
    │   └─ 解法：
    │       • 改善內容深度和原創性
    │       • 確保每個頁面至少 300+ 字
    │       • 減少低品質頁面（Content Pruning）
    │       • 優化網站速度，增加 Crawl Budget
    │
    │   原因：已檢索 — 目前未建立索引
    │   ├─ Google 看到了但決定不收錄
    │   └─ 解法：
    │       • 增強內部連結 → 增加重要性訊號
    │       • 獲得外部連結 → 增加權威訊號
    │           （香港本地連結：香港01、經濟日報、
    │             OpenRice、商會目錄、HKTDC 等）
    │       • 提交 Sitemap 中的 lastmod 日期
    │
    │   原因：漫遊器已排除（noindex）
    │   ├─ 檢查是否誤設了 noindex
    │   └─ 解法：如果是故意的（後台頁面/感謝頁面），OK
    │          如果不是 → 移除 noindex 標籤
    │
    └─→ 第三步：建立監控機制
        每週查看 GSC 索引報表
        設定自動化通知（透過 GSC API 或第三方工具）
```

## 診斷場景五：CTR 異常低

### 症狀
排名在前 5 名以內，但 CTR 遠低於該位置的平均值。

### 診斷流程

```
排名高 CTR 低
    │
    ├─→ 檢查一：Title Tag 吸引力
    │   用這個公式評估你的 Title：
    │   ┌─────────────────────────────────┐
    │   │ [主要關鍵字] + [獨特賣點]          │
    │   │         + [數字/年份]             │
    │   │         + [觸發點擊的元素]         │
    │   │                                   │
    │   │ ❌ 「SEO 教學」                    │
    │   │ ✅ 「2026 SEO 完整教學：香港實戰    │
    │   │     7 個步驟，由零到首頁排名」      │
    │   └─────────────────────────────────┘
    │   🇭🇰 香港用戶對「年份」「香港」「邊間好」
    │      「推介」「平唔平」呢啲字眼特別敏感
    │
    ├─→ 檢查二：Meta Description
    │   ┌─────────────────────────────────┐
    │   │ - 是否包含 CTA？                  │
    │   │ - 是否回答用戶的痛點？             │
    │   │ - 是否在 150 字以內（行動版限制）？ │
    │   │ - 有冇寫明 HK$ 價錢 / 地區？       │
    │   └─────────────────────────────────┘
    │
    ├─→ 檢查三：SERP 功能競爭
    │   搜尋你的目標關鍵字，看看 SERP 上有沒有：
    │   ┌─────────────────────────────────┐
    │   │ • AI Overviews（2026 最常見）      │
    │   │ • Featured Snippet（佔據位置 0）  │
    │   │ • PAA（People Also Ask）         │
    │   │ • 廣告（佔據前 4 個位置）          │
    │   │ • 影片輪播 / 圖片輪播             │
    │   │ • 本地包（Local Pack / Google 地圖）│
    │   └─────────────────────────────────┘
    │   如果有 AI Overviews 直接回答問題
    │   → 你的內容需要在深度上超越 AI 能提供的
    │   → 或爭取被 AI Overviews 引用
    │   如果有 Local Pack（含地區名嘅查詢特別常見）
    │   → 你嘅 Google 商家檔案（GBP）要優化
    │
    ├─→ 檢查四：結構化資料缺失
    │   競爭對手的搜尋結果有星級評分、FAQ、麵包屑
    │   你的沒有 → 視覺上被比下去
    │   解法：加上對應的 Schema 標記
    │
    └─→ 檢查五：品牌辨識度
        排名第 3 名但前面是維基百科和知名品牌
        → 用戶會傾向點擊認識的網站
        → 長期策略：累積品牌權威和知名度
        → 香港做法：做本地媒體曝光（香港01、明報、
          經濟日報、星島）、OpenRice / TripAdvisor 評價、
          LIHKG 連登口碑
```

## 診斷場景六：改版/搬家後的 SEO 異常

### 常見症狀
- 網站改版後流量下跌
- 域名遷移後排名消失（香港常見：`.com` 轉 `.hk` / `.com.hk`，或公司改名換域名）
- 重新設計後頁面失蹤

### 診斷流程

```
網站改版後異常
    │
    ├─→ 第一步：檢查 301 轉址
    │   用 Screaming Frog 爬取舊 URL 清單
    │   ┌─────────────────────────────────┐
    │   │ ✓ 每個舊 URL → 返回 301          │
    │   │ ✓ 目標 URL → 返回 200            │
    │   │ ✗ 沒有 301 → 404 → SEO 資產流失  │
    │   │ ✗ 301 → 301 鏈 → 權重衰減       │
    │   └─────────────────────────────────┘
    │
    ├─→ 第二步：檢查 Canonical 設定
    │   新頁面的 canonical 指向是否正確？
    │   - 不能指向舊 URL
    │   - 不能多個頁面指向同一個 canonical
    │
    ├─→ 第三步：檢查內部連結
    │   網站改版後，內部連結結構可能全亂了：
    │   ┌─────────────────────────────────┐
    │   │ - 導航選單的連結更新了嗎？         │
    │   │ - 文章內的內部連結還是舊 URL？     │
    │   │ - 相關文章推薦區塊指向正確嗎？     │
    │   └─────────────────────────────────┘
    │
    ├─→ 第四步：檢查內容變化
    │   改版後內容有被刪減嗎？
    │   - 文字量是否大幅減少？
    │   - Heading 結構是否被破壞？
    │   - 圖片 alt 屬性是否遺失？
    │
    ├─→ 第五步：檢查技術設定
    │   ┌─────────────────────────────────┐
    │   │ - robots.txt 是否改變？           │
    │   │ - SSL 憑證是否正確？              │
    │   │ - Sitemap 是否更新？              │
    │   │ - 頁面速度是否變慢？              │
    │   │ - 行動版是否正常？                │
    │   │ - hreflang（zh-HK / en-HK / zh-CN）是否保留？│
    │   └─────────────────────────────────┘
    │
    ├─→ 第六步：GSC 地址變更
    │   GSC → 設定 → 地址變更
    │   通知 Google 你的網站已遷移
    │   ⚠️ 同時要做 Bing Webmaster Tools 嘅
    │      「Site Move」（Yahoo 香港用 Bing 索引）
    │
    └─→ 第七步：更新香港本地引用（容易漏！）
        ┌─────────────────────────────────┐
        │ • Google 商家檔案（GBP）網站連結   │
        │ • OpenRice / TripAdvisor 商戶資料 │
        │ • Facebook / IG / 小紅書 專頁連結 │
        │ • HKTDC、商會目錄、公司註冊處資料  │
        │ • 電郵簽名、名片、WhatsApp Business│
        └─────────────────────────────────┘
```

## 診斷場景七：新內容無法獲得排名

### 症狀
發布超過 4 週的新文章，曝光幾乎為零，排名在 50 名以後。

### 診斷流程

```
新內容無排名
    │
    ├─→ 檢查一：是否被索引？
    │   GSC → 網址檢查 → 輸入 URL
    │   如果未索引 → 手動「請求建立索引」
    │   如果返回「已檢索但未索引」→ 內容品質問題
    │
    ├─→ 檢查二：關鍵字競爭力
    │   用 Ahrefs/SEMrush 查看目標關鍵字的 KD（Keyword Difficulty）
    │   ┌─────────────────────────────────┐
    │   │ KD > 70：高難度，新網站很難競爭    │
    │   │ KD 40-70：中等，需要優質內容+連結  │
    │   │ KD < 40：低難度，內容+內部連結即可  │
    │   └─────────────────────────────────┘
    │   如果 KD 過高 → 改用長尾關鍵字策略
    │   🇭🇰 香港市場細，好多「大詞」搜尋量得
    │      幾百／月，但競爭一樣激烈。
    │      建議攻「地區 + 服務」長尾
    │      （例：「將軍澳 裝修 報價」）
    │      KD 低、意圖清晰、轉化率高
    │
    ├─→ 檢查三：內部連結強度
    │   新文章從哪些頁面獲得內部連結？
    │   → 從相關的舊文章加入連結
    │   → 從導航/分類頁加入連結
    │   → 目標：至少 3-5 條內部連結指向新文章
    │
    ├─→ 檢查四：內容深度與格式
    │   搜尋目標關鍵字（用 google.com.hk），分析 Top 3 的內容：
    │   ┌─────────────────────────────────┐
    │   │ - 他們的字數範圍？               │
    │   │ - 他們使用了什麼格式？（清單/指南）│
    │   │ - 他們包含了哪些子主題？          │
    │   │ → 你的內容必須覆蓋同樣的子主題     │
    │   │ → 並提供他們沒有的獨特視角         │
    │   └─────────────────────────────────┘
    │   🇭🇰 香港用戶鍾意：比較表、價錢表（HK$）、
    │      地區分店清單、WhatsApp 即時查詢
    │
    └─→ 檢查五：等待時間
        「Sandbox 效應」— 新網站/新內容需要時間建立信任
        - 高權威網站：1-2 週
        - 中等權威：3-6 週
        - 新網站/低權威：2-6 個月
        → 這是正常的，繼續發布優質內容，不要放棄
```

## 診斷場景八：季節性判斷 vs 真實問題

### 症狀
流量出現週期性波動，不確定是季節性還是 SEO 問題。

### 診斷流程

```
流量波動判別
    │
    ├─→ 方法一：Google Trends 驗證（地區設「香港」）
    │   搜尋你的核心關鍵字，查看過去 5 年的趨勢曲線
    │   ┌─────────────────────────────────┐
    │   │ 每年同月份都下降 → 季節性         │
    │   │ 今年特別低於往年 → SEO 問題       │
    │   └─────────────────────────────────┘
    │   🇭🇰 香港典型季節性：
    │      • 農曆新年：B2B 跌、零售/餐飲升
    │      • 暑假（7-8月）：補習、旅遊升；B2B 跌
    │      • 9 月開學：教育、補習高峰
    │      • 11-12 月：零售、聖誕、年結服務升
    │      • 颱風季（6-10月）：本地服務突跌
    │
    ├─→ 方法二：年比年比較（YoY）
    │   GSC → 成效 → 比較 → 去年同期
    │   ┌─────────────────────────────────┐
    │   │ YoY 持平或上升 → 季節性           │
    │   │ YoY 大幅下降 → 真問題             │
    │   └─────────────────────────────────┘
    │   注意：唔好對比農曆新年日期唔同嘅年份，
    │        要用「農曆」對「農曆」先準確
    │
    ├─→ 方法三：對照組分析
    │   找一個「不受季節影響」的關鍵字群組
    │   看看這組關鍵字是否也掉了？
    │   ┌─────────────────────────────────┐
    │   │ 對照組也掉 → 全站問題             │
    │   │ 只有季節性關鍵字掉 → 季節性        │
    │   └─────────────────────────────────┘
    │
    └─→ 方法四：檢查競爭對手
        用第三方工具查看競爭對手是否也掉了
        競爭對手也掉 → 行業季節性或市場需求變化
        只有你掉 → 你就是問題
```

## 萬用診斷 SOP：任何 SEO 問題的起手式

當你不知道從哪裡開始時，按照這個順序跑一遍：

```
🔍 SEO 問題萬用診斷 SOP（香港版）

階段一（10 分鐘）：排除外部因素
☐ 1. 查看是否有 Google 演算法更新？
☐ 2. GSC 手動操作檢查
☐ 3. Google Trends（地區：香港）確認需求變化
☐ 4. 確認不是香港假期 / 農曆新年 / 颱風 / 季節性波動
☐ 5. 檢查 Bing Webmaster Tools（Yahoo 香港 + Copilot 索引）
→ 如果都不是 → 問題在網站本身，進入階段二

階段二（15 分鐘）：範圍定位
☐ 6. GSC 比較報表：問題是全站還是特定頁面？
☐ 7. GSC 比較報表：問題是排名還是 CTR？
☐ 8. GSC 比較報表：問題是香港流量還是海外流量？
☐ 9. GSC 比較報表：問題是手機還是桌面？（香港以手機為主）
→ 找出問題範圍後 → 進入階段三

階段三（20 分鐘）：技術排查
☐ 10. GSC 索引報表：收錄是否正常？
☐ 11. robots.txt 是否正確？
☐ 12. 網站速度 / CWV 是否正常？
☐ 13. 最近有沒有改版/搬家/插件更新？
☐ 14. hreflang / canonical 設定是否正常？（多語言網站）
→ 排除技術問題 → 進入階段四

階段四（30 分鐘）：內容與連結分析
☐ 15. 受影響頁面的內容是否過時？（年份、價錢、HK$）
☐ 16. 競爭對手的內容是否超越你了？
☐ 17. 內部連結結構是否健康？
☐ 18. 反向連結是否有流失或異常？
☐ 19. GBP / OpenRice 等本地平台資料是否一致？
→ 找到根本原因 → 制定行動計劃

階段五（持續）：行動與監控
☐ 20. 根據診斷結果制定修復方案
☐ 21. 先做影響最大的改動（P0）
☐ 22. 記錄每次改動的時間和內容
☐ 23. 改動後觀察 2-4 週
☐ 24. 無效就回溯，重新診斷
```

## 診斷結果記錄模板

每次做完診斷，務必記錄下來。這不僅幫助你追蹤，也幫助你在下次問題發生時更快定位：

```markdown
## SEO 診斷記錄

- **日期：** 2026/07/23
- **網站：** [香港網店 example.hk]
- **問題描述：** 有機流量較上月下降 35%
- **受影響範圍：** Blog 分類頁面為主，產品頁正常
- **診斷過程：**
  1. 確認無演算法更新（searchliaison 無公告）
  2. 排除香港季節性因素（7 月非長假，去年同期正常）
  3. GSC 比較：曝光下降 40%，點擊下降 35% → 排名問題
  4. 按國家分組：只係香港流量跌，台灣/馬來西亞正常
     → 本地競爭加劇，唔係全站問題
  5. 排名追蹤：3 個核心關鍵字從 Top 3 掉到 Top 8-12
  6. 檢查競爭對手：2 個香港競品在同期發布了更新的內容
  7. 內容質量檢查：我們的內容還是 2024 年的數據
- **根本原因：** 內容過時，被香港本地競爭對手超越
- **行動方案：**
  1. 更新 3 篇核心文章內容（加入 2026 香港數據）— 7/25 前
  2. 發布 2 篇新的深度內容（加入地區長尾關鍵字）— 8/1 前
  3. 建立內容更新日曆 — 8/5 前
  4. 同步檢查 Bing Webmaster Tools 索引狀態 — 7/25 前
- **預期恢復時間：** 2-4 週
- **跟進日期：** 8/15 檢查排名變化
```

## 本章重點回顧

| 診斷場景 | 第一檢查點 | 關鍵工具 |
|----------|-----------|----------|
| 流量暴跌 | 演算法更新 / 手動操作 / 香港假期 | GSC + searchliaison |
| 排名緩慢下滑 | 內容新鮮度 + 競品動態 | Ahrefs（地區：香港）+ SERP 分析 |
| 高流量低轉換 | 搜尋意圖匹配度 | GA4 + GSC 查詢報表 |
| 大量頁面未索引 | Canonical / hreflang / 品質 | GSC 索引報表 + Bing WMT |
| CTR 異常低 | SERP 功能（AI Overviews / Local Pack）+ Title | GSC + SERP 分析 |
| 改版後異常 | 301 轉址 + 內部連結 + 本地引用 | Screaming Frog |
| 新內容無排名 | 索引狀態 + KD | GSC + Ahrefs |
| 季節性判斷 | YoY 比較 + Google Trends（香港） | GSC + Trends |

> 💡 核心心法：**先定位範圍，再找原因，一次只改一個變數，追蹤效果。** 香港市場細，數據樣本少，更加要小心唔好將正常波動當成問題、亦唔好將真問題當成季節性。
