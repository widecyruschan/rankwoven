## 什麼是國際 SEO？（香港視角）

**國際 SEO（International SEO）** 是針對不同國家和語言的受眾，優化網站的策略。它不只是多語言翻譯，而是涉及**地理定位、當地搜尋引擎、文化差異、技術架構**等全面策略。

```
多語言 SEO vs 國際 SEO 的關係：

多語言 SEO = 用不同語言服務不同語言嘅受眾
國際 SEO   = 在不同國家/地區的搜尋引擎中獲得排名

  → 一個網站可以只有一個語言，但需要國際 SEO
    （例如：全英文網站，想喺香港、新加坡、英國排到）

  → 一個網站可以有多語言，但唔一定需要國際 SEO
    （例如：香港網站只服務香港，但提供繁中同英文）

對香港嚟講，兩者係「同時發生」嘅：
  香港本地：繁中 + 英文雙語（多語言 SEO，見第 53 章）
  跨境需求：大灣區內地客、東南亞、海外港人（國際 SEO，本章）
```

> **重要觀念：** 香港**唔係**「進軍國際嘅跳板」。香港本身已經係一個雙語 + 跨境需求並存嘅市場：本地要用繁中 + 英文，同時有內地客（簡中）、東南亞客、海外港人客。所以你嘅國際 SEO 規劃，應該由「香港嘅實際客源」出發，而唔係「先做好香港再話進軍世界」。

## Google 的地理定位機制（香港出發）

Google 如何判斷一個網站（或頁面）的目標國家？

### 訊號 1：ccTLD（國家頂級域名）— 最強訊號

```
香港網站：
  yoursite.hk        → Google 自動定位為香港內容（HKIRC 註冊，需香港商業登記）
  yoursite.com.hk    → 同樣定位香港，企業感更強

⚠️ 注意：
  .com、.org、.net 等通用域名**不會**自動進行地理定位
  → 用 .com 做香港生意，就要靠 hreflang + 內容訊號 + GSC 設定補足
```

### 訊號 2：hreflang 標籤

hreflang 告訴 Google 頁面的語言和地區目標。**香港標準組合**：

```
/zh-hk/  → hreflang="zh-hk"  香港繁中（主力）
/en-hk/  → hreflang="en-hk"  香港英文
/zh-cn/  → hreflang="zh-cn"  內地簡中
x-default → 指向 /zh-hk/ 或語言選擇頁
```

詳見第 53 章。

### 訊號 3：Google Search Console 的地理定位設定

```
如果你的域名係 .com 等通用域名，
你可以喺 Search Console 手動設定目標地區：

Search Console → 設定 → 國際目標 → 選擇目標國家

⚠️ 注意：
  → 只對 .com 等通用域名有效
  → .hk / .com.hk 域名唔使設定（自動定位香港）
  → Google 逐步淘汰呢個設定，主要靠 hreflang 同內容訊號
```

### 訊號 4：伺服器位置（影響較小）

```
伺服器喺香港 → 微弱嘅香港訊號 + 香港用戶速度快（重要！）
伺服器喺美國 → 唔一定代表美國目標

Google 官方講：伺服器位置唔係主要地理定位訊號。
但對香港用戶嘅 Core Web Vitals 影響實際，
所以香港主站建議用香港或亞洲節點（AWS ap-east-1、阿里雲香港、
Cloudflare 香港 PoP）。
```

### 訊號 5：當地反向連結和內容

```
嚟自香港網站嘅連結 → 香港定位訊號
  （香港01、明報、經濟日報、香港旅發局、HKTDC、.hk/.edu.hk 網站）

內容提到香港、用 HK$、提及本地事件 → 香港定位訊號
  （例如「香港公眾假期照常營業」「港鐵中環站 3 分鐘」）
```

| 架構 | 香港例子 | 地理訊號 | SEO 權威集中度 | 成本 |

## 香港品牌嘅三大跨境場景

### 場景 1：大灣區 / 中國內地市場（最常見）

```
方案：
  → 簡體中文版用 /zh-cn/ 子目錄起步
  → 若喺內地有實體營運並完成 ICP 備案，先考慮獨立 .cn 域名

搜尋引擎格局（同香港完全不同）：
  ✅ 百度主導（Google 喺內地不可用）
  ✅ 微信「搜一搜」係重要入口（公眾號、小程序）
  ✅ 小紅書係年輕人嘅 discovery + 搜尋入口
  ✅ 抖音 / 影片號做內容分發

技術要點：
  ✅ 針對百度做 SEO（Baidu SEO），唔係淨係 Google
  ✅ 百度唔支援 hreflang（要靠獨立 URL 結構）
  ✅ 百度偏好靜態頁面（少 JavaScript）、JSON-LD 支援有限
  ✅ 內地伺服器或香港伺服器可提升爬取速度（唔備案通常放香港）
  ✅ 收錄速度慢，要用百度站長平台主動提交
  ✅ 內容要符合內地法規（敏感內容、醫療/金融廣告限制）

內容要點：
  ✅ 用字要轉做內地習慣（「激光」唔係「鐳射」、「充值」唔係「增值」）
  ✅ 關鍵字用簡中（「香港 牙医 价格」唔係「香港 牙醫 價錢」）
  ✅ 支付/聯絡要支援微信支付、支付寶、內地手機號
  ✅ 小紅書筆記 + 微信公眾號內容要同步經營
```

### 場景 2：東南亞市場（新加坡、馬來西亞）

```
方案：
  → yoursite.com.hk/sg/、yoursite.com.hk/my/
  → 或英文主站 /en/ 涵蓋（視資源）

點解港商常做東南亞：
  → 地理近、時區相同、華人市場、物流成熟
  → 新加坡同香港一樣係中英雙語環境

內容策略：
  ✅ 新加坡：英文為主，可加簡中（新加坡用簡體字）
  ✅ 馬來西亞：英文 + 馬來文，視目標族群
  ✅ 每個國家獨立嘅本地化內容（唔只係語言）
  ✅ 強調當地付款方式（PayNow、GrabPay）、運送政策、退換貨
  ✅ 價錢顯示當地貨幣（SGD / MYR），可以加 HK$ 參考
```

### 場景 3：海外港人 / 英文市場（英國、澳洲、加拿大、美國）

```
方案：
  → 英文版 /en-gb/、/en-au/、/en-ca/
  → 或獨立 ccTLD（如果預算充足）

點解值得做：
  → 近年大量港人移居英國、澳洲、加拿大
  → 渠哋仍然用繁中搜尋，亦會用英文
  → 對香港品牌（食品、教育、專業服務、移民相關服務）有需求

內容注意：
  ✅ 英文本地化差異：
     colour (UK/AU) vs color (US)
     flat (UK) vs apartment (US)
     dental surgery (UK) vs dental office (US)
  ✅ 唔好忽略繁中版：海外港人一樣會打「英國 香港人 牙醫」
  ✅ 每個國家獨立嘅 Google Search Console 屬性
  ✅ 價錢顯示當地貨幣（GBP / AUD / CAD）
  ✅ 提及當地實際情況（例如「英國 NHS 牙科 vs 私家牙科」）
```

## 國際 SEO 的技術層面

### CDN（內容傳遞網路）

```
點解香港跨境網站需要 CDN？

  速度就係排名因素：
  如果伺服器喺香港，倫敦嘅用戶訪問你個網，
  延遲可能高達 200-300ms。呢個會影響 Core Web Vitals 同排名。

CDN 推薦：
  → Cloudflare（全球最大，有免費方案，香港 PoP 表現好）
  → Fastly
  → Akamai（企業級）
  → AWS CloudFront（配合 ap-east-1 香港區）

設定策略：
  ✅ 用 CDN 將內容快取到全球節點
  ✅ 確保 CDN 唔會阻擋 Googlebot / 百度爬蟲（白名單）
  ✅ 唔好對 Googlebot 做地理定向（要俾爬蟲睇到晒所有語言版本）
  ✅ 內地市場要額外考慮：Cloudflare 喺內地訪問唔穩定，
     做內地生意要另設內地可達嘅節點或獨立部署
```

### Googlebot 的地理爬取

```
重要概念：
  Googlebot 主要從美國 IP 爬取你的網站。
  呢個代表，如果你對唔同地區 IP 顯示唔同內容（IP 定向），
  Googlebot 可能只睇到美國版本。

Google 的建議：
  ❌ 唔好基於 IP 自動重定向（例如：內地 IP → 自動跳 /zh-cn/）
  ❌ 唔好對 Googlebot 隱藏其他地區嘅內容
  ✅ 使用 hreflang 標記所有語言/地區版本
  ✅ 提供清晰的語言/地區選擇器
  ✅ 如果要基於 IP 俾建議，用橫幅（Banner）而唔係重定向

香港常見踩雷：
  有啲香港網站會將内地 IP redirect 去簡中版，
  結果 Googlebot（美國 IP）睇到嘅係繁中版，
  但 /zh-cn/ 就因為 redirect 而收錄唔到 → 內地客搵你唔到。
```

### 多地區價格與貨幣顯示

```
技術建議：
  → 用 HTML 標記價格而唔係 JavaScript 動態生成
  → 確保 Googlebot 可以爬取所有貨幣版本嘅價格
  → 唔好對唔同地區顯示完全不同嘅頁面結構

結構化資料：
  → 喺 Schema 用 priceCurrency 標記貨幣
  "priceCurrency": "HKD"   （香港主站）
  "priceCurrency": "SGD"   （新加坡版）
  "priceCurrency": "CNY"   （內地版）
  "priceCurrency": "GBP"   （英國版）

香港提醒：
  → 消委會指引：顯示價錢要列明係咪已包其他費用
  → 跨境版要講清運費、關稅、退換貨政策
```

## 國際 SEO 的常見陷阱（香港版）

| 陷阱 | 問題 | 解決方案 |
|------|------|---------|
| 自動 IP 重定向 | Googlebot 只睇到一個版本，/zh-cn/ 收錄唔到 | 用橫幅建議 + hreflang |
| 所有語言共用一個 Sitemap | 無法分別追蹤每個語言版本嘅索引情況 | 每個語言版本獨立 Sitemap |
| 忽略百度（如果做內地市場） | 喺內地完全冇搜尋流量 | 獨立制定百度 + 微信 + 小紅書策略 |
| 繁簡直接轉換當「簡中版」 | 用字唔合內地習慣，Google 當重複內容 | 做真正嘅簡中本地化（用字、支付、習慣） |
| 喺翻譯中直接用 Google Translate | 低品質內容，可能被懲罰 | 專業翻譯 + SEO 本地化 |
| 不設定 hreflang x-default | Google 自行選擇預設版本 | 始終設定 x-default（香港多數指向 /zh-hk/） |
| 所有地區共用一個聯絡頁面 | 用戶體驗差、信任度低 | 每個目標地區獨立聯絡資訊（WhatsApp、微信、當地電話） |
| 使用參數（?lang=en）而非路徑 | Google 唔建議，SEO 效能差 | 用路徑 /en-hk/ 而非參數 |
| 忽略當地法規 | 網站可能喺目標地區無法訪問 | 研究當地隱私法、內容法規（內地 ICP、歐盟 GDPR） |
| 用 Cloudflare 做內地市場 | 內地訪問唔穩定 | 內地市場另設可達節點 |

## 國際 SEO 的路線圖（香港出發）

### 階段 1：研究與規劃

```
☐ 確認目標市場（建議由 2-3 個開始）
   香港本地（繁中 + 英文）→ 大灣區（簡中）→ 東南亞 / 海外港人
☐ 分析每個目標市場嘅搜尋量、競爭度
☐ 研究當地搜尋引擎生態（Google 主導？定係百度/微信/Naver？）
☐ 研究當地競爭對手嘅 SEO 策略
☐ 選擇架構（ccTLD / Subdirectory / Subdomain）
```

### 階段 2：技術實施

```
☐ 建立目標地區嘅 URL 結構（/zh-cn/、/sg/、/en-gb/）
☐ 實施 hreflang 標籤（zh-hk + en-hk + zh-cn + x-default）
☐ 為每個地區/語言建立獨立 Sitemap
☐ 設定 CDN（內地市場要另計）
☐ 設定 Search Console 屬性（每個地區獨立）
☐ 提交 Bing Webmaster Tools（AI 搜尋時代必做）
```

### 階段 3：內容與連結

```
☐ 為每個目標市場做獨立關鍵字研究（唔好直接翻譯）
☐ 優先翻譯同本地化核心頁面（首頁、服務、價目表、聯絡）
☐ 建立每個市場嘅本地化內容（含粵語/內地用語差異）
☐ 開始建立當地反向連結
☐ 喺當地社群平台建立存在感（微信/小紅書/抖音 或 Facebook/IG）
```

### 階段 4：監控與迭代

```
☐ 追蹤每個地區/語言嘅關鍵字排名
☐ 監控每個地區/語言嘅搜尋流量
☐ 檢查 hreflang 錯誤（Search Console）
☐ 監控百度收錄情況（如做內地）
☐ 監控 AI 搜尋引用（ChatGPT / Perplexity / Copilot 有冇引用你）
☐ 根據數據調整內容和策略
```

## 國際 SEO 工具推薦

| 工具 | 用途 |
|------|------|
| **Google Search Console** | 監控各地區嘅搜尋表現和 hreflang 錯誤 |

## 總結檢查清單

| 任務 | 說明 |
|------|------|
| ☐ 確認目標市場 | 香港雙語打底，再選 1-2 個跨境市場 |
| ☐ 選擇正確的 URL 架構 | 香港主站用 .hk/.com.hk，跨境用子目錄 |
| ☐ 實施 hreflang 標籤 | zh-hk / en-hk / zh-cn 雙向標記 + x-default |
| ☐ 每個地區/語言獨立 Sitemap | 方便分別追蹤索引情況 |
| ☐ 獨立關鍵字研究 | 每個目標市場嘅關鍵字研究（含粵語/內地用語） |
| ☐ 內容本地化 | 唔係翻譯，係針對當地受眾嘅內容創作 |
| ☐ 設定 CDN | 確保各地用戶有好的網站速度（內地另計） |
| ⚠ 避免 IP 自動重定向 | 用橫幅提示 + 語言選擇器 |
| ☐ 建立當地反向連結 | 每個目標市場獨立的連結建設計劃 |
| ☐ 考慮非 Google 搜尋引擎 | 百度、微信、小紅書（內地）；Bing（AI 搜尋） |
| ☐ 提交 Bing Webmaster Tools | ChatGPT / Copilot / Yahoo 香港都靠 Bing |
| ☐ 監控和調整 | 使用 Search Console 同各地數據優化策略 |
