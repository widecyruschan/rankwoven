## 為什麼要先學名詞？

SEO 領域充滿大量專業術語與縮寫。對初學者來說，光是看到「SERP」、「CTR」、「DA」、「Sitemap」這些詞就足以讓人卻步。本章整理 50+ 個 SEO 核心名詞，按類別分組，讓你快速建立完整的詞彙地圖。

> **建議使用方式**：先快速瀏覽一次建立印象，之後遇到不熟悉的詞隨時回來查閱。

---

## 一、搜尋引擎基礎名詞

| 名詞 | 英文全稱 | 說明 |
|------|----------|------|
| **SEO** | Search Engine Optimization | 搜尋引擎優化，透過改善網站結構與內容來提升在搜尋結果中的排名 |
| **SEM** | Search Engine Marketing | 搜尋引擎行銷，包含 SEO（自然流量）與 PPC（付費廣告） |
| **SERP** | Search Engine Results Page | 搜尋引擎結果頁面，用戶輸入關鍵字後看到的結果列表 |
| **演算法（Algorithm）** | — | 搜尋引擎用來決定排名的一系列規則與計算公式 |
| **爬蟲（Crawler / Spider / Bot）** | — | 搜尋引擎自動抓取網頁內容的程式，Google 的叫 Googlebot |
| **索引（Index）** | — | 搜尋引擎將抓取的網頁內容儲存到資料庫的過程，只有被索引的頁面才會出現在搜尋結果 |
| **檢索（Crawling）** | — | 爬蟲發現並訪問網頁的過程 |
| **排名（Ranking）** | — | 搜尋引擎根據演算法對已索引的頁面進行排序的過程 |

## 二、關鍵字相關名詞

| 名詞 | 說明 |
|------|------|
| **關鍵字（Keyword）** | 用戶在搜尋引擎中輸入的查詢詞 |
| **長尾關鍵字（Long-tail Keyword）** | 由 3 個以上詞彙組成的、較具體的搜尋查詢，搜尋量低但轉換率高，例如「台北東區推薦日式拉麵」 |
| **短頭關鍵字（Head Keyword）** | 由 1-2 個詞組成的高流量、高競爭關鍵字，例如「拉麵」 |
| **搜尋意圖（Search Intent）** | 用戶搜尋時背後的目的，分為資訊型、導航型、交易型、商業調查型四種 |
| **關鍵字密度（Keyword Density）** | 關鍵字在頁面中出現的頻率，通常以百分比表示；Google 已不建議機械性地追求特定密度 |
| **關鍵字蠶食（Keyword Cannibalization）** | 網站內多個頁面競爭同一個關鍵字，導致搜尋引擎無法判斷哪個頁面更相關 |
| **LSI 關鍵字（Latent Semantic Indexing）** | 與主關鍵字語意相關的輔助詞彙，幫助搜尋引擎理解內容主題深度 |
| **搜尋量（Search Volume）** | 特定關鍵字在固定期間內（通常每月）被搜尋的次數 |
| **關鍵字難度（Keyword Difficulty / KD）** | 針對特定關鍵字排上第一頁的難易程度，通常以 0-100 表示 |

## 三、頁面優化（On-Page SEO）名詞

| 名詞 | 說明 |
|------|------|
| **Title Tag（標題標籤）** | HTML `<title>` 中的文字，顯示在瀏覽器分頁和搜尋結果的藍色可點擊標題 |
| **Meta Description（中繼描述）** | HTML `<meta name="description">` 的內容，顯示在搜尋結果標題下方的摘要文字 |
| **H1-H6 標籤（Heading Tags）** | HTML 標題層級標籤，H1 最重要，每個頁面原則上只有一個 H1 |
| **Alt Text（替代文字）** | 圖片的文字描述，幫助搜尋引擎理解圖片內容，也是無障礙設計的一部分 |
| **URL 結構（URL Structure）** | 網址的格式設計，好的 URL 簡短、包含關鍵字、使用連字號分隔 |
| **內部連結（Internal Link）** | 從網站的一個頁面連結到同一網站內另一個頁面的超連結 |
| **麵包屑導航（Breadcrumb）** | 顯示用戶當前位置的路徑導航，例如「首頁 > 分類 > 文章」 |
| **結構化資料（Structured Data / Schema）** | 使用 Schema.org 標準標記網頁內容，幫助搜尋引擎理解內容並顯示豐富結果 |
| **精選摘要（Featured Snippet）** | 搜尋結果最頂部直接顯示答案的區塊，又稱「第零位」 |

## 四、技術 SEO 名詞

| 名詞 | 說明 |
|------|------|
| **Sitemap（網站地圖）** | 一份列出網站所有頁面的 XML 檔案，幫助爬蟲發現和索引頁面 |
| **Robots.txt** | 網站根目錄的檔案，告訴爬蟲哪些頁面可以或不該抓取 |
| **Canonical URL（標準網址）** | 當多個網址指向相同內容時，用來指定「主要版本」的標籤 |
| **301 轉址（301 Redirect）** | 永久性網頁轉址，會將 SEO 權重傳遞到新網址 |
| **302 轉址（302 Redirect）** | 暫時性網頁轉址，通常不會傳遞完整權重 |
| **404 錯誤（404 Error）** | 頁面不存在時的回應狀態碼 |
| **Page Speed（頁面速度）** | 網頁載入的速度，是 Google 的排名因素之一 |
| **Core Web Vitals（核心網頁指標）** | Google 定義的三個使用者體驗指標：LCP（最大內容繪製）、FID/INP（互動延遲）、CLS（累計版面位移） |
| **HTTPS / SSL** | 安全的網站傳輸協議，Google 已將其列為排名信號 |
| **行動優先索引（Mobile-First Indexing）** | Google 主要以行動版網頁內容來進行索引和排名 |
| **渲染（Rendering）** | 瀏覽器將 HTML/CSS/JavaScript 轉換為可視頁面的過程 |
| **JavaScript SEO** | 確保依賴 JavaScript 渲染的內容能被搜尋引擎正確抓取和索引 |

## 五、站外 SEO 與連結名詞

| 名詞 | 說明 |
|------|------|
| **反向連結（Backlink）** | 其他網站連結到你的網站的超連結，是 Google 重要的排名因素 |
| **Domain Authority（DA，網域權重）** | Moz 開發的指標（1-100），預測網站在搜尋引擎中的排名能力 |
| **Domain Rating（DR，網域評級）** | Ahrefs 開發的指標（1-100），衡量網站反向連結的質量與數量 |
| **PageRank（PR）** | Google 創始人開發的演算法，根據連結數量和質量評估頁面重要性 |
| **連結汁液（Link Juice）** | SEO 行話，指透過超連結傳遞的排名權重 |
| **Nofollow 連結** | 帶有 `rel="nofollow"` 屬性的連結，告訴搜尋引擎不要傳遞權重 |
| **Dofollow 連結** | 沒有 nofollow 屬性的標準連結，會傳遞權重 |
| **錨點文字（Anchor Text）** | 超連結上可點擊的文字，是重要的排名信號 |
| **垃圾連結（Spam Link）** | 來自低質量或不相關網站的連結，可能導致 Google 懲罰 |
| **連結農場（Link Farm）** | 專門用來建立大量互相連結的網站群，屬於黑帽 SEO 手法 |

## 六、分析與成效名詞

| 名詞 | 說明 |
|------|------|
| **點擊率（CTR，Click-Through Rate）** | 搜尋結果中看到你的連結後實際點擊的比例 = 點擊次數 / 曝光次數 |
| **跳出率（Bounce Rate）** | 用戶進入網站後只看一個頁面就離開的比例 |
| **平均工作階段停留時間（Avg. Session Duration）** | 用戶在網站上停留的平均時間 |
| **轉換率（Conversion Rate）** | 完成目標動作（購買、填表、訂閱等）的訪客比例 |
| **有機流量（Organic Traffic）** | 透過自然搜尋結果進入網站的流量，不含付費廣告 |
| **曝光次數（Impressions）** | 你的網站在搜尋結果中被用戶看到的次數 |
| **排名追蹤（Rank Tracking）** | 持續監控特定關鍵字的排名變化 |
| **GA4（Google Analytics 4）** | Google 最新版本的網站分析工具 |
| **GSC（Google Search Console）** | Google 提供的免費工具，用於監測網站在搜尋結果中的表現 |

## 七、內容與策略名詞

| 名詞 | 說明 |
|------|------|
| **內容行銷（Content Marketing）** | 透過創造有價值的內容來吸引目標受眾的行銷策略 |
| **長青內容（Evergreen Content）** | 不會隨時間過時的內容，能持續吸引流量 |
| **內容差距分析（Content Gap Analysis）** | 分析競爭對手有哪些你沒有的內容主題，找出可開發的內容方向 |
| **E-E-A-T** | Experience（經驗）、Expertise（專業）、Authoritativeness（權威）、Trustworthiness（信任），Google 評估內容品質的核心框架 |
| **YMYL（Your Money or Your Life）** | Google 定義的「涉及金錢或生活」類頁面，如醫療、財務、法律內容，標準更嚴格 |
| **內容更新（Content Refresh）** | 定期更新舊文章以提高其相關性和排名 |

## 九、新時代 SEO 名詞

| 名詞 | 說明 |
|------|------|
| **AISO（AI SEO）** | 針對 AI 搜尋引擎（如 ChatGPT Search、Perplexity）進行的內容優化 |
| **AEO（Answer Engine Optimization）** | 答案引擎優化，針對直接回答用戶問題的搜尋模式進行優化 |
| **GEO（Generative Engine Optimization）** | 生成式引擎優化，針對 AI 生成搜尋結果進行內容優化 |
| **SGE（Search Generative Experience）** | Google 的 AI 驅動搜尋體驗，在搜尋結果中直接生成摘要答案 |
| **零點擊搜尋（Zero-Click Search）** | 用戶在搜尋結果頁面上直接獲得答案而不需要點擊任何連結 |
| **語音搜尋（Voice Search）** | 透過語音助手（Siri、Google Assistant）進行的搜尋 |
| **視覺搜尋（Visual Search）** | 透過圖片而非文字進行的搜尋，如 Google Lens |

---

## 重點回顧

1. **SEO 名詞分七大類**：搜尋引擎基礎、關鍵字、On-Page、技術 SEO、站外連結、分析工具、新時代 SEO
2. **不要死記硬背**：先建立概念框架，實作過程中自然會熟悉
3. **重點掌握**：Crawling → Indexing → Ranking 三階段、On-Page vs Off-Page 的區別、Core Web Vitals 三大指標
4. **跟上趨勢**：AISO / AEO / GEO 是新時代 SEO 的重要方向
