> YouTube 是世界第二大搜尋引擎（僅次於 Google 本身）。如果你有影片內容，YouTube SEO 是一個完全不同的遊戲規則。

---

## YouTube SEO vs Google SEO：核心差異

| 維度 | Google SEO | YouTube SEO |
|------|-----------|-------------|
| 排名因素 | 內容 + 連結 + 技術 | 觀看時長 + CTR + 互動 + 關鍵字匹配 |
| 爬取方式 | Googlebot 讀取 HTML | 演算法分析影片 metadata + 觀看行為 |
| 點擊訊號 | CTR 次要 | CTR 關鍵（縮圖是命） |
| 停留時間 | 頁面參與時間 | 觀看時長（Watch Time）最重要 |
| 關鍵字位置 | Title + H1 + 內容 | 標題 + 描述 + 標籤 + 字幕 |
| 外部訊號 | 反向連結 | 嵌入 + 分享 + 外部流量 |

## YouTube 排名五大核心因素

```
YouTube SEO 排名權重（業界估算）：

觀看時長與留存率  ████████████████████ 40%
點擊率（CTR）     ██████████████       28%
關鍵字相關性      ██████████           18%
互動（讚/留言/分享）█████              9%
頻道權威度        ███                 5%
```

### 1. 觀看時長與觀眾留存率（最重要）

YouTube 的核心目標是「讓用戶留在平台上越久越好」。所以：

- **觀看時長（Watch Time）＞ 觀看次數（Views）**
  - 一支 500 次觀看但平均看 8 分鐘的影片
  - 比一支 2000 次觀看但平均看 30 秒的影片更有 SEO 價值

- **觀眾留存率（Audience Retention）：**
  - YouTube 後台 → 觀看 retention 曲線
  - 前 30 秒流失率是最關鍵指標
  - 曲線平緩 > 曲線陡降

### 2. 點擊率（CTR — Click Through Rate）

縮圖 + 標題決定了用戶會不會點進來。

- **YouTube 平均 CTR：** 4-8%
- **CTR > 10%：** YouTube 會大量推薦你的影片
- **CTR < 3%：** 曝光會逐漸減少

**提高 CTR 的關鍵：**
- 縮圖的「視覺衝擊力」
- 標題的「好奇心缺口」
- 不要用點擊誘餌（Clickbait）— 高 CTR + 低留存 = 演算法懲罰

### 3. 關鍵字相關性

YouTube 透過以下方式理解你的影片內容：

- 影片標題
- 影片描述（前 2-3 行最重要）
- 影片標籤（Tags）
- 字幕/CC（YouTube 會自動生成並分析）
- 你實際「說」出來的內容（語音辨識）

### 4. 互動訊號

- 按讚數
- 留言數（和你的回覆）
- 分享次數
- 儲存到播放清單
- 訂閱（從該影片來的訂閱）

### 5. 頻道權威度

- 頻道總觀看時長
- 頻道訂閱數
- 頻道內容一致性（主題聚焦）
- 頻道上傳頻率

## YouTube SEO 實戰步驟

### 步驟 1：關鍵字研究（YouTube 版）

**工具：**
- YouTube 搜尋建議（自動完成）— 最直接
- TubeBuddy / vidIQ（瀏覽器外掛）— 看關鍵字搜尋量和競爭度
- Google Trends（類型選「YouTube 搜尋」）

**YouTube 關鍵字的特性：**
```
YouTube 上最常被搜尋的關鍵字類型：
1. 「如何 / 怎麼」（教學型）— How to XXX
2. 「開箱 / 實測」（評測型）— XXX Review
3. 「教學」（中文市場大宗）— XXX 教學 / XXX 入門
4. 「Vlog」（生活型）
5. 「音樂/娛樂」（娛樂型）
```

### 步驟 2：標題優化

**YouTube 標題最佳實踐：**
```
理想格式：
[主要關鍵字] + [獨特賣點] + [情緒觸發]

❌ 「iPhone 評測」
✅ 「iPhone 17 Pro 完整評測：用了 30 天後我後悔了嗎？」

關鍵點：
- 前 60 字元最重要（搜尋結果不會截斷）
- 主要關鍵字放在最前面
- 加入數字（7 天、10 個原因）
- 創造「好奇心缺口」
- 不要用全部大寫或過多驚嘆號
```

### 步驟 3：縮圖設計

縮圖是 YouTube SEO 的「Title Tag 殺手級增強版」。

**高 CTR 縮圖原則：**
```
1. 臉部特寫 + 誇張表情（效果最佳）
2. 高對比色（YouTube 背景是白色，深色縮圖更突出）
3. 文字不超過 4 個字（太大=雜亂，太小=看不清）
4. 統一的品牌風格（讓訂閱者一眼認出）
5. 用箭頭/圓圈標示重點（引導視線）

工具：Canva / Photoshop
尺寸：1280 × 720（16:9）
檔案大小：<2MB
```

### 步驟 4：描述與標籤

**描述（Description）最佳實踐：**
```
前 2-3 行（顯示在搜尋結果中）：
✅ 總結影片內容
✅ 包含主要關鍵字
✅ 有 CTA

範例：
「這支影片教你如何在 2026 年用 7 個步驟做好 YouTube SEO。
從關鍵字研究到縮圖設計，完整步驟教學。
👇 時間戳記在下面 👇」

剩餘描述：
- 詳細的內容摘要（150-200 字）
- 時間戳記（Timestamps / Chapters）
- 相關連結（你的網站、社群媒體）
- 相關影片推薦
- Hashtags（3-5 個）
```

**標籤（Tags）策略：**
```
標籤優先級：
1. 主要目標關鍵字（1-2 個）
2. 相關關鍵字變體（5-10 個）
3. 廣泛類別標籤（2-3 個）

範例（影片主題：YouTube SEO 教學）：
youtube seo, youtube seo 2026, youtube seo tutorial,
youtube 排名, youtube 優化, youtube 演算法,
seo, video marketing, content creator
```

### 步驟 5：字幕與 CC 檔案

```
為什麼字幕對 SEO 很重要？
- YouTube 會分析字幕文字來理解影片內容
- 字幕讓搜尋可以在影片的「任何一句話」中找到你
- 多語言字幕可以觸及國際觀眾

行動：
✅ 上傳自己的字幕檔案（比 YouTube 自動生成更準確）
✅ 使用 .srt 格式
✅ 包含關鍵字在字幕中
✅ 關鍵字自然地出現在開場 30 秒內
```

### 步驟 6：影片內容結構（留住觀眾）

```
前 15 秒 — Hook（勾住觀眾）
  → 直接切入重點 / 提出問題 / 展示結果

15 秒 - 1 分鐘 — 預告價值
  → 「這支影片會教你 XXX」
  → 快速預覽你會涵蓋的內容

1 分鐘 - 結尾 — 主體內容
  → 分段清楚（用畫面文字分隔）
  → 每 2-3 分鐘一個轉折或新觀點
  → 保持節奏（不要有太長的空白停頓）

結尾 — CTA
  → 呼籲按讚、留言、訂閱
  → 推薦下一支要看的影片（用 YouTube 結束畫面功能）
```

## YouTube 的特殊 SEO 功能

### 時間戳記（Chapters / Timestamps）

```
在描述中加入時間戳記，格式：

0:00 介紹
1:23 第一步：關鍵字研究
3:45 第二步：標題優化
6:12 第三步：縮圖設計
...

YouTube 會自動在播放進度條上顯示章節標記
→ 增加在搜尋結果中的視覺吸引力
→ Google 搜尋結果可能直接顯示章節連結
```

### 結束畫面與資訊卡（End Screen & Cards）

```
結束畫面（最後 20 秒）：
- 推薦 1-2 支相關影片
- 訂閱按鈕
- 外部連結（需符合 YouTube 政策）

資訊卡（影片中間）：
- 在影片關鍵時刻彈出
- 連結到其他影片或播放清單
- 增加 Session Watch Time
```

### 播放清單（Playlist）SEO

```
播放清單本身就是一個可以被搜尋的「頁面」：

✅ 播放清單標題包含關鍵字
✅ 播放清單描述詳細說明內容
✅ 將相關影片按邏輯順序排列
✅ 系列影片放在同一播放清單
→ 增加 Session Watch Time（一個接一個看）
```

## YouTube 數據分析指南

### 關鍵指標（YouTube Studio）

```
觀看次數（Views）
  → 基本指標，但不是最重要

觀看時長（Watch Time / Hours）
  → 最重要的指標 ⭐
  → YouTube 演算法的核心目標

觀眾留存率（Audience Retention）
  → 前 30 秒流失率（盡量 < 30%）
  → 整體留存率（> 50% 為佳）

點擊率（CTR）
  → 曝光點擊率 4-8% 為正常
  → < 2% → 需要換縮圖和標題

流量來源（Traffic Source）
  → YouTube 推薦 > YouTube 搜尋 > 外部 > 其他
  → 推薦佔比越高 = 演算法越喜歡你

觀眾人口統計
  → 年齡、性別、地區、觀看裝置
```

## YouTube + Google SEO 的協同效應

```
YouTube 影片可以出現在 Google 搜尋結果中：

1. 影片輪播（Video Carousel）
2. 精選影片片段（Video Featured Snippet）
3. 一般搜尋結果中的影片縮圖

如何讓你的 YouTube 影片在 Google 排名：

✅ 目標有「影片意圖」的關鍵字
   例如：how to、教學、開箱、評測、流程

✅ 發布影片後嵌入你的網站
   在相關部落格文章中嵌入 YouTube 影片
   Google 會看到影片的嵌入和使用情況

✅ 加入 VideoObject Schema 到嵌入頁面

✅ 影片標題和描述包含目標關鍵字
```

```
發布後：
☐ 在社群媒體分享

```
