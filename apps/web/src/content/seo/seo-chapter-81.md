> YouTube 係世界第二大搜尋引擎（只係輸俾 Google 本身）。喺香港，YouTube 更加係「第二個 Google」— 唔少人搵食評、開箱、補習、裝修、按揭資訊，第一站唔係網頁，而係直接上 YouTube 打「邊間好」「推介」「點揀」。如果你有影片內容，YouTube SEO 係一套完全不同的遊戲規則。

## YouTube SEO vs Google SEO：核心差異

| 維度 | Google SEO | YouTube SEO |
|------|-----------|-------------|
| 排名因素 | 內容 + 連結 + 技術 | 觀看時長 + CTR + 互動 + 關鍵字匹配 |
| 爬取方式 | Googlebot 讀取 HTML | 演算法分析影片 metadata + 觀看行為 |
| 點擊訊號 | CTR 次要 | CTR 關鍵（縮圖是命） |
| 停留時間 | 頁面參與時間 | 觀看時長（Watch Time）最重要 |
| 關鍵字位置 | Title + H1 + 內容 | 標題 + 描述 + 標籤 + 字幕 |
| 外部訊號 | 反向連結 | 嵌入 + 分享 + 外部流量 |

**香港視角補充：**
```
香港用戶嘅 YouTube 使用特性：
- 香港 Google 市佔 ~92-95%，YouTube 同 Google 帳號綁定，影片好易喺 Google SERP 出現
- 廣東話口語搜尋量大：「抽濕機推介」「旺角髮型屋邊間好」「按揭計算機教學」
- 香港頻道觀眾群唔只本地：仲有馬來西亞、台灣、澳洲/加拿大華人
  → 字幕同時照顧繁中 + 簡體/英文，可以放大觸及
- 香港係雙語社會，財經/B2B/科技類頻道常用中英夾雜標題
```

互動（讚/留言/分享）█████              9%
頻道權威度        ███                 5%
```

### 1. 觀看時長與觀眾留存率（最重要）

YouTube 的核心目標是「讓用戶留在平台上越久越好」。所以：

- **觀看時長（Watch Time）＞ 觀看次數（Views）**
  - 一支 500 次觀看但平均看 8 分鐘的影片
  - 比一支 2000 次觀看但平均看 30 秒的影片更有 SEO 價值

- **觀眾留存率（Audience Retention）：**
  - YouTube 後台 → 觀看 retention 曲線
  - 前 30 秒流失率是最關鍵指標
  - 曲線平緩 > 曲線陡降

**香港頻道實例：**
```
試當真、小薯茄呢類搞笑頻道：靠高密度剪接 + 節奏快，留存曲線特別平
點 Cook Guide、煮食教學類：觀眾通常睇到尾（要學完整個步驟），Watch Time 極高
龔成教室、財經類：觀眾會重複睇 + 儲存落「稍後觀看」，對演算法係強訊號

共通點：佢哋嘅影片喺頭 15 秒就會講清楚「呢條片你會得到啲乜」
```

### 2. 點擊率（CTR — Click Through Rate）

縮圖 + 標題決定了用戶會不會點進來。

- **YouTube 平均 CTR：** 4-8%
- **CTR > 10%：** YouTube 會大量推薦你的影片
- **CTR < 3%：** 曝光會逐漸減少

**提高 CTR 的關鍵：**
- 縮圖的「視覺衝擊力」
- 標題的「好奇心缺口」
- 不要用點擊誘餌（Clickbait）— 高 CTR + 低留存 = 演算法懲罰

```
香港市場嘅 CTR 小貼士：
- 香港觀眾對「$」同「HK$」特別敏感，縮圖加「HK$398 值唔值？」反應好好
- 地區名入標題好有效：「銅鑼灣」「旺角」「沙田」「將軍澳」
  （「旺角 5 間隱世食堂」CTR 通常高過「5 間隱世食堂」）
- 廣東話口語標題（「呢部機我後悔咗」）比書面語（「本產品使用心得」）CTR 高一大截
```

### 3. 關鍵字相關性

YouTube 透過以下方式理解你的影片內容：

- 影片標題
- 影片描述（前 2-3 行最重要）
- 影片標籤（Tags）
- 字幕/CC（YouTube 會自動生成並分析）
- 你實際「說」出來的內容（語音辨識）

```
⚠️ 香港頻道必讀：廣東話語音辨識
- YouTube 自動字幕語言揀「廣東話（繁體）」（yue-Hant-HK）先會準
- 自動字幕錯字率喺廣東話上偏高（「呢個」→「你個」），
  → 所以一定要自己上載 .srt，唔好靠自動生成
- 廣東話同書面中文係兩套詞彙：
  口語講「抽濕機」，字幕寫「抽濕機」唔好寫「除濕機」（後者係台灣用語）
- 目標關鍵字如果係書面語（例如「除濕機推薦」），
  → 字幕同描述要同時出現書面語寫法，口語講「抽濕機」都冇問題
```

### 4. 互動訊號

- 按讚數
- 留言數（和你的回覆）
- 分享次數
- 儲存到播放清單
- 訂閱（從該影片來的訂閱）

```
香港互動特性：
- 香港觀眾鍾意喺留言區「講兩句」，尤其係飲食、地產、時事、財經類
- 留言區出現廣東話討論＝影片主題命中本地痛點
- 「分享去 WhatsApp / Facebook 群組」喺香港比例特別高
  → 片尾 CTA 可以直接講「Share 俾你啲朋友」而唔係淨係講「Subscribe」
```

### 5. 頻道權威度

- 頻道總觀看時長
- 頻道訂閱數
- 頻道內容一致性（主題聚焦）
- 頻道上傳頻率

## YouTube SEO 實戰步驟

### 步驟 1：關鍵字研究（YouTube 版）

**工具：**
- YouTube 搜尋建議（自動完成）— 最直接
- TubeBuddy / vidIQ（瀏覽器外掛）— 看關鍵字搜尋量和競爭度
- Google Trends（地區揀「香港」，類型選「YouTube 搜尋」）

**YouTube 關鍵字的特性：**
```
YouTube 上最常被搜尋的關鍵字類型：
1. 「如何 / 怎麼 / 點樣」（教學型）— How to XXX
2. 「開箱 / 實測」（評測型）— XXX Review
3. 「教學」（中文市場大宗）— XXX 教學 / XXX 入門
4. 「Vlog」（生活型）
5. 「音樂/娛樂」（娛樂型）

香港版再加三種：
6. 「邊間好 / 推介 / 比較」— 「旺角邊間髮型屋好」「抽濕機推介 2026」
7. 「值唔值 / 中伏」— 「XX 值唔值買」「XX 中伏實測」
8. 「幾錢 / HK$」— 「裝修幾錢一呎」「日本旅遊幾錢」
呢三類係香港人買嘢前最常打嘅字，競爭度通常低過「推薦」類
```

### 步驟 2：標題優化

**YouTube 標題最佳實踐：**
```
理想格式：
[主要關鍵字] + [獨特賣點] + [情緒觸發]

❌ 「iPhone 評測」
✅ 「iPhone 17 Pro 完整評測：用了 30 天後我後悔了嗎？」

香港版示範：
❌ 「抽濕機評測」
✅ 「抽濕機推介 2026：香港 300 呎單位實測 5 部，$2,000 樓下邊部最抵？」

❌ 「日本旅遊攻略」
✅ 「大阪 5 日4 夜 HK$6,000 玩到盡｜機票酒店交通全公開（2026 最新版）」

關鍵點：
- 前 60 字元最重要（搜尋結果不會截斷）
- 主要關鍵字放在最前面
- 加入數字（7 天、10 個原因）
- 創造「好奇心缺口」
- 不要用全部大寫或過多驚嘆號
- 香港市場：地區名（18 區 / 屋苑名 / 商場名）係天然嘅 CTR 放大器
```

### 步驟 3：縮圖設計

縮圖是 YouTube SEO 的「Title Tag 殺手級增強版」。

**高 CTR 縮圖原則：**
```
1. 臉部特寫 + 誇張表情（效果最佳）
2. 高對比色（YouTube 背景是白色，深色縮圖更突出）
3. 文字不超過 4 個字（太大=雜亂，太小=看不清）
4. 統一的品牌風格（讓訂閱者一眼認出）
5. 用箭頭/圓圈標示重點（引導視線）

工具：Canva / Photoshop
尺寸：1280 × 720（16:9）
檔案大小：<2MB

香港注意：
- 縮圖文字用繁體，唔好用簡體（會被當「內地片」，影響本地 CTR）
- 英文縮圖文字喺香港接受度高（雙語社會），但主力關鍵字仍建議繁中
```

### 步驟 4：描述與標籤

**描述（Description）最佳實踐：**
```
前 2-3 行（顯示在搜尋結果中）：
✅ 總結影片內容
✅ 包含主要關鍵字
✅ 有 CTA

範例：
「這支影片教你如何在 2026 年用 7 個步驟做好 YouTube SEO。
從關鍵字研究到縮圖設計，完整步驟教學，專為香港繁中頻道而寫。
👇 時間戳記在下面 👇」

剩餘描述：
- 詳細的內容摘要（150-200 字）
- 時間戳記（Timestamps / Chapters）
- 相關連結（你的網站、IG、Facebook、小紅書）
- 相關影片推薦
- Hashtags（3-5 個）

香港版建議加：
- 價錢一律寫 HK$（唔好寫 NT$ / ¥）
- 地區、店名、交通寫清楚（「銅鑼灣站 F 出口行 3 分鐘」）
- 如涉及跨境：加「內地版 / 香港版」分別說明（好多香港人專登搜呢個）
```

**標籤（Tags）策略：**
```
標籤優先級：
1. 主要目標關鍵字（1-2 個）
2. 相關關鍵字變體（5-10 個）
3. 廣泛類別標籤（2-3 個）

範例（影片主題：YouTube SEO 教學）：
youtube seo, youtube seo 2026, youtube seo tutorial,
youtube 排名, youtube 優化, youtube 演算法,
seo, video marketing, content creator

香港頻道示範（影片主題：抽濕機推介）：
抽濕機推介, 抽濕機推薦, 抽濕機2026, 香港抽濕機, 抽濕機邊間好,
抽濕機比較, dehumidifier hong kong, 家居電器, 香港天氣, 梅雨季節
→ 口語（推介/邊間好）同書面語（推薦/比較）要並存
```

### 步驟 5：字幕與 CC 檔案

```
為什麼字幕對 SEO 很重要？
- YouTube 會分析字幕文字來理解影片內容
- 字幕讓搜尋可以在影片的「任何一句話」中找到你
- 多語言字幕可以觸及國際觀眾

行動：
✅ 上傳自己的字幕檔案（比 YouTube 自動生成更準確）
✅ 使用 .srt 格式
✅ 包含關鍵字在字幕中
✅ 關鍵字自然地出現在開場 30 秒內

香港雙語做法：
✅ 主力字幕：廣東話口語（繁體）— 照顧本地觀眾同 Google 語意理解
✅ 第二軌字幕：英文 — 照顧香港外籍/雙語觀眾同海外華人
✅ 做內地客生意：加簡體中文軌，但唔好取代繁體軌
```

### 步驟 6：影片內容結構（留住觀眾）

```
前 15 秒 — Hook（勾住觀眾）
  → 直接切入重點 / 提出問題 / 展示結果

15 秒 - 1 分鐘 — 預告價值
  → 「這支影片會教你 XXX」
  → 快速預覽你會涵蓋的內容

1 分鐘 - 結尾 — 主體內容
  → 分段清楚（用畫面文字分隔）
  → 每 2-3 分鐘一個轉折或新觀點
  → 保持節奏（不要有太長的空白停頓）

結尾 — CTA
  → 呼籲按讚、留言、訂閱
  → 推薦下一支要看的影片（用 YouTube 結束畫面功能）

香港觀眾節奏偏好：
- 本地搞笑/生活類（如小薯茄、試當真）節奏極快，轉場密
- 教學/財經類（如點 Cook Guide、龔成教室）節奏可以慢，但要「資訊密度高」
- 廣東話講解嘅資訊承載量高，可以講得快少少，但字幕要跟上
```

## YouTube 的特殊 SEO 功能

### 時間戳記（Chapters / Timestamps）

```
在描述中加入時間戳記，格式：

0:00 介紹
1:23 第一步：關鍵字研究
3:45 第二步：標題優化
6:12 第三步：縮圖設計
...

YouTube 會自動在播放進度條上顯示章節標記
→ 增加在搜尋結果中的視覺吸引力
→ Google 搜尋結果可能直接顯示章節連結
→ 香港用戶搜「步驟型」內容時（例如「按揭申請流程」），
   章節連結會喺 Google SERP 直接顯示，CTR 提升明顯
```

### 結束畫面與資訊卡（End Screen & Cards）

```
結束畫面（最後 20 秒）：
- 推薦 1-2 支相關影片
- 訂閱按鈕
- 外部連結（需符合 YouTube 政策）

資訊卡（影片中間）：
- 在影片關鍵時刻彈出
- 連結到其他影片或播放清單
- 增加 Session Watch Time
```

### 播放清單（Playlist）SEO

```
播放清單本身就是一個可以被搜尋的「頁面」：

✅ 播放清單標題包含關鍵字
✅ 播放清單描述詳細說明內容
✅ 將相關影片按邏輯順序排列
✅ 系列影片放在同一播放清單
→ 增加 Session Watch Time（一個接一個看）

香港應用例子：
- 「香港 18 區美食地圖」系列 → 一個播放清單，每區一條片
- 「日本旅遊攻略 2026」系列 → 機票/住宿/交通/行程分集
- 「SEO 由零開始」粵語教學系列 → 章節式播放清單
```

## YouTube 數據分析指南

### 關鍵指標（YouTube Studio）

```
觀看次數（Views）
  → 基本指標，但不是最重要

觀看時長（Watch Time / Hours）
  → 最重要的指標 ⭐
  → YouTube 演算法的核心目標

觀眾留存率（Audience Retention）
  → 前 30 秒流失率（盡量 < 30%）
  → 整體留存率（> 50% 為佳）

點擊率（CTR）
  → 曝光點擊率 4-8% 為正常
  → < 2% → 需要換縮圖和標題

流量來源（Traffic Source）
  → YouTube 推薦 > YouTube 搜尋 > 外部 > 其他
  → 推薦佔比越高 = 演算法越喜歡你

觀眾人口統計
  → 年齡、性別、地區、觀看裝置

香港頻道必睇「地區」分佈：
  香港本地 vs 台灣 vs 馬來西亞 vs 其他
  → 如果非本地佔比高，就要考慮加英文/簡體字幕、價錢標示加註幣別
  → 如果本地佔比高，就繼續深耕地區名同廣東話口語關鍵字

「外部」流量來源要特別留意有冇嚟自：
  LIHKG（連登）、Facebook 社團、小紅書、OpenRice blog
  → 呢啲係香港主要嘅內容擴散渠道，證明你嘅片喺本地有擴散力
```

## YouTube + Google SEO 的協同效應

```
YouTube 影片可以出現在 Google 搜尋結果中：

1. 影片輪播（Video Carousel）
2. 精選影片片段（Video Featured Snippet）
3. 一般搜尋結果中的影片縮圖

如何讓你的 YouTube 影片在 Google 排名：

✅ 目標有「影片意圖」的關鍵字
   例如：how to、教學、開箱、評測、流程
   香港版：推介、邊間好、點揀、點做、實測

✅ 發布影片後嵌入你的網站
   在相關部落格文章中嵌入 YouTube 影片
   Google 會看到影片的嵌入和使用情況

✅ 加入 VideoObject Schema 到嵌入頁面

✅ 影片標題和描述包含目標關鍵字

✅ 香港本地加分配合：
   - 影片嵌入頁加入 LocalBusiness Schema（門市/餐廳/診所適用）
   - 同時喺 Google 商家檔案（GBP）貼上影片連結
   - 餐飲類同時更新 OpenRice，令「店名 + 片」形成一個實體網絡
```

☐ 如果 CTR 低 → 換縮圖
☐ 如果留存率低 → 檢查前 30 秒內容
☐ 檢查 YouTube Studio「地區」分佈，調整後續字幕策略
```

## 本章重點回顧

| 排名因素 | 權重 | 優化重點 |
|----------|------|----------|
| 觀看時長 + 留存率 | 40% | 內容結構 + 前 30 秒 Hook |
| 點擊率（CTR） | 28% | 縮圖 + 標題（加地區名/HK$ 特別有效） |
| 關鍵字相關性 | 18% | 標題/描述/標籤/字幕（廣東話 + 書面語雙軌） |
| 互動訊號 | 9% | 按讚/留言/分享/儲存 |
| 頻道權威 | 5% | 長期一致性 |

> 💡 **YouTube SEO 的核心公式：好的縮圖讓人點進來 + 好的內容讓人留下來看。缺一不可。香港市場再加兩味：廣東話口語關鍵字 + 地區名，CTR 通常即刻有分別。**
