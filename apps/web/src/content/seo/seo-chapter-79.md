> SEO 唔係一個「做完就冇事」嘅 project — 佢係一個要持續維運嘅系統。呢份每月清單等你唔會忘記任何重要嘅事。
>
> 香港版加咗幾樣嘢：Google 商家檔案（GBP）維護、OpenRice／TripAdvisor 等本地平台、Bing Webmaster Tools（Yahoo 香港）、香港節慶內容日曆、同埋品牌聲譽監控（連登、Facebook 社團）。呢啲係香港網站每個月都要跟嘅。

## 維運哲學：建立 SEO 節奏

```
每週（戰術層級）
  執行日常優化、內容發布、數據監控
  香港加：GBP 貼文、評論回覆

每月（策略層級）
  成效回顧、策略調整、深度審查
  香港加：本地引用一致性檢查、地區頁更新

每季（戰略層級）
  策略大方向調整、競爭分析、資源規劃
  香港加：旺季內容前置部署（提前 6-10 週）
```

## 第一週：數據回顧與策略調整

### 上個月成效回顧（2 小時）

```
☐ 1.1 GSC 月報分析
   → 過去 28 天 vs 前 28 天的流量/曝光/CTR/排名變化
   → 過去 28 天 vs 去年同期（YoY 比較）
     ⚠️ 香港提醒：農曆新年日期每年唔同，
        要用農曆對農曆，唔好用西曆月份直接比
   → 記錄變化最大的 5 個關鍵字（上升和下降各 5）

☐ 1.2 GA4 有機流量分析
   → 有機流量趨勢（MoM + YoY）
   → 有機轉換數和轉換率
   → 參與率（Engagement Rate）變化
   → 品牌 vs 非品牌流量比例
   → 香港 vs 海外流量分佈

☐ 1.3 排名追蹤
   → Top 10 關鍵字排名變化
   → 目標關鍵字排名分佈
   → 新進入 Top 10 和掉出 Top 10 的關鍵字
   → 地區關鍵字（「地區 + 服務」）排名與本地包出現率

☐ 1.4 Bing Webmaster Tools 檢查（香港必做）
   → Yahoo 香港 ~3-6% 份額用 Bing 索引
   → 檢查索引狀態、點擊趨勢、技術問題
   → 亦係 Microsoft Copilot / ChatGPT 搜尋嘅索引來源

☐ 1.5 目標達成檢視
   → 對比月初設定的目標
   → 達成了哪些？沒達成哪些？
   → 沒達成的根本原因是什麼？
```

### 本月策略設定（1 小時）

```
☐ 1.6 根據上月數據設定本月優先事項
   完成上個月未完成的任務 + 調整方向

☐ 1.7 設定本月內容日曆
   規劃本月要發布的內容（目標關鍵字 + 發布日期）
   🇭🇰 對齊香港節慶：農曆新年、復活節、暑假、
      開學、萬聖、聖誕、除夕、行業旺季
      旺季內容要提前 6-10 星期部署

☐ 1.8 確認本月資源
   寫手產能？開發團隊時間？預算（HK$）是否有變？
```

## 第二週：內容與 On-Page 優化

### 內容維護（3 小時）

```
☐ 2.1 發布本週計劃的內容（1-2 篇）
   → 確認 SEO Brief 已給寫手（含香港用語要求）
   → 審查完成的文章（SEO 檢查 → 用語檢查 → 發布）
   → 發布後：手動請求 GSC 索引（並同步 Bing WMT）
   → 如有多語言版本：確認 hreflang 互相指向正確

☐ 2.2 內容更新（Content Refresh）
   選擇 3-5 篇需要更新的舊文章：
   挑選標準：
   - 排名在 4-15 名之間（努力一下就能進 Top 3）
   - 流量較上月下降 >10%
   - 發布超過 12 個月

   更新內容：
   - 加入最新數據和案例（優先香港本地數據）
   - 更新年份標記（如「2026 年」）
   - 更新 HK$ 價錢（香港物價/收費變得快）
   - 補充競爭對手有但你沒有的子主題
   - 更新後修改 lastmod 日期

☐ 2.3 內部連結維護
   → 在新文章中加入 3-5 條指向舊文章的連結
   → 在 3 篇舊文章中插入新文章的連結
   → 檢查導航結構是否需要調整
   → 地區頁 ↔ 服務頁嘅雙向連結是否完整
```

### On-Page 優化（1 小時）

```
☐ 2.4 低垂果實優化
   GSC → 成效 → 篩選平均排名 11-20
   選擇 3-5 個高曝光但排名在第二頁的關鍵字

   優化對應頁面：
   - Title Tag：加入更吸引人的元素
     （香港用戶對「HK$」「地區名」「年份」敏感）
   - 內容：補充更多深度資訊
   - 內部連結：增加來自高權威頁面的連結

☐ 2.5 SERP 檢查
   搜尋你的 Top 5 核心關鍵字（用 google.com.hk）
   檢查 SERP 變化：
   - 有沒有新的 AI Overviews？
   - Featured Snippet 被誰拿走了？
   - 有冇 Local Pack（本地包）？你嘅 GBP 喺唔喺入面？
   - 競爭對手的排名有沒有變化？
   - 小紅書 / YouTube / 連登嘅內容有冇上榜？
```

## 第三週：技術監控、本地 SEO 與連結建設

### 技術 SEO 例行檢查（2 小時）

```
☐ 3.1 GSC 索引狀態檢查
   → 索引 → 頁面 → 查看有沒有新增的「未索引」頁面
   → 索引率應保持在 90% 以上
   → 處理新發現的索引問題

☐ 3.2 GSC 體驗報表
   → Core Web Vitals：有沒有新的不良 URL？
   → 行動可用性：有沒有新的問題？
     （香港手機流量佔比高，行動版問題影響特別大）

☐ 3.3 Sitemap 狀態
   → 確認 Sitemap 最後讀取日期更新
   → 檢查 Sitemap 錯誤（如有）

☐ 3.4 404 錯誤監控
   → 用 Screaming Frog 爬取網站
   → 檢查是否有新的 404 頁面
   → 對有流量的 404 頁面設定 301 轉址

☐ 3.5 安全性與手動操作
   → GSC 安全性問題檢查
   → GSC 手動操作檢查
   （幾秒鐘的事，不要跳過）

☐ 3.6 hreflang / 多語言檢查（每月快速掃）
   → zh-HK / en-HK / zh-CN 有冇互相指向錯誤
   → 新頁面有冇漏加 hreflang
```

### 本地 SEO 例行維護（1 小時，香港必做）

```
☐ 3.7 Google 商家檔案（GBP）
   → 檢查資料正確（地址、電話 +852、營業時間、分類）
   → 發布 1-2 篇 Google 貼文（優惠、新服務、活動）
   → 回覆所有新評論（正面要謝，負面要專業回應）
   → 上載新相片（香港用戶好睇相）
   → 查看洞察報告：曝光、來電、導航、網站點擊

☐ 3.8 本地引用（NAP）一致性檢查
   → 網站、GBP、Facebook、OpenRice、HKTDC、
     商會目錄嘅地址電話係咪一致
   → 發現唔一致立即更正

☐ 3.9 行業平台維護（視業務）
   → 餐飲：OpenRice 商戶資料、相片、回應食評
   → 旅遊/酒店：TripAdvisor 資料與評論
   → 零售/服務：Facebook 專頁、小紅書專頁更新

☐ 3.10 品牌聲譽監控
   → Google Alerts（品牌名，中英文 + 簡繁）
   → 搜尋「[品牌名] 評價 / 伏 / 點」
   → 檢查連登（LIHKG）、Uwants、Facebook 社團有冇
     相關討論
```

### 連結建設（2 小時）

```
☐ 3.11 反向連結健康檢查
   → Ahrefs/SEMrush（地區：香港）查看新增和失去的連結
   → 有沒有可疑的新連結？（DR<5、不相關網站）
   → 重要連結是否還在？
   → 有冇突然暴增？（可能係負面 SEO，見第 73 章）

☐ 3.12 連結建設任務
   每月至少完成以下之一：
   → 撰寫 1 篇 Guest Post 並發布（香港行業媒體/部落格）
   → 找到 3 個 Broken Link 機會並 outreach
   → 發布 1 份值得被引用的原創內容（香港市場調查/
     數據報告/免費工具，例如 HK$ 計算機）
   → 在 1-2 個香港媒體獲得品牌提及
     （香港01、明報、經濟日報、星島、頭條日報、am730）
   → 提交 1-2 個香港本地目錄/商會

☐ 3.13 競爭對手連結監控
   → 查看主要香港競品的新增連結
   → 有沒有你可以複製的連結機會？
```

## 第四週：分析深化與下月準備

### 深度分析（2 小時）

```
☐ 4.1 內容成效分析
   → 本月發布的內容表現（有流量了嗎？有排名嗎？）
   → 找出本月表現最佳的內容（為什麼？可以複製嗎？）
   → 找出本月表現最差的內容（需要改進或刪除？）

☐ 4.2 用戶行為分析
   → GA4 著陸頁報表：Top 10 著陸頁的參與率和轉換率
   → 高流量低轉換的頁面 → 需要 CRO 優化
   → 低流量高轉換的頁面 → 需要更多曝光
   → 檢查 WhatsApp / 電話 / 地圖點擊事件（香港主要 CTA）

☐ 4.3 轉換漏斗分析
   → SEO 用戶的完整轉換路徑（GA4 路徑探索）
   → 哪個環節流失最多？
   → 中間頁面是否需要優化？

☐ 4.4 關鍵字機會發現
   → GSC 查詢報表中，找「曝光高但不在 Top 10」的關鍵字
   → 這些是新內容或內容優化的機會
   → 香港專屬：留意「地區 + 服務」長尾詞嘅機會
     （18 區 × 核心服務）
```

### 下月準備（1 小時）

```
☐ 4.5 規劃下月內容日曆（對齊香港節慶與旺季）
☐ 4.6 設定下月 KPI 目標
   - 有機流量目標（MoM + YoY）
   - 目標關鍵字排名目標
   - 地區關鍵字 / 本地包出現率目標
   - 轉換數目標（HK$ 營收目標）
   - 內容發布數量目標
☐ 4.7 更新 SEO Dashboard（月報版本）
☐ 4.8 準備月報簡報（如果需要向上報告）
☐ 4.9 檢查預算使用狀況（HK$）
```

## 每季額外任務（在月底額外執行）

```
每季一次（3/6/9/12 月）：
☐ 完整技術 SEO 審計（Screaming Frog 全站爬取）
☐ 完整內容審查（Content Audit）：
   → 評估所有內容的表現
   → 決定哪些更新、合併、刪除（Content Pruning）
☐ 競爭對手全面分析：
   → 競品的內容策略變化
   → 競品的連結策略變化
   → 競品的技術更新
   → 競品嘅 GBP / OpenRice 表現
☐ 策略大方向回顧：
   → 目前的策略是否仍然有效？
   → 行業趨勢是否改變？
   → 是否需要調整資源分配？
☐ 香港專屬季度任務：
   → 檢查即將到來嘅旺季（暑假／開學／聖誕／
     農曆新年）內容係咪已經提前部署
   → 檢查所有本地平台資料（NAP）一致性
   → 檢查多語言版本（繁中/英文/簡中）內容同步情況
   → 回顧香港法規變動對內容嘅影響
     （如消委會指引、行業廣告規管更新）
```

| 連結建設 | 1 小時 | 3% |
| 策略規劃 | 1 小時 | 4% |

|----------|-----------|------|
