> SEO 不是一個「做完就沒事」的專案 — 它是一個需要持續維運的系統。這份每月清單讓你不會忘記任何重要的事。

---

## 維運哲學：建立 SEO 節奏

```
每週（戰術層級）
  執行日常優化、內容發布、數據監控

每月（策略層級）
  成效回顧、策略調整、深度審查

每季（戰略層級）
  策略大方向調整、競爭分析、資源規劃
```

---

## 第一週：數據回顧與策略調整

### 上個月成效回顧（2 小時）

```
☐ 1.1 GSC 月報分析
   → 過去 28 天 vs 前 28 天的流量/曝光/CTR/排名變化
   → 過去 28 天 vs 去年同期（YoY 比較）
   → 記錄變化最大的 5 個關鍵字（上升和下降各 5）

☐ 1.2 GA4 有機流量分析
   → 有機流量趨勢（MoM + YoY）
   → 有機轉換數和轉換率
   → 參與率（Engagement Rate）變化
   → 品牌 vs 非品牌流量比例

☐ 1.3 排名追蹤
   → Top 10 關鍵字排名變化
   → 目標關鍵字排名分佈
   → 新進入 Top 10 和掉出 Top 10 的關鍵字

☐ 1.4 目標達成檢視
   → 對比月初設定的目標
   → 達成了哪些？沒達成哪些？
   → 沒達成的根本原因是什麼？
```

### 本月策略設定（1 小時）

```
☐ 1.5 根據上月數據設定本月優先事項
   完成上個月未完成的任務 + 調整方向

☐ 1.6 設定本月內容日曆
   規劃本月要發布的內容（目標關鍵字 + 發布日期）

☐ 1.7 確認本月資源
   寫手產能？開發團隊時間？預算是否有變？
```

## 第二週：內容與 On-Page 優化

### 內容維護（3 小時）

```
☐ 2.1 發布本週計劃的內容（1-2 篇）
   → 確認 SEO Brief 已給寫手
   → 審查完成的文章（SEO 檢查 → 發布）
   → 發布後：手動請求 GSC 索引

☐ 2.2 內容更新（Content Refresh）
   選擇 3-5 篇需要更新的舊文章：
   挑選標準：
   - 排名在 4-15 名之間（努力一下就能進 Top 3）
   - 流量較上月下降 >10%
   - 發布超過 12 個月

   更新內容：
   - 加入最新數據和案例
   - 更新年份標記（如「2026 年」）
   - 補充競爭對手有但你沒有的子主題
   - 更新後修改 lastmod 日期

☐ 2.3 內部連結維護
   → 在新文章中加入 3-5 條指向舊文章的連結
   → 在 3 篇舊文章中插入新文章的連結
   → 檢查導航結構是否需要調整
```

### On-Page 優化（1 小時）

```
☐ 2.4 低垂果實優化
   GSC → 成效 → 篩選平均排名 11-20
   選擇 3-5 個高曝光但排名在第二頁的關鍵字

   優化對應頁面：
   - Title Tag：加入更吸引人的元素
   - 內容：補充更多深度資訊
   - 內部連結：增加來自高權威頁面的連結

☐ 2.5 SERP 檢查
   搜尋你的 Top 5 核心關鍵字
   檢查 SERP 變化：
   - 有沒有新的 AI Overviews？
   - Featured Snippet 被誰拿走了？
   - 競爭對手的排名有沒有變化？
```

## 第三週：技術監控與連結建設

### 技術 SEO 例行檢查（2 小時）

```
☐ 3.1 GSC 索引狀態檢查
   → 索引 → 頁面 → 查看有沒有新增的「未索引」頁面
   → 索引率應保持在 90% 以上
   → 處理新發現的索引問題

☐ 3.2 GSC 體驗報表
   → Core Web Vitals：有沒有新的不良 URL？
   → 行動可用性：有沒有新的問題？

☐ 3.3 Sitemap 狀態
   → 確認 Sitemap 最後讀取日期更新
   → 檢查 Sitemap 錯誤（如有）

☐ 3.4 404 錯誤監控
   → 用 Screaming Frog 爬取網站
   → 檢查是否有新的 404 頁面
   → 對有流量的 404 頁面設定 301 轉址

☐ 3.5 安全性與手動操作
   → GSC 安全性問題檢查
   → GSC 手動操作檢查
   （幾秒鐘的事，不要跳過）
```

### 連結建設（2 小時）

```
☐ 3.6 反向連結健康檢查
   → Ahrefs/SEMrush 查看新增和失去的連結
   → 有沒有可疑的新連結？（DR<5、不相關網站）
   → 重要連結是否還在？

☐ 3.7 連結建設任務
   每月至少完成以下之一：
   → 撰寫 1 篇 Guest Post 並發布
   → 找到 3 個 Broken Link 機會並 outreach
   → 發布 1 份值得被引用的原創內容（研究報告/數據/工具）
   → 在 1-2 個行業媒體獲得品牌提及

☐ 3.8 競爭對手連結監控
   → 查看主要競品的新增連結
   → 有沒有你可以複製的連結機會？
```

## 第四週：分析深化與下月準備

### 深度分析（2 小時）

```
☐ 4.1 內容成效分析
   → 本月發布的內容表現（有流量了嗎？有排名嗎？）
   → 找出本月表現最佳的內容（為什麼？可以複製嗎？）
   → 找出本月表現最差的內容（需要改進或刪除？）

☐ 4.2 用戶行為分析
   → GA4 著陸頁報表：Top 10 著陸頁的參與率和轉換率
   → 高流量低轉換的頁面 → 需要 CRO 優化
   → 低流量高轉換的頁面 → 需要更多曝光

☐ 4.3 轉換漏斗分析
   → SEO 用戶的完整轉換路徑（GA4 路徑探索）
   → 哪個環節流失最多？
   → 中間頁面是否需要優化？

☐ 4.4 關鍵字機會發現
   → GSC 查詢報表中，找「曝光高但不在 Top 10」的關鍵字
   → 這些是新內容或內容優化的機會
```

### 下月準備（1 小時）

```
☐ 4.5 規劃下月內容日曆
☐ 4.6 設定下月 KPI 目標
   - 有機流量目標（MoM + YoY）
   - 目標關鍵字排名目標
   - 轉換數目標
   - 內容發布數量目標
☐ 4.7 更新 SEO Dashboard（月報版本）
☐ 4.8 準備月報簡報（如果需要向上報告）
```

## 每季額外任務（在月底額外執行）

```
每季一次（3/6/9/12 月）：
☐ 完整技術 SEO 審計（Screaming Frog 全站爬取）
☐ 完整內容審查（Content Audit）：
   → 評估所有內容的表現
   → 決定哪些更新、合併、刪除（Content Pruning）
☐ 競爭對手全面分析：
   → 競品的內容策略變化
   → 競品的連結策略變化
   → 競品的技術更新
☐ 策略大方向回顧：
   → 目前的策略是否仍然有效？
   → 行業趨勢是否改變？
   → 是否需要調整資源分配？
```

| On-Page 優化 | 4 小時 | 13% |

| 任務類別 | 月花費時間 | 比例 |
|----------|-----------|------|
| 內容創作與更新 | 25 小時 | 36% |
